# 2次元 非定常 熱伝導シミュレーター — 拡散方程式の時間発展可視化

2次元非定常熱伝導シミュレーター「NovaSolver」は、熱伝導方程式の数値解析をリアルタイムで体験できるCAE教育ツールです。自由に境界条件や初期条件を設定し、クリックで熱源を追加。熱の広がりを疑似カラーアニメーションで直感的に可視化し、非定常熱伝導の理解を深めます。

**Category:** 構造解析

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/heat-equation-2d.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/heat-equation-2d.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/heat-equation-2d.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/heat-equation-2d
python -m http.server 8000
# open http://localhost:8000
```
