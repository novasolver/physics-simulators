# 土壌液状化ポテンシャルシミュレーター

土壌液状化のリスクを無料で簡単シミュレーション。NovaSolverのオンライン計算機で、SPT N値や深度プロファイルを入力するだけで、Seed-Idriss法に基づく液状化判定と安全率（FS）をリアルタイムに計算・可視化します。地盤の安全性を迅速に評価できるツールです。

**Category:** 地盤工学

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/soil-liquefaction
python -m http.server 8000
# open http://localhost:8000
```
