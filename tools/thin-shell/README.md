# 薄肉圧力容器応力計算ツール

薄肉圧力容器の応力計算を支援するツールです。円筒および球形の容器について、フープ応力、軸応力、Von Mises相当応力を簡単に計算できます。安全率の確認や必要最小板厚の即時評価が可能で、設計初期段階からの効率的な強度検討をサポートします。

**Category:** 構造解析
