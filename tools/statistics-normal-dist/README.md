# 正規分布・統計計算ツール

正規分布・統計計算ツール：平均・標準偏差をリアルタイム操作してPDF・CDF・信頼区間を計算。z得点や68-95-99.7ルールで分布を直感的に理解。統計解析・品質管理向け。

**Category:** 統計学・確率論

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/statistics-normal-dist
python -m http.server 8000
# open http://localhost:8000
```
