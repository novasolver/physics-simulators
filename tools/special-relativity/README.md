# 特殊相対性理論シミュレーター

特殊相対性理論の効果を無料でシミュレーション。速度を変えると、時間の遅れ（時間膨張）や長さの縮み（長さ収縮）、ローレンツ因子をリアルタイム計算。ミンコフスキー図や運動エネルギーも視覚的に理解できるオンライン計算機です。光速に近い世界を直感的に学べます。

**Category:** 物理シミュレーター

python -m http.server 8000
