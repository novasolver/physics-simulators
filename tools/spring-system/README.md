# バネ・ダンパー系の静的・動的解析

NovaSolverのバネ・ダンパー系解析シミュレーターは、直列・並列・混合モデルの静的たわみと動的ステップ応答を無料で計算できるオンライン計算機です。等価剛性・固有振動数・減衰比をリアルタイム表示し、直感的なグラフで振動挙動を視覚的に解析できます。設計や学習に最適なツールです。

**Category:** 振動・波動

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/spring-system
python -m http.server 8000
# open http://localhost:8000
```
