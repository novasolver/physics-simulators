# 球面収差シミュレーター — 軸光線と辺縁光線の焦点差

平凸球面レンズで光線高さ h に応じて焦点位置がずれる球面収差を、3次収差式で可視化。曲率半径・屈折率・入射高をスライダーで変えながら、軸上球差と焦点ぼけの仕組みを学べます。

**Category:** 光学シミュレーター
