# プラズマシミュレーター

プラズマシミュレーター「NovaSolver」は、荷電粒子のローレンツ力とサイクロトロン運動をリアルタイムで可視化する学習ツールです。E×Bドリフトやプラズマ振動をシミュレーションでき、電磁気CAEや核融合工学の基礎理解に最適です。直感的な操作で高度な物理現象を学べます。

**Category:** 電磁気・プラズマ

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/plasma-sim.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/plasma-sim.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/plasma-sim.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/plasma-sim
python -m http.server 8000
# open http://localhost:8000
```
