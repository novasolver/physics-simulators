# スペクトラム拡散の処理利得シミュレーター

直接拡散方式（DSSS）の通信リンクを設計するツールです。チップレートとデータレートを変えると、処理利得・占有帯域幅・ジャミングマージンがリアルタイムで分かり、妨害波の下でも通信が成立する条件を探せます。

**Category:** 電気・通信

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/spread-spectrum-processing-gain.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/spread-spectrum-processing-gain.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/spread-spectrum-processing-gain.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/spread-spectrum-processing-gain
python -m http.server 8000
# open http://localhost:8000
```
