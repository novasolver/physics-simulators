# カム機構シミュレーター

カム機構シミュレーターで、フォロワーの変位・速度・加速度をリアルタイムに可視化。SHM、サイクロイダル、多項式カムプロファイルの動きと圧力角を計算・比較し、CAE設計に役立つカム理論を学べます。NovaSolverの直感的ツールで設計を効率化。

**Category:** 機構設計

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/cam-mechanism
python -m http.server 8000
# open http://localhost:8000
```
