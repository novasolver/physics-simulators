# ピトー管 流速測定シミュレーター

ピトー管は、全圧と静圧の差（差圧）から流れの速さを測る計器です。差圧・流体・ダクト径を変えると、ベルヌーイの式による流速、体積流量、レイノルズ数がリアルタイムで分かり、流量測定の原理を直感的に学べます。

**Category:** 流体力学
