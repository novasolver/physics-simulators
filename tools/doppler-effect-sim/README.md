# ドップラー効果シミュレーター

ドップラー効果シミュレーターで、動く音源による音波の圧縮や超音速時の衝撃波（マッハ円錐）をリアルタイムアニメーションで可視化。マッハ数や観測周波数を即時計算できるCAE音響シミュレーションで、物理現象を直感的に学べます。

**Category:** 波動・音響

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/doppler-effect-sim.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/doppler-effect-sim.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/doppler-effect-sim.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/doppler-effect-sim
python -m http.server 8000
# open http://localhost:8000
```
