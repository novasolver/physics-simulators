# プラントル・グラウェルト 圧縮性補正 シミュレーター — 亜音速空気力学

プラントル・グラウェルトの補正則で、亜音速マッハ数における翼面の圧力係数 C_p・揚力係数 C_L の増加をリアルタイムで可視化。非圧縮性値・マッハ数・比熱比を変えて、補正係数や全圧/静圧比の変化を学べます。

**Category:** 空気力学シミュレーター
