# 窓の日射熱取得（SHGC）シミュレーター

窓ガラスから室内に入る熱を計算するツールです。ガラスの種類・窓面積・日射強度・遮蔽を変えると、太陽から入る日射熱と内外温度差で伝わる貫流熱、そして夏の冷房負荷への影響がリアルタイムで分かります。

**Category:** 建築環境

git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/solar-heat-gain-window
python -m http.server 8000
# open http://localhost:8000
