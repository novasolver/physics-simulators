# ADC サンプリングジッタと SNR 劣化シミュレーター

ADC サンプリングジッタが SNR に与える影響をシミュレーションで検証。波形・SNR曲線・誤差分析により、高周波入力でのジッタ劣化を定量評価。ジッタ解析・信号品質評価に最適。

**Category:** 対話型シミュレーター
