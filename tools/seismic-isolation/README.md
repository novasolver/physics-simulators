# 免震構造解析ツール

建物質量・免震剛性・減衰比・地盤種別を変えながら固有周期・変位・加速度低減率をリアルタイムで計算。設計応答スペクトルと免震周期を重ねて表示します。

**Category:** 構造・耐震工学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/seismic-isolation.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/seismic-isolation.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/seismic-isolation.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/seismic-isolation
python -m http.server 8000
# open http://localhost:8000
```
