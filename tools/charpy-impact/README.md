# charpy-impact

CVN衝撃エネルギー対温度曲線（tanh近似）をリアルタイム描画。DBTT・USE・LSEのパラメータ調整、照射脆化シフト、溶接HAZ曲線を可視化。

**Category:** 解析ツール

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/charpy-impact.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/charpy-impact.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/charpy-impact.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/charpy-impact
python -m http.server 8000
# open http://localhost:8000
```
