# 蒸留塔設計ツール — McCabe-Thiele法

McCabe-Thiele法による蒸留塔の理論段数計算ツールです。エタノール-水系を例に、供給液組成や還流比を自由に調整し、y-x線図の変化をリアルタイムで可視化。最小還流比も即座に算出できる直感的なシミュレーターで、蒸留塔設計の理解と効率化を支援します。

**Category:** 化学工学
