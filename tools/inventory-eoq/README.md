# 在庫管理・経済的発注量（EOQ）計算機

年間需要・発注コスト・保有コストを入力してEOQを自動計算。在庫推移グラフとコストトレードオフ曲線をリアルタイム可視化し、再発注点・安全在庫も算出します。

**Category:** オペレーションズリサーチ

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/inventory-eoq.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/inventory-eoq.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/inventory-eoq.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/inventory-eoq
python -m http.server 8000
# open http://localhost:8000
```
