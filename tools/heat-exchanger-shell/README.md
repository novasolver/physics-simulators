# シェルアンドチューブ熱交換器

シェルアンドチューブ熱交換器の設計計算ツール。流量・温度・伝熱係数Uを変動させながらLMTD・F補正係数・伝熱面積・NTU・有効度をリアルタイム算出。熱交換量と温度プロファイルを可視化。

**Category:** 熱工学
