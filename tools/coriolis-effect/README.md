# コリオリ力シミュレーター — 回転系と台風

コリオリ力シミュレーターで、地球の自転が生む台風の渦やフーコー振り子の原理を視覚的に理解しよう。回転系と慣性系を並べて比較できるシミュレーションで、コリオリ力の影響を直感的に学べます。NovaSolverの教材で、流体力学や気象学の理解を深めましょう。

**Category:** 地球物理・流体力学
