気液平衡シミュレーター — ラウールの法則

二成分の理想混合物が液体と蒸気で平衡したとき、それぞれの相の組成と温度はどう決まるのか。ラウールの法則とアントワン式から、沸点・露点・平衡組成・比揮発度をリアルタイムに計算し、蒸留がなぜ成分を分けられるのかをT-x-y線図とy-x平衡線図で直感的に確かめられるツールです。

理論・主要公式

$$p_i=x_i\,P_i^{sat}(T),\qquad \sum_i x_i P_i^{sat}=P\ \ (\text{沸点})$$

ラウールの法則。各成分の分圧 p_i は液相モル分率 x_i と純成分蒸気圧 P_i^sat の積。分圧の和が全圧に達する温度が沸点（バブルポイント）。

$$\log_{10}P^{sat}=A-\frac{B}{C+T},\qquad y_1=\frac{x_1 P_1^{sat}}{P}$$

純成分蒸気圧はアントワン式で温度の関数として求める（T:℃、P^sat:mmHg、定数A・B・Cは成分固有）。平衡蒸気組成 y₁ はラウールの法則から直接得られる。

$$\alpha=\frac{P_1^{sat}}{P_2^{sat}}$$

比揮発度 α は軽質・重質成分の蒸気圧の比。蒸気は常に揮発しやすい成分（軽質成分）に富み、αが1から離れるほど蒸留での分離が容易になる。

気液平衡とラウールの法則とは

🙋
「気液平衡」って言葉、化学工学でよく出てきますけど…要するに液体と蒸気が混ざって落ち着いた状態のことですか？
🎓
そう、その理解で大丈夫。閉じた容器にベンゼンとトルエンの混合液を入れて温度を一定に保つと、液面の上に蒸気がたまる。蒸発と凝縮の速さがちょうど釣り合って、液も蒸気も組成が変わらなくなった状態、それが気液平衡だ。問題は「液が50:50のとき、上の蒸気は何対何になるのか」「何度で沸き始めるのか」。これに答えるのがラウールの法則なんだ。
🙋
ラウールの法則って、p = x·P みたいな式でしたっけ。あれ、何を言ってるんですか？
🎓
ざっくり言うと「各成分が出す蒸気の圧力（分圧）は、その成分が液の中にどれだけいるか（モル分率 x）と、その成分が単独で純液体だったときの蒸気圧 P^sat の掛け算で決まる」ということ。p_i = x_i·P_i^sat だね。ベンゼンが液の半分を占めるなら、ベンゼンの分圧は純ベンゼンの蒸気圧の半分。全圧はベンゼンとトルエンの分圧の合計。理想混合物ならこれだけで気液平衡が解けるんだ。
🙋
純成分の蒸気圧 P^sat って温度で変わりますよね。それはどうやって出すんですか？
🎓
そこでアントワン式の出番だ。log₁₀P^sat = A − B/(C+T) という形で、A・B・Cは成分ごとに実験から決まった定数。温度Tを入れれば純成分の蒸気圧が出る。本ツールはこれを使って、「液相組成 x₁ を固定したとき、Σx_i·P_i^sat = P を満たす温度Tはどこか」を二分法で探している。その温度が沸点、バブルポイントだよ。スライダーで x₁ を動かすと、沸点がベンゼンの沸点80℃とトルエンの110℃の間でなめらかに動くのが見える。
🙋
なるほど。それで、平衡の蒸気はなぜいつも軽い成分のほうに偏るんですか？結果カードを見ると y₁ がいつも x₁ より大きいです。
🎓
いい質問。軽質成分（ここではベンゼン）は同じ温度でトルエンより蒸気圧が高い。だから y₁ = x₁·P1^sat/P の P1^sat が大きく、y₁ は x₁ より持ち上がる。つまり蒸気は必ず「揮発しやすいほう」に富む。これがまさに蒸留の心臓部だ。一度気化させて凝縮させるだけでベンゼンが濃くなる。それを段ごとに何回も繰り返せば、50:50の原料から99%のベンゼンが取れる。下のy-x平衡線図で、平衡曲線が対角線 y=x よりずっと上にあるのが、その「ひと気化ぶんの濃縮」を表しているんだ。
🙋
比揮発度 α っていう数字も出ますよね。あれは何の役に立つんですか？
🎓
α は分離の「しやすさメーター」だと思えばいい。α = P1^sat/P2^sat、つまり2成分の蒸気圧の比だ。αが2や3なら平衡曲線が対角線から大きく膨らんで、少ない段数で分離できる。αが1.1くらいだと曲線が対角線にぴったり張り付いて、分離に何十段も必要になる。実務では「αが1.05を切るような系は普通の蒸留では無理。抽出蒸留や別の方法を考える」と判断する。αがちょうど1になると共沸点で、単純な蒸留では決して純粋にできない。系を切り替えて、αがどう変わるか試してみるといいよ。

よくある質問

ラウールの法則は、理想溶液において各成分の分圧 p_i が、その成分の液相モル分率 x_i と、純液体としての蒸気圧 P_i^sat の積に等しいとする法則です（p_i = x_i·P_i^sat）。全圧 P は各成分の分圧の和になります。本ツールはアントワン式で純成分蒸気圧を温度の関数として求め、ベンゼン-トルエンのような分子構造が似た混合物について、沸点・露点・平衡組成を計算します。化学的に似た成分どうしの混合物では、この単純な理想モデルが実用十分な精度を与えます。
沸点（バブルポイント）は、ある組成の液体を加熱したとき最初の泡が発生する温度で、各成分の分圧の和がちょうど全圧に達する条件 Σx_i·P_i^sat = P で決まります。露点（デューポイント）は、ある組成の蒸気を冷却したとき最初の液滴が現れる温度で、Σy_i/P_i^sat = 1/P で決まります。同じ全圧でも、液相組成と蒸気相組成が同じでない限り沸点と露点は一致しません。T-x-y線図では下側の曲線が沸点、上側が露点で、その間が気液二相の共存領域です。
比揮発度 α は軽質成分と重質成分の純成分蒸気圧の比 α = P1^sat/P2^sat で、蒸留による分離のしやすさを表します。αが1から離れるほど、平衡蒸気は液体より軽質成分に大きく富み、1段の気化・凝縮で組成が大きく変わるため、少ない段数で高純度に分離できます。逆にαが1に近い混合物（沸点の近い成分どうし）は分離が難しく、蒸留塔の段数や還流比を大きくする必要があります。αがちょうど1になる共沸点では、単純な蒸留では分離できません。
軽質成分は同じ温度で重質成分より高い純成分蒸気圧をもちます。ラウールの法則では平衡蒸気組成は y_1 = x_1·P1^sat/P で与えられ、P1^sat が大きいほど y_1 は x_1 より大きくなります。つまり気相は必ず揮発しやすい成分に富むのです。この「気化のたびに軽質成分が濃縮される」現象こそ蒸留の原理で、気化と凝縮を段ごとに繰り返すことで、原料よりずっと高純度の留出液が得られます。本ツールのy-x平衡線図で、平衡曲線が対角線 y=x より常に上にあることがこの濃縮を表しています。

実世界での応用

蒸留塔の設計：石油精製や石油化学プラントの蒸留塔は、気液平衡の計算なしには設計できません。原油を軽質ナフサ・灯油・軽油などに分けるのも、ベンゼンとトルエンを分離するのも、原理は本ツールと同じ「気化のたびに軽質成分が濃縮される」現象の積み重ねです。設計では各段の気液平衡を解いて、必要な理論段数と還流比を決めます。比揮発度αが分離の難易度を直接決めるため、設計の初期検討でまずαを確認します。

溶剤の回収・精製：塗装・印刷・半導体製造などで使われた溶剤を回収・再利用する工程でも、蒸留による精製が広く使われます。トルエンやヘキサンのような炭化水素溶剤は化学的に似た成分との混合物になりやすく、理想に近い気液平衡を示すため、ラウールの法則ベースの計算が有効です。回収率と純度の目標から、塔の運転条件をこの種の平衡計算で決めます。

プロセスシミュレーターの基礎：Aspen PlusやPro/IIといった商用プロセスシミュレーターは、内部で膨大な気液平衡計算を繰り返しています。理想溶液ではラウールの法則、非理想系では活量係数モデル（NRTL、UNIQUACなど）や状態方程式を使い分けます。本ツールが扱う理想モデルは、こうした高度なモデルを理解する出発点であり、シミュレーション結果が妥当かを概算で確認するサニティチェックにも使えます。

教育・概念理解：化学工学を学ぶうえで、T-x-y線図とy-x平衡線図を「読める」ことは基礎中の基礎です。沸点曲線と露点曲線がつくる二相領域、タイラインによる液と蒸気の組成の読み取り、平衡曲線と対角線の隔たりが分離能を表すこと——これらを数式だけでなく図で体感することが、後のマッケーブ・シール法による段数決定や蒸留塔設計の理解につながります。

よくある誤解と注意点

まず最大の注意点が、「ラウールの法則はすべての混合物に使える」と思い込むことです。ラウールの法則は理想溶液、すなわち分子の大きさや種類が似ていて、異種分子間の相互作用が同種分子間とほぼ等しい混合物でのみ成り立ちます。本ツールが扱うベンゼン-トルエンやペンタン-ヘキサンはまさに理想に近い系ですが、エタノール-水のように水素結合が絡む系では理想からの大きなずれが生じ、共沸（αが1になり蒸留で分離できなくなる点）が現れます。非理想系では活量係数 γ を導入した修正ラウールの法則 p_i = γ_i·x_i·P_i^sat が必要で、本ツールの結果をそのまま当てはめることはできません。

次に、「沸点と露点を混同する」こと。同じ組成の数値でも、それを液相組成 x₁ と読むか蒸気相組成 y₁ と読むかで、求まる温度はまったく違います。x₁=0.5 の液を加熱して泡が出る温度（沸点）と、y₁=0.5 の蒸気を冷却して露がつく温度（露点）は別物です。本ツールが沸点用と露点用に別々の入力スライダー（x₁ と y₁）を用意しているのはこのためです。T-x-y線図でも、下側の曲線（沸点）は液相組成の横軸で、上側の曲線（露点）は蒸気相組成の横軸で読む、という使い分けを忘れないでください。

最後に、「全圧を上げれば必ず分離しやすくなる」わけではないという点。圧力を変えると沸点・露点の温度は当然変わりますが、比揮発度αも温度依存性を通じて変化します。一般に圧力（したがって温度）を上げるとαは1に近づき、分離はむしろ難しくなる傾向があります。一方で減圧蒸留は、熱に弱い物質を低温で扱えるうえ、αを稼げる利点があります。圧力の選択は、分離のしやすさ・運転温度・装置コスト・冷却水や熱源の都合を総合して決めるもので、本ツールで全圧Pを動かしながらαの変化を観察すると、その感度をつかめます。

使い方ガイド

  1. 液相組成 x₁ (0～1) をスライダーで設定し、全圧 (20～300 kPa) を入力します
  2. 入力を変更すると自動で、ラウールの法則 P = x₁P₁ᵛᵃᵖ + (1-x₁)P₂ᵛᵃᵖ に基づきバブルポイント T_b が算出されます
  3. 蒸気組成 y₁ = x₁P₁ᵛᵃᵖ / P_total から平衡蒸気組成が自動計算され、T-x-y線図上に気液平衡曲線がプロットされます
  4. 蒸気組成 y₁ から逆算して露点 T_d と平衡液組成 x₁ を求め、比揮発度 α = (y₁/y₂)/(x₁/x₂) を表示します

具体的な計算例

ベンゼン-トルエン混合液（常圧 101 kPa）で x₁(ベンゼン) = 0.4 の場合：二分法でバブルポイント T_b ≈ 95.0℃ が求まり、その温度でアントワン式より P₁ᵛᵃᵖ ≈ 157 kPa、P₂ᵛᵃᵖ ≈ 64 kPa と計算されます。平衡蒸気組成は y₁ = 0.4×157/101 ≈ 0.622 となり、比揮発度 α ≈ 2.47、液相と蒸気の濃度差 y₁ − x₁ ≈ 0.222 から分離のしやすさが評価できます。

実務での注意点

  • アントワン係数はデータベース値（例：ベンゼン A=6.90565, B=1211.033, C=220.79）を使用し、外挿温度範囲（通常20～200℃）を超えると精度低下が著しくなります
  • 非理想混合系（エタノール-水など）ではラウール法則が適用不可のため、活量係数モデル（NRTL、Wilson式）への切替が必須です
  • 蒸留塔設計時には y₁ - x₁ の値が大きいほど理論段数が少なくなり、コスト削減につながりますが、相対揮発度 α が1に近い場合は段数が急増します
