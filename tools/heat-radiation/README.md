# 黒体放射シミュレーター — プランク分布とシュテファン-ボルツマン則

黒体放射シミュレーターで温度変化のプランク分布をリアルタイム可視化。ウィーンのピーク波長やシュテファン-ボルツマン則による放射パワーを計算・比較できます。

**Category:** 熱放射・熱解析

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/heat-radiation
python -m http.server 8000
# open http://localhost:8000
```
