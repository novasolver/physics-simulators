# 複合材料 積層板解析（CLT・ABDマトリクス）

古典積層理論（CLT）に基づき、複合材料積層板のABDマトリクス・等価弾性係数・繊維角依存剛性・積層別失敗指数をリアルタイム計算する手法を解説。Aij、Bij、Dijの定式化と有効ヤング率Exの算出式を通じ、積層設計の基礎を学べます。

**Category:** 複合材料解析ツール
