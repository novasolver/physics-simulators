# LED設計・熱解析シミュレーター

壁面電力効率（WPE）・ジャンクション温度・光束・ビン選択をリアルタイム計算。駆動電流-効率カーブで最適動作点を即座に特定。光学設計と熱設計を統合した実務向けLEDエンジニアリングツール。

**Category:** 解析ツール

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/led-design.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/led-design.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/led-design.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/led-design
python -m http.server 8000
# open http://localhost:8000
```
