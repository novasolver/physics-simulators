梁モデル・SFD・BMD

上＝梁と荷重（青矢印＝集中荷重・水色矢印群＝等分布荷重・三角＝支点）／中＝SFD V(x)／下＝BMD M(x)、赤マーカー＝M_max 位置

理論・主要公式

両端単純支持梁（長さ L）に、位置 a の集中荷重 P・全長の等分布荷重 w・位置 b の外力モーメント M_0 が作用するとき、釣合から反力が決まり、断面ごとに V(x) と M(x) が定まります。

力とモーメントの釣合から右支点反力 R_B、左支点反力 R_A：

$$R_B = \frac{P\,a + w\,L^2/2 + M_0}{L},\qquad R_A = P + w\,L - R_B$$

せん断力 V(x)。H(·) はヘビサイドの階段関数：

$$V(x) = R_A - w\,x - P\,H(x-a)$$

曲げモーメント M(x)：

$$M(x) = R_A\,x - \frac{w\,x^2}{2} - P\,(x-a)\,H(x-a) + M_0\,H(x-b)$$

M(x) の極値は dM/dx = V(x) = 0 の位置に現れ、その点が設計上もっとも応力が大きくなる断面です。

SFD・BMD シミュレーターとは

🙋
先生、SFD と BMD って構造系の授業で必ず出てくるんですけど、いまいち「で、何の役に立つの？」がわかってないんです。
🎓
ざっくり言うと、SFD は梁を「縦に断ち切ろうとする力」の地図、BMD は梁を「グニャッと曲げようとする力」の地図だ。設計者はこの BMD の最大値を見て、「ここに一番大きな曲げ応力が出るから、ここで折れないように断面を決めよう」と判断する。シミュレーターで P や w を動かすと、BMD の山がどう動くか観察できる。
🙋
SFD と BMD の関係って何でしたっけ？ 似てるようで違う図ですよね。
🎓
関係はとてもシンプルで dM/dx = V(x)、つまり BMD の傾きが SFD の値なんだ。だから SFD が 0 を横切るところで BMD は山か谷の頂点になる。初期値（L=6, P=30, a=2.5, w=10）で SFD を見てごらん。x=a=2.5 のところで V が +22.5 から −7.5 へジャンプしている。この符号反転点で BMD が頂上 M_max=87.5 kN·m に達する。教科書通りの結果だ。
🙋
あ、本当だ。じゃあ集中荷重を 0 にして等分布だけにしたら、頂点はどこに来るんですか？
🎓
やってみよう。P=0、w=10、L=6 にすると、R_A=R_B=30 kN で対称、SFD は左端 +30 から直線で減って中央で 0、右端 −30。BMD は中央 x=3 で最大、値は wL²/8 = 10·36/8 = 45 kN·m。教科書の「等分布荷重を受ける単純梁の最大モーメント wL²/8」がそのまま出てくる。シミュレーターの数値と手計算が一致することを必ず確認してから、複合荷重に進むのが王道だよ。
🙋
なるほど！じゃあ a の位置を動かして P を中央に持っていったら、BMD の三角形が中央でピークになるはずですよね？
🎓
その通り。a=L/2 だと PL/4 が集中荷重単独の最大モーメントになる。複合荷重では、集中分の三角形ピーク（x=a）と分布分の放物線ピーク（x=L/2）が重なり合った形になる。BMD の山頂が、a を端へ寄せると集中荷重側に、a を中央に寄せると中央付近に動くのを観察してみよう。これが「最大応力位置がどこに出るか」を予測する直感を養う一番の練習になる。

SFD・BMDの覚えておくべき5つの特徴

せん断力図（SFD）と曲げモーメント図（BMD）は、次の5つの性質を押さえると手早く正確に描け、検算もできます。

  1. 微分関係：せん断力は曲げモーメントの傾きに等しく、$V = dM/dx$ が成り立ちます。BMDを微分するとSFDになります。
  2. 極値条件：せん断力が0になる位置で曲げモーメントが極値（最大）になります。$M_{max}$ を探すときは $V=0$ の点に注目します。
  3. 集中荷重の段差：集中荷重の作用点でSFDは荷重の大きさだけ段差（ジャンプ）し、BMDはその点で折れ曲がります（尖る）。
  4. 荷重次数と図の形：荷重のない区間はSFDが一定・BMDが直線、等分布荷重の区間はSFDが直線（1次）・BMDが2次曲線（放物線）です。荷重の次数より1つずつ次数が上がります。
  5. 境界での値：単純支持の支点と自由端では曲げモーメント＝0、片持ち梁の固定端では曲げモーメントが最大（ホギング）になります。上のシミュレーターで「支持条件」を切り替え、この違いを確認できます。

SFD・BMDの描き方（5ステップ）

  1. 反力を求める：鉛直方向とモーメントの釣合い（$\sum V = 0$, $\sum M = 0$）から支点反力 $R_A, R_B$（片持ちは固定端反力と固定端モーメント）を計算します。
  2. 区間を分ける：集中荷重の位置、分布荷重の始端・終端、支点を境に梁をいくつかの区間に分けます。
  3. せん断力を求める：各区間で左端から任意位置 $x$ で切断し、左側部分の鉛直釣合いから $V(x)$ を求めてSFDを描きます。
  4. 曲げモーメントを求める：同じ切断面まわりのモーメント釣合いから $M(x)$ を求めてBMDを描きます。$M(x)=\int V\,dx$ の関係も使えます。
  5. 検算する：$V=0$ の位置で $M$ が極値になること、支点・自由端で $M=0$ になることを確認します。

このツールは上の手順を自動化したものです。手計算の答え合わせや、荷重・スパンを変えたときの図形の変化を直感的に確認するのに使えます。

反力・せん断力・曲げモーメントの公式一覧

代表的な梁と荷重に対する反力・最大せん断力・最大曲げモーメントの公式です（$P$＝集中荷重、$w$＝等分布荷重強度、$L$＝スパン）。

梁・荷重反力最大せん断力 Vmax最大曲げモーメント Mmax
単純梁・中央集中荷重$R_A=R_B=P/2$$P/2$$PL/4$（中央）
単純梁・等分布荷重$R_A=R_B=wL/2$$wL/2$（支点）$wL^2/8$（中央）
片持ち梁・先端集中荷重$R=P,\ M_A=PL$$P$$PL$（固定端）
片持ち梁・等分布荷重$R=wL,\ M_A=wL^2/2$$wL$（固定端）$wL^2/2$（固定端）

単純梁は曲げモーメントが中央（径間内）で最大になるのに対し、片持ち梁は固定端で最大になるのが大きな違いです。同じ荷重なら片持ち梁のほうが最大モーメントが大きく、不利になります。

よくある質問

下向き荷重を正、上向き反力を正としています。せん断力 V(x) は断面の左側に上向きの合力が残るときを正、曲げモーメント M(x) は梁を下に凸に曲げる向きを正としています（いわゆる「サギング」を正）。BMD のグラフが正側に膨らんでいるとき、梁の下側に引張、上側に圧縮の応力が生じている状態です。設計の符号規約は教科書や規格で異なることがあるため、計算結果を他資料と照合する際は規約の整合に注意してください。
集中荷重 P は「点」に集中した力なので、その位置で SFD は瞬時に P だけ段差を生じます。BMD は SFD の積分なので、SFD が階段状に飛んだ位置では BMD は連続ですが、傾きが急変します。つまり折れ点（折線）になります。逆に外力モーメント M_0 が作用する点では、BMD が M_0 だけジャンプし SFD は連続です。実構造では完全な「点荷重」は理想化で、実際には荷重は微小領域に分布しています。
はい、教科書レベルの手計算で完全に追えます。釣合から R_B = (30·2.5 + 10·6²/2)/6 = (75 + 180)/6 = 42.5 kN、R_A = 30 + 60 − 42.5 = 47.5 kN。せん断力は V(0+) = 47.5、V(2.5−) = 47.5 − 25 = 22.5、V(2.5+) = 22.5 − 30 = −7.5、V(6−) = −7.5 − 35 = −42.5、最後に R_B が加わって V(6) = 0 で釣合います。最大モーメントは V が符号を変える x = a = 2.5 で、M = 47.5·2.5 − 10·2.5²/2 = 118.75 − 31.25 = 87.5 kN·m。シミュレーターの数値（R_A=47.5, R_B=42.5, M_max=87.5, x=2.50）と完全一致するはずです。
最大曲げモーメント M_max が得られたら、曲げ応力は σ = M_max·c / I で計算します。ここで I は断面二次モーメント、c は中立軸から断面の最外縁までの距離です。矩形断面（幅 b・高さ h）なら I = bh³/12、c = h/2 で、断面係数 Z = I/c = bh²/6 を使うと σ = M_max/Z と簡潔に書けます。既定値の M_max = 87.5 kN·m を、例えば H 形鋼 H-300×150（Z ≈ 4.81×10⁻⁴ m³）で受けると σ ≈ 182 MPa。SS400 の許容応力 160 MPa を超えるため、断面アップか部材変更が必要、と判断できます。

実世界での応用

梁部材の断面選定：鉄骨造の梁や木造の根太を設計するとき、まず SFD・BMD で最大せん断力 V_max と最大モーメント M_max を求め、それから許容応力（曲げ・せん断）を満たす最小断面を逆算します。H 形鋼の鋼材表から断面係数 Z と断面二次モーメント I を選び、σ = M_max/Z ≤ σ_allow と τ = V_max/A_w ≤ τ_allow（A_w はウェブ断面積）の両方が満たされる断面を採用します。

クレーンガーダ・橋桁の検討：クレーンの主桁では、走行する集中荷重（吊り荷を含む台車重量）を様々な位置に置いて BMD を作り、各位置の M_max の包絡線（影響線）を取ります。設計値は単一位置の M_max ではなく、可動荷重が全位置を通過した際の最大値で決まります。本シミュレーターで a スライダーを動かすことは、影響線解析の一歩目に相当します。

機械設計のサニティチェック：FEM 解析で複雑な梁構造を解く前後に、その一部を単純な梁モデルに簡略化して理論解と比較します。FEM 結果の最大曲げ応力が理論解と桁オーダーで合わなければ、メッシュ品質や境界条件の設定ミスを疑います。本ツールは現場のサニティチェックに使える簡易電卓として機能します。

教育・授業教材：「せん断力 → 曲げモーメント」の積分関係や「dM/dx = V」を、グラフを動かしながら体感するのは、紙の教科書だけでは難しい部分です。本ツールで荷重を順番に追加（w だけ→P を加える→a を動かす）すると、SFD と BMD がどう変化するかが連続的に見えるため、構造力学の入口教材として有効です。

よくある誤解と注意点

最も多い誤解は、「最大曲げモーメントは荷重の真下に出る」と決め込んでしまうことです。これは「単純梁＋中央集中荷重」だけの話で、複合荷重では最大位置は荷重位置とずれます。例えば一端に近い集中荷重と全長分布荷重が同時にかかる場合、最大モーメントは集中荷重の位置にも、梁の中央にも、その中間にも現れ得ます。本シミュレーターは V(x)=0 となる点を 401 点で離散探索し、さらに集中荷重点を別途評価することで、この位置を正確に求めています。a スライダーを動かしながら M_max 発生位置がどう変化するかを観察するのが、一番確実な学習法です。

次に多いのが、「SFD と BMD は別物だから別々に求める」と思い込むことです。両者は dM/dx = V(x) という積分・微分関係で結ばれた一つのペアです。SFD のグラフ面積が BMD の差分になり、SFD の符号反転位置が BMD の極値位置になります。手計算で BMD を求めるときも、まず反力から SFD を描き、その面積を順次積算して BMD を作るのが定石です。シミュレーターの SFD と BMD のグラフを上下に並べたとき、SFD が 0 を横切る位置で BMD のラインが平坦（接線が水平）になっていることを目視で確認してください。これが理論の整合チェックになります。

最後に、「両端単純支持＝両端ヒンジ」と「両端固定」の区別を曖昧にしないことです。本シミュレーターは両端単純支持（左ピン、右ローラー）を仮定しています。両端固定梁では端部に固定モーメントが発生し、最大曲げモーメントは固定端側に移動します。同じ荷重でも、両端固定にすると中央のモーメントは単純支持の 1/3 程度に下がりますが、端部に最大値が現れます。境界条件は構造設計で最も基本的かつ重要な仮定なので、現物の支持状態が「単純支持に近いのか固定に近いのか」を慎重に判断する必要があります。

準拠規格・前提条件

準拠/参考： 梁の静力学（オイラー・ベルヌーイ梁）。単純支持梁で静的平衡 \(\sum F = 0,\ \sum M = 0\) より支点反力 \(R_B = (P\,a + wL^2/2 + M_0)/L\)、\(R_A = P + wL - R_B\)。せん断力 \(V(x)=R_A - wx - P\,H(x-a)\)、曲げモーメント \(M(x)=\int V\,dx\)。

モデルの前提： 線形弾性・小変形、単純支持（ピン＋ローラー）、集中荷重Pと等分布荷重wを扱います。符号規約はたわみ正（下に凸）を正のM、下向き荷重を正とします。せん断変形・自重は無視。

適用範囲・限界： 反力・SFD・BMDは厳密です（例：\(L{=}6\text{m}, P{=}30\text{kN}\,@\,a{=}2.5\text{m}, w{=}10\text{kN/m}\) で \(R_A{=}47.5, R_B{=}42.5\text{kN}\)、\(M_\text{max}{=}87.50\text{kN·m}\,@\,x{=}2.5\text{m}\)、\(R_A{+}R_B{=}\) 全荷重90kN）。断面性能に依存する応力・たわみ量は別途必要です。

使い方ガイド

  1. 梁の長さ L（m）をスライダーで設定します。例：2 m の鋼製梁を想定する場合、L を 2 に設定してください。
  2. 集中荷重 P（kN）と作用位置 a（m、左支点からの距離）を入力します。例えば P = 15 kN、a = 0.8 m とすれば、左支点から 0.8 m の位置に 15 kN の荷重が下向きに作用します。
  3. 等分布荷重 W（kN/m）を設定します。全長に均等に分布する場合、例えば W = 5 kN/m を入力すると、梁全体に 5 kN/m の荷重が加わります。シミュレーターは反力 R_A、R_B、最大曲げモーメント M_max とその発生位置を自動計算し、SFD と BMD をリアルタイム表示します。

具体的な計算例

長さ L = 4 m の単純支持梁に、左支点から a = 1.5 m の位置に集中荷重 P = 20 kN、全長に等分布荷重 W = 3 kN/m が作用する場合を想定します。反力は R_B = (20×1.5 + 3×4²/2)/4 = 13.5 kN、R_A = 20 + 3×4 − 13.5 = 18.5 kN となります。せん断力は荷重点 x = 1.5 m で +14 kN から −6 kN へ符号が変わるため、最大曲げモーメントはこの位置で生じ、M_max = 18.5×1.5 − 3×1.5²/2 ≈ 24.4 kN・m です。SFD と BMD で、せん断力の不連続位置とモーメントの最大位置が一致することを確認できます。

実務での注意点

  1. 集中荷重の作用位置 A が支点位置（A = 0 または A = L）に設定された場合、反力計算が不安定になるため、最低でも梁長の 1% 以上内側に配置してください。
  2. 等分布荷重 W は全長均等分布のみに対応しており、部分的な分布荷重や三角形分布は別途解析が必要です。
  3. 建築設計では床スラブの自重を 5～10 kN/m²、梁幅を考慮した等分布荷重に換算してから入力してください。例：幅 300 mm のスラブなら W = 7.5 × 0.3 = 2.25 kN/m となります。
  4. 曲げひび割れ判定には、許容曲げモーメント（材質による）との比較が必須です。鋼材 F値 235 N/mm²、断面係数 Z = 650 cm³ の場合、許容 M = 235 × 650 / 1000 = 152.75 kN・m です。
