# 斜張橋ケーブルの張力シミュレーター

斜張橋の床版を主塔から吊り下げる斜めのステイケーブルを設計するツールです。床版荷重・ケーブル角度・長さ・断面積を変えると、ケーブルに生じる張力・水平分力・応力・安全率・弾性伸び・自重サグがリアルタイムで分かります。

**Category:** 構造解析
