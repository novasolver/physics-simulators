# 待ち行列理論シミュレーター（M/M/1・M/M/c）

到着率 λ・サービス率 μ・サーバー数 c を調整して、平均待ち時間・系内人数・確率分布をリアルタイムで可視化。コンビニのレジ増設やコールセンターの最適設計に使えるアーランC公式を体験できます。

**Category:** 確率・統計
