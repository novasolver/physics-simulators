# 流動層シミュレーター — 最小流動化速度・圧力損失

粒子径・密度・流体粘度を調整してアルキメデス数・Umf・Ut をリアルタイム計算。Ergun 式による圧力損失曲線と粒子床アニメーションで流動化の物理を直感的に理解できます。

**Category:** 化学工学
