# カーボンニュートラル計算ツール

家庭・交通・食事・電力から年間CO₂排出量を計算。電化・再エネ導入・食生活改善の削減効果をスライダーで即時確認し、カーボンニュートラルへの道筋を数値で把握。

**Category:** 環境・サステナビリティ

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/carbon-neutrality-calc.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/carbon-neutrality-calc.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/carbon-neutrality-calc.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/carbon-neutrality-calc
python -m http.server 8000
# open http://localhost:8000
```
