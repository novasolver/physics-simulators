# PERT/CPM ネットワーク工程管理計算機

PERT/CPM工程管理計算機。最大12アクティビティのAONネットワークでクリティカルパス算出。PERT期待工期te=(a+4m+b)/6、前向き・後ろ向きパス、余裕時間TF=LS-ES、納期達成確率をリアルタイム計算。ガントチャート付き。

**Category:** 設計支援

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/pert-cpm
python -m http.server 8000
# open http://localhost:8000
```
