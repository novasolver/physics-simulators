# ストーンコラム（砕石パイル）工法シミュレーター

軟弱粘土地盤に剛性の高い砕石コラムを格子状に打設して改良するストーンコラム工法（バイブロ置換工法）を設計するツールです。コラム直径・間隔・砕石の摩擦角・粘土の強度・配置パターンを変えると、Priebeの簡易理論に基づく面積置換率・応力集中比・沈下低減係数・改良率が即座に分かります。

**Category:** 地盤工学
