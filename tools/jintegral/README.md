# J積分・応力拡大係数（KI）推定ツール

き裂先端の破壊力学量（J積分・応力拡大係数KI）をき裂形状と荷重から計算。延性破壊・脆性破壊を評価し、臨界き裂サイズと残余強度をリアルタイムで推定するCAEツール。破壊力学シミュレーター

**Category:** 破壊力学
