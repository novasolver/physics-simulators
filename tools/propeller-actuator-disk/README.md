# プロペラのアクチュエータディスク理論シミュレーター

プロペラを「無限に薄いディスク」と見なすアクチュエータディスク理論（フルードの運動量理論）のツールです。直径・推力・前進速度を変えると、空気に与える誘導速度、後流速度、理想所要動力、そしてプロペラ効率の上限であるフルード効率がリアルタイムで分かります。

**Category:** 航空宇宙
