# 凸レンズ・凹レンズ 光線追跡シミュレーター

凸レンズと凹レンズの光の進み方をリアルタイムでシミュレーション。焦点距離や物体の位置を自由に変更し、実像・虚像ができる過程を光線追跡で視覚的に学べる光学シミュレーターツールです。光学の基礎理解や授業・自習に最適です。

**Category:** 光学シミュレーター

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/lens-optics
python -m http.server 8000
# open http://localhost:8000
```
