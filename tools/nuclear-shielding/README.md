# 放射線遮蔽計算ツール

放射線遮蔽計算ツール：ガンマ線の減弱係数・HVL・TVL・透過線量率をリアルタイム計算。鉛・コンクリート・水などで遮蔽設計を最適化するCAEツール。

**Category:** 電磁気 / 放射線

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/nuclear-shielding.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/nuclear-shielding.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/nuclear-shielding.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/nuclear-shielding
python -m http.server 8000
# open http://localhost:8000
```
