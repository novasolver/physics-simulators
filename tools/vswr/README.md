# VSWR シミュレーター — 反射係数・定在波比・回帰損失

線路 Z_0 と負荷 Z_L から反射係数・VSWR・回帰損失・ミスマッチ損失を可視化。複素負荷を含めて、整合の良し悪しと反射電力の様子を体感できます。

**Category:** RF・電磁波シミュレーター
