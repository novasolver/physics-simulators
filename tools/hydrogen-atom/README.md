# 水素原子スペクトル・ボーアモデル

水素原子スペクトルとボーアモデルのシミュレーション。エネルギー準位遷移、ライマン系列・バルマー系列の放出吸収スペクトルをリアルタイム計算・可視化。量子力学教育・分光分析に最適。

**Category:** 物理シミュレーター

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/hydrogen-atom.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/hydrogen-atom.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/hydrogen-atom.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/hydrogen-atom
python -m http.server 8000
# open http://localhost:8000
```
