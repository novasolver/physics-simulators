# 沈降速度・ストークスの法則計算機

粒子径・密度・流体粘度から終端速度をリアルタイム計算。ストークス法則・アレン域・ニュートン域の自動判定で、沈降解析・遠心分離シミュレーションに対応。

**Category:** 物理シミュレーター

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/sedimentation.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/sedimentation.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/sedimentation.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/sedimentation
python -m http.server 8000
# open http://localhost:8000
```
