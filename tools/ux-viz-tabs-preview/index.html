使い方ガイド

  1. メッシュ生成パネルで要素分割数を設定（四面体要素：10,000～50,000個推奨）
  2. 材料データベースから鋼（ヤング率E=206GPa）またはアルミ（E=69GPa）を選択
  3. 荷重条件タブで境界条件と外力を定義し「計算実行」をクリック
  4. 変形図、応力分布（Mises応力）、変位ベクトル場をリアルタイムで確認
  5. スライダーで変形倍率（1～100倍）を調整して詳細な変形挙動を観察

具体的な計算例

長さ3m、断面150×150mm角パイプ（厚さ6mm）の片持ちはり先端に50kNの集中荷重を作用させた場合、先端変位は約18mmとなります。鋼（E=206GPa）であれば許容応力150MPaに対して最大Mises応力が128MPaで安全率1.17を確保。一方、同一条件でアルミ（E=69GPa、許容応力100MPa）では先端変位54mm、応力42MPaとなり、たわみが支配的になる設計制約が顕在化します。

実務での注意点

  • 溶接部周辺は応力集中係数Kt=1.5～2.5で再評価が必須（視覚化では均質材として扱われるため）
  • 大変形領域（変位が寸法の10%超）では幾何学的非線形性を有効化して再計算
  • 複雑な組立体は各部品の接触設定（摩擦係数μ=0.15～0.3）と拘束タイプ（完全接着vs滑り接触）を明示的に定義
  • FEA結果の妥当性検証：平面梁理論との簡易計算による照合（δ=PL³/3EI）
