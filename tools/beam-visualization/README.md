# はり（梁）の断面特性ビジュアライザー

6種類の断面形状を選び、寸法スライダーを動かすと断面二次モーメント・断面係数・曲げ応力分布がリアルタイム更新。I形鋼の断面効率を矩形と比較しよう。

**Category:** 構造解析ツール

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/beam-visualization.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/beam-visualization.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/beam-visualization.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/beam-visualization
python -m http.server 8000
# open http://localhost:8000
```
