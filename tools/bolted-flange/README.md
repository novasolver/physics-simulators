# ボルト締めフランジ継手設計シミュレーター

無料のオンライン「フランジ継手設計シミュレーター」です。ASME規格に基づき、ボルト荷重やガスケット着座荷重、作動条件、漏洩チェックをリアルタイムで計算。配管フランジの設計・検証を効率的に行えます。信頼性の高い継手設計をサポートする計算機です。

**Category:** 構造解析

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/bolted-flange
python -m http.server 8000
# open http://localhost:8000
```
