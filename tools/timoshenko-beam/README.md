# チモシェンコ梁シミュレーター — せん断変形を考慮した先端撓み

チモシェンコ梁シミュレーターで片持梁のせん断変形を可視化。オイラー・ベルヌーイ理論との比較により短い梁の撓みを精密に計算できます。梁シミュレーション・有限要素法解析に最適。

**Category:** 構造力学シミュレーター

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/timoshenko-beam
python -m http.server 8000
# open http://localhost:8000
```
