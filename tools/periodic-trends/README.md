# 元素周期表トレンド可視化

元素周期表の原子半径・イオン化エネルギー・電気陰性度をヒートマップで可視化。周期律の傾向を視覚的に学習できるCAEツール。元素の物性変化を直感的に理解。

**Category:** 高校化学・元素周期表

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/periodic-trends.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/periodic-trends.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/periodic-trends.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/periodic-trends
python -m http.server 8000
# open http://localhost:8000
```
