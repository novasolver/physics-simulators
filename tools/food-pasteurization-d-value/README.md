# 食品殺菌 D 値・F 値 シミュレーター

食品殺菌・パスチャライゼーションの D 値・F 値・log 不活性化を計算。対象微生物・殺菌温度・時間・初期菌数・Z 値・基準温度を変えて、低酸性缶詰の commercial sterility や HTST 設計、品質低下（C 値）を同時に評価できる無料シミュレーターです。

**Category:** 食品工学・殺菌設計

- 🇯🇵 [日本語](https://novasolver.jp/tools/food-pasteurization-d-value.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/food-pasteurization-d-value
python -m http.server 8000
# open http://localhost:8000
```
