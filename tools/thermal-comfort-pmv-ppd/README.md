# 室内温熱環境 PMV・PPD シミュレーター — Fanger ISO 7730

室温・平均放射温度・気流速度・湿度・着衣量・代謝量からFangerのPMV（予測平均温冷感申告）とPPD（予測不満足者率）をリアルタイム計算。ISO 7730 / ASHRAE 55のカテゴリA/B/Cで快適性を評価できる無料シミュレーターです。

**Category:** HVAC・温熱環境
