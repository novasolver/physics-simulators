# 膜分離 MF/UF/NF/RO シミュレーター — MWCO とフラックス設計

精密濾過(MF)・限外濾過(UF)・ナノ濾過(NF)・逆浸透(RO)を一つの画面で比較するツールです。膜種類・溶質分子量・操作圧・温度・ファウリング係数を変えると、排除率・実フラックス・透過流量・CIP周期がリアルタイムで分かり、水処理プラントや医薬・食品プロセスの膜選定の当たり付けに使えます。

**Category:** 水処理・分離工学
