# 浮力・浮体安定性シミュレーター

浮力・浮体安定性シミュレーター｜メタセンター高さGMと復原てこGZ曲線をリアルタイム計算。船体安定性の境界を視覚的に探索できるCAEツール。

**Category:** 流体解析

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/buoyancy-stability.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/buoyancy-stability.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/buoyancy-stability.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/buoyancy-stability
python -m http.server 8000
# open http://localhost:8000
```
