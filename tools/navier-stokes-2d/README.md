# 2D Navier-Stokes 流れシミュレーター

NovaSolverの2D Navier-Stokes流れシミュレーターで、蓋駆動キャビティ流れを可視化。レイノルズ数を自由に変更し、複雑な流体の挙動をブラウザ上でリアルタイム解析できます。CFD（数値流体力学）の学習や現象の直感的な理解に最適なシミュレーションツールです。

**Category:** 流体解析

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/navier-stokes-2d.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/navier-stokes-2d.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/navier-stokes-2d.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/navier-stokes-2d
python -m http.server 8000
# open http://localhost:8000
```
