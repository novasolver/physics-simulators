# 等エントロピー流れ計算機

等エントロピー流れ計算機は、マッハ数と比熱比を入力するだけで、圧縮性流体の温度比・圧力比・密度比・面積比および垂直衝撃波の特性を瞬時に計算します。CAE解析や流体力学の学習に役立つ直感的なシミュレーターツールです。ラバルノズルの模式図で可視化、工学設計や研究開発の基礎計算をサポートします。

**Category:** 圧縮性流体
