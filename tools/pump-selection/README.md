# ポンプ選定・システム曲線・運転点

遠心ポンプのQ-H特性曲線とシステム曲線の交点（運転点）をリアルタイムで計算。効率曲線や軸動力の確認、並列・直列運転のシミュレーションも可能です。アフィニティ則を用いた回転数変更時の性能予測や、ポンプ選定の基礎を数式とともに解説。CAEを活用したポンプシステムの最適な設計・運用を支援します。

**Category:** 流体解析
