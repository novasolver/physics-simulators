# フィン付きヒートシンク設計ツール

フィン付きヒートシンクの設計を支援するオンラインツールです。自然対流と強制対流の両方のモードで、熱抵抗やフィン効率、最適なフィン間隔をリアルタイム計算。接合部温度の上昇を即時に確認でき、ヒートシンクの最適設計を効率的に行えます。

**Category:** 熱解析
