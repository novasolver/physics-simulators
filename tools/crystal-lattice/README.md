# 結晶格子ビューワー

単純立方・BCC・FCC・HCP・ダイヤモンド・NaCl・グラフェン（2D）の結晶構造をアイソメトリックビューで回転アニメーション表示。配位数・充填率・径分布関数g(r)を計算します。

**Category:** 材料科学 / 結晶学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/crystal-lattice.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/crystal-lattice.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/crystal-lattice.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/crystal-lattice
python -m http.server 8000
# open http://localhost:8000
```
