# 浸透圧シミュレーター

浸透圧シミュレーターで van't Hoff式をリアルタイム計算。濃度・温度・電解質係数の変化による浸透圧と水位差をシミュレーション。

**Category:** 高校化学・溶液

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/osmotic-pressure.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/osmotic-pressure.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/osmotic-pressure.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/osmotic-pressure
python -m http.server 8000
# open http://localhost:8000
```
