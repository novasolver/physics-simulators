# WBGT（湿球黒球温度）暑熱指数シミュレーター

WBGT（湿球黒球温度）暑熱指数シミュレーターは、乾球温度・相対湿度・日射量から自然湿球温度・黒球温度・WBGT 指数をリアルタイム計算します。厚生労働省・JIS Z 8504 基準で、運動・作業中止判定の危険度区分を直感的に確認できます。

**Category:** 労働衛生シミュレーター
