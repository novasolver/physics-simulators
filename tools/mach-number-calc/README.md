# マッハ数・圧縮性流れ計算機

マッハ数・圧縮性流れの等エントロピー関係と垂直衝撃波特性を即座に計算。亜音速から極超音速まで対応し流れ場を可視化するCAE計算機。

**Category:** 空気力学 / 圧縮性流体

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/mach-number-calc.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/mach-number-calc.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/mach-number-calc.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/mach-number-calc
python -m http.server 8000
# open http://localhost:8000
```
