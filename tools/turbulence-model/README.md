# 乱流モデル選択ガイド・y+計算機

乱流モデル選択ガイド・y+計算機｜k-ε・k-ω SST・LES・Spalart-Allmarasを比較し、最適なモデルと壁面y+を自動算出。入口乱流条件も対応。

**Category:** 流体解析

- 🇯🇵 [日本語](https://novasolver.jp/tools/turbulence-model.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/turbulence-model.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/turbulence-model
python -m http.server 8000
# open http://localhost:8000
```
