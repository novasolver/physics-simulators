# モンテカルロ法・統計シミュレーター — 中心極限定理と分布収束

ランダムサンプリングでπを推定・積分計算・中心極限定理を体験。モンテカルロ法の収束をリアルタイムアニメーションで可視化。ランダムウォーク・拡散過程も含む。

**Category:** 数値解析・統計

```bash
git clone https://github.com/novasolver/physics-simulators
```
