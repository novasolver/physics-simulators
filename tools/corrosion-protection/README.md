# 腐食防食設計計算機

異種金属接触のガルバニック腐食電流を計算し、鉄のE-pH図（ポーベ図）で腐食・不動態・免疫域を可視化。犠牲陽極の寿命を推定します。

**Category:** 材料・腐食工学
