# 熱膨張シミュレーター

温度変化による熱膨張と熱応力をシミュレーション。橋梁やパイプライン設計に必須のCAE解析で、線膨張係数とヤング率を基に拘束応力をリアルタイム計算・可視化します。

**Category:** 熱力学・材料力学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/thermal-expansion-sim.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/thermal-expansion-sim.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/thermal-expansion-sim.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/thermal-expansion-sim
python -m http.server 8000
# open http://localhost:8000
```
