# B-tree インデックス探索コストと階層数シミュレーター

B-treeインデックス探索コストと階層数をシミュレーション。木構造、階層コスト、範囲走査を分析し、索引設計最適化に必要なパラメータを確認できます。

**Category:** 対話型シミュレーター

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/database-index-btree-cost.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/database-index-btree-cost.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/database-index-btree-cost.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/database-index-btree-cost
python -m http.server 8000
# open http://localhost:8000
```
