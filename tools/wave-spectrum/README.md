# 波浪スペクトル・有義波高計算機

波浪スペクトルと有義波高を瞬時に計算できる無料オンラインツールです。JONSWAPやピアソン-モスコウィッツなど主要モデルに対応。リアルタイムで波高や周期を算出し、視覚的な波面アニメーションも確認できます。海洋工学や海岸研究に役立つ波浪計算を簡単に実行しましょう。

**Category:** 流体解析

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/wave-spectrum
python -m http.server 8000
# open http://localhost:8000
```
