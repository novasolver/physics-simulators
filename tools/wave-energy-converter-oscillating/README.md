# 波力発電 WEC シミュレーター — OWC・点吸収体・減衰式

海洋波のエネルギーを電力に変換する Wave Energy Converter (WEC) の出力を、4 主要形式（OWC・点吸収体・減衰式・オーバートップ）で比較できるツールです。有義波高・周期・装置幅・PTO効率から、波エネルギー密度・捕獲幅比・年間発電量・LCOE までを推算します。

**Category:** 海洋再エネ・波力発電
