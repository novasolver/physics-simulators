# コンクリート型枠側圧 ACI 347 シミュレーター

生コンクリートが型枠に与える側圧 P_max を ACI 347R-14 式で計算します。打設速度・温度・セメント種別・混和剤・部材形状（壁／柱）を変えると、設計側圧と等価圧力高さ、プライウッド許容スパン、フォームタイ間隔、凝結時間がリアルタイムで分かります。

**Category:** コンクリート工事・型枠
