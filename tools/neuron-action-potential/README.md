# ニューロン・活動電位シミュレーター

ホジキン-ハクスレーモデルによる活動電位の数値シミュレーション。刺激電流・チャネルコンダクタンスを変えてイオンチャネルの開閉と膜電位変化をリアルタイム計算します。

**Category:** 神経科学・生体電気

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/neuron-action-potential.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/neuron-action-potential.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/neuron-action-potential.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/neuron-action-potential
python -m http.server 8000
# open http://localhost:8000
```
