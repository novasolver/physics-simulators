# シュミッド因子 シミュレーター — 単結晶のすべり系活性化

m = cosλ cosφ から単結晶のすべり系活性化と分解せん断応力 τr = σ m をリアルタイム計算。降伏応力 σy = τcrss/m と安全係数、m(λ) 曲線を可視化し結晶塑性を体感できます。

**Category:** 材料変形シミュレーター
