# 結晶成長シミュレーター

結晶成長シミュレーター：DLAモデルで樹枝状結晶・雪の結晶を生成、フラクタル次元をリアルタイム推定。拡散律速凝集シミュレーション

**Category:** 材料・凝固

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/crystal-growth.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/crystal-growth.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/crystal-growth.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/crystal-growth
python -m http.server 8000
# open http://localhost:8000
```
