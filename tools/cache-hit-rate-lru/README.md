# LRU キャッシュヒット率と容量効果シミュレーター

LRUキャッシュのヒット率と容量効果をシミュレーション。スタック距離模式図でキャッシュ容量追加の効果を視覚化。メモリ最適化とパフォーマンス向上を実現します。

**Category:** 対話型シミュレーター

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/cache-hit-rate-lru.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/cache-hit-rate-lru.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/cache-hit-rate-lru.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/cache-hit-rate-lru
python -m http.server 8000
# open http://localhost:8000
```
