# レーザー共振器設計シミュレーター

レーザー共振器設計シミュレーターで閾値電流・スロープ効率・縦モード間隔をリアルタイム計算。L-I特性曲線とスペクトル図を動的に可視化し、レーザー設計の最適化を実現。

**Category:** 電磁気・光学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/laser-design.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/laser-design.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/laser-design.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/laser-design
python -m http.server 8000
# open http://localhost:8000
```
