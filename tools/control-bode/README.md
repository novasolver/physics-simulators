# ボード線図シミュレーター

ボード線図シミュレーターで伝達関数のゲイン線図・位相線図をリアルタイム生成。安定判別とゲイン余裕・位相余裕の解析が可能。制御系設計に必須のツール。

**Category:** 制御工学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/control-bode.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/control-bode.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/control-bode.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/control-bode
python -m http.server 8000
# open http://localhost:8000
```
