# 腐食速度計算ツール — Butler-Volmer式・エバンス図

腐食速度計算ツール：Butler-Volmer式とエバンス図を用いたタフェルスロープ・腐食電流密度からの腐食速度（mm/year）およびStern-Geary分極抵抗の実時間計算。

**Category:** 電磁気・光学

git clone https://github.com/novasolver/physics-simulators
