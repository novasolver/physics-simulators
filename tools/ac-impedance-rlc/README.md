# 直列 RLC 回路 シミュレーター — 交流インピーダンスと共振

抵抗 R、コイル L、コンデンサ C を直列に接続した交流回路。周波数 f を変えてインピーダンス |Z|、位相角 φ、共振周波数 f0、Q 値をリアルタイム計算し、log-log 周波数特性を可視化します。

**Category:** 電気回路シミュレーター
