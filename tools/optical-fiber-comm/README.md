# 光ファイバー通信シミュレーター

光ファイバー通信のNA（開口数）や減衰、分散特性をリアルタイムでシミュレーション。コアとクラッドの屈折率、伝送距離を自在に変更し、シングルモードとマルチモードの違いを視覚的に理解できます。NovaSolverで光伝送の基礎を効果的に学びましょう。

**Category:** 光通信工学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/optical-fiber-comm.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/optical-fiber-comm.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/optical-fiber-comm
python -m http.server 8000
# open http://localhost:8000
```
