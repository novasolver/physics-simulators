# 毛管現象（毛細管上昇）シミュレーター

細い管を液体に浸すと、表面張力だけで液体がひとりでに上がっていく「毛管現象」を再現するツールです。管の内径・表面張力・接触角・液体密度を変えると、毛管圧力・上昇高さ・メニスカスの形がリアルタイムで分かります。

**Category:** 流体工学
