# 渦電流シミュレーター

表皮深さ δ = √(2ρ/ωμ) の可視化から、渦電流損失・制動力まで。誘導加熱・変圧器コア設計・NDTの基礎を直感的に理解できます。

**Category:** 電磁気学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/eddy-current.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/eddy-current.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/eddy-current.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/eddy-current
python -m http.server 8000
# open http://localhost:8000
```
