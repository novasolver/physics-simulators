# 勾配降下法シミュレーター

勾配降下法シミュレーターでSGD・Adam・RMSpropなどの最適化アルゴリズムの動作を2D損失関数上でリアルタイム可視化。機械学習の収束過程を直感的に理解できます。

**Category:** 機械学習・最適化

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/gradient-descent.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/gradient-descent.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/gradient-descent.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/gradient-descent
python -m http.server 8000
# open http://localhost:8000
```
