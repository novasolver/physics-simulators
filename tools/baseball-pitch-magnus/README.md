# 野球変化球・マグヌス力シミュレーター

球速・回転数・回転軸を調整してカーブ・スライダー・ストレートの投球軌道を計算。マグヌス効果と重力の組み合わせで、変化球の変化量をリアルタイム可視化。

**Category:** 流体力学・スポーツ科学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/baseball-pitch-magnus.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/baseball-pitch-magnus.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/baseball-pitch-magnus.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/baseball-pitch-magnus
python -m http.server 8000
# open http://localhost:8000
```
