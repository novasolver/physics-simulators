# 免震化による固有周期シフトと応答低減シミュレーター

免震化による固有周期シフトと応答低減シミュレーター。応答スペクトル、免震層変位、ベースシア低減を比較し、長周期化と減衰効果を確認。耐震設計の数値解析に。

**Category:** 対話型シミュレーター

git clone https://github.com/novasolver/physics-simulators
