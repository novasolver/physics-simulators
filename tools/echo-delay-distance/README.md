# エコー遅延・距離計算ツール

音波が反射して戻ってくるまでの時間（遅延）から距離を計算します。温度・媒質・距離をスライダーで調整し、ソナー・コウモリの反響定位の原理をアニメーションで体験。

**Category:** 音響・波動

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/echo-delay-distance.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/echo-delay-distance.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/echo-delay-distance.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/echo-delay-distance
python -m http.server 8000
# open http://localhost:8000
```
