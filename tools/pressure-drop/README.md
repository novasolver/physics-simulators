# 管路圧力損失計算機

管路圧力損失計算機｜Darcy-Weisbach式とColebrook-White方程式で摩擦損失を計算。継手・弁のK係数損失対応。ムーディ線図表示で配管設計に最適。

**Category:** 流体解析

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/pressure-drop.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/pressure-drop.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/pressure-drop.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/pressure-drop
python -m http.server 8000
# open http://localhost:8000
```
