# 2D静力学ソルバー

NovaSolverの2D静力学ソルバーは、はりや支持条件、集中荷重・分布荷重を設定するだけで、反力をリアルタイム計算。せん断力図(SFD)と曲げモーメント図(BMD)を即座に可視化します。構造力学の基礎学習や設計検証に最適な無料ツールです。

**Category:** 構造力学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/statics-2d.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/statics-2d.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/statics-2d
python -m http.server 8000
# open http://localhost:8000
```
