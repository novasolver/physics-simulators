# Henderson-Hasselbalch シミュレーター — 緩衝液の pH

Henderson-Hasselbalch シミュレーターは、弱酸とその共役塩基からなる緩衝液の pH・[A−]/[HA] 比・緩衝能 β・有効緩衝範囲をリアルタイムに計算します。pKa・全濃度・共役塩基分率・加える強酸/強塩基量を変えて、緩衝液の挙動と滴定曲線を可視化できます。

**Category:** 化学シミュレーター
