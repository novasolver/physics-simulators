# ヒートシンク熱抵抗シミュレーター

フィン効率・フィンアレイ・強制/自然対流の熱抵抗ネットワークをリアルタイム計算。ジャンクション温度・熱抵抗合計・フィン効率を即時算出。電子冷却・パワーデバイス設計に必須の本格的ヒートシンク設計シミュレーター。

**Category:** 熱解析

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/heat-sink
python -m http.server 8000
# open http://localhost:8000
```
