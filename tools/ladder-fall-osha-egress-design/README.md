# 梯子・避難経路 OSHA 安全設計

梯子の設置角度・体重・材質と、避難経路の幅・人数・歩行距離から、OSHA 1910.23 の 4:1 ルール、転落帯の要否、避難経路の収容人数と推定避難時間をひとつの画面で確認できます。建設現場・工場・倉庫・店舗の安全計画づくりにそのまま使えます。

**Category:** 安全工学・労働災害
