# モールの応力円ツール

モールの応力円ツール - 応力成分σx、σy、τxyから主応力・最大せん断応力をリアルタイム計算。応力解析・有限要素法の設計検証に。

**Category:** 応力解析ツール

git clone https://github.com/novasolver/physics-simulators
