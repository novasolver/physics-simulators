# LMTD シミュレーター — 対向流と並流の対数平均温度差

LMTD シミュレーターは、高温・低温流体の入口出口温度から対向流（counter-flow）と並流（parallel-flow）の対数平均温度差を実時間に計算し、温度プロファイル比較と LMTD 関数曲線で対向流の伝熱性能優位を可視化する熱交換器設計ツールです。

**Category:** 熱交換器シミュレーター
