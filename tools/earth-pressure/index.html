理論・主要公式

$$K_a = \tan^2\!\left(45^\circ - \tfrac{\phi}{2}\right) = \frac{1-\sin\phi}{1+\sin\phi}$$

主働土圧係数。壁が背後土から離れる方向に変位したときの最小土圧比。

$$K_p = \tan^2\!\left(45^\circ + \tfrac{\phi}{2}\right) = \frac{1+\sin\phi}{1-\sin\phi}$$

受働土圧係数。壁が土側に押し込まれるときの最大抵抗。$K_p = 1/K_a$ の関係。

$$K_0 = 1 - \sin\phi$$

静止土圧係数（ヤキー式）。剛な壁・正規圧密土に適用。

$$P_a = \tfrac{1}{2}K_a\,\gamma\,H^2 + K_a\,q\,H,\quad P_p = \tfrac{1}{2}K_p\,\gamma\,H^2 + K_p\,q\,H$$

壁高Hあたりの全主働土圧Pa・全受働土圧Pp（単位幅）。第1項は自重項、第2項は載荷項。

ランキン土圧シミュレーターとは

🙋
擁壁って、結局どんな力がかかってるんですか？土を後ろから押されてる感じですよね？
🎓
いい質問だ。擁壁の背後の土は重力で常に壁を押そうとしている。これを「土圧」と呼ぶんだ。このツールで使っているのは「ランキン土圧理論」で、垂直壁・水平地表という単純な条件で、主働土圧Paと受働土圧Ppを計算できる。試しに「内部摩擦角φ」を30°から40°に上げてみて。Kaがガクッと下がって、Paが小さくなるのが見えるよ。
🙋
え、φを上げると土圧が減るんですか？逆だと思ってました…
🎓
よくある誤解だね。φは「土が自分で踏ん張る力」を表しているから、φが大きいほど土自身が崩れにくく、壁に寄りかかる量が減る。砂山を作るとき、湿った砂のほうが急な角度で立つよね。あれと同じだ。逆に「受働土圧Pp」はφが大きいほど指数的に増える。Kp = 1/Ka の関係だから、φ=30°ならKp/Ka = 9倍、φ=40°なら約20倍にもなる。
🙋
なるほど！じゃあ「地表載荷q」は何のためにあるんですか？倉庫が建つとか、そういう想定ですか？
🎓
その通り！擁壁の上の地表に倉庫やトラックが乗ると、その荷重が下の壁にも伝わる。ランキン理論では、qがあると深さによらず一定値Ka·qが加わって、土圧分布は「三角形＋矩形」になる。ツールでqを0から50kPaに上げると、上端から赤い矩形が伸びるのが見えるよ。実務では交通荷重を10〜20kPaの等価分布で与えることが多いね。
🙋
「静止土圧K0」というのもありますね。Ka・Kpとは別物ですか？
🎓
いい目のつけどころ。Ka・Kpは壁が動くことが前提だが、地下室の壁や橋台みたいに「動かない剛な壁」では主働状態に達しない。そこで「静止土圧K0=1−sinφ」を使う。φ=30°ならK0=0.5で、Ka=0.333よりも大きい。地下室の壁を設計するときに「主働で計算したら危険側」になるのはこの差のせいだ。

物理モデルと主要な数式

ランキン理論は、半無限の土塊に作用する応力状態が「ランキン状態」と呼ばれる極限平衡に達したとき、水平方向の有効応力 $\sigma_h$ と鉛直有効応力 $\sigma_v$ の比が一定の係数になるという考え方です。

主働状態（壁が背後土から離れる）では $\sigma_h = K_a \sigma_v$、受働状態（壁が土側に押し込まれる）では $\sigma_h = K_p \sigma_v$ となります。垂直擁壁・水平地表・壁面摩擦δ=0という条件下で、係数は次のように導かれます。

$$K_a = \tan^2(45^\circ - \phi/2),\quad K_p = \tan^2(45^\circ + \phi/2),\quad K_0 = 1 - \sin\phi$$

深さ $z$ における主働水平土圧は $\sigma_a(z) = K_a (\gamma z + q)$ で、壁高Hで積分すると単位幅あたりの全主働力 $P_a = \tfrac{1}{2}K_a \gamma H^2 + K_a q H$ が得られます。受働側も同様にKpで置き換えるだけです。

実世界での応用

擁壁の安定計算：道路擁壁・宅地擁壁の転倒・滑動・支持力のチェックで、背面側に作用する荷重としてランキン主働土圧Paを用います。φを過小評価すると過剰設計、過大評価すると危険側になるため、地盤調査での厳密な強度評価が前提です。

矢板・親杭横矢板の根入れ：掘削側の受働抵抗力をPpで評価し、必要根入れ深さを決めます。受働側は壁が土を「押す」状態になるため、係数Kpの妥当性確認が重要です。

地下室壁・橋台背面：変位できない剛な壁では主働には達しないので、静止土圧K0で評価します。φ=30°ならK0/Ka ≈ 1.5なので、無視すると1.5倍の過小評価になります。

FEM解析の境界条件チェック：PLAXISやMidasGTSで地盤−構造連成解析を行う前に、本ツールで手計算レベルの土圧を見積もり、解析結果のオーダーが妥当かサニティチェックします。

よくある誤解と注意点

「ランキンとクーロンの混在使用」：ランキンは壁面摩擦δ=0、クーロンはδ>0を扱えます。実際の擁壁背面ではδ=φ/2〜2φ/3 程度ですが、ランキンを使うと安全側になります。逆に、壁面が傾斜していたり地表面が傾斜している場合は、ランキンでは表現できないのでクーロンや有限要素法を使います。

「Kp の過信」：Kp は計算上はKa の何倍にもなりますが、Kp の値を擁壁設計で全量使うと危険側になります。受働土圧は壁が大きく変位して初めて発揮されるため、実務では安全率FS=2〜3 で割って使うのが標準です。

「地下水の無視」：地下水位がある場合は、水位以下では水中重量γ' = γ - γw を使い、別途水圧を加算する必要があります。本ツールは乾燥土相当の単純化モデルなので、水位がある現場では別途補正が必要です。

よくある質問

ランキンは垂直壁・水平地表・壁面摩擦δ=0の単純化条件下の理論で、土塊全体の応力状態から係数を導きます。クーロンは壁面摩擦・壁面/地表の傾斜を扱える極限すべり面解析です。教科書では入門としてランキンを学び、実務では条件に応じて使い分けます。
主働土圧Paは壁が背後土から離れる方向に動くときの最小土圧で、擁壁の安定計算で背面側荷重として使います。受働土圧Ppは壁が土側に押し込まれるときの最大抵抗力で、つま先側や根入れ部の側方抵抗として評価します。同じφでもKpはKaの約9倍と大きい点に注意してください。
壁が変位しない剛な構造（地下室壁、ボックスカルバート、剛性の高い橋台）では主働状態に達せず、初期応力状態のK0を使います。正規圧密土ではヤキー式 K0=1-sinφ が広く用いられ、過圧密土ではOCR^sinφを乗じて補正します。
等分布載荷qがあるときは深さによらず一定の上載圧Ka·qが土圧分布に矩形として加算されます。壁高Hでの全主働力には Ka·q·H の項として現れます。倉庫荷重や交通荷重を等価分布として与えるのが実務的です。

使い方ガイド

  1. 土の内部摩擦角φ(度)をスライダーで設定します。一般的な砂質土は30～35°、粘性土は15～25°の範囲です。
  2. 単位体積重量γ(kN/m³)を入力します。砂利質土は18～20 kN/m³、粘土は16～18 kN/m³が標準値です。
  3. 擁壁高さH(m)と壁面上部の均布荷重q(kN/m²)を設定すると、深さ方向の主働土圧σa と受働土圧σp の分布が自動計算されます。
  4. Ka(主働係数)、Kp(受働係数)、合力Pa、Ppの値をリアルタイムで確認し、設計照査に利用します。

具体的な計算例

砂質土擁壁の設計例：φ=35°、γ=19 kN/m³、H=4.5m、q=10 kN/m²の場合、ランキン理論により Ka=0.271、Kp=3.690が算出されます。深さ3.0mでは主働土圧σa=19×0.271×3.0+10×0.271≈17.6 kPa、受働土圧σp=19×3.690×3.0≈210 kPa となります。これにより主働土圧合力Pa≈85 kN/m、受働土圧合力Pp≈285 kN/m の値から擁壁の転倒・滑動安全率を検証できます。

実務での注意点

  1. ランキン理論は平坦な地盤面を仮定するため、勾配地盤や不規則な斜面では修正係数が必要です。
  2. 飽和粘土（φ=0）の場合は付着力c を別途考慮し、主働土圧がマイナスになる転圧層を設計に反映させます。
  3. 計算値は静的条件での理論値であり、地震時にはミオーヘによる動的係数補正が不可欠です。
  4. 受働土圧は受働状態（壁が土に押される）を実現できない条件では採用できないため、設計荷重の方向を確認してください。
