# ランキン土圧 シミュレーター — 擁壁の主働・受働土圧

ランキン理論に基づき、垂直擁壁・水平地表における主働 Pa・受働 Pp・静止 Ko 土圧をリアルタイム計算。深さ方向の土圧分布と Ka/Kp/Ko 係数曲線を即時可視化します。

**Category:** 地盤工学シミュレーター

- 🇯🇵 [日本語](https://novasolver.jp/tools/earth-pressure.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/earth-pressure
python -m http.server 8000
# open http://localhost:8000
```
