# 非線形振動シミュレーター — Duffing振動子

非線形振動シミュレーターで、Duffing振動子の周波数応答を無料で解析。ハードニング・ソフトニング型ばねの挙動、ジャンプ現象、骨格曲線をインタラクティブに可視化し、振動工学の理解を深められます。オンライン計算機NovaSolverで高度な振動解析を体験しましょう。

**Category:** 振動・波動
