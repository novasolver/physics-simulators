# ボーア水素原子モデル

ボーア水素原子モデルのエネルギー準位・軌道半径・スペクトル線をリアルタイム可視化。量子数パラメータ調整で遷移・バルマー系列を探索できるCAEツール。

**Category:** 原子物理

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/bohr-hydrogen-model.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/bohr-hydrogen-model.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/bohr-hydrogen-model.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/bohr-hydrogen-model
python -m http.server 8000
# open http://localhost:8000
```
