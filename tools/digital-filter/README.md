# デジタルフィルター設計ツール（IIR/FIR）

無料のデジタルフィルター設計ツール「NovaSolver」で、Butterworth、Chebyshev、FIR移動平均フィルターを簡単設計。周波数応答をリアルタイムで可視化し、フィルター係数や群遅延、阻止帯域減衰量も自動計算。ブラウザ上で直感的に高度なフィルター設計が行えます。

**Category:** 解析ツール

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/digital-filter.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/digital-filter.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/digital-filter.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/digital-filter
python -m http.server 8000
# open http://localhost:8000
```
