# 応力-ひずみ曲線・材料非線形モデル

応力-ひずみ曲線と材料非線形モデルの解説。鋼・アルミ・ゴム・コンクリートのσ-ε曲線をリアルタイム比較。Ramberg-Osgood、バイリニア、べき乗硬化モデル対応。

**Category:** 材料・破壊

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/stress-strain-curve
python -m http.server 8000
# open http://localhost:8000
```
