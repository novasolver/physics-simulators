# 流体圧力・浮力シミュレーター

流体圧力と浮力をリアルタイムで可視化するシミュレーター。水深や流体密度を変えて、物体が浮く・沈む条件を直感的に学べます。潜水艦や船、油圧ジャッキのプリセットで応用例も学習可能。流体静力学（静圧・パスカルの原理・浮力）の基礎理解に最適な教育ツールです。

**Category:** 流体静力学

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/fluid-pressure
python -m http.server 8000
# open http://localhost:8000
```
