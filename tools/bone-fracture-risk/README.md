# 骨折リスク・骨強度・疲労計算機

骨折リスク・骨強度・疲労計算機。皮質骨の応力・安全率・S-N疲労曲線をリアルタイム計算。骨粗しょう症Tスコアと10年骨折リスク予測に対応。

**Category:** 生体工学

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/bone-fracture-risk
python -m http.server 8000
# open http://localhost:8000
```
