# 質量拡散・フィックの法則シミュレーター

質量拡散・フィックの法則シミュレーター｜拡散係数・濃度プロファイルを設定して浸炭・水素脆化解析に対応。境界条件シミュレーション。

**Category:** 対話型シミュレーター

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/mass-diffusion.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/mass-diffusion.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/mass-diffusion.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/mass-diffusion
python -m http.server 8000
# open http://localhost:8000
```
