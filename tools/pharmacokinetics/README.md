# 薬物動態シミュレーター（1/2コンパートメントモデル）

薬物動態シミュレーターで1コンパートメント・2コンパートメントモデルの血中濃度推移を計算。Cmax、Tmax、AUC、半減期の自動算出から定常状態の予測まで、無料で簡単にシミュレーションできます。治療ウィンドウの視覚化で適正投与設計を支援するオンライン計算ツールです。

**Category:** 化学工学
