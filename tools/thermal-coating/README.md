# 遮熱コーティング（TBC）断熱効果計算機

多層熱抵抗モデルでTBCの断熱効果を可視化。YSZ・Mullite・Al₂O₃の材料と膜厚を変えながら各層の温度分布・熱抵抗・基板温度をリアルタイム確認。材料比較と感度解析を3つのグラフで展開。

**Category:** 熱解析
