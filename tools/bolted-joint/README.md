# ボルト締結解析（予荷重・疲労）シミュレーター

予荷重・外力・ボルト/フランジ剛性を設定して、荷重分配・分離安全率・疲労安全率をリアルタイム解析。継手ダイアグラム・グッドマン線図・予荷重感度の3グラフ付き。

**Category:** 機械設計

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/bolted-joint
python -m http.server 8000
# open http://localhost:8000
```
