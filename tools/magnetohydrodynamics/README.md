# 磁気流体力学（MHD）シミュレーター — ハートマン流れ

磁気流体力学（MHD）シミュレーターでハートマン流れを可視化。磁場強度を調整すると速度プロファイルが平坦化する様子をリアルタイムアニメーションで確認できます。液体金属冷却や電磁ポンプの設計・研究に役立つ理論計算ツールです。NovaSolverで高度なMHD解析を体験しましょう。

**Category:** 磁気流体力学
