# 分子動力学シミュレーター

分子動力学シミュレーターでレナード=ジョーンズポテンシャルとVerlet積分を用いた粒子相互作用計算。気液固相転移をリアルタイム観察できるCAE解析ツール。

**Category:** 分子シミュレーション

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/molecular-dynamics.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/molecular-dynamics.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/molecular-dynamics.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/molecular-dynamics
python -m http.server 8000
# open http://localhost:8000
```
