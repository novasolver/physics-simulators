# 仮説検定（z検定・t検定）

仮説検定（z検定・t検定）をインタラクティブに実施。p値・棄却域・Cohen's dをリアルタイム計算し、統計的有意性を検証。エンジニア向け統計解析ツール。

**Category:** 数理・統計

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/hypothesis-test.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/hypothesis-test.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/hypothesis-test.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/hypothesis-test
python -m http.server 8000
# open http://localhost:8000
```
