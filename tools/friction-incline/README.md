# 摩擦・斜面シミュレーター

傾斜角・質量・静止/動摩擦係数をスライダーで操作。斜面上の物体に働く重力・垂直抗力・摩擦力を可視化し、加速度・臨界傾斜角をリアルタイム計算します。

**Category:** 力学・摩擦

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/friction-incline.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/friction-incline.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/friction-incline.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/friction-incline
python -m http.server 8000
# open http://localhost:8000
```
