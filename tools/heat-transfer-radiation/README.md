# 輻射熱伝達計算シミュレーター

輻射熱伝達計算ツールでStefan-Boltzmann則に基づく放射熱流束を簡単シミュレーション。表面温度や放射率、面積を入力するだけで熱流束をリアルタイム計算。熱流束曲線と輻射抵抗も視覚的に確認できるNovaSolverの無料ツールです。

**Category:** 熱解析

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/heat-transfer-radiation
python -m http.server 8000
# open http://localhost:8000
```
