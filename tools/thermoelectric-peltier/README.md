# ペルチェ素子・熱電変換計算機

ペルチェ素子の冷却性能とゼーベック発電効率を無料で計算できるオンラインツールです。Bi₂Te₃などの材料を選択し、冷却能力QcやCOP、最大温度差ΔTmax、最適動作電流をリアルタイムで自動計算。熱電変換モジュールの設計・評価をサポートします。

**Category:** 熱解析
