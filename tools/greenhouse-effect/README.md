# 温室効果・地球温暖化シミュレーター

温室効果ガスシミュレーター：CO₂・CH₄・N₂Oの濃度変化による放射強制力と気温変動をリアルタイム可視化。エネルギーバランスモデルで地球温暖化メカニズムを解析。

**Category:** 地球科学・気候

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/greenhouse-effect.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/greenhouse-effect.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/greenhouse-effect.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/greenhouse-effect
python -m http.server 8000
# open http://localhost:8000
```
