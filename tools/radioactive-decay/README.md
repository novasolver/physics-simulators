# 放射性崩壊・半減期計算機

放射性崩壊・半減期計算機は、C-14やU-235など主要な核種の崩壊をリアルタイムでシミュレーション。半減期や崩壊定数の自動計算、崩壊連鎖の可視化グラフで、年代測定や放射線の減衰を直感的に理解できます。無料で簡単に使えるオンライン計算ツールです。

**Category:** 物理シミュレーター
