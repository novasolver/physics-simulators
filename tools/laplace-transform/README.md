# ラプラス変換・逆変換シミュレーター

ラプラス変換・逆変換シミュレーター：部分分数展開・極零点マップをリアルタイム計算。時間領域と周波数領域を可視化して制御工学の動的解析に対応。

**Category:** 制御工学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/laplace-transform.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/laplace-transform.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/laplace-transform.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/laplace-transform
python -m http.server 8000
# open http://localhost:8000
```
