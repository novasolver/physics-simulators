# 複合（サバテ）サイクル — 定容+定圧 ハイブリッド加熱

現代ディーゼル機関の理想サイクルである複合（サバテ）サイクルを可視化するツールです。圧縮比・圧力上昇比・締切り比・比熱比を変えると、熱効率・各点の温度と圧力・定容加熱と定圧加熱の割合がリアルタイムで分かり、P-V線図のアニメーションとオットーサイクルとの効率比較が見られます。

**Category:** 熱力学
