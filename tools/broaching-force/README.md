# ブローチ加工の引抜力シミュレーター

多数の刃が同時に切削するブローチ加工の引抜力と切削動力をリアルタイム計算します。切削幅・一刃あたり切込量・比切削抵抗・同時切削歯数・引抜速度を変えて、ブローチマシンの能力選定や工具設計に活用できます。

**Category:** 加工技術

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/broaching-force
python -m http.server 8000
# open http://localhost:8000
```
