# 電場・電位分布可視化シミュレーター

複数の点電荷が作る電位分布を赤青カラーマップで可視化。等電位線・電場ベクトルをリアルタイムで描画します。双極子・反発電荷・多重極の構造を直感的に理解できます。

**Category:** 電磁気学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/electric-potential-field.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/electric-potential-field.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/electric-potential-field.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/electric-potential-field
python -m http.server 8000
# open http://localhost:8000
```
