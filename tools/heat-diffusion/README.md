# 2D熱拡散シミュレーター

2D熱拡散シミュレーターで、フーリエの熱方程式をリアルタイムに体験。クリックで熱源を配置し、材料や境界条件を自由に変更。鋼材・銅・木材の熱拡散率の違いを視覚的に学び、温度場の時間発展を観察できます。熱伝導の基礎をインタラクティブに理解する教育ツールです。

**Category:** 対話型シミュレーター
