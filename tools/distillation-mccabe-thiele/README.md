# McCabe-Thiele 法による蒸留段数シミュレーター

McCabe-Thiele法による蒸留段数シミュレーターで、平衡曲線と操作線から理論段数を求める。還流比感度や組成到達性を可視化し、蒸留設計の分離難度を評価。

**Category:** 対話型シミュレーター
