# フィン熱伝達シミュレーター

NovaSolverのフィン熱伝達シミュレーターは、矩形、三角形、環状フィンからフィンアレイまで、様々な形状の効率と温度分布をリアルタイムで可視化。最適なフィン設計と間隔をシミュレーションし、伝熱性能の向上を支援します。熱設計の効率化と最適化に役立つツールです。

**Category:** 熱解析シミュレーター

## Live demos

- 🇺🇸 [English](https://novasolver.jp/en/tools/fin-heat-transfer.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/fin-heat-transfer
python -m http.server 8000
# open http://localhost:8000
```
