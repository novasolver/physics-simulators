理論・主要公式
有効磁界: $H_e = H + \alpha M$
非可逆磁化: $M_{an}= M_s \coth\!\left(\tfrac{H_e}{a}\right) - \tfrac{a}{H_e}$
磁束密度: $B = \mu_0(H + M)$
損失: $W = \mu_0 \oint H\,dM$

磁気ヒステリシスとは

🙋
磁気ヒステリシスって何ですか？画面に描かれる輪っか（ループ）が何を表しているのかよく分かりません。
🎓
大まかに言うと、磁石の「記憶力」と「頑固さ」を表す現象だよ。横軸の磁界H（磁石を磁化させる力）を強くしたり弱くしたりしても、縦軸の磁束密度B（磁石の強さ）がすぐには追いつかず、遅れて変化するんだ。その遅れの軌跡がループになる。シミュレーターの「印加磁界振幅」スライダーを動かすと、ループの横幅が変わるのがわかるよ。これが材料の「頑固さ」の目安になるんだ。
🙋
え、そうなんですか！じゃあ、材料を「軟鉄」から「ハード磁石」に変えると、ループがすごく太くなるのは、もっと「頑固」になるから？
🎓
その通り！ハード磁石は一度磁化すると、逆向きの強い磁界（保磁力Hc）をかけないと磁化がゼロに戻らない、つまり「記憶力」が強い永久磁石だ。ループが太いほど、その面積に比例した「ヒステリシス損失」という無駄な熱が発生する。モーターの鉄心に使ったら効率が悪くて発熱ばかりしてしまうね。逆に「トランスコア」はループが細くて損失が小さい、優等生材料なんだ。
🙋
損失が面積で決まるんですね…。でも、なぜループができるんですか？材料の中で何が起きているの？
🎓
良い質問だ！磁性体の中には「磁区」という小さな磁石の部屋がたくさんあって、その壁（磁壁）が動くことで全体が磁化するんだ。この壁が材料中の不純物に引っかかる（ピン留めされる）と、動き出すのに余計なエネルギーが必要で、戻るときも別の引っかかりがある。これが「遅れ」の正体だ。Jiles-Athertonモデルはこのピン留め効果を数式化している。シミュレーターで「飽和磁化」を変えると、磁石の部屋の最大サイズが変わるから、ループの上下の高さ（残留磁束密度Br）が変化するよ。操作してみて！

よくある質問

磁界Hの振幅や周波数が極端に大きいと、Jiles-Athertonモデルの収束計算が不安定になる場合があります。まずはHの最大値を小さく（例：500 A/m以下）して試してください。また、パラメータaやkの値を初期値（例：a=1000, k=1500）から大きく変更しすぎないように注意してください。
Msは飽和磁化（材料固有値）、aは磁壁相互作用の形状係数、kはピン留め強度、cは可逆磁化の割合、αは平均磁界係数です。まずは標準的な軟磁性材料（例：Ms=1.6e6, a=1000, k=1500, c=0.1, α=1e-5）から始め、B-Hループの角張りや傾きを見ながら微調整してください。
表示される損失はJ/m³/cycle（1サイクルあたりの体積損失）です。これに材料の体積（m³）と動作周波数（Hz）を掛けると、W単位の電力損失が得られます。例えば変圧器鉄心の設計では、この損失値に積層係数や温度補正を加えて総損失を見積もります。
現バージョンではアニメーション速度の直接変更機能はありませんが、スライダーでHの掃引速度（周波数）を調整することで実質的に速度変更が可能です。また、任意の磁界値でループを確認したい場合は、Hの振幅をその値に固定し、掃引回数を1回に設定して再生してください。

実世界での応用

変圧器・インダクタの鉄心：電力損失と発熱を抑えるため、ヒステリシスループが細く（保磁力Hcが小さく）、損失Wが最小の軟磁性材料（例：方向性ケイ素鋼板、アモルファス合金）が選ばれます。シミュレーターの「トランスコア」がこれに近い特性です。

永久磁石（モーター・スピーカー）：一度磁化したらその強さを長く保つ必要があるため、残留磁束密度Brと保磁力Hcが共に大きな硬磁性材料（例：ネオジム磁石、フェライト磁石）が使われます。シミュレーターの「ハード磁石」が該当します。

磁気記録媒体（HDD、磁気テープ）：情報のビットを微細な磁区の向きで記録します。書き込み時には局所的に磁化を反転させ、読み出し時にはその状態が安定に保持される必要があるため、適度な保磁力を持つ材料が研究されます。

非破壊検査・磁気シールド：材料の磁気特性の違いをヒステリシスループで評価し、内部の欠陥を検出したり、外部磁場から精密機器を守るシールド材の設計に活用されます。シミュレーターで材料を切り替える行為は、まさにこの材料選定プロセスに相当します。

よくある誤解と注意点

このシミュレーターを使い始めるとき、いくつかつまずきやすいポイントがあるよ。まず「保磁力Hcが大きい材料＝良い磁石」という短絡的な考え方。確かにハード磁石はHcが大きいけど、用途によって「良い」の基準は全く違うんだ。例えば、スピーカーの磁気回路には、ある程度Hcが大きくて温度変化に強い（減磁しにくい）材料が求められる。一方、モーターのコアはHcが小さい（ループが細い）軟鉄材料が必須で、ここにハード磁石を使ったら発熱だらけで回らない。材料選択は「何を実現したいか」から逆算してね。

次にパラメータ設定の落とし穴。シミュレーター上で「飽和磁化」や「分子場係数α」を自由に変えられるけど、現実の材料はこれらのパラメータが互いに独立じゃないんだ。例えば、フェライトのαをむやみに大きくしすぎると、非物理的なループ形状（例えば、角張りすぎたり）が出ることがある。実務でJ-Aモデルのパラメータを同定する時は、実測のB-Hループデータにフィッティングさせて、一組のパラメータ群として決定するのが鉄則だ。例えば、あるフェライト材では $M_s=3.2\times10^5$ [A/m], $a=50$ [A/m], $α=0.001$ といった具合に、バランスの取れた値のセットになるよ。

最後に、「シミュレーションのループ面積＝そのまま発熱量」と思い込むこと。確かにヒステリシス損失Wはループ面積に比例するけど、実際の機器での発熱は、これに「渦電流損失」が加わることを忘れてはいけない。特に交流磁界中では周波数が高くなるほど渦電流損失が支配的になる。このツールで「トランスコア」を選んで周波数を上げてもループ形状は変わらない（渦電流を考慮してないから）けど、現実では薄い珪素鋼板を積層する理由は、まさにこの渦電流を抑えるためなんだ。

使い方ガイド

  1. 飽和磁化Ms（A/m）を入力：軟磁性鉄芯の場合1.7×10⁶、ハードフェライトの場合3.8×10⁵を目安に設定
  2. 保磁力Hc（A/m）を入力：軟鋼は40、アルニコ磁石は5.1×10⁴、サマリウムコバルトは9.2×10⁵の値を参照
  3. 残留磁束密度Br（T）を入力：電磁鋼板は1.5～2.0、永久磁石は0.2～1.4の範囲で設定
  4. 最大磁場Hmax（A/m）を入力：シミュレーション計算範囲を決定（通常5.0×10⁴～1.0×10⁵）
  5. 「計算実行」ボタンでJiles-Athertonモデルに基づくB-Hループをリアルタイム描画
  6. 損失値と透磁率μr最大値をグラフ下部の統計値から確認

具体的な計算例

珪素鋼板（方向性電磁鋼板）のB-Hループ解析：Ms=1.72×10⁶A/m、Hc=48A/m、Br=1.92T、Hmax=8.0×10⁴A/mを入力した場合、計算結果はBHmax=502kJ/m³、ヒステリシス損失4.8kJ/m³/cycle、最大相対透磁率μr=2850となります。50Hz駆動時の電力損失は240W/m³に相当し、トランス鉄芯設計の効率評価に用います。

実務での注意点

  • 軟磁性材料（鉄粉、珪素鋼）はHc値が小さいため、Hmax設定を適切に（通常500～5000A/m）しないと飽和領域を正確に捉えられない
  • 永久磁石材料（ネオジム、フェライト）は第二象限のB-Hループが重要：逆磁場印加時の減磁特性をHc値で厳密に管理する必要があります
  • 温度変化による飽和磁化低下（一般に℃あたり0.1～0.3%）は本シミュレーターには未反映のため、実測値との比較時に補正が必要
  • 周波数上昇によるヒステリシス損失増加（f²に比例）：50Hzから400Hzへの運転条件変更では損失が64倍になるため、冷却設計を検討してください
