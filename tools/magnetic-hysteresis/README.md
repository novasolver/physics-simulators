# 磁気ヒステリシスシミュレーター

磁気ヒステリシスシミュレーターはJiles-Athertonモデルで磁性材料のB-Hループをリアルタイム計算。保磁力・ヒステリシス損失・残留磁束密度の解析に最適です。

**Category:** 電磁気学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/magnetic-hysteresis.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/magnetic-hysteresis.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/magnetic-hysteresis.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/magnetic-hysteresis
python -m http.server 8000
# open http://localhost:8000
```
