# 蒸気圧縮冷凍サイクル計算ツール

蒸気圧縮冷凍サイクルのP-h線図をリアルタイムで可視化し、COP・冷凍効果・圧縮仕事を即座に計算できるシミュレーターです。冷媒R134a、R410A、R290に対応。蒸発温度や凝縮温度、圧縮機効率を調整して、効率的な冷凍サイクルの設計と学習をサポートします。

**Category:** 熱力学
