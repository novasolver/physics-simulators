# 同軸ケーブル特性インピーダンス計算機 — Z_0 と伝搬速度

内導体半径・外導体内径・誘電体の比誘電率を変えて、同軸ケーブルの特性インピーダンス Z_0・速度因子・単位長キャパシタンス／インダクタンスがどう決まるかを直感的に学べます。

**Category:** 電磁気・伝送線路シミュレーター
