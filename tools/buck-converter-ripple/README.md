# 降圧コンバータのインダクタ電流リップルシミュレーター

降圧コンバータのインダクタ電流リップル解析シミュレーター。L/C定数と周波数設計の不足を把握し、スイッチング波形とリップルマップから最適値を検証できます。

**Category:** 対話型シミュレーター

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/buck-converter-ripple.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/buck-converter-ripple.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/buck-converter-ripple.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/buck-converter-ripple
python -m http.server 8000
# open http://localhost:8000
```
