# 反応拡散シミュレーター

反応拡散シミュレーターでGray-Scottモデルによるチューリングパターン生成。拡散係数やフィード率をリアルタイム調整してパターン形成をシミュレート。

**Category:** 自己組織化

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/reaction-diffusion.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/reaction-diffusion.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/reaction-diffusion.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/reaction-diffusion
python -m http.server 8000
# open http://localhost:8000
```
