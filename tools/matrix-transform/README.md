# 行列変換ビジュアライザー — 線形代数の幾何学的意味

行列変換ビジュアライザー「NovaSolver」は、2×2行列による線形変換を幾何学的にリアルタイム可視化。回転やスケーリング、せん断、固有ベクトルを直感的なアニメーションで理解でき、行列式や固有値も即時計算。線形代数の本質を視覚的に学べるシミュレーターです。

**Category:** 線形代数・数値解析

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/matrix-transform.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/matrix-transform.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/matrix-transform
python -m http.server 8000
# open http://localhost:8000
```
