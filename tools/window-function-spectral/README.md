# 窓関数のスペクトル特性比較 — メインローブ幅とサイドローブ抑圧

窓関数のスペクトル特性を比較。矩形・Hann・Hamming・Blackman窓のメインローブ幅とサイドローブ特性をシミュレータで可視化。漏れスペクトル抑制と周波数分解能のトレードオフを学習できます。

**Category:** 信号処理シミュレーター
