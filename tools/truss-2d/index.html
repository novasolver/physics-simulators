各部材の剛性マトリクスをアセンブルして全体剛性方程式を構成：

$$[K]\{u\}=\{F\}$$

部材軸力（変位から計算）：

$$f = \frac{EA}{L}\bigl[(u_j-u_i)\cos\theta + (v_j-v_i)\sin\theta\bigr]$$

部材剛性マトリクス（局所系）：$k = \dfrac{EA}{L}$，全体系へ座標変換して加算。

平面トラス解析（節点法）とは

🙋
このシミュレーターで「直接剛性法」って何をしているんですか？ 荷重をかけると、なぜ軸力や変位が一瞬で計算できるんですか？
🎓
大まかに言うと、トラスの各部材をバネに見立てて、全体を一つの大きな連立方程式で解いているんだ。上の「弾性係数 E」や「断面積 A」のスライダーを動かすと、このバネの硬さが変わる。シミュレーターは、荷重がかかった時に、すべての節点がつり合う位置を一気に計算して、各部材が引っ張られているか（赤）、押しつぶされているか（青）を色で教えてくれるんだよ。
🙋
え、そうなんですか！ でも、ワーレントラスとKトラスで、結果の色のパターンが全然違います。形によって力の伝わり方が変わるということですか？
🎓
その通り！ 例えば、プラットトラスは斜め材が引張になることが多く、実務では鋼材を効率的に使える設計として橋梁でよく使われる。シミュレーターで「プラットトラス」を選んで、真ん中の節点に下向き荷重をかけてみて。斜め材が赤（引張）になるのが確認できるよ。一方で「Kトラス」は、部材が細かく分かれて圧縮材が短くなるので、座屈しにくい構造なんだ。
🙋
なるほど！ でも、この計算結果って実際の設計で信用できるんですか？ 数式で出てくる「全体剛性マトリクス[K]」って何者なんですか…。
🎓
良い質問だね。このシミュレーターの根幹は、まさにその「全体剛性マトリクス[K]」を組み立てて解くことなんだ。これは、ANSYSやAbaqusといった本格的なCAEソフトが内部でやっている計算の基礎そのもの。パラメータ「E」や「A」を変えると、このマトリクスの値が変わり、解である変位{u}が変わる。だから、材料を鋼からアルミに変えた時の挙動を、すぐにシミュレートできるんだ。

よくある質問

単位系は特に指定されていませんが、N（ニュートン）とmm（ミリメートル）の組み合わせを推奨します。例えば、1000Nの荷重を加える場合は「1000」と入力してください。整合性が取れていれば、kNとmなど他の単位系でも計算可能です。
赤色は引張軸力、青色は圧縮軸力を表しています。リアルタイムで色が変化するため、どの部材に引張・圧縮が生じているか直感的に把握できます。色の濃さは軸力の大きさに比例し、濃いほど大きな力がかかっています。
特異になる原因は、節点に拘束条件（固定・ピン支持など）が不足していることです。少なくとも1節点のx,y方向を固定し、別の節点で回転を止める必要があります。また、すべての節点が一直線上に並んでいないかも確認してください。
入力した荷重の大きさと、部材の断面積・ヤング率のバランスを確認してください。例えば、断面積を1mm²、ヤング率を200GPa（鋼）とした場合、1000Nの荷重で数mm程度の変位が目安です。極端な値の場合は単位系のミスが疑われます。

実世界での応用

橋梁設計：プラットトラスやワーレントラスは、鉄道橋や道路橋の基本形式です。シミュレーターで荷重位置を変えながら、どの部材が最大の引張力や圧縮力を受けるかを調べ、最適な断面積Aを決定する初期設計に活用されます。

建築構造（屋根・トラスフレーム）：体育館や工場の大空間を覆う屋根トラスに応用されます。雪荷重や風荷重を様々な節点にかけることで、部材軸力の分布を把握し、接合部（ガセットプレート）の設計に重要な情報を提供します。

建設機械（クレーンブーム）：移動式クレーンのブームは、軽量かつ高い強度が要求されるKトラス構造が多用されます。吊り上げ荷重（シミュレーターの節点荷重）に対する変形量を計算し、作業時のたわみ制限を満たすかを確認します。

CAEソフトウェアの前処理・検証：ANSYSのLINK180要素やAbaqusのT2D2要素は、ここで使っているのと同一定式化です。本格解析前に、このシミュレーターでモデルの構成や境界条件の設定が正しいかを簡易チェックする用途もあります。

よくある誤解と注意点

このシミュレーターを使い始めるとき、いくつか気をつけてほしいポイントがあるよ。まず、「変位が小さすぎて見えない！計算がおかしいのでは？」という声をよく聞く。実際の鋼橋（E=205 GPa）で、断面積1000 mm²の部材に10 kNの荷重をかけたら、伸びはほんのミクロン単位だ。シミュレーターでは視認性のために変位を誇張表示していることを忘れずに。実務ではこの計算結果を信頼するが、「支持条件」のモデル化には要注意。ここでは単純なピン支持だが、実際の構造物では回転や移動がある程度拘束されることも多く、それが結果を大きく変えるんだ。

次に、パラメータ「E」と「A」の設定。例えば「A」を極端に小さくすると、軸力は変わらないが変位が膨大になり、現実的でなくなる。逆に「E」を木材の値（約10 GPa）にすると、鋼（約200 GPa）と比べて同じ荷重で約20倍の変位になる。材料を変えた影響を評価するのは良いが、部材が極端に細長くなると座屈という別の現象が支配的になるので、このツールの結果だけでは安全判断できない点に注意しよう。

最後に、「ゼロ部材」の見落とし。荷重がかかっていない特定の節点では、力のつり合いから軸力が0になる部材がある。シミュレーターでは軸力0は黒表示かもしれないが、設計上は「必要ない部材」ではなく、構造形状を保つために必要な部材であることが多い。Kトラスなどで確認してみてほしい。

使い方ガイド

  1. プリセットを選び、ヤング率E(GPa)と部材断面積A(cm²)を設定します。既定例は鋼材E=200GPa、A=10cm²です
  2. 必要に応じて荷重表で各節点のX方向・Y方向荷重fx、fy(kN)を編集します。節点座標と支点条件はプリセット形状に固定されています
  3. 入力を変更すると直接剛性法で自動計算され、全節点の変位と全部材の軸力が更新されます
  4. 最大引張力・最大圧縮力・最大変位を確認し、カラーマップで引張(赤)・圧縮(青)の分布を確認します

具体的な計算例

既定の「シンプルビーム」プリセットでE=200GPa、A=10cm²、節点3と節点4にそれぞれ下向き20kNを載荷すると、最大引張力は13.3kN、最大圧縮力は-24.0kN、最大変位は0.438mmです。重複部材を除いた節点数/部材数は5 / 7として表示されます。

実務での注意点

  • 部材接続の誤入力はマトリックスの特異性を招く。支点反力の合計が外力に等しいことで妥当性を確認すること
  • 断面積が極端に異なる部材がある場合、剛性比が大きくなり数値計算の精度が低下。相対誤差1%以内を目安に収束判定
  • 座標入力時の単位統一が重要：mm入力の場合、荷重はkN、結果変位はmmとなるため計算係数1000を適用
  • 圧縮部材の座屈を考慮する場合、オイラー公式で座屈荷重を別途計算し、許容値と比較が必要
