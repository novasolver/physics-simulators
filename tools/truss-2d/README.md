# 平面トラス解析（節点法）

平面トラス解析で節点法とFEMを用いて軸力・変位を計算。引張圧縮をカラー表示するCAEツール。トラス構造設計に必要な剛性マトリックス解析を実装。

**Category:** 構造解析

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/truss-2d.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/truss-2d.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/truss-2d.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/truss-2d
python -m http.server 8000
# open http://localhost:8000
```
