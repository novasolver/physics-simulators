# 大豆発芽率 温度・水分依存モデル

大豆の出芽は地温・土壌水分・播種深・土壌硬度の組合せで決まります。本ツールは品種別係数と圃場条件から、単一日の発芽率、有効積算温度、累積発芽率、出芽日数、予測収量までを一括計算し、播種計画の意思決定を支援します。

**Category:** 農学・種子発芽
