# 理想気体シミュレーター

温度・体積・モル数を動かして圧力をリアルタイム計算。P-V線図・P-T線図・V-T線図の3タブで「ボイルの法則」「シャルルの法則」「状態方程式」を直感的に体感できます。

**Category:** 熱力学 / 高校物理

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/gas-laws.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/gas-laws.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/gas-laws.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/gas-laws
python -m http.server 8000
# open http://localhost:8000
```
