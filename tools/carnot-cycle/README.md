# カルノーサイクルシミュレーター

高温・低温熱源の温度を動かすたびに、P-V図とT-S図、そしてカルノー効率がその場で更新。等温膨張・断熱膨張・等温圧縮・断熱圧縮がどう連なっているかを目で追って理解できます。

**Category:** 熱力学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/carnot-cycle.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/carnot-cycle.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/carnot-cycle.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/carnot-cycle
python -m http.server 8000
# open http://localhost:8000
```
