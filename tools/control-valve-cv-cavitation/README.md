# 調節弁 Cv とキャビテーション係数シミュレーター

調節弁Cvとキャビテーション係数シミュレーター。流量・差圧・蒸気圧から必要Cv値、開度余裕、キャビテーションリスクを評価。制御弁設計・選定に必須のツール。

**Category:** 対話型シミュレーター
