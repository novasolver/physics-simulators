# 重ね合わせ法 梁の変形計算ツール

単純支持梁に集中荷重・分布荷重・集中モーメントを最大3つまで重ね合わせ。たわみ曲線と曲げモーメント図をリアルタイム描画し、最大たわみ・反力・端部勾配を瞬時に算出します。

**Category:** 構造解析

git clone https://github.com/novasolver/physics-simulators

python -m http.server 8000
