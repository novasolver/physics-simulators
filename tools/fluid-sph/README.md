# SPH流体シミュレーター

SPH流体シミュレーターで液体の流れをリアルタイム解析。粘性・表面張力・乱流を粒子法でシミュレーション。CAE・CFD解析に対応。

**Category:** 流体力学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/fluid-sph.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/fluid-sph.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/fluid-sph.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/fluid-sph
python -m http.server 8000
# open http://localhost:8000
```
