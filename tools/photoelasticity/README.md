# 光弾性応力解析 — 等色縞パターン可視化

光弾性応力解析で等色縞パターンを可視化し、主応力差をリアルタイム確認。試験片形状や荷重による応力分布をFEM検証に活用する光弾性実験シミュレーション。

**Category:** 実験的応力解析

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/photoelasticity.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/photoelasticity.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/photoelasticity.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/photoelasticity
python -m http.server 8000
# open http://localhost:8000
```
