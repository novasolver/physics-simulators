# ガルバニック系列・異種金属腐食計算機

ガルバニック腐食計算機：海水中20種金属の電位系列を可視化し、任意の異種金属カップルのEMF・腐食電流密度・リスクレベルを即時計算。面積比の影響を考慮した混成電位モデルで腐食促進係数を算出し、20×20適合性マトリクスで組み合わせの危険度を一目で評価できます。

**Category:** 材料・破壊
