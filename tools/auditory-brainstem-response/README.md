# 聴性脳幹反応 ABR シミュレーター

聴性脳幹反応（ABR, Auditory Brainstem Response）の Wave I-V 潜時、Inter-Peak Interval、SNR 改善、推定聴力閾値を計算する無料シミュレーター。新生児聴覚スクリーニング・後迷路性病変診断・術中聴神経モニタリングの教育用ツールです。

**Category:** 医工学・聴覚診断

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/auditory-brainstem-response
python -m http.server 8000
# open http://localhost:8000
```
