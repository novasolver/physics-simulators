# 固有振動数計算

NovaSolverの固有振動数計算ツールで、片持ち梁・両端支持梁・固定梁、円板・矩形膜の振動解析を簡単に。境界条件と形状を入力するだけで、複数の振動モードと固有振動数を即座に計算。モード形状のアニメーション可視化で、設計や研究開発を強力にサポートします。

**Category:** 振動解析

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/frequency-natural
python -m http.server 8000
# open http://localhost:8000
```
