# DNA複製シミュレーター

ヘリカーゼが二重らせんをほどき、DNA ポリメラーゼ III が新しい鎖を合成する複製過程を可視化。先行鎖の連続合成と遅れ鎖の岡崎フラグメントの違いをリアルタイムアニメで観察できます。

**Category:** 分子生物学シミュレーション

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/dna-replication.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/dna-replication.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/dna-replication.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/dna-replication
python -m http.server 8000
# open http://localhost:8000
```
