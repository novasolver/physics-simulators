# 箱の中の粒子（無限井戸型ポテンシャル）

量子力学の基礎：箱の中の粒子（無限井戸型ポテンシャル）の波動関数・エネルギー準位をインタラクティブに可視化。電子・陽子・中性子の量子数n=1〜8までのψₙ(x)と確率密度|ψₙ|²をリアルタイム描画。重ね合わせ状態の時間発展アニメーションも。

**Category:** 物理シミュレーター
