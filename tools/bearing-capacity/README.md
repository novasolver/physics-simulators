# 地盤の支持力計算機（テルツァーギ・マイヤーホフ）

地盤支持力計算機でテルツァーギ・マイヤーホフ式に基づく極限支持力と許容支持力をリアルタイム計算。粘着力や内部摩擦角、基礎幅などのパラメータをスライダーで簡単調整し、即座に結果を確認できます。沈下量や偏心荷重の補正にも対応した無料オンラインシミュレーターです。

**Category:** 地盤工学
