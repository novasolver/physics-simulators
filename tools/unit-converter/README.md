# 単位変換計算機（エンジニアリング全般）

長さ・質量・力・圧力・温度・エネルギー・粘度・熱伝導率など 16 カテゴリ、100 種以上の工学単位を一括変換するエンジニアリングツール。Abaqus/LS-DYNA で必須の SI と mm-tonne-s 系もサポートし、CAE 主要単位をハイライト表示します。

**Category:** 機械力学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/unit-converter.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/unit-converter.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/unit-converter.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/unit-converter
python -m http.server 8000
# open http://localhost:8000
```
