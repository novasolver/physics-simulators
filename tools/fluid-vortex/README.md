# 渦流れ シミュレーター

自由渦・強制渦・ランキン渦の速度分布 vθ(r) と圧力分布 p(r) をリアルタイム可視化。パラメータを操作してキャビテーション発生も予測しよう。

**Category:** 流体力学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/fluid-vortex.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/fluid-vortex.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/fluid-vortex.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/fluid-vortex
python -m http.server 8000
# open http://localhost:8000
```
