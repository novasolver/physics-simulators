# ファブリー・ペロー干渉計シミュレーター — フィネスと透過スペクトル

2枚の高反射ミラーの間で多重干渉する光のAiry透過スペクトルを可視化。自由スペクトル領域FSR・フィネス・FWHM・Q値をリアルタイム計算します。

**Category:** 光学シミュレーター
