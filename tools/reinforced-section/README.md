# 鉄筋コンクリート断面解析（曲げ・せん断）

鉄筋コンクリート断面の曲げ耐力（φMn）や中立軸を、ACI 318準拠のホイットニー応力ブロック法で即座に計算できる無料オンラインシミュレーターです。梁幅、有効せい、鉄筋量、材料強度を入力するだけで、断面性能とひずみ図をリアルタイムに解析。設計・学習に最適なツールです。

**Category:** 構造解析
