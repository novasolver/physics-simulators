# 翼型揚力シミュレーター — NACA薄翼理論

NACA薄翼理論に基づき、翼型の揚力係数・抗力係数・L/D比をリアルタイムでシミュレーション。迎え角や翼弦、風速などのパラメータを自由に変更して、揚力と抗力の関係を視覚的に学べます。航空力学の理解を深める直感的な翼型揚力シミュレーターです。

**Category:** 空力シミュレーター
