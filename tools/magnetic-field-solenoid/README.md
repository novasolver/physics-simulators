# ソレノイド磁場計算シミュレーター

ソレノイド磁場計算シミュレーター - 巻数・電流・長さから内部磁場・軸上磁場分布・インダクタンスをリアルタイム計算。電磁気設計・コイル解析に対応。

**Category:** 電磁気学・電磁石設計

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/magnetic-field-solenoid.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/magnetic-field-solenoid.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/magnetic-field-solenoid.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/magnetic-field-solenoid
python -m http.server 8000
# open http://localhost:8000
```
