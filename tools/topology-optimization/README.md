# トポロジー最適化（SIMP法）シミュレーター

トポロジー最適化（SIMP法）シミュレーターで構造最適化を実現。材料配置の反復計算を可視化、密度法・ペナルティ係数・荷重条件を設定して最適な部品形態を探索できます。

**Category:** 構造最適化

- 🇺🇸 [English](https://novasolver.jp/en/tools/topology-optimization.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/topology-optimization
python -m http.server 8000
# open http://localhost:8000
```
