# ボーズ・アインシュタイン分布 シミュレーター — ボソンの量子統計

化学ポテンシャル μ・温度 T・エネルギー E からボソンの占有数 n_BE(E) を可視化。マクスウェル・ボルツマン分布との比較と E→μ での発散（BEC 兆候）をリアルタイムに学べます。

**Category:** 統計力学シミュレーター
