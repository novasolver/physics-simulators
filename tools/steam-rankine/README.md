# 水蒸気・ランキンサイクル計算機

NovaSolverの無料オンライン計算機で、ランキンサイクルの熱効率や仕事量を簡単シミュレーション。ボイラーや復水器の圧力、タービン効率を設定するだけで、T-s線図と計算結果がリアルタイム表示。再熱サイクルにも対応した、火力発電や蒸気タービンの設計・学習に最適なツールです。

**Category:** 熱解析

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/steam-rankine
python -m http.server 8000
# open http://localhost:8000
```
