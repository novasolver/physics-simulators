# 複素数・フェーザー計算機

直交形式・極形式での四則演算・べき乗・平方根をリアルタイム計算し、アルガン図にベクトル描画。交流回路インピーダンス（ZR/ZL/ZC）とフェーザー回転アニメーションも対応。

**Category:** 電磁気・光学

git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/complex-numbers
python -m http.server 8000
