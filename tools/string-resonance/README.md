# 弦の共鳴・定在波シミュレーター

弦の共鳴・定在波シミュレーター。張力・線密度から固有モード・基本周波数・倍音をリアルタイム計算・可視化。定在波解析に最適。

**Category:** 構造振動 / 波動物理
