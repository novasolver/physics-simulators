# モンテカルロ法で π を推定 — visual 入門デモ

モンテカルロ法によるπ推定の可視化デモ。乱数サンプリングと単位円判定でπを数値計算、収束過程をリアルタイム表示。確率的シミュレーション学習に最適。

**Category:** 数理・統計

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/monte-carlo-pi.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/monte-carlo-pi.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/monte-carlo-pi.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/monte-carlo-pi
python -m http.server 8000
# open http://localhost:8000
```
