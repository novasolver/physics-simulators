# テイラー展開・近似精度可視化

テイラー展開の近似精度を可視化。sin、cos、eˣなど関数の次数・展開点による誤差・収束半径の変化を直感的に学習。数値計算・CAE解析の基礎理解に。

**Category:** 数理・統計

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/taylor-series.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/taylor-series.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/taylor-series.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/taylor-series
python -m http.server 8000
# open http://localhost:8000
```
