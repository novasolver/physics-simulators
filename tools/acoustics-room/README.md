# 室内音響シミュレーター

部屋の寸法と吸音材を変えてSabineのRT60と固有モード周波数をリアルタイム計算。コンサートホールから会議室まで最適な音響設計を探索しよう。

**Category:** 音響工学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/acoustics-room.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/acoustics-room.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/acoustics-room.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/acoustics-room
python -m http.server 8000
# open http://localhost:8000
```
