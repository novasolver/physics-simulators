# 空気圧回路計算機

空気圧回路の設計に必要なシリンダ推力や空気消費量、Cv値、圧力降下などをリアルタイムで計算できる無料オンライン計算機です。工場自動化や産業機械の設計を支援し、効率的な空気圧回路設計を実現します。NovaSolverの直感的なツールを今すぐお試しください。

**Category:** 流体解析

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/pneumatic-circuit.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/pneumatic-circuit
python -m http.server 8000
# open http://localhost:8000
```
