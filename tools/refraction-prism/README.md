# プリズム・光の屈折シミュレーター

入射角・プリズム頂角・ガラスの種類を変えて光の屈折・分散・全反射をリアルタイム可視化。スネルの法則・偏角・虹のメカニズムを直感的に理解できます。

**Category:** 光学・波動

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/refraction-prism.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/refraction-prism.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/refraction-prism.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/refraction-prism
python -m http.server 8000
# open http://localhost:8000
```
