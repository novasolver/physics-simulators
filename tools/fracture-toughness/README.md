# 破壊靱性試験解析ツール

破壊靱性試験解析ツール「NovaSolver」は、CT試験や3点曲げ試験のデータからKIC値の計算とASTM E399に基づく妥当性判定を自動で実施。J積分や塑性域サイズの解析、P-v曲線の可視化も可能です。鋼・アルミ・チタンなど材料の破壊力学解析を強力にサポートします。

**Category:** 破壊力学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/fracture-toughness.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/fracture-toughness.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/fracture-toughness
python -m http.server 8000
# open http://localhost:8000
```
