# 垂直軸風車 VAWT 性能設計シミュレーター — Darrieus・Savonius

垂直軸風車（VAWT: Darrieus／Savonius／ヘリカル）の出力係数 Cp、出力、翼端速度、ソリディティ、年間発電量を計算。ロータ半径・高さ・翼数・翼弦長・風速・TSR を変えて、都市・小型風車の設計を検討できる無料シミュレーターです。

**Category:** 風力エネルギー・都市風車
