# BMI・体組成計算ツール

身長・体重・年齢・性別を入力してBMI、理想体重、体脂肪率推定、基礎代謝量（BMR）をリアルタイム計算。健康管理の基礎指標を数値で把握しよう。

**Category:** 健康・生体計測

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/bmi-body-composition.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/bmi-body-composition.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/bmi-body-composition.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/bmi-body-composition
python -m http.server 8000
# open http://localhost:8000
```
