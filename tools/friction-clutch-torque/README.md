# 摩擦クラッチの伝達トルク シミュレーター

円板（プレート）式摩擦クラッチが伝えられるトルクを設計するツールです。摩擦面の内外径・押付け力・摩擦係数・対数を変えると、有効摩擦半径・伝達トルク・最大面圧がリアルタイムで分かり、滑らず・焼けないクラッチの寸法を探せます。

**Category:** 機械要素設計
