# 積層造形・3Dプリント熱計算

積層造形・3Dプリント熱計算：FDM/SLA/SLS/DMLS対応、造形時間・エネルギー密度・反り予測をリアルタイム解析。PLA/ABS/チタン合金の熱応力シミュレーション。

**Category:** 製造工学
