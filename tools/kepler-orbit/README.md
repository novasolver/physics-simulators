# ケプラー楕円軌道 体験シミュレーター — 実在天体プリセット

ハレー彗星・地球・火星・水星など実在天体の楕円軌道を、離心率と長半径を変えて体感できる学習シミュレーター。万有引力による速度変化（近日点で速く・遠日点で遅く）と等面積法則を直感アニメで理解できます。概念整理は『ケプラーの法則』、数値解は『ケプラー方程式』を併用してください。

**Category:** 宇宙力学・天体物理
