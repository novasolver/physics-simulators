# エレベーター加速度・体重変化シミュレーター

エレベーター加速度・体重変化シミュレーターで、加速度フェーズにおける見かけの体重変化を可視化。慣性力と非慣性系の物理を直感的に体験できます。加速度シミュレーション。

**Category:** 力学・慣性力

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/elevator-acceleration.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/elevator-acceleration.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/elevator-acceleration.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/elevator-acceleration
python -m http.server 8000
# open http://localhost:8000
```
