# 養魚池 エアレータ 溶存酸素 SOTR 設計

養魚池のエアレータ容量を「溶存酸素（DO）収支」から設計するツールです。池の寸法・魚種・養殖密度・水温・エアレータ種類とkWを変えると、1日のO₂需要、エアレータが実際に供給できる量、目標DOを保つために必要な電力、年間電気代がリアルタイムで分かります。

**Category:** 養殖・水質管理
