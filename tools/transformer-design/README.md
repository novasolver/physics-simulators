# トランス設計・変圧器計算ツール

トランス設計・変圧器計算ツール。巻数比・コア断面積から効率・漏れインダクタンス・磁束密度をリアルタイム計算。電源回路設計に必須の変圧器特性シミュレーター。

**Category:** 電気機器

- 🇺🇸 [English](https://novasolver.jp/en/tools/transformer-design.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/transformer-design
python -m http.server 8000
# open http://localhost:8000
```
