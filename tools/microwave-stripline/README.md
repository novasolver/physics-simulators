# マイクロストリップライン設計計算機

マイクロストリップライン設計計算機で特性インピーダンス・減衰量を即座に計算。分析・合成モード搭載、RF基板設計に必須のツール。インピーダンス計算、マイクロストリップ設計対応。

**Category:** 電磁気・光学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/microwave-stripline.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/microwave-stripline.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/microwave-stripline.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/microwave-stripline
python -m http.server 8000
# open http://localhost:8000
```
