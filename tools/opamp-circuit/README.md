# オペアンプ基本回路シミュレーター

オペアンプ基本回路の反転・非反転・積分・微分など6回路をシミュレーション。入出力波形と伝達特性をリアルタイム可視化。ゲイン・帯域幅・クリッピング確認。

**Category:** 電磁気・光学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/opamp-circuit.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/opamp-circuit.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/opamp-circuit.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/opamp-circuit
python -m http.server 8000
# open http://localhost:8000
```
