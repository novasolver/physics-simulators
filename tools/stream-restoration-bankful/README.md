# 河川復元・バンクフル流量設計シミュレーター

人工改修された河川を自然形態へ戻す復元設計のツールです。流域面積・川幅・水深・河床勾配・粒径・マニング係数を変えると、バンクフル流量、流速、幅深さ比、Rosgen河型、河床粒子の移動限界がリアルタイムで分かります。

**Category:** 水文・自然河川工学
