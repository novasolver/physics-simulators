# 振動減衰シミュレーター — SDOF減衰振動・対数減衰率

NovaSolverの振動減衰シミュレーターは、1自由度減衰振動（SDOF）の動きをリアルタイムで可視化します。不足減衰・臨界減衰・過減衰の応答を比較し、対数減衰率や整定時間をスライダーで直感的に操作。CAEシミュレーションで振動解析の理解を深めましょう。

**Category:** 構造解析
