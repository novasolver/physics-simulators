# カム・フォロワー設計計算機

カム・フォロワー設計計算機で、カム輪郭とフォロワー動作をリアルタイムアニメーションで可視化。変位・速度・加速度曲線をグラフ表示し、最大圧力角や接触応力も自動計算。SHM・サイクロイド・多項式など主要な運動則に対応した無料オンライン設計ツールです。

**Category:** 機械力学
