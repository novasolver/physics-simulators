# ポリマー粘度・流動解析ツール

ポリマー粘度・流動解析ツール。Carreau-Yasudaモデルで粘度曲線をリアルタイム計算し、射出成形CAEの初期検討を効率化。ゲート圧力損失・冷却時間算出。

**Category:** 高分子流動 / レオロジー

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/polymer-viscosity.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/polymer-viscosity.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/polymer-viscosity.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/polymer-viscosity
python -m http.server 8000
# open http://localhost:8000
```
