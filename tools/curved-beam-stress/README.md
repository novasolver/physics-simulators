# 曲がり梁応力シミュレーター

曲がり梁応力シミュレーターで曲率半径と曲げモーメントから最大応力を概算。内外縁応力差を短時間で計算できる設計支援ツール。

**Category:** 対話型シミュレーター

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/curved-beam-stress.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/curved-beam-stress.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/curved-beam-stress.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/curved-beam-stress
python -m http.server 8000
# open http://localhost:8000
```
