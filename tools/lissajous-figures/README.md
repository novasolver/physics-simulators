# リサジュー図形シミュレーター — 振動合成とパターン

リサジュー図形シミュレーター。2つの直交振動の周波数比・位相差・減衰を操作して、複雑で美しいパラメトリック曲線をブラウザでリアルタイムに描画できます。

**Category:** 振動・波形パターン

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/lissajous-figures.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/lissajous-figures.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/lissajous-figures.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/lissajous-figures
python -m http.server 8000
# open http://localhost:8000
```
