# 共振周波数シミュレーター

強制振動と共振現象をグラフィカルに学べるシミュレーターです。質量、バネ定数、減衰比をスライダーで調整し、共振周波数と共振曲線の変化をリアルタイムに可視化。振幅倍率、Q値、半値幅、位相遅れを確認でき、CAE振動解析の基礎が直感的に理解できます。

**Category:** 構造解析
