# 音響共鳴・管楽器シミュレーター

開管・閉管・ヘルムホルツ共鳴器の固有振動数と定在波をリアルタイム可視化。管の長さ・温度・倍音番号を操作して、フルート・クラリネット・ボトルの音響挙動を探ろう。

**Category:** 音響シミュレーター
