# ジャイロスコープ・歳差運動シミュレーター

ジャイロスコープの歳差運動を直感的に学べる無料オンラインシミュレーターです。スピン角速度や質量などのパラメータを調整し、リアルタイムで歳差速度や角運動量を計算・可視化。回転機械の設計から宇宙機の姿勢制御まで、物理現象の理解を深める教育ツールとして活用できます。

**Category:** 機械力学

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/gyroscope
python -m http.server 8000
# open http://localhost:8000
```
