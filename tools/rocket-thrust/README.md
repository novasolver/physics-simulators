# ロケット推力・デルタV計算ツール

ロケット推力・デルタV計算ツール：ツィオルコフスキー方程式によるΔV計算、比推力・質量比解析、実エンジン比較で設計検証を実現。

**Category:** 宇宙工学・推進工学

- 🇺🇸 [English](https://novasolver.jp/en/tools/rocket-thrust.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/rocket-thrust.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/rocket-thrust
python -m http.server 8000
# open http://localhost:8000
```
