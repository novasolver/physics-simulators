# 橋梁トラス有限要素法解析

NovaSolverの橋梁トラス有限要素法解析シミュレーター。プラットトラスやワーレントラスの軸力（引張・圧縮）をリアルタイム可視化。荷重や断面積を変更して、最大変位と応力を簡単に確認できる構造解析ツールです。直感的な操作で橋梁設計の基礎を学べます。

**Category:** 構造解析

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/bridge-truss.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/bridge-truss.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/bridge-truss
python -m http.server 8000
# open http://localhost:8000
```
