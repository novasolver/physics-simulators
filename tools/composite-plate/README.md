# 複合材料積層板 CLTシミュレーター

複合材料積層板の設計を支援する無料オンラインCLTシミュレーターです。古典積層理論に基づき、ABD行列、面内歪み、曲率、各層応力をリアルタイム計算。Tsai-WuやTsai-Hill破壊基準による強度評価も可能で、CFRP・GFRP積層板の初期設計と検証に最適です。

**Category:** 解析ツール

python -m http.server 8000
