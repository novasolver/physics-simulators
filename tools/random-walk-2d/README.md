# 2Dランダムウォーク

複数ウォーカーの軌跡と平均二乗変位（MSD）をリアルタイム可視化。格子・ガウス・レヴィフライトを切り替えて拡散則を比較。

**Category:** 確率・拡散

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/random-walk-2d.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/random-walk-2d.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/random-walk-2d.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/random-walk-2d
python -m http.server 8000
# open http://localhost:8000
```
