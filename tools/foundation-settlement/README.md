# 基礎沈下計算ツール

基礎幅・根入れ深さ・荷重・N値・土質を入力すると、テルツァーギ式で極限支持力と安全率を計算し、圧密沈下曲線を即描画。土層断面と応力球の可視化付きで、基礎設計の初期検討に使えます。

**Category:** 地盤工学
