# Diffie-Hellman 鍵共有シミュレーター — 公開鍵交換の数論

公開素数 p と原始根 g を共有し、Alice と Bob が秘密鍵から公開値を交換して共通鍵に到達する過程を小さな数で可視化。なぜ二人が同じ鍵にたどり着けるかを直感的に学べます。

**Category:** 暗号教育シミュレーター
