# 電磁誘導（ファラデーの法則）シミュレーター

磁石がコイルを通過する際の電磁誘導をリアルタイムアニメーション。ファラデーの法則・レンツの法則を磁束変化・誘導起電力・誘導電流の向きで体験。

**Category:** 電磁気学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/faradays-law.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/faradays-law.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/faradays-law.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/faradays-law
python -m http.server 8000
# open http://localhost:8000
```
