# パリス則 疲労き裂伝播シミュレーター

パリス則に基づく疲労き裂伝播シミュレーター。初期き裂寸法・応力振幅・材料定数から臨界寸法までの伝播挙動と残余寿命をリアルタイム計算。疲労解析・き裂進展予測。

**Category:** 破壊力学・疲労

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/crack-growth-paris.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/crack-growth-paris.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/crack-growth-paris.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/crack-growth-paris
python -m http.server 8000
# open http://localhost:8000
```
