# ムーディー線図 シミュレーター — 管摩擦係数

ムーディー線図シミュレーターは、ダーシー・ワイスバッハ式とスワミー・ジェイン明示式から、円管内流れの摩擦係数 f・圧力損失 ΔP・水頭損失を実時間で計算します。レイノルズ数と相対粗さ ε/D を変えて、層流と乱流の摩擦特性を直感的に学べます。

**Category:** 管路流体シミュレーター
