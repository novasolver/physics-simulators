# 船舶復原力・メタセンタ計算機

船舶の復原性評価を支援するCAEツール「船舶復原力・メタセンタ計算機」の紹介記事です。箱型・船型フォームに対し、KB・BM・GM・GZ曲線をリアルタイム計算。IMO A.749基準の自動判定と横断面ビジュアライズで、設計段階からの安定性確認を効率化します。

**Category:** 流体解析
