# レイリー・リッツ法 固有振動数推定計算機

レイリー・リッツ法を用いた固有振動数推定計算機。モード形状変更でレイリー商の変化をリアルタイム確認でき、構造振動解析と上限定理の理解に最適。固有値問題・はり振動計算。

**Category:** 構造振動解析

- 🇺🇸 [English](https://novasolver.jp/en/tools/rayleigh-method.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/rayleigh-method.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/rayleigh-method
python -m http.server 8000
# open http://localhost:8000
```
