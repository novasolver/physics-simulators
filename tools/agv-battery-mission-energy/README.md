# AGV 走行ミッションの電池消費と余裕シミュレーター

AGV走行ミッションの電池消費と余裕シミュレーターで、走行抵抗・残SOC・距離感度から完走可能条件を検証。バッテリー設計・ミッション計画の最適化に。

**Category:** 対話型シミュレーター
