# 超高圧処理 HPP 食品殺菌シミュレーター

400〜800 MPa の静水圧で食品を「焼かずに殺菌」する HPP（High Pressure Processing）の設計ツールです。処理圧力・保持時間・対象微生物・製品カテゴリを変えると、log 削減・断熱加温・スループット・単位コストがリアルタイムで分かり、ジュースや食肉のプロセス設計を実用条件で検討できます。

**Category:** 食品工学・非加熱処理
