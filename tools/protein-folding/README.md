# タンパク質特性・分子量計算機

分子量・pH・温度からタンパク質の正味電荷、流体力学的半径Rh、Stokes-Einstein拡散係数D、沈降係数s、SDS-PAGE推定位置をリアルタイム計算します。

**Category:** 生物工学
