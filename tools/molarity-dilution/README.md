# モル濃度・希釈計算シミュレーター

モル濃度・希釈計算シミュレーターで希釈の法則C₁V₁=C₂V₂を可視化。濃度計算と希釈操作をアニメーションで直感的に学習できます。

**Category:** 高校化学・溶液

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/molarity-dilution.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/molarity-dilution.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/molarity-dilution.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/molarity-dilution
python -m http.server 8000
# open http://localhost:8000
```
