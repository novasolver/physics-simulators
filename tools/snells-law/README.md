# スネルの法則シミュレーター — 光の屈折・全反射

スネルの法則シミュレーターで光の屈折・全反射を可視化。屈折率と入射角をリアルタイム操作、臨界角自動計算。光学設計・検証に必須の光線追跡ツール。

**Category:** 高校物理・光学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/snells-law.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/snells-law.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/snells-law.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/snells-law
python -m http.server 8000
# open http://localhost:8000
```
