# 二元合金状態図・凝固シミュレーター

二元合金（Cu-Ni型・Sn-Pb型）の状態図と凝固過程をシミュレーション。レバールールによる固相率・液相率の計算から、シール凝固曲線や微細組織の形成までをリアルタイムで可視化する材料科学学習ツール「NovaSolver」です。合金設計や教育・研究に役立ちます。

**Category:** 材料・破壊

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/phase-diagram.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/phase-diagram.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/phase-diagram
python -m http.server 8000
# open http://localhost:8000
```
