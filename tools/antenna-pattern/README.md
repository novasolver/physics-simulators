# アンテナ指向性パターンシミュレーター

NovaSolverのアンテナ指向性パターンシミュレーターは、半波長ダイポールや八木アンテナなどの指向性をリアルタイムで可視化。利得や半値角（HPBW）を自動計算する無線工学・電磁気学の教育・学習支援ツールです。直感的な操作でアンテナ設計の基礎が学べます。

**Category:** 電磁気・無線工学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/antenna-pattern.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/antenna-pattern.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/antenna-pattern
python -m http.server 8000
# open http://localhost:8000
```
