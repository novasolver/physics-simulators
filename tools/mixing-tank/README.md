# 撹拌タンク設計計算ツール — 動力数・所要動力・混合時間

NovaSolverの撹拌タンク設計計算ツールは、所要動力・混合時間・動力数の計算をリアルタイムで実行。ラッシュトンタービンなど主要な攪拌翼の動力数曲線を可視化し、スケールアップ則も学べます。効率的な撹拌タンク設計をサポートする無料シミュレーターです。

**Category:** 流体解析

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/mixing-tank.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/mixing-tank.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/mixing-tank
python -m http.server 8000
# open http://localhost:8000
```
