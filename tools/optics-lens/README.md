# 薄肉レンズ計算機 — 光線図・像距離・倍率

薄肉レンズ計算機「NovaSolver」は、焦点距離や物体距離から像距離・倍率をリアルタイムで計算。凸レンズ・凹レンズの光線図をインタラクティブに可視化し、光学設計やレンズの基礎学習をサポートします。直感的なシミュレーションで理解が深まります。

**Category:** 光学シミュレーター

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/optics-lens
python -m http.server 8000
# open http://localhost:8000
```
