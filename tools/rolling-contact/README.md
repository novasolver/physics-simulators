# 転がり接触応力計算

ヘルツ接触理論に基づいて転がり接触の応力を解析。接触タイプ・材料・荷重を変えて接触半径・最大接触圧・表面下応力分布をリアルタイムで確認できます。

**Category:** 解析ツール

## Live demos

- 🇺🇸 [English](https://novasolver.jp/en/tools/rolling-contact.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/rolling-contact.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/rolling-contact
python -m http.server 8000
# open http://localhost:8000
```
