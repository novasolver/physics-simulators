# 二次曲線エクスプローラー

円・楕円・放物線・双曲線のパラメータをリアルタイム操作。焦点・準線・離心率の関係、極座標形式、円錐断面との対応関係を一画面で同時に可視化します。

**Category:** 数学・幾何学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/conic-sections-explorer.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/conic-sections-explorer.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/conic-sections-explorer.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/conic-sections-explorer
python -m http.server 8000
# open http://localhost:8000
```
