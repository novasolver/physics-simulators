# 表面粗さ変換・加工法選定 Ra/Rz/Rq

表面粗さRa/Rz/Rq/Rmaxを相互変換し、加工法別の達成可能粗さ範囲を比較。ISOシンボル・ANSIグレード対応。機械加工・表面処理の仕上げ面選定。

```bash
git clone https://github.com/novasolver/physics-simulators

python -m http.server 8000
```
