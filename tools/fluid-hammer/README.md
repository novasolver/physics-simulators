# ウォーターハンマー・管内衝撃圧計算機

ウォーターハンマー・管内衝撃圧計算機でバルブ急閉鎖時のジュコフスキー衝撃圧をリアルタイム計算。管材・流速・閉鎖時間から安全設計を検討。

**Category:** 流体力学シミュレーター

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/fluid-hammer.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/fluid-hammer.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/fluid-hammer.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/fluid-hammer
python -m http.server 8000
# open http://localhost:8000
```
