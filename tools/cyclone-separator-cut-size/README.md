# サイクロン分離器のカット径と効率曲線シミュレーター

サイクロン分離器のカット径と捕集効率をシミュレーション。入口速度、粒子密度、粘度から効率曲線を評価し、粉体分級装置の設計・最適化に活用できます。

**Category:** 対話型シミュレーター

```bash
git clone https://github.com/novasolver/physics-simulators
```
