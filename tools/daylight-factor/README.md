# 昼光率シミュレーター

部屋が天空の光（自然採光）でどれだけ明るくなるかを評価するツールです。窓面積・ガラス透過率・室内の反射率を変えると、平均昼光率と室内推定照度がリアルタイムで分かり、照明に頼りすぎない明るい部屋を設計できます。

**Category:** 建築環境

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/daylight-factor.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/daylight-factor.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/daylight-factor.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/daylight-factor
python -m http.server 8000
# open http://localhost:8000
```
