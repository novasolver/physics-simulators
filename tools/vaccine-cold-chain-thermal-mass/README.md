# ワクチン コールドチェーン 熱マス保冷時間シミュレーター

ワクチン輸送クーラーの保冷時間を熱マス・断熱・蓄冷材から計算。mRNAワクチン（−70℃）から通常ワクチン（2-8℃）まで、VIP/PIR/EPS断熱、ドライアイス/ジェル/水氷の組合せで、WHO PQS適合性を判定する無料シミュレーター。

**Category:** 医薬品物流・コールドチェーン
