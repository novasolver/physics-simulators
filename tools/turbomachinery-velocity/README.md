# ターボ機械速度三角形シミュレーター

羽根車の入口・出口条件（周速U・軸速Cm・入口角α₁・出口相対角β₂）を操作し、速度三角形の描画とオイラー方程式による比仕事・反動度をリアルタイム計算します。

**Category:** 流体機械 / ターボ機械

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/turbomachinery-velocity.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/turbomachinery-velocity.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/turbomachinery-velocity.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/turbomachinery-velocity
python -m http.server 8000
# open http://localhost:8000
```
