# 太陽放射量・最適傾斜角計算機

太陽放射量・最適傾斜角計算機：緯度経度標高から日射量と最適傾斜角を算出、太陽位置と年間発電量をシミュレーション。PV設計に必須のツール。

**Category:** 環境・エネルギー

git clone https://github.com/novasolver/physics-simulators
