# 張出梁シミュレーター — 反力・SFD・BMD・撓み

左右ピン支持の主径間と右端から張り出した自由端を持つ梁を、等分布荷重と先端集中荷重で解析。反力・最大曲げモーメント・張出端撓みとSFD/BMD分布をリアルタイム可視化します。

**Category:** 構造解析シミュレーター

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/beam-overhang
python -m http.server 8000
# open http://localhost:8000
```
