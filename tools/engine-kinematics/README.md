# エンジン機構解析（クランク-スライダー運動学）

エンジン機構解析シミュレーターで、クランク-スライダー機構の動きを可視化。ピストンの変位・速度・加速度を無料で計算できます。4気筒やV6など主要エンジンのプリセット付き。運動グラフとアニメーションで直感的に解析。オンライン計算機NovaSolverで、設計・学習をサポートします。

**Category:** 機械力学

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/engine-kinematics
python -m http.server 8000
# open http://localhost:8000
```
