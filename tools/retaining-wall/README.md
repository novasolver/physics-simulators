# 擁壁設計計算機

ランキン・クーロン土圧理論による擁壁の安定照査。転倒・滑動・支持力の安全率をリアルタイム計算。地震時Mononobe-Okabe法対応。

**Category:** 地盤工学

- 🇺🇸 [English](https://novasolver.jp/en/tools/retaining-wall.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/retaining-wall
python -m http.server 8000
# open http://localhost:8000
```
