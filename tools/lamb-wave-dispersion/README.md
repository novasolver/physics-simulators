# Lamb 波分散 シミュレーター — 平板の S_0/A_0 モード

Lamb 波分散シミュレーターは、平板を伝わる対称モード S_0（非分散）と反対称モード A_0（板曲げ波・分散）の位相速度・波長をリアルタイムで計算します。ヤング率・密度・周波数・板厚を変えて構造ヘルスモニタリングの基礎を体感できる無料ツールです。

**Category:** 構造ヘルスモニタリングシミュレーター
