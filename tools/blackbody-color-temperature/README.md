# 黒体放射の色温度とスペクトル分布シミュレーター

黒体放射のスペクトル分布と色温度を対話形式でシミュレーション。温度変化による放射パワー計算と可視域への波長シフトを実験的に学習。

**Category:** 対話型シミュレーター

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/blackbody-color-temperature.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/blackbody-color-temperature.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/blackbody-color-temperature.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/blackbody-color-temperature
python -m http.server 8000
# open http://localhost:8000
```
