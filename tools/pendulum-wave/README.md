# 振り子波シミュレーター

振り子波シミュレーターで進行波・定在波・カオスの波動現象を可視化。複数振り子による干渉パターンを解析・シミュレーション。

**Category:** 高校物理・楽しいシミュレーター

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/pendulum-wave.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/pendulum-wave.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/pendulum-wave.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/pendulum-wave
python -m http.server 8000
# open http://localhost:8000
```
