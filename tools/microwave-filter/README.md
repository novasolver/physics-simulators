# マイクロ波フィルター設計ツール

Butterworth・Chebyshev・楕円フィルターのプロトタイプ設計。|S21|・|S11|周波数特性とグループ遅延をリアルタイム可視化。LPF/HPF/BPF/BPS変換対応。

**Category:** 振動・波動

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/microwave-filter.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/microwave-filter.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/microwave-filter.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/microwave-filter
python -m http.server 8000
# open http://localhost:8000
```
