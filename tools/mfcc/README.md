# MFCC 特徴量シミュレーター — メル周波数ケプストラム係数

音声信号からプリエンファシス・ハミング窓・FFT・メルフィルタバンク・対数・DCT を経て MFCC を抽出する流れを段階的に可視化。音声認識の標準特徴量を直感的に学べます。

**Category:** 音声信号処理シミュレーター

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/mfcc.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/mfcc.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/mfcc.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/mfcc
python -m http.server 8000
# open http://localhost:8000
```
