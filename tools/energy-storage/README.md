# エネルギー貯蔵システム比較（ラゴンプロット）

エネルギー貯蔵システム（リチウムイオン電池・鉛蓄電池・スーパーキャパシタなど）をラゴンプロットで視覚的に比較。必要なエネルギー量と出力条件から最適な蓄電技術を自動推薦し、コスト試算も可能な対話型シミュレーターです。NovaSolverのCAEツールで、システム設計を効率的に支援します。

**Category:** 環境・エネルギー

- 🇺🇸 [English](https://novasolver.jp/en/tools/energy-storage.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/energy-storage
python -m http.server 8000
# open http://localhost:8000
```
