# ヘルツ接触応力シミュレーター

Hertz接触理論に基づき、球・円柱の接触における圧力分布、接触半径、表面下最大せん断応力をリアルタイムで計算・可視化します。

**Category:** 計算ツール

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/hertz-contact.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/hertz-contact.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/hertz-contact.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/hertz-contact
python -m http.server 8000
# open http://localhost:8000
```
