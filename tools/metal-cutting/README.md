# 切削加工シミュレーター

切削加工シミュレーターでMerchant理論による切削力・背分力をリアルタイム計算。工具寿命予測とMerchant円の可視化で加工条件を最適化。

**Category:** 製造・加工

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/metal-cutting.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/metal-cutting.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/metal-cutting.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/metal-cutting
python -m http.server 8000
# open http://localhost:8000
```
