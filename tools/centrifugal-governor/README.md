# 遠心調速機（ガバナー）シミュレーター

ワットの蒸気機関を有名にした遠心調速機（フライボール・ガバナー）を体感するツールです。フライボールの質量・中央スリーブ荷重・アーム長さ・回転数を変えると、ボールが描く円錐振り子の高さ・アーム角・遠心力・動作開始回転数がリアルタイムで分かります。

**Category:** 機械要素設計
