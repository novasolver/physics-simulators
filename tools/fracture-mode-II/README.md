# モードII/III破壊力学・混合モード破壊

混合モード破壊力学シミュレーターで、き裂の進展と破壊をオンラインで解析。応力拡大係数(KI, KII, KIII)や破壊靭性、き裂偏向角をリアルタイム計算。最大周方向応力基準やひずみエネルギー解放率に基づく混合モード破壊評価を無料で体験。研究開発や材料評価に最適なツールです。

**Category:** 材料・破壊

git clone https://github.com/novasolver/physics-simulators
