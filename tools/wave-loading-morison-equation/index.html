海面と没水部材 — 水粒子軌道・力ベクトル

海面を進む線形波と没水円柱（jacket leg）。青矢印＝慣性力 F_i、赤矢印＝抗力 F_d、白点＝水粒子軌道。KC 数で支配モードを表示します。

波周期内の荷重時刻歴 — F_drag・F_inertia・F_total
KC 数 vs 部材径 D — レジーム判定
理論・主要公式

$$F = \rho C_M V \dot u + \tfrac{1}{2}\rho C_D A |u|u,\qquad KC = \frac{u_{max} T}{D}$$

第1項＝慣性力（流体加速度に比例）、第2項＝抗力（速度の二乗、符号は |u|u で保持）。ρ＝海水密度 1025 kg/m³、C_M＝慣性係数（粗面円柱 2.0）、C_D＝抗力係数（粗面円柱 1.0-1.2、滑面 0.65）、V＝排除体積／単位長、A＝投影面積／単位長。

$$u_{max}=\omega\,\tfrac{H_s}{2},\qquad \dot u_{max}=\omega^{2}\,\tfrac{H_s}{2},\qquad \lambda=\tfrac{2\pi}{k},\quad k=\tfrac{\omega^{2}}{g}\ (\text{deep water})$$

線形波理論（Airy 波）による水面（z=0）での水粒子速度・加速度の最大値。深海近似 k=ω²/g、ω=2π/T。Stokes 5次など高次理論はピーク値が 10-30% 増えるが、KC・C_D の選定不確定性に比べれば二次的。

$$F_{total}/L = \sqrt{F_{drag}^{2}+F_{inertia}^{2}}\quad (\text{quadrature sum at peak})$$

慣性力と抗力は位相が 90° ずれるため、それぞれのピーク値の二乗和平方根が時刻歴中の最大荷重に近い値を与える。厳密には合成波形を時刻歴で評価する。

Morison 式による海洋構造物の波浪荷重計算

🙋
「Morison 式」って、洋上風車や石油プラットフォームの設計でよく聞きますけど、要するに何をしてる式なんですか？
🎓
ざっくり言うと「海の中にある細長い柱に、波がどれくらいの力で押すか」を出す式だね。1950 年に Morison・O'Brien・Johnson・Schaaf の 4 人が、メキシコ湾の石油プラットフォームの脚柱に流体抗力理論と付加質量理論を「とりあえず足し算しちゃおう」という大胆な発想で組み合わせたのが始まりだ。F = ρ·C_M·V·du/dt + ½·ρ·C_D·A·|u|·u というのが本体。第1項が「流れが加速してるときに引きずられる慣性の力」、第2項が「流れが速いときに後ろに渦ができて引っ張られる抗力」だよ。
🙋
なるほど、流体力学の 2 つの効果を足してるんですね。でも左のスライダーで「部材直径 D」を 10 m まで上げると、KC 数がすごく小さくなって「慣性支配」って出ます。これってどういう意味ですか？
🎓
いい質問だね。KC = u_max·T/D は「1 波周期で水粒子が部材径の何倍動くか」を表すんだ。D が大きくなると KC が小さくなる。例えば KC=2 だと、水粒子は柱の直径の 2 倍しか動かないから、柱の後ろに大きな渦が剥がれて成長する時間がない。だから抗力よりも「水を加速・減速させる慣性」が支配的になる。逆に細いパイプ（riser、KC=50 とか）だと、水粒子が柱の 50 個分も往復するから渦がガンガン発達して、抗力支配になるんだ。
🙋
じゃあ jacket platform の脚柱（D=2m くらい）はちょうど中間域ってことですか？
🎓
そう、デフォルト条件だと KC≈9.4 で、まさに遷移域だね。下のグラフ「KC 数 vs 部材径」を見ると、5 < KC < 20 の帯に jacket leg が入ってる。この遷移域は実は設計上いちばん厄介なところで、C_D と C_M の値が KC の関数として暴れるんだ。Sarpkaya の実験データだと KC=10 付近で C_D が 1.4 まで跳ね上がったりする。だから API RP 2A は安全側に C_D=1.05、C_M=1.2（粗面マリン成長付きの場合）を推奨してたりするんだよ。
🙋
海洋付着物が出てきましたが、これって設計でどれくらい考慮するんですか？
🎓
これがけっこう効くんだ。北海の jacket では運用 20 年で mussel（イガイ）や hydroid が 5〜10 cm 厚に成長することがあって、実質直径が増える上に表面粗さが激増するから、C_D は 0.65（新設・滑面）から 1.2 程度まで倍増する。設計実務では「マリン成長厚 50 mm、密度 1325 kg/m³、C_D=1.2」のような追加仕様を寿命中後期の検討に入れるんだ。日本では沿岸の barnacle 成長が早いから、洋上風車のモノパイル基礎の TP（transition piece）部分は付着物清掃を定期的にやる前提で設計してるよ。
🙋
最後に、計算結果の「全波浪荷重 293 kN」って数字、jacket 脚 1 本に対しては大きいんですか？
🎓
没水長 50 m あたりの 1 本荷重としては、まあ標準的なオーダーだね。4 脚 jacket なら波直角面に対して 2 本が同時に最大荷重を受けるから、ベースシア（水平剪断力）でざっくり 500-600 kN。これに浮上 30 m の腕でモーメントを取ると 10-15 MN·m の転倒モーメントになる。実際の北海 jacket だと 100 年再現波（H_s=14 m, T_p=15 s）でベースシア 50-100 MN、転倒モーメント 3-5 GN·m が設計支配荷重になるよ。本ツールはあくまでオーダー検討用で、本設計は SACS や USFOS のような時系列非線形解析でやるんだ。

よくある質問

Morison 式は「波長に対して構造物の直径が十分小さい（おおむね D < λ/5）細長部材」に対する波浪荷重の標準的な経験式です。具体的には固定式 jacket プラットフォームの脚柱・水平ブレース、conductor、riser、subsea pipeline、洋上風車のモノパイル基礎などが対象です。一方で大径重力式構造物（GBS）や半潜水式の浮体ポンツーンのように直径が波長と同オーダーになる場合は、回折効果が無視できなくなるため Morison 式ではなく拡散理論（MacCamy-Fuchs 等）や 3D 拡散解析を用います。
粗面の円柱（jacket leg）では設計実務として C_D ≈ 1.0〜1.2、C_M ≈ 2.0 を採用するのが API RP 2A WSD と DNV-OS-J101 の共通的な目安です。滑面ではそれぞれ C_D ≈ 0.65、C_M ≈ 1.6 程度まで下がります。値は Reynolds 数 Re と Keulegan-Carpenter 数 KC、表面粗さの関数で、Sarpkaya・Isaacson らの実験データから決定されます。海洋付着物（barnacle、mussel）が成長すると C_D は最大 2 倍に増加するため、寿命中後期の劣化荷重を別途検討します。
KC = u_max·T/D は「1 波周期中に水粒子が部材径の何倍動くか」を表す無次元数で、抗力と慣性力のどちらが支配的かを示します。KC < 5 では水粒子の振幅が小さく流れが部材を「揺さぶる」だけで剥離渦が発達せず、慣性力（C_M 項）が支配します（大径円柱・モノパイル）。KC > 20〜30 では十分な振幅で渦放出が起き、抗力（C_D 項）が支配します（riser・パイプライン）。5 < KC < 20 は遷移域で両者が同オーダーとなり、設計上もっとも注意が必要な領域です。
目安は「波長 λ に対する部材直径 D」の比です。D/λ < 0.2（≈ 1/5）であれば Morison 式（細長物体近似）で十分です。例えば本ツールのデフォルト条件（H_s=6 m, T_p=12 s）では λ≈225 m なので、D=2 m の jacket leg は D/λ≈0.009 と十分小さく Morison 式が適切です。D/λ > 0.2 の大径構造物（GBS の重力式ベース、貯油タンク、巨大モノパイル直径 8〜10 m 級）では構造が波場そのものを乱す回折・反射効果が大きくなり、MacCamy-Fuchs の解析解または境界要素法（BEM、WAMIT/HydroD）による拡散解析が必要になります。

実世界での応用

固定式 jacket プラットフォーム（メキシコ湾・北海）：シェル、エクソンモービル、エクイノールが運用する石油・ガス生産プラットフォームの大多数は鋼製 jacket 構造で、脚柱（直径 1〜2 m）と水平・斜めブレースが Morison 式の主要適用対象です。100 年再現波（北海中央部で H_s≈14 m, T_p≈15 s）に対するベースシアと転倒モーメントを SACS や USFOS で時系列非線形解析し、ジャケット脚と杭基礎を設計します。50 年使われている老朽プラットフォームでは、設計時より過酷な波浪条件が観測されており、Morison 式の再評価で寿命延長判定が行われています。

洋上風車のモノパイル基礎（北海・日本沿岸）：Hornsea（イギリス）や Walney Extension など世界の洋上ウィンドファームの主流基礎は直径 7〜10 m の鋼管モノパイルです。直径が大きいため KC < 5 の慣性支配域に入り、Morison 式に MacCamy-Fuchs の回折補正係数を掛けた「修正 Morison 式」で評価します。日本の千葉県銚子沖や秋田沖の商業洋上ウィンドファームでも DNV-OS-J101 / IEC 61400-3 に基づき同様の設計が行われています。波浪と風荷重の動的相互作用（aero-hydro-elastic coupling）が FAST や Bladed で解析されます。

浮体式洋上風車・スパー型 FPSO の係留システム：Hywind Scotland（世界初の商業浮体式ウィンドファーム）や日本の福島浮体式実証は、スパー型・セミサブ型の浮体に風車を載せたものです。浮体の係留ライン（チェーン直径 100〜150 mm、ポリエステルロープ）に対しても Morison 式で波浪・潮流荷重を評価し、係留張力の動的解析を OrcaFlex 等で行います。Vestas や MHI-Vestas は実証段階から商用機への量産フェーズに移行中で、Morison 計算は係留索の疲労寿命評価の基礎データになります。

海底パイプライン・ライザー設計：大水深石油・ガス田の subsea pipeline（直径 0.3〜0.6 m）や rigid riser は、底層流と内部波で慢性的に Morison 荷重を受けます。直径が小さく KC が大きいため抗力支配で、VIV（渦励振振動 vortex-induced vibration）が長期疲労破壊の主要モードになります。Shear7 や VIVA といった専用ソフトで Morison ベースのモード解析を行い、ストレーキ（らせん突起）の有無や張力調整で対応します。深海ブラジル沖の Petrobras 油田群が代表例です。

よくある誤解と注意点

まず最大の落とし穴が、「C_D と C_M を 1 セットの定数として固定する」こと。実際にはこれらは Reynolds 数 Re、KC 数、表面粗さ k/D の関数として大きく変化します。Sarpkaya の古典的な振動水槽実験では、KC=10 付近で C_D が 0.6 から 1.4 まで揺れ動き、KC=30 で平均的に 0.8 に落ち着く、というように振る舞いが複雑です。北海ジャケットの再評価で「設計時の C_D=0.7 を実測 C_D=1.1 に直したら荷重が 60% 増えた」という事例もあります。設計コード（API RP 2A、DNV-OS-J101）が推奨する保守的な値を使うのが原則で、特殊条件では水槽試験または CFD で個別検証してください。

次に、「水面の波しか考えない」こと。本ツールも線形波（Airy 波）で表面 z=0 の最大値を計算していますが、実際には水深方向に水粒子速度が指数関数的に減衰します（深海では exp(-kz)）。深海で水深 50 m まで没水した jacket leg では、表面で u_max=1.57 m/s が水深 30 m で約 0.68 m/s（=1.57·exp(-0.028·30)=1.57·0.43）まで減衰します。設計実務では水深方向に荷重分布を積分する必要があり、本ツールの「全波浪荷重 = ピーク荷重×没水長」はあくまでオーダー把握用の上限値です。SACS や USFOS では水深方向の積分が自動的に行われます。

最後に、「Morison 式は深海・浅海どちらでも同じ」という誤解。本ツールは深海近似（k=ω²/g）を使っており、浅海（d/λ < 0.05）ではこれが大きく外れます。浅海では λ ≈ T·√(g·d) となり、波長は水深の関数になります。例えば水深 d=15 m、T_p=10 s の浅海条件では深海近似 λ=156 m に対し実際は λ≈115 m（誤差 30%）、u_max も同程度ずれます。浅海・中間水深の設計では一般分散関係 ω² = g·k·tanh(k·d) を Newton-Raphson 法で解く必要があります。沿岸近くの jetty・ブレークウォーター・洋上風車では浅海・中間水深効果が必須です。

使い方ガイド

  1. 有義波高（Hs）と周期（Tp）を入力します。北海油田の典型値は Hs=6m、Tp=12s です。
  2. 水深と部材径（モノパイル外径など）を設定します。洋上風車では水深 30～50m、径 8～12m が標準です。
  3. 抗力係数 CD（0.6～1.2）と慣性係数 CM（1.5～2.0）を調整し、リアルタイムで波長λ、水粒子速度 u_max、単位長あたりの抗力・慣性力を確認します。
  4. KC 数（Keulegan-Carpenter 数）が 5 未満なら慣性力が支配的、15 以上なら抗力が支配的です。

具体的な計算例

Jacket プラットフォーム（水深 40m、部材径 1.2m、Hs=5m、Tp=10s）の場合：波長λ≈156m、最大水粒子速度 u_max≈1.57m/s、KC≈13.1（遷移域）です。CD=1.0、CM=1.6 として、単位長あたり抗力＝1.52kN/m、慣性力＝1.83kN/m、合成（直交和）＝約2.38kN/m となります。全波浪荷重は部材有効長で積分し、安全率 1.35 を乗じて設計荷重を算定します。

実務での注意点

  • 相対粗度 ks/D や Reynolds 数によって CD は変動します。酸化したスチール杭は ks≈0.5mm を参照してください。
  • 周期波理論（Airy 波）は Hs/λ < 0.14 で有効ですが、浅海域では Stokes 波や Cnoidal 波への遷移を検討してください。
  • KC < 5 の低周波高波では CM 支配のため、インライン振動による加速度項を厳密に評価し、構造減衰（対数減衰率 δ < 0.05）の影響を含めてください。
