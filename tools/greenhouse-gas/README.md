# 温室効果ガス排出量・CO₂換算計算機

NovaSolverの温室効果ガス排出量・CO₂換算計算機で、あなたのライフスタイルに応じた年間カーボンフットプリントを簡単計算。電力、移動、食事などからのCO₂排出量を自動算出し、世界平均との比較グラフで視覚的に把握できます。環境配慮の第一歩を、この無料ツールで始めましょう。

**Category:** 環境・カーボン計算機

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/greenhouse-gas
python -m http.server 8000
# open http://localhost:8000
```
