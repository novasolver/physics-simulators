# 材料選択チャート（アシュビーチャート）ビジュアライザー

30種の材料ファミリーを対数スケールでプロット。X/Y軸を自由に切り替えて比剛性・比強度・破壊靭性の性能指数ガイドラインを確認し、最適材料を直感的に選ぼう。

**Category:** 材料・破壊

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/material-selection.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/material-selection.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/material-selection.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/material-selection
python -m http.server 8000
# open http://localhost:8000
```
