# DBSCANシミュレーター — 密度ベースクラスタリング

DBSCAN密度ベースクラスタリングの実時間シミュレーター。εとMinPtsパラメータを変更してコア点・境界点・ノイズ判定と任意形状クラスタ検出を学習できます。

**Category:** 機械学習シミュレーター

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/dbscan.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/dbscan.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/dbscan.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/dbscan
python -m http.server 8000
# open http://localhost:8000
```
