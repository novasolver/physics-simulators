# 鉄道カーブ カント・カント不足シミュレーター

鉄道カーブのカント（超高）と カント不足を計算する無料シミュレーター。軌間・設計速度・曲線半径・車両種別・設計カント・緩和曲線形式から、平衡カント、横加速度、最大バランス速度、緩和曲線長、乗り心地を求められます。新幹線・在来線・貨物線の線形設計に。

**Category:** 鉄道・線路設計
