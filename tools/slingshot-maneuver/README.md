# 重力スリングショット（スイングバイ）軌道シミュレーター

重力スリングショット（スイングバイ）の軌道シミュレーターで、宇宙探査の速度変化を可視化。惑星の質量や宇宙機の速度を自由に調整し、フライバイ前後の軌道変化をリアルタイムにシミュレーション。無料で使えるオンライン軌道力学ツールで、天体力学を直感的に学べます。

**Category:** 軌道力学 / 宇宙工学

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/slingshot-maneuver
python -m http.server 8000
# open http://localhost:8000
```
