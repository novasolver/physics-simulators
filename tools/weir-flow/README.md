# 堰の流量シミュレーター — 矩形堰と三角堰

開水路の代表的な流量計測装置である矩形堰（Rehbock 式）と三角堰（Thomson 式）の越流流量を可視化。越流水深・堰幅・堰高・ノッチ角を変えて、水深から流量を求める原理を学べます。

**Category:** 水理シミュレーター
