# 終端沈降速度シミュレーター — 球形粒子の沈降と抗力係数

球形粒子が流体中を重力沈降する終端速度を Reynolds 域別に反復計算。粒子径・密度・粘度を変えて、Stokes 域・中間域・Newton 域での沈降挙動と抗力係数の遷移を直感的に学べます。

**Category:** 流体力学シミュレーター
