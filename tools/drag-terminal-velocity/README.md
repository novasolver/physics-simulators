# 空気抵抗・終端速度シミュレーター

物体の質量・抗力係数・断面積を自由に変えて落下運動をリアルタイム可視化。スカイダイバー・野球ボール・雨滴などのプリセットで終端速度の違いを体感しよう。

**Category:** 流体力学シミュレーター

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/drag-terminal-velocity.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/drag-terminal-velocity.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/drag-terminal-velocity.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/drag-terminal-velocity
python -m http.server 8000
# open http://localhost:8000
```
