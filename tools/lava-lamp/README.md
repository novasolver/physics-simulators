# ラバランプ シミュレーター

熱膨張・アルキメデス浮力・粘性抵抗を組み合わせたラバランプの物理シミュレーター。温度差による密度変化でブロブが上昇・下降するサイクルを再現し、自然対流の本質を学べます。熱膨張係数や加熱強度を調整して、流体中の浮力と沈降の原理を体験しましょう。

**Category:** 熱解析
