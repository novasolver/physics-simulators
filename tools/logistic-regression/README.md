# ロジスティック回帰（2D 2クラス分類）シミュレーター

ロジスティック回帰の2クラス分類シミュレーター。シグモイド関数とクロスエントロピー損失を勾配降下法で最小化し、学習率・正則化の影響を可視化。機械学習の基礎を習得できます。

**Category:** 機械学習シミュレーター

- 🇺🇸 [English](https://novasolver.jp/en/tools/logistic-regression.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/logistic-regression.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/logistic-regression
python -m http.server 8000
# open http://localhost:8000
```
