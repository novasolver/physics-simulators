# Z変換・デジタル信号システム解析

Z変換・デジタル信号システムの極零点プロット・周波数応答・安定性判定をリアルタイム解析。伝達関数H(z)の設計検証に。

**Category:** 振動・波動

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/z-transform.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/z-transform.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/z-transform.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/z-transform
python -m http.server 8000
# open http://localhost:8000
```
