RF受信チェーン — 信号と雑音の流れ

3段のブロックを信号（青）と雑音（赤）の波束が左から右へ流れます。信号レベルと雑音フロアがどちらも各段で上昇し、各段通過後の累積NFが表示されます。

累積雑音指数（各段通過後）
各段の雑音寄与（フリスの3項）
理論・主要公式

$$F_{total}=F_1+\frac{F_2-1}{G_1}+\frac{F_3-1}{G_1 G_2}$$

フリスのカスケード雑音公式。後段の雑音寄与は先行段の利得（の積）で割られるため、第1段の雑音係数が総合性能を支配する。

$$NF=10\log_{10}F,\qquad T_e=(F-1)\,T_0$$

雑音指数 NF[dB] と等価雑音温度 Te[K]。両者は雑音係数 F の別表現で、相互変換できる。基準温度 T₀ = 290 K。

ここで利得 G・雑音係数 F はすべて線形比（dB ではない）であり、F = 10^(NF/10)、G = 10^(G_dB/10) で換算する。基準温度 T₀ = 290 K。

カスケード雑音指数とは

🙋
「雑音指数」って、受信機がどれくらい雑音を出すかの指標ですよね。それを段ごとに足していくだけじゃダメなんですか？
🎓
いいところを突いてきたね。単純に足し算じゃないんだ。受信機はアンテナのあとにアンプ、ミキサ、フィルタ…と何段もつながった「縦続接続（カスケード）」になっている。各段は信号を増幅すると同時に、自分自身の雑音も加えてしまう。ここで効いてくるのが「後ろの段の雑音は、前の段で大きく増幅された信号と一緒に評価される」という事実なんだ。だから後段の雑音は、前段の利得で「薄められる」。これを正確に表すのがフリスの公式だよ。
🙋
薄められる、ですか。式だと F_total = F1 + (F2−1)/G1 + (F3−1)/(G1·G2) ですけど、この割り算が「薄める」部分なんですね。
🎓
そのとおり。2段目の雑音寄与 (F2−1) は第1段の利得 G1 で割られ、3段目は G1·G2 で割られる。左のスライダーで第1段の利得 G1 を 15 dB から 30 dB に上げてみて。総合NFがほとんど第1段の NF1 に張り付くのが見えるはずだ。逆に G1 を 0 dB まで下げると、後段の雑音がそのまま漏れ出して総合NFが一気に悪化する。
🙋
なるほど。じゃあ第1段がすごく重要ってことですか？2段目を頑張って低雑音にしても意味がない？
🎓
まさにそれが「第1段支配」だ。だからRF受信機の最前段には、必ず「NFが小さくて利得が大きい」低雑音増幅器、いわゆるLNA（Low Noise Amplifier）を置く。デフォルト値で第2段の NF2 を 4 dB から 12 dB まで上げてみて。総合NFがほとんど動かないだろう？ 第1段のLNAが十分な利得を持っていれば、2段目が多少うるさくても受信機全体はびくともしない。逆に、お金と労力をかけるべきは第1段だけ、という設計判断ができるわけだ。
🙋
下の棒グラフを見ると、第1段の寄与だけ飛び抜けて大きいです。これが「支配的」ってことなんですね。等価雑音温度っていうのも出てますけど、これは何ですか？
🎓
等価雑音温度 Te は、雑音係数を「温度」の言葉で言い換えたものだよ。Te = (F−1)·T0、T0 は 290 K。NF が 1 dB を切るような超低雑音の系——衛星通信や電波天文の受信機——では、NF を dB で語るより Te を K（ケルビン）で語ったほうが差が見やすいんだ。例えば NF=0.5 dB と 0.3 dB の差は dB だとわずかだけど、Te だと 35 K と 21 K でかなり違って見える。両方とも同じ情報の別表現で、F = 1 + Te/T0 でいつでも行き来できる。

よくある質問

縦続接続された段の総合雑音係数はフリスの公式 F_total = F1 + (F2−1)/G1 + (F3−1)/(G1·G2) で求めます。F は線形の雑音係数、G は線形の利得で、雑音指数 NF[dB] からは F = 10^(NF/10)、利得 G[dB] からは g = 10^(G/10) と換算します。総合雑音指数は NF_total = 10·log10(F_total) [dB] です。後段の雑音寄与が先行段の利得で割られる点が、この式の最大のポイントです。
フリスの公式では、2段目の雑音寄与は (F2−1)/G1、3段目は (F3−1)/(G1·G2) と、先行する段の利得の積で割られます。つまり第1段の利得 G1 が大きいほど後段の雑音は薄められ、総合NFは第1段の NF1 にほぼ等しくなります。だから第1段には NF が小さく利得が大きいLNAを置くのが鉄則です。LNAの利得が十分なら、2段目が多少うるさくても総合性能はほとんど劣化しません。
等価雑音温度 Te は、雑音係数 F を温度の言葉で表したもので Te = (F−1)·T0 で定義されます。T0 は基準温度 290 K です。雑音指数 NF[dB] は商用無線でよく使われ、Te[K] は衛星通信や電波天文のように極端に低雑音な系で使われます。両者は同じ情報の別表現で、F = 1 + Te/T0 で相互変換できます。例えば NF=1.5 dB は F≈1.41、Te≈120 K に対応します。
最も効くのは第1段の雑音指数 NF1 を下げることです。総合NFは第1段にほぼ等しいため、NF1 を 0.5 dB 下げれば総合NFもほぼ 0.5 dB 下がります。次に第1段の利得 G1 を上げると、後段の雑音寄与 (F2−1)/G1 が小さくなり、後段の影響を抑えられます。逆に、第1段の前にケーブルやフィルタなど損失のある素子（利得が負）を入れると、その損失分がそのまま総合NFに上乗せされるため避けるべきです。

実世界での応用

携帯電話・無線LANの受信フロントエンド：スマートフォンや Wi-Fi ルータの受信部は、アンテナのすぐ後ろにLNAを置き、その後にミキサ・IFアンプ・フィルタが続きます。受信感度はほぼ最前段のLNAの雑音指数で決まるため、メーカーはここに最も低NFのデバイスを投入します。本ツールで第1段の NF1 を動かすと、総合NFがほぼ同じだけ動くのが確認でき、なぜLNAの選定が最重要なのかが分かります。

衛星通信・GPS受信機：静止衛星や測位衛星からの電波は極端に微弱で、受信機は等価雑音温度で性能を語ります。低雑音ブロックダウンコンバータ（LNB）は Te が数十Kオーダーの超低雑音設計で、アンテナ直下に置かれます。アンテナとLNBの間にケーブルを挟むと、その損失がそのまま雑音温度に上乗せされるため、LNBはアンテナフィードに直結するのが定石です。

電波天文・レーダー：電波望遠鏡の受信系は、Te を可能な限り下げるために初段を冷却（クライオスタット）することすらあります。フリスの公式に従えば、初段の Te を下げ利得を確保すれば、後段のミキサや分光計の雑音は無視できるレベルまで薄められます。本ツールの「累積雑音指数」グラフは、この「初段でほぼ決まり、後段でほとんど増えない」様子を可視化しています。

計測器・スペクトラムアナライザ設計：スペクトラムアナライザやネットワークアナライザの受信部も多段構成で、表示できる最小レベル（DANL）は総合NFで決まります。プリアンプを内蔵・外付けする際は、フリスの公式で「プリアンプを足すと総合NFがどこまで改善するか」を見積もります。利得の低いプリアンプを足しても効果が薄いことも、この式から説明できます。

よくある誤解と注意点

まず最大の誤解が、「雑音指数は dB なので、段ごとに足し算すればよい」というものです。フリスの公式は雑音指数（dB）ではなく、線形の雑音係数 F と線形の利得 G で計算します。NF=3 dB は F=2、NF=6 dB は F≈4 であって、F どうしを式に入れてから最後に NF_total = 10·log10(F_total) で dB に戻します。dB のまま足したり割ったりすると、まったく違う答えになります。本ツールが内部で 10^(NF/10) の換算を行っているのはこのためです。

次に、「第1段の前に損失素子を入れても大したことはない」という油断です。アンテナとLNAの間にケーブル・コネクタ・帯域フィルタを挟むと、それは利得が負の「段」になります。損失 L dB の素子は雑音指数も L dB で、しかもそれが第1段になると、後続のLNAの寄与がその損失で割られて悪化します。結果として総合NFは「損失 + 元のNF」にほぼ等しくなります。1 dB のケーブル損失は、そのまま 1 dB の受信感度劣化です。だからLNAは可能な限りアンテナの直近に置きます。

最後に、「総合NFさえ良ければ受信機は完成」という思い込みです。フリスの公式が扱うのは小信号の雑音性能だけで、強い入力に対する歪み（IP3、1 dB 圧縮点）やダイナミックレンジは別問題です。第1段の利得を欲張って上げすぎると、後段が強信号で飽和・混変調を起こしやすくなります。実務では、NF を下げる方向と、線形性（歪みにくさ）を確保する方向のトレードオフを取りながら、各段の利得配分を決めます。雑音と歪みの両方を見て初めて、まともな受信機設計になります。

使い方ガイド

  1. 第1段増幅器の利得G1（dB）と雑音指数NF1（dB）を入力。LNA設計では通常G1=20～30dB、NF1=0.5～1.5dBの範囲
  2. 第2段増幅器の利得G2（dB）と雑音指数NF2（dB）を入力。ミキサー段ではG2=-8～0dB、NF2=8～12dBが一般的
  3. 「計算」をクリックするとフリスの公式により総合NF、等価雑音温度Te、各段の寄与度を自動算出

具体的な計算例

受信チェーンで第1段LNA：G1=25dB、NF1=0.8dB、第2段：G2=-6dB、NF2=10dB（第3段は既定のG3=10dB、NF3=6dB）の場合、フリス公式による総合NF≈1.03dB、等価雑音温度Te≈78K、第1段寄与度≈95%となります。この設計では高利得LNAが支配的なため、後段の劣化は抑制されます。対してG1=10dBに低下させると総合NF≈5.2dBに悪化し、Te≈664Kとなり、低ノイズ第1段の重要性が明確になります。

実務での注意点

  1. 第1段利得が3dB低下すると総合NFはほぼ同じ値だけ上昇する特性を利用し、LNA設計ではG1≥20dBを確保してから後段のノイズ指数最適化を実施
  2. 衛星受信系では等価雑音温度Teと感度（EIRP必要値）が直結するため、Teを60K以下に抑えることが契約仕様。計算結果から必要なLNA仕様を逆算
  3. ミキサー段（第2段）でG2が負値の場合、分母が小さくなり第2段の寄与が相対的に増加。このため変換利得≥0dBのミキサー設計が重要
  4. 温度変動によるNF変化（±0.3dB/25℃）を見込み、常温下でのシミュレーション結果に0.2dB安全率を追加するのが実務慣例
