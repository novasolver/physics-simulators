# 地震ハザード応答スペクトル計算機

地震ハザード応答スペクトル計算機：建物の固有周期・地盤種別・地域係数から設計用応答スペクトルSa(T)とベースシア力Vをリアルタイム計算。地盤増幅効果と減衰比を可視化。

**Category:** 地震工学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/seismic-hazard.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/seismic-hazard.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/seismic-hazard.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/seismic-hazard
python -m http.server 8000
# open http://localhost:8000
```
