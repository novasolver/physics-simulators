# ビュフォンの針シミュレーター — 確率でπを推定する

等間隔の平行線が引かれた床に、針をランダムに投げる古典実験。線と交差する確率から円周率πを推定します。本数・針長さ・線間隔を変えて、確率と幾何の不思議なつながりを体験しましょう。

**Category:** 確率・モンテカルロ
