# 遠心クラッチ シミュレーター

回転数が上がると自動でつながる遠心クラッチを設計するツールです。シューの質量・個数・回転半径・ばね力・回転数を変えると、遠心力・ドラム押付け力・伝達トルク・接続開始回転数がリアルタイムで分かり、狙いどおりの回転数で滑らかに接続するクラッチの寸法を探せます。

**Category:** 機械要素設計

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/centrifugal-clutch
python -m http.server 8000
# open http://localhost:8000
```
