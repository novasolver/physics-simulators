# 太陽熱温水器・集熱量シミュレーター

太陽熱温水器の集熱量をHWB式でシミュレーション。集熱面積・日射量・入口水温から瞬時集熱量・日積算量・タンク昇温量を計算。熱効率曲線解析に対応。

**Category:** 再生可能エネルギーシミュレーター

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/solar-thermal.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/solar-thermal.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/solar-thermal.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/solar-thermal
python -m http.server 8000
# open http://localhost:8000
```
