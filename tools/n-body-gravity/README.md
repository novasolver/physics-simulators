# 多体重力シミュレーター（N体問題）

星・惑星・小惑星を配置し、重力による軌道運動・衝突・合体をリアルタイム可視化。figure-8軌道・太陽系・連星・銀河プリセット付き。

**Category:** 宇宙物理 / 軌道力学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/n-body-gravity.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/n-body-gravity.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/n-body-gravity.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/n-body-gravity
python -m http.server 8000
# open http://localhost:8000
```
