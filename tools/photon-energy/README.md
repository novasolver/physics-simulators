# 光子エネルギー・量子効率計算機

波長・光源出力・照射面積・量子収率から光子エネルギー、フラックス、照度、光化学反応速度を即時算出。UV〜IRの全スペクトル領域に対応。

**Category:** 電磁気・量子光学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/photon-energy.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/photon-energy.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/photon-energy.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/photon-energy
python -m http.server 8000
# open http://localhost:8000
```
