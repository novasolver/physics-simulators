# 浸透圧・ファントホッフ式計算ツール

浸透圧のファントホッフ式計算ツール。π=iCRTでリアルタイム計算し、細胞の浸透圧状態や逆浸透膜の必要圧力を即座に可視化。エンジニアの設計計算に。

**Category:** 化学・生物工学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/osmosis-pressure.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/osmosis-pressure.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/osmosis-pressure.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/osmosis-pressure
python -m http.server 8000
# open http://localhost:8000
```
