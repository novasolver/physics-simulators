薄肉開断面のせん断流とせん断中心 — C 形チャンネル

理論・主要公式

薄肉開断面に横せん断力 V を加えると、断面の中央線に沿ってせん断流 q(s) が流れます。任意の点 s での値は、その点から自由端までの面積モーメント Q(s) を断面 2 次モーメント I で割って V を掛けたものです。

せん断流の基本式。Q(s) は中央線に沿った片側の面積モーメント、I は断面全体の I_x：

$$q(s) = \frac{V\,Q(s)}{I}$$

C 形断面の I_x（肉厚一定 t、ウェブ高さ h、フランジ幅 b）：

$$I_x = \frac{t\,h^3}{12} + \frac{b\,t\,h^2}{2}$$

フランジ・ウェブの最大せん断流（接合点とウェブ中央）：

$$q_{\text{flange,max}} = \frac{V\,t\,h\,b}{2I}, \qquad q_{\text{web,max}} = \frac{V}{I}\!\left(\frac{b\,t\,h}{2}+\frac{t\,h^2}{8}\right)$$

ねじりを生じさせないせん断中心位置 e（ウェブ中心線からの距離）：

$$e = \frac{b^2\,h^2\,t}{4\,I} \;=\; \frac{3\,b^2}{h+6b}$$

横荷重 V をこの点 e に通せば、フランジに流れる q(s) のモーメントとちょうど釣り合い、梁は曲げのみで応答してねじれません。

薄肉開断面のせん断流とせん断中心シミュレーターとは

🙋
C 形のチャンネル材を梁として使うとき、ウェブの真上から荷重を載せたのに、なぜか梁がねじれるって聞いたんですけど、本当ですか？
🎓
本当だよ。C 形断面は左右非対称だから、「ねじりを起こさない荷重作用点」がウェブの中心とは別の場所にあるんだ。それを「せん断中心」と呼ぶ。シミュレーターの赤い × 印を見てごらん。ウェブの中央線（青い縦線）から左に飛び出した位置にあるだろう？ 既定値（h=200, b=100, t=5）だと、ウェブから 37.5 mm も外側にある。
🙋
なんでそんな断面の外側に作用点が来るんですか？
🎓
フランジに流れるせん断流が原因だ。横荷重 V を加えると、上下のフランジには互いに反対向きのせん断流が流れる。これがウェブ中央まわりに「ねじりモーメント」を作るんだ。シミュレーターの右のグラフで、左端と右端（UF と LF）に三角形の山が見えるだろう？これがフランジの q だ。ウェブの真上に荷重を載せてしまうと、フランジの q が作るモーメントを打ち消す相手がいないから、梁はねじれる。それを打ち消すには、荷重の作用点をウェブから少し離した位置——つまりせん断中心——に持ってこないといけない。
🙋
フランジ幅 b を大きくすると、せん断中心の e がどんどん大きくなりますね。逆にウェブ高さ h を大きくすると小さくなる。
🎓
その通り。式は $e = 3b^2/(h+6b)$ で、b の 2 乗で効くからフランジが長いほど劇的に外側に飛び出す。逆に背の高い C（h が大きい）はウェブの曲げ抵抗が支配的になって、e は相対的に小さくなる。実務で「C 形ランナーの上に直接荷重を置くな」と言われるのは、これが原因だ。アングル材や Z 形も同じ理屈で、対称軸を持たない開断面は必ずせん断中心が図心からずれる。
🙋
じゃあ実際の設計ではどう対処するんですか？荷重をわざわざ断面の外側に通すのは難しそうですけど。
🎓
3 つの王道がある。一つ目はウェブ外側にブラケット（張出し板）を溶接して荷重をせん断中心に通すこと。二つ目は背中合わせの C を 2 本組んで I 形（対称断面）にしてしまうこと。三つ目は閉断面化——フランジ先端どうしを薄板で繋いで角型管にすると、ねじり剛性が一気に数百倍に跳ね上がる（Bredt 公式の世界）。自動車のサイドメンバーで C 形にハットパネルを溶接して閉断面化するのは、まさにこの三つ目の対策だよ。

よくある質問

図心は断面の面積重心で、軸力や曲げモーメントの基準点として使います。せん断中心は「横荷重を加えてもねじりが生じない作用点」で、せん断流のモーメント釣り合いから決まる別の点です。両軸対称断面（円・正方形・I 形）では両者が一致しますが、C 形・Z 形・アングルなど対称軸を 1 本以下しか持たない断面では一致しません。せん断中心は対称軸上には必ず乗りますが、対称軸外への位置はせん断流計算で求めます。
開断面のねじり定数は J = (1/3)Σbt³ で、肉厚 t の 3 乗にしか依存しません。同じ断面積でも閉断面の J = 4A²/∮(ds/t) は囲む面積 A の 2 乗で効くため、典型的には開断面の数百〜数千倍のねじり剛性を持ちます。例えば 200×100×5 mm の C 形と、それを閉じた角型管とでは、ねじり剛性が約 1000 倍違うことも珍しくありません。だからねじりが効く構造（自動車車体・橋梁の主桁・クレーン）は閉断面化が基本です。
I 形断面は両軸対称なのでせん断中心と図心が一致し、ウェブ中心線上にあります。Z 形断面は点対称（180°回転で重なる）なので、せん断中心と図心が一致します。アングル（L 形）はやや特殊で、せん断中心は 2 枚の脚の交点付近にあります。一般則として、対称軸が 2 本ある断面は両者一致、対称軸が 1 本だけの断面（C 形・T 形・ハット形）はせん断中心が対称軸上の図心とは別の位置にずれます。
梁要素（Beam, Frame）で薄肉開断面をモデル化する場合、多くの汎用ソルバー（Abaqus・ANSYS・Nastran）はせん断中心オフセットを断面プロパティとして指定できます。荷重をウェブ中心の節点に作用させると、ソルバー側でせん断中心まわりのねじりを自動計算します。一方シェル要素や 3D ソリッドで断面を実寸モデル化すれば、せん断中心は自然に再現されます。注意点は、梁要素を使うときに「節点位置 = せん断中心」とすべきか「節点位置 = 図心」とすべきかをマニュアルで確認すること。誤って図心位置に節点を置くと、荷重と境界条件の解釈がずれて結果が大きく狂います。

実世界での応用

自動車のフレーム・サイドメンバー設計：軽量化のため C 形（ハットチャンネル含む）が多用されますが、開断面のままではねじり剛性が極端に低く、コーナリング時の車体変形を許容できません。底面にフロアパネルや別のハット材を溶接して閉断面化することで、ねじり剛性を 100 倍以上に向上させるのが定石です。荷重作用点とせん断中心の関係を理解することは、補強板の位置決定や溶接線設計の前提知識になります。

建築の鉄骨・冷間成形鋼の二次部材：母屋や胴縁に使われる軽量 C 形鋼（リップ付きチャンネル）は、屋根荷重を素直に受けると必ずねじりが発生します。設計実務では二次部材の中央に Tie-rod（タイロッド）を入れてねじり変形を拘束する、あるいは Z 形断面を採用してねじり挙動を緩和する、などの対策がとられます。

航空機の桁・ストリンガー設計：軽量化のため極限まで肉を薄くした開断面が並ぶ航空機構造では、せん断流計算と座屈解析が設計の中心になります。スキンとストリンガーが囲む「マルチセル閉断面」のせん断流分布を解くために、開断面の基礎（本シミュレーターの内容）が前提知識になります。

ロボット・産業機械のアーム構造：長尺アームを軽量化したいとき、開断面（C 形・コ形チャンネル）は魅力的ですが、把持位置からの荷重がせん断中心からずれているとアームがねじれて先端位置決め精度が崩れます。せん断中心位置を把握して、駆動ユニットや負荷の取付ブラケットの位置を意図的にせん断中心に合わせる設計が行われます。

よくある誤解と注意点

最も多い誤解は、「せん断中心は断面の中（材料部分）にあるはず」と思い込むことです。C 形のような片開き断面では、せん断中心は「材料がない空間」、つまりフランジと反対側のウェブ外側に位置することがほとんどです。シミュレーターでも赤い × 印が断面の輪郭の外側に出ているのが見えるはずです。これは数学的な仮想点であり、ここに直接荷重を加えるには張出しブラケットなどの物理的な機構が必要になります。「外側にあるなら作用させようがないじゃないか」というのが現場の本音で、だからこそ閉断面化や対称化が選ばれます。

次に多いのが、「フランジ幅 b を増やせばねじり問題が緩和される」と勘違いすることです。シミュレーターで b を増やしてみてください——せん断中心の e はむしろ大きくなり、ねじり問題は悪化します。式 $e = 3b^2/(h+6b)$ から分かる通り、b の 2 乗で増えるからです。曲げ剛性を上げようとフランジを大きくすると、副作用としてねじりへの感度が上がる。これが「曲げとねじりは独立に最適化できない」という構造設計の難しさの典型例です。

最後に、本シミュレーターが示す e は「肉厚一定」かつ「フランジ・ウェブの中心線で薄肉理論を適用」した近似値である点に注意してください。実機の C 形鋼ではフランジ付け根に R がある、肉厚が場所によって異なる、リップ（折返し）が付くなど、理想化から外れる要素が複数あります。実際の設計では、JIS や AISI のような規格集に各標準断面のせん断中心位置が表として与えられているのでそれを参照するか、シェル要素モデルで FEM 解析するのが確実です。本シミュレーターはあくまで原理と感覚をつかむための教育ツールとして使ってください。

使い方ガイド

  1. ウェブ高さH、フランジ幅B、板厚tをmm単位で入力します。C形チャンネルの寸法が断面図に反映されます
  2. せん断力VをN単位で設定すると、薄肉開断面理論によりせん断流q=V×S/I_xが自動計算されます
  3. フランジ根元とウェブ中央のせん断流ピーク値、および中立軸からのせん断中心位置eを確認します
  4. シミュレータはリアルタイムで応力分布ベクトル場を表示し、ねじり発生条件を判定します

具体的な計算例

C形チャンネル：H=200mm、B=75mm、t=6.5mm、せん断力V=50kN。断面2次モーメントI_x≈1250cm⁴。フランジ根元での静モーメントS=75×6.5×(100-3.25)≈48,300mm³、せん断流q=50,000×48,300/1,250,000,000≈1.93N/mm。ウェブ中央(y=100mm)でのせん断流q_web=50,000×56,600/1,250,000,000≈2.26N/mm。せん断中心位置e≈12.8mm(ウェブ外側)。この位置に荷重を加えるとねじり変形が発生しません

実務での注意点

  • 開断面では閉断面と異なり、ウェブ厚さが小さいと局所的な大きなせん断応力が発生します。H=300mm、t=5mmの場合、高さ方向の応力勾配が急になるため溶接部設計に注意が必要です
  • せん断中心がウェブ外側に位置するため、フランジ外縁に荷重を加えるとねじり応力τ=M_t/C_tが加算され、疲労破壊リスクが増加します
  • 鋼製C形チャンネル(SS400)では降伏応力235MPaに対し、V=100kNで局所応力が100MPaを超える場合、塑性化による応力再配分を考慮した設計が必要です
  • 薄肉開断面理論は壁厚比H/t≥15を仮定しており、H/t<10の場合は有限要素法による検証を推奨します
