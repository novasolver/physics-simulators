# 薄肉開断面のせん断流とせん断中心 — C 形チャンネル

C 形断面のせん断流 q(s)=VQ(s)/I 分布と、ねじりを起こさない荷重作用点であるせん断中心 e の位置を可視化。ウェブ高さ・フランジ幅・肉厚・せん断力を変えて、断面外に飛び出すせん断中心の振る舞いを学べます。

**Category:** 構造力学シミュレーター
