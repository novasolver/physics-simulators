# オゾン・UV 消毒シミュレーター — CT値・IT値設計

水処理・下水のオゾン・UV・塩素消毒の CT 値（C×T）・IT 値（UV線量）と必要滞留時間を計算。Cryptosporidium・Giardia・ウイルス・大腸菌の log 不活性化を、反応槽容積・流量・濃度・水温から設計できる無料シミュレーターです。

**Category:** 水処理・衛生工学
