# ギブズの相律 シミュレーター — 相平衡の自由度

ギブズの相律 F = C − P + 2 − N により、成分数 C・相数 P・追加拘束数 N から相平衡の自由度 F、1 つの強度量固定下の F、2 つの強度量固定下の F、共存可能な最大相数 P_max を実時間に計算します。T-P 相図の概念図と F-P 線図で不変点・単変点・二変点を可視化します。

**Category:** 相平衡シミュレーター
