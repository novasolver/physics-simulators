# マイケルソン干渉計 シミュレーター — 光路差と縞

光路差・波長・ミラー移動量をスライダーで動かすたびに、マイケルソン干渉計の検出強度・位相差・縞次数が即更新。光学系の模式図と縞パターンが並んで見えるので、二光束干渉の感覚をすっと掴めます。

**Category:** 光学シミュレーター
