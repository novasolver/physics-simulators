# 動吸振器（TMD）シミュレーター — Den Hartog最適設計

質量比μ・主系減衰比・TMDパラメータを操作して周波数応答のピーク低減効果を確認。Den Hartog最適設計との比較で最適チューニングを直感的に理解できます。

**Category:** 振動・波動
