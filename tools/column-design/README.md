# 鋼柱設計計算機

鋼柱設計計算機でH形鋼・角型鋼管の座屈強度をAISC規定に準拠して計算。軸力と曲げの相互作用で設計安全余裕をリアルタイム確認できます。

**Category:** 鋼構造設計

- 🇺🇸 [English](https://novasolver.jp/en/tools/column-design.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/column-design.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/column-design
python -m http.server 8000
# open http://localhost:8000
```
