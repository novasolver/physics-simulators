# 電力計算シミュレーター

交流回路の電力計算を可視化するシミュレーターです。有効電力・無効電力・皮相電力の関係をフェーザー図で直感的に理解できます。電圧や力率角を調整し、RLC回路から三相電力まで、様々な条件での瞬時計算を体験しましょう。理論の学習や設計業務を強力にサポートします。

**Category:** 電気工学
