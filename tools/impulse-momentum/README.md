# 衝撃・運動量シミュレーター（1D/2D衝突）

NovaSolverの衝撃・運動量シミュレーターで、1D/2D衝突を視覚的に理解。弾性・非弾性衝突をリアルタイムアニメーションで再現し、反発係数による運動量保存とエネルギー損失の違いを体感できます。衝撃力グラフと力積の可視化で、物理学習を深める無料ツールです。

**Category:** 古典力学・高校物理

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/impulse-momentum
python -m http.server 8000
# open http://localhost:8000
```
