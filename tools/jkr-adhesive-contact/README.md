# JKR粘着接触シミュレーター — Johnson-Kendall-Roberts理論

JKR粘着接触シミュレーター：Johnson-Kendall-Roberts理論に基づき、軟質弾性体の球接触における粘着力と接触半径をリアルタイム計算。Hertz理論との比較で粘着効果を解析。

**Category:** トライボロジー・接触力学
