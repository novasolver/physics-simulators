# 弾性振り子（バネ振り子）シミュレーター

弾性振り子シミュレーターで非線形振動を可視化。RK4数値積分によるリアルタイム解析で、パラメトリック共振やカオス現象、エネルギー移動を精密に検証できます。

**Category:** 非線形振動・カオス

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/spring-pendulum.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/spring-pendulum.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/spring-pendulum.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/spring-pendulum
python -m http.server 8000
# open http://localhost:8000
```
