# 周波数応答関数（FRF）計算

NovaSolverの周波数応答関数（FRF）計算ツールで、1自由度・2自由度系の振動解析を可視化。共振周波数や減衰比をリアルタイム計算し、ボード線図（振幅・位相）で直感的に理解できます。構造振動の基礎学習や設計検証に最適なシミュレーターです。

**Category:** 振動解析

python -m http.server 8000
