# 回折格子・干渉縞シミュレーター

格子間隔・波長・入射角・スリット数を操作して回折角・角度分散・分解能をリアルタイム計算。白色光の虹色分散もCanvas上でアニメーション表示する。

**Category:** 波動光学 / 干渉・回折

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/diffraction-grating.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/diffraction-grating.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/diffraction-grating.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/diffraction-grating
python -m http.server 8000
# open http://localhost:8000
```
