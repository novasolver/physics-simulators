# 燃焼計算シミュレーター

メタン CH₄、オクタン C₈H₁₈、プロパン C₃H₈、水素 H₂ の量論を解き、当量比 φ から生成物組成・断熱火炎温度・空燃比を即時算出。炎アニメーションで希薄・量論・濃混合の違いを比較できるエンジン設計向け燃焼シミュレーターです。

**Category:** 熱流体解析
