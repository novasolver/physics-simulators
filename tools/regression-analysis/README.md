# 回帰分析・曲線フィッティングツール

NovaSolverは、散布図にクリックでデータ点を追加するだけで、線形回帰や多項式、指数・べき乗曲線へのフィッティングをリアルタイムで実行できる無料ツールです。決定係数（R²）や回帰式を即時表示し、回帰分析と曲線フィッティングを直感的に学び、実行できます。

**Category:** 統計・データ解析

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/regression-analysis.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/regression-analysis.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/regression-analysis.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/regression-analysis
python -m http.server 8000
# open http://localhost:8000
```
