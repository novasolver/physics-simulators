# 向心力 シミュレーター — 等速円運動の力学

等速円運動する物体に作用する向心力 F_c=mv²/r をリアルタイム可視化。質量・接線速度・半径・重力加速度を変えて向心加速度 a_c=v²/r、周期 T=2πr/v、g単位加速度を計算し、v²則の曲線で速度依存性を確認できます。

**Category:** 古典力学シミュレーター
