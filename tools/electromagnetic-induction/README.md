# 電磁誘導・ファラデーの法則シミュレーター

コイルパラメータと磁場を設定して、磁束Φ・誘導起電力ε・誘導電流Iをリアルタイム可視化。レンツの法則アニメーション・相互インダクタンス・変圧器計算に対応。

**Category:** 電磁気・光学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/electromagnetic-induction.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/electromagnetic-induction.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/electromagnetic-induction.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/electromagnetic-induction
python -m http.server 8000
# open http://localhost:8000
```
