# 波の反射・透過シミュレーター

音波・弾性波（P波・SH波）が異なる媒質の界面に当たったとき、どれだけ反射し透過するかを計算。インピーダンス比と入射角を動かして全反射臨界角を体感しよう。

**Category:** 波動力学シミュレーター

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/wave-reflection.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/wave-reflection.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/wave-reflection
python -m http.server 8000
# open http://localhost:8000
```
