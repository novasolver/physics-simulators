# 理想気体シミュレーター（PVT曲面）

理想気体シミュレーターで状態方程式PV=nRTを3D曲面とアニメで可視化。温度・物質量変化時の圧力・密度・内部エネルギー応答をリアルタイムで探索できるCAEツール。

**Category:** 熱力学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/ideal-gas-3d.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/ideal-gas-3d.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/ideal-gas-3d.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/ideal-gas-3d
python -m http.server 8000
# open http://localhost:8000
```
