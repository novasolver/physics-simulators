# クレーン荷重・ロープ張力計算

クレーン設計の実務向け計算ツール。ロープ本数・吊り角度・シーブ効率・動荷重係数を考慮し、ロープ張力・ドラム引張力・安全荷重（SWL）・必要破断強度を自動算出します。設計プロセスを効率化し、安全性を確保するための包括的な計算手法を提供します。

**Category:** 構造力学
