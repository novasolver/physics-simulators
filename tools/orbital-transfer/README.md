# ホーマン遷移軌道シミュレーター

ホーマン遷移軌道をリアルタイム可視化。初期軌道半径・目標軌道半径を設定してΔv1・Δv2・遷移時間を自動計算。宇宙探査機の軌道変更を直感的に理解。LEO→GEO・地球→火星・地球→金星プリセット付き。

**Category:** 物理シミュレーター

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/orbital-transfer
python -m http.server 8000

```
