# 振動絶縁器シミュレーター — 伝達率TRと周波数比

基礎の振動から設備への伝達率TRをリアルタイム計算。質量・ばね定数・減衰比・強制角振動数を変えると、周波数比√2を境に絶縁領域へ移行する様子をTR-r線図で確認できます。

**Category:** 振動工学シミュレーター
