# ねじ・ボルト締め付けトルク計算機

ねじ・ボルト締め付けトルク計算機：メートルネジ・UNC・UNF対応。締め付けトルク・自己締結条件をリアルタイム算出。トルク曲線可視化。

**Category:** 機械力学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/screw-thread.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/screw-thread.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/screw-thread.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/screw-thread
python -m http.server 8000
# open http://localhost:8000
```
