# 転がり軸受寿命計算機（L10寿命・動等価荷重）

ラジアル荷重・アキシアル荷重・軸受型式・動定格荷重を入力するだけで、ISO 281 に基づく動等価荷重 P とベーシック定格寿命 L10h を時間と年で表示。回転速度別の寿命曲線で工況点の位置も把握できます。

**Category:** 解析ツール
