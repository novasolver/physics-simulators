# ベイズの定理ビジュアライザー

事前確率・真陽性率・偽陽性率を操作して事後確率をリアルタイム計算。医療検査・品質管理・機械学習における証拠に基づく確率更新を、棒グラフと混同行列で可視化します。

**Category:** 確率・統計

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/bayes-theorem-visual.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/bayes-theorem-visual.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/bayes-theorem-visual.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/bayes-theorem-visual
python -m http.server 8000
# open http://localhost:8000
```
