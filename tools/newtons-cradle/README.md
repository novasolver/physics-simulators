# ニュートンのゆりかご — 弾性衝突・運動量保存

ニュートンのゆりかご — 弾性衝突と運動量保存をシミュレーションで体験。反発係数・重力を変更して衝突エネルギーを可視化し、力学計算の検証に活用できます。

**Category:** 物理シミュレーター

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/newtons-cradle.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/newtons-cradle.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/newtons-cradle.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/newtons-cradle
python -m http.server 8000
# open http://localhost:8000
```
