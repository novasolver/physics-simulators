# オプション価格計算機（ブラック-ショールズ）

ブラック-ショールズモデルに基づくオプション価格計算ツールです。理論価格とデルタ・ガンマ・ベガ・シータ・ローの全5グリークスをリアルタイムで計算。インプライドボラティリティの推定や、ペイオフ図・デルタ曲線の視覚化も可能。オプション取引の分析と戦略立案を強力にサポートします。

**Category:** 金融工学
