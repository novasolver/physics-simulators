# PEM水電解装置の水素製造シミュレーター

PEM（固体高分子膜）水電解スタックのセル電圧・電流密度・セル数・温度を変えて、水素生成量・HHV効率・比エネルギー消費・過電圧をリアルタイムに見られるツールです。再生可能電力からグリーン水素を作るプラントの概念設計や、効率と電流密度のトレードオフの検討に使えます。

**Category:** エネルギー工学
