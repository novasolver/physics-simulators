# 土の圧密沈下計算ツール

テルツァーギの圧密理論に基づき、正規圧密粘土・過圧密粘土の圧密沈下量を計算できるシミュレーターです。最終沈下量やt50、t90をリアルタイムに可視化し、地盤工学の学習や基礎設計を支援します。地盤沈下計算の理解を深めるためのCAEツールです。

**Category:** 地盤工学

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/soil-consolidation
python -m http.server 8000
# open http://localhost:8000
```
