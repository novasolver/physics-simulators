# ISO はめあい公差セレクタ

ISO 286 の穴基準はめあいで、基準寸法と公差クラス（H7/g6 など）を選ぶと、穴と軸の寸法許容差・最大すきま・最小すきま・はめあいの種類がリアルタイムで分かります。公差域図で穴と軸の位置関係も可視化します。

**Category:** 機械要素設計
