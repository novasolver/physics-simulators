# 地震による液状化沈下計算機

Tokimatsu-Seed法（1987）に基づき、循環応力比CSR・循環抵抗比CRR・安全率FL・体積ひずみ・液状化後沈下量を解析。Mw=7.5 を基準としたCRR評価と修正N値補正を内蔵し、液状化対策設計や地震リスク評価に活用できます。

**Category:** 地盤工学
