# マンデルブロ集合ビューワー

マンデルブロ集合をブラウザ上で美しく探索できるインタラクティブなフラクタルビューワーです。無限ズームで神秘的な模様を発見し、ジュリア集合への切り替えやスムースカラーリング機能で数値計算の世界を可視化。幾何学の複雑さを体験できるオンラインシミュレーターです。

**Category:** フラクタル・数値計算

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/fractal-mandelbrot.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/fractal-mandelbrot.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/fractal-mandelbrot.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/fractal-mandelbrot
python -m http.server 8000
# open http://localhost:8000
```
