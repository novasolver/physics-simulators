# ハイゼンベルクの不確定性原理シミュレーター

ハイゼンベルクの不確定性原理をガウス波束でリアルタイム可視化。位置と運動量の不確定性の関係を直感的にシミュレーション。量子力学の基本原理を理解する教育ツール。

**Category:** 量子力学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/heisenberg-uncertainty.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/heisenberg-uncertainty.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/heisenberg-uncertainty.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/heisenberg-uncertainty
python -m http.server 8000
# open http://localhost:8000
```
