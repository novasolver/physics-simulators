# 航空機の上昇率（余剰パワー法）シミュレーター

飛行機がどれだけ速く高度を稼げるかを「余剰パワー法」で計算するツールです。機体重量・エンジンの利用可能パワー・水平飛行に必要なパワー・上昇速度を変えると、上昇率・上昇角・上昇勾配がリアルタイムで分かり、飛行機が高度を得る仕組みを直感的に理解できます。

**Category:** 航空宇宙
