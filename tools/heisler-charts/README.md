# ハイスラー線図シミュレーター — 非定常熱伝導

一様温度の物体を急に対流環境にさらしたときの非定常熱伝導を、ハイスラー線図の一項近似で計算するツールです。ビオ数とフーリエ数を変えると、平板・球の中心温度と任意位置の無次元温度がリアルタイムで分かります。

**Category:** 熱工学
