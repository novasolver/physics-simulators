# 高度座屈解析（初期不整・P-δ曲線）

断面形状・端末条件・偏心距離を設定し、オイラー座屈荷重・長細比・P-δ曲線をリアルタイム計算。初期不整の影響と変形モード形状を可視化します。

**Category:** 構造安定性

- 🇯🇵 [日本語](https://novasolver.jp/tools/column-buckling-adv.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/column-buckling-adv.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/column-buckling-adv.html)

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/column-buckling-adv
python -m http.server 8000
```
