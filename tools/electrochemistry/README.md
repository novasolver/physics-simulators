# 電気化学・電解計算機

ファラデーの法則に基づき、電気めっき・電気分解・電解精製の計算を支援するツールです。電流、時間、電流効率を入力するだけで、析出量、膜厚、エネルギー消費量をリアルタイムに算出。複雑な手計算を簡略化し、研究開発や現場での迅速な評価を可能にします。

**Category:** 電磁気・電気化学
