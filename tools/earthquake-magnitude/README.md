# 地震マグニチュード・震度変換計算機

地震マグニチュード・震度変換計算機。マグニチュード、震源深さ、震央距離からPGA・気象庁震度・MMIスケールをリアルタイム計算。地震波伝播ビジュアル対応。

**Category:** 地球物理シミュレーター

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/earthquake-magnitude.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/earthquake-magnitude.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/earthquake-magnitude.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/earthquake-magnitude
python -m http.server 8000
# open http://localhost:8000
```
