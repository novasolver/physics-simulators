# 波の干渉・重ね合わせシミュレーター

2つの正弦波の周波数や位相を自由に設定し、干渉と重ね合わせをリアルタイムアニメーションで可視化。同位相・逆位相による強め合いと弱め合い、うなり、定在波の発生を直感的に体験できるシミュレーターです。波動の基本原理を学び、数式と現象を結びつけましょう。

**Category:** 振動・波動
