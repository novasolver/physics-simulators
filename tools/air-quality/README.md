# 空気質指数（AQI）計算機

空気質指数（AQI）計算機：PM2.5、PM10、NO₂、O₃、CO濃度からAQIをリアルタイム計算。WHO指針との比較と健康カテゴリ判定。環境工学・大気質評価。

**Category:** 環境工学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/air-quality.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/air-quality.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/air-quality.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/air-quality
python -m http.server 8000
# open http://localhost:8000
```
