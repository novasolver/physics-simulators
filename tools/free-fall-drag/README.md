# 自由落下・終端速度シミュレーター

自由落下・終端速度シミュレーターで、質量・空気抵抗・断面積による落下運動の違いを数値解析。真空落下と空気中落下を比較し、終端速度を解析的に学習。

**Category:** 機械力学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/free-fall-drag.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/free-fall-drag.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/free-fall-drag.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/free-fall-drag
python -m http.server 8000
# open http://localhost:8000
```
