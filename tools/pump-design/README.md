# 遠心ポンプ設計計算ツール

遠心ポンプ設計計算ツール：H-Q曲線とシステム曲線の交点をリアルタイム解析。軸動力・比速度・適正流量を確認できるCAEツール。

**Category:** 流体機械

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/pump-design.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/pump-design.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/pump-design.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/pump-design
python -m http.server 8000
# open http://localhost:8000
```
