# 噴流混合・速度/温度プロファイル発達

自由噴流・衝突噴流の速度・温度プロファイルの発達をシミュレート。噴流出口速度・ノズル径・温度差を操作し、混合層の広がり方と相似則を直感的に理解できます。

**Category:** 流体解析
