# 蒸気特性計算機

蒸気特性計算機「NovaSolver」は、モリエ線図（h-s図）と水蒸気表を用いて、水蒸気の比エンタルピー・比エントロピー・比容積・乾き度をリアルタイム計算。温度・圧力スライダーで飽和蒸気、過熱蒸気、湿り蒸気の状態を可視化し、熱力学解析を支援します。

**Category:** 熱力学

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/steam-properties
python -m http.server 8000
# open http://localhost:8000
```
