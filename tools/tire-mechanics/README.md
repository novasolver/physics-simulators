# タイヤ力学シミュレーター — Pacejka Magic Formula

Pacejka Magic Formulaに基づくタイヤ力学シミュレーターです。スリップ角や荷重を調整し、タイヤの横力・縦力・摩擦円をリアルタイムで計算・可視化。コーナリング剛性や最大横力の分析を支援するCAEツールで、車両運動性能の検討に最適です。

**Category:** 機械力学
