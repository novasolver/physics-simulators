# 沸騰相関式シミュレーター

沸騰相関式シミュレーターで沸騰伝熱の熱流束、圧力、蒸気品質から熱伝達率とCHF余裕を迅速に概算。沸騰相関式の実務計算ツール。

**Category:** 対話型シミュレーター

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/boiling-correlations-detail.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/boiling-correlations-detail.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/boiling-correlations-detail.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/boiling-correlations-detail
python -m http.server 8000
# open http://localhost:8000
```
