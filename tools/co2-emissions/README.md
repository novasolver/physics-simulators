# CO2排出量・ライフサイクル評価ツール

NovaSolverの無料CO2排出量・LCAシミュレーターで、あなたの活動の環境影響を可視化。電気・ガス・輸送・建材など、IPCC手法に基づき排出量を自動計算。ネットゼロ達成年数や植林換算もわかりやすく表示し、脱炭素戦略の第一歩をサポートします。

**Category:** 環境・エネルギー

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/co2-emissions
python -m http.server 8000
# open http://localhost:8000
```
