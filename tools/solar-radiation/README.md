# 太陽放射・日射量計算ツール

太陽放射・日射量計算ツール「NovaSolver」は、緯度や日付、傾斜角を入力するだけで太陽高度と日射量をリアルタイム計算。傾斜面と水平面の日射量を比較し、太陽軌道をグラフで可視化します。太陽光発電パネルの設計や建築の日射解析に最適なシミュレーターです。

**Category:** 熱・エネルギー解析

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/solar-radiation
python -m http.server 8000
# open http://localhost:8000
```
