# 損傷許容設計・残余強度・検査間隔

損傷許容設計・残余強度・検査間隔の評価ツール。Paris則によるき裂成長解析、臨界き裂寸法、POD曲線をリアルタイム計算。航空機・圧力容器の検査間隔設計に対応。

**Category:** 構造解析
