# ビオ・サバールの法則 シミュレーター — 円電流ループの磁場

半径 R の円電流ループ（電流 I、巻数 N）が軸上距離 z に作る磁束密度 B(z) を、ビオ・サバールの法則から実時間に計算します。中心磁場・半値幅・3D ループ透視図・ベル型 B(z) プロファイル曲線を同時に可視化。

**Category:** 電磁気シミュレーター
