# ポンプキャビテーション・NPSH計算機

NovaSolverの無料オンライン計算機で、ポンプキャビテーションのリスクを簡単評価。NPSH（有効値と必要値）を自動計算し、吸込ヘッドや配管損失からキャビテーション余裕を即座にチェック。ポンプ選定や運転条件の最適化に役立つ信頼性評価ツールです。

**Category:** 流体解析

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/pump-cavitation
python -m http.server 8000
# open http://localhost:8000
```
