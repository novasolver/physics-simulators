# 複合材料積層板の ABD 行列とカップリングシミュレーター

複合材料積層板のABD行列シミュレーター。単層弾性率、積層角、積層数からA11、D11、総厚を評価。カップリング効果の実務的な理解とFRP設計に対応。

**Category:** 対話型シミュレーター

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/composite-laminate-abd-detail
python -m http.server 8000
# open http://localhost:8000
```
