# 加法混色・減法混色シミュレーター

RGB スライダーで光の加法混色を、CMY スライダーで絵具の減法混色をリアルタイム体験。ベン図・HSL 変換・スペクトル分布・色差 ΔE 計算で色彩科学を直感的に可視化します。

**Category:** 光・色彩

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/color-mixing-additive.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/color-mixing-additive.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/color-mixing-additive.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/color-mixing-additive
python -m http.server 8000
# open http://localhost:8000
```
