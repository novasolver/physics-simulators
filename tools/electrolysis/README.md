# 電気分解・電気めっき計算ツール

ファラデーの法則による電気めっき・電気分解計算ツール。電流・時間・面積から金属析出量や膜厚をリアルタイム算出。Cu/Ni/Cr/Zn/Au/Ag対応。

**Category:** 電気化学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/electrolysis.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/electrolysis.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/electrolysis.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/electrolysis
python -m http.server 8000
# open http://localhost:8000
```
