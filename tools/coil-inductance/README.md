# コイルインダクタンス計算器

空芯コイルのインダクタンスを、Nagaoka係数とWheeler式で高精度に計算できるシミュレーターです。コイルの直径・長さ・巻数を自在に変更し、リアルタイムでL-N曲線やL-D曲線を可視化。電磁気設計や回路設計の効率化に最適なツールです。

**Category:** 電磁気解析
