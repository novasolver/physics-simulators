# 射出成形・充填圧力・冷却時間計算機

ランナー形状・溶融粘度・成形品肉厚を入力して充填圧力・冷却時間・型締め力・サイクルタイムを即計算。溶融樹脂の充填過程をアニメーションで可視化します。

**Category:** プラスチック成形プロセス計算機

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/injection-molding.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/injection-molding.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/injection-molding.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/injection-molding
python -m http.server 8000
# open http://localhost:8000
```
