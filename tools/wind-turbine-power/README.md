# 風力発電パワーシミュレーター — ベッツ限界・Weibull分布・年間発電量

風力発電パワーシミュレーター：ロータ直径・Cp係数・風速パラメータからベッツ限界とWeibull分布による年間発電量AEPを計算。風力発電設計・性能評価の最適化ツール。

**Category:** 環境・エネルギー
