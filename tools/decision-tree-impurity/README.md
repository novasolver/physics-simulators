# 決定木の不純度指標 — Gini・Entropy・誤分類率の比較

2クラス分類における3つの不純度指標を1つのグラフで比較。クラス比と分割を変えて、なぜCARTがGiniを使うのか、なぜ誤分類率が分割基準に向かないのかを直感的に学べます。

**Category:** 機械学習シミュレーター
