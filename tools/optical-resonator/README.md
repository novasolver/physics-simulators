# 光共振器・レーザー設計ツール

Fabry-Perot光共振器の設計を支援する無料シミュレーションツールです。FSR（自由スペクトル範囲）、フィネス、Q値、光子寿命をリアルタイムで計算。エアリー関数による透過曲線とガウシアンビームプロファイルを可視化し、レーザー共振器の設計・解析を直感的に行えます。

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/optical-resonator
python -m http.server 8000
# open http://localhost:8000
```
