# 圧入・締まり嵌めシミュレーター

圧入・締まり嵌め設計のためのシミュレーター。ラメ式で接触圧力と応力分布を計算し、締め代・材料特性のパラメトリック解析が可能。ハブシャフト応力評価に。

**Category:** 構造解析

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/press-fit.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/press-fit.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/press-fit.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/press-fit
python -m http.server 8000
# open http://localhost:8000
```
