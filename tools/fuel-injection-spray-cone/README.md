# 燃料噴霧 噴霧角・SMD シミュレーター

ディーゼル・GDI・ポート噴射インジェクタの噴霧形成を設計するツールです。噴射圧力・環境密度・ノズル孔径・燃料・噴射時間を変えると、噴射速度、噴霧コーン角、Sauter 平均粒径 SMD、噴霧到達距離がリアルタイムで分かり、燃焼とエミッションを両立する噴射条件を探せます。

**Category:** 内燃機関・噴射系
