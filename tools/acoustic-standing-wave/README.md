# 音響定在波シミュレーター

音響定在波シミュレーターで閉管・開管の固有周波数とモード形状をリアルタイム可視化。管長・温度・境界条件を変更して音圧分布を解析できるCAEツール。

**Category:** 音響解析ツール

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/acoustic-standing-wave.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/acoustic-standing-wave.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/acoustic-standing-wave.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/acoustic-standing-wave
python -m http.server 8000
# open http://localhost:8000
```
