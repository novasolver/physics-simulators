# パーセバルの定理 — 時間と周波数のエネルギー保存

離散信号の時間域エネルギーと周波数域エネルギーがDFTで完全に一致することを、正弦・矩形パルス・ガウスの3信号で実時間検証。フーリエ解析の中核となる保存則を直感的に体感できます。

**Category:** 信号処理シミュレーター
