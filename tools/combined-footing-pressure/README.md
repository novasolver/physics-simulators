# 複合フーチングの接地圧シミュレーター

2本の柱を1枚で支える複合フーチング（連続フーチング）を設計するツールです。2本の柱荷重・柱間距離・フーチング寸法を変えると、合力の偏心量と地盤に伝わる接地圧の分布、核内外の判定がリアルタイムで分かり、均一に近い接地圧の基礎を探せます。

**Category:** 地盤工学
