# 信号変調シミュレーター

信号変調シミュレーターでAM・FM・PM変調の波形とスペクトルをリアルタイム表示。搬送波周波数・変調指数を操作しながら通信変調の本質を学習できます。

**Category:** 通信工学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/signal-modulation.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/signal-modulation.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/signal-modulation.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/signal-modulation
python -m http.server 8000
# open http://localhost:8000
```
