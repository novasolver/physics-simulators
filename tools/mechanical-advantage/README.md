# 機械的利益・簡単な機械 計算ツール

NovaSolverの機械的利益計算ツールは、てこ、滑車、斜面、ねじジャッキ、輪軸の機械的利益(MA)と効率を簡単に計算。摩擦の影響を視覚的に理解でき、荷重と力の関係をグラフで確認可能。機械工学の学習やCAE入門に最適なシミュレーターです。

**Category:** 機械工学ツール

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/mechanical-advantage
python -m http.server 8000
# open http://localhost:8000
```
