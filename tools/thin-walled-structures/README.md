# 薄肉断面のせん断流れ・ねじり計算機（ブレット-バタリー）

閉断面（箱型・円形）と開断面（C形・I形）のねじり剛性をブレット-バタリー理論でリアルタイム比較。せん断流れ矢印と応力分布を断面周りにアニメーション表示。

**Category:** 構造解析ツール
