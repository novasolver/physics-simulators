# レシプロエンジン熱力学シミュレーター

レシプロエンジンの熱力学サイクルを可視化・解析するシミュレータです。オットー・ディーゼル・アトキンソン・デュアルサイクルのP-V線図をリアルタイム描画し、圧縮比などのパラメータ変更で熱効率・仕事量を即座に計算。ピストン動作アニメーションで理解が深まります。NovaSolverでエンジン設計や学習を効率化しましょう。

**Category:** 熱力学

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/piston-engine
python -m http.server 8000
# open http://localhost:8000
```
