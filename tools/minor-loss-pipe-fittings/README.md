# 管継手の局所損失 シミュレーター — K 値法

エルボ・バルブ・継手などの局所損失係数 ΣK と直管摩擦損失を合算し、配管系の全圧力損失 ΔP、水頭損失 h_L、等価長さ L_e を即座に可視化します。流体は水（ρ = 1000 kg/m³）、f = 0.020 を仮定。

**Category:** 管路流体シミュレーター
