室内残響時間 RT60 シミュレーター

部屋の寸法・壁/天井/床の材質・人数・吸音パネルから、室内残響時間 RT60 を Sabine 式と Eyring 式で同時に算出します。オフィスからコンサートホール、録音スタジオ、教会まで、用途別の目標残響時間と比較しながら音響設計を進められるツールです。

室内モデル — 音源・反射波・RT60 ゲージ

中央の音源から発した音が壁・天井・床で反射しながら -60 dB 減衰するまでが RT60。黄色帯が吸音パネル、人型が在室者。RT60 ゲージの色は用途別目標との偏差を示します。

理論・主要公式

$$RT_{\text{Sabine}} = \frac{0.161\,V}{A},\qquad RT_{\text{Eyring}} = \frac{-0.161\,V}{S\,\ln(1-\bar\alpha)}$$

V：室容積 [m³]、A=Σαᵢ·Sᵢ：等価吸音面積 [m² Sabin]、ᾱ=A/S：平均吸音率、S：全表面積 [m²]。Eyring 式は ᾱ が大きい吸音室で精度が高い。

$$A = \sum_i \alpha_i S_i + N_p\,a_p + S_{\text{panel}}\,\alpha_{\text{panel}}$$

壁・天井・床の吸音と、人数 Nₚ（1 人 ≈ 0.46 m² Sabin）、吸音パネル面積 S_panel（α≈0.9）の寄与の総和が A。

$$\text{STI} \approx \frac{1}{1 + RT_{60}/0.5}$$

音声明瞭度の簡易プロキシ。RT60 が短いほど STI が 1 に近づき、話し言葉の理解度が上がる。

室内残響時間 RT60 — Sabine・Eyring 式 音響設計

🙋
残響時間 RT60 って、よく音響の本に出てきますけど、要するに「響きの長さ」のことですか？
🎓
そう、ほぼその理解で OK。厳密には「音源を止めた瞬間からエネルギーが 60 dB 落ちるまでにかかる時間」を秒で表したものだ。例えば手をパンと叩いて 0.5 秒で消えれば RT60=0.5 秒、教会のように 4 秒残れば RT60=4 秒。1898 年に Wallace Sabine が Harvard の Fogg 美術館で測った結果から導いた式 RT = 0.161·V/A が、今でも一番よく使われる基本式なんだ。
🙋
部屋が大きいほど長く響くのは何となく分かるんですが、「A」って何ですか？
🎓
A は「等価吸音面積」、単位は m² Sabin。各面の吸音率 α と面積 S を掛けて足したもので、A = α₁S₁ + α₂S₂ + ... となる。コンクリートは α=0.02 とほぼ無吸音、音響タイルは α=0.7、カーペットは α=0.4。デフォルト設定（10×8×3.5m のオフィス）でやってみると、A≈108 m² Sabin、V=280 m³ で RT60≈0.42 秒。これは目標 0.5 秒のオフィスとして「ちょうど良い」レベルだ。
🙋
同じツールに Sabine と Eyring の 2 つが並んでますが、なんで使い分けるんですか？
🎓
Sabine 式は α が小さいライブな部屋では十分正確だけど、ᾱ が 0.3 を超えるような吸音性の高い部屋では実測より長めに出てしまう。そこで Eyring 式 RT = -0.161·V/(S·ln(1-ᾱ)) が出てくる。ln の中に (1-ᾱ) があるから、ᾱ が大きいほど補正が効く。録音スタジオで「用途」を studio にしてみて。壁を木パネル、天井を音響タイル、吸音パネルを 50 m² くらい入れると、Sabine と Eyring の差が広がるのが見えるはずだ。
🙋
話し声がよく聞こえる教室、と、余韻が美しいホール、では目標値が大きく違いますよね。
🎓
そこが音響設計のおもしろいところだね。話し言葉の明瞭度を重視するなら RT60 は短いほど良い：オフィス 0.5 秒、教室 0.6 秒、講演ホール 1.0 秒。一方、クラシック音楽の響きを楽しむコンサートホールは 1.8〜2.0 秒が黄金値で、サントリーホール 1.9 秒、ベルリン Philharmonie 2.0 秒、Carnegie Hall 1.8 秒と、世界の名ホールはこの帯に集まっている。教会は 4 秒以上もザラで、グレゴリオ聖歌はその残響を前提に書かれているくらいだ。用途を切り替えて目標値の違いを体感してみて。
🙋
RT60 を実際に短くしたい時って、何から手を付ければいいですか？
🎓
一番効くのは「吸音パネル」を増やすこと。α=0.9 のロックウール系パネルを 10 m² 足すと A が 9 増える。次に天井材を「むき出し」から「音響タイル」に変えると、80 m²×(0.7-0.1)=48 m² Sabin も追加できて劇的に短くなる。床のカーペットも効くけど、衛生面で導入できない場面も多い。実務では「壁・天井・床のどこをいじれるか」が設計の制約になり、本ツールで材質を切り替えながら目標値に追い込んでいくのが定石だよ。

よくある質問

Sabine 式 RT = 0.161·V/A は平均吸音率 ᾱ が概ね 0.2 以下のライブな部屋で実用十分です。ᾱ が 0.3 を超える吸音性の高い部屋（録音スタジオ・無響室寄りの部屋）では Sabine 式が過大評価しがちなので、Eyring 式 RT = -0.161·V/(S·ln(1-ᾱ)) を使います。本ツールでは両方を同時に表示し、デッドな部屋ほど両式の値が乖離する様子を確認できます。
オフィス 0.4〜0.6 秒、教室 0.6〜0.8 秒、会議室 0.6〜0.9 秒、講演主体のホール 0.9〜1.4 秒、コンサートホール 1.8〜2.2 秒、録音スタジオ 0.2〜0.4 秒、教会 4 秒前後が一般的な目安です。本ツールは用途を選ぶと自動で目標値を設定し、現在の RT60 との偏差を表示します。話し言葉の明瞭度を重視するか、響きを楽しむかで設計指針が大きく変わります。
吸音パネル（ロックウールやグラスウール系）の 500 Hz 吸音率は概ね 0.9 と高く、A = 0.9·S_panel ぶんの等価吸音面積が追加されます。例えば 280 m³ のオフィスで現在 RT60=1.2 秒、目標 0.5 秒の場合、A を約 2.4 倍に増やす必要があり、不足分の A を 0.9 で割ったパネル面積を追加します。実務では壁面・天井に分散配置し、初期反射音の集中を避けるのがコツです。
着衣した成人 1 人あたりの等価吸音面積は概ね 0.46 m² Sabin で、人が増えるほど A が増え RT60 が短くなります。コンサートホールでは満席と空席で RT60 が 0.3〜0.5 秒変わることがあり、これを補うために空席時の吸音を増やす椅子（吸音背もたれ）を使うのが定番です。本ツールでは「人数」スライダーを動かすと、満席・空席の差をシミュレーションできます。

実世界での応用

オフィス・コワーキング空間：近年のフリーアドレス化と Web 会議の普及で、オフィスの音響設計が重要視されています。目標 RT60≒0.5 秒を狙い、天井に吸音タイル、床にカーペット、間仕切りに吸音パネルを組み込む構成が定番です。本ツールで「用途=office」「天井=acoustic-tile」「床=carpet」と組み合わせると、デフォルトのままで目標域に収まることが確認できます。RT60 が長すぎると会議の聞き取りにくさや集中力低下を招くため、改装時には必ず音響を検討すべきです。

コンサートホール・劇場：サントリーホール（1.9 s）、ベルリン Philharmonie（2.0 s）、Carnegie Hall（1.8 s）など世界の名ホールは満席時で 1.8〜2.2 秒の RT60 を狙って設計されています。ODEON や CATT-Acoustic、EASE などの 3D 音線追跡シミュレータで詳細解析を行いますが、初期設計段階では本ツールのような Sabine 計算で容積と吸音面の概算を決めます。「ホール（用途=auditorium）」を選ぶと目標 1.8 秒との偏差を確認できます。

録音スタジオ・無響室：録音スタジオは目標 RT60=0.2〜0.4 秒、無響室は限りなく 0 秒を狙います。吸音パネル（α=0.9 のロックウール系）を壁・天井全面に施工し、Eyring 式での評価が必須となる領域です。本ツールで「用途=studio」「壁=wood-panel」「天井=acoustic-tile」「吸音パネル=80 m²」のように極端な吸音設計を入力すると、Sabine と Eyring の差が顕著になり、デッドな部屋ほど Eyring 式が必要だと体感できます。

教室・学校・体育館：教室の RT60 目標は ANSI S12.60 で 0.6 秒以下と規定されており、これを満たさないと児童の語彙習得や読解力に影響することが米国の研究で示されています。日本の学校も校舎リフォーム時に音響改善が進んでおり、天井に吸音材・後壁に吸音パネルが標準仕様になりつつあります。体育館は容積が大きく RT60 が長くなりやすいため、屋根面への吸音処理が効果的です。

よくある誤解と注意点

まず大きな落とし穴が、「RT60 の周波数依存を忘れる」こと。本ツールは設計簡便化のため 500 Hz の代表値で計算していますが、実際の RT60 は周波数で大きく変わります。多くの吸音材は低音（125 Hz）には効きにくく、低音だけ RT60 が 2〜3 倍長いという部屋は珍しくありません。これがいわゆる「ブーミング」の原因です。実機設計では 125/250/500/1k/2k/4k Hz の 6 バンドで個別に計算し、低音には共鳴吸音体（Helmholtz レゾネータ）を追加します。ISO 3382 のインパルス応答測定も同様にオクターブバンドごとに評価します。

次に、「Sabine 式だけで吸音設計を完結させる」誤解。Sabine 式は ᾱ が小さい部屋では正確ですが、吸音材を大量に入れた録音スタジオでは過大評価になり、実測より長く出ます。本ツールで Sabine と Eyring を並べて表示しているのはこの注意喚起のためで、ᾱ が 0.3 を超えたら Eyring 式の値を採用してください。さらに ᾱ が 0.5 を超えると Eyring も限界に近づき、空気吸収やエッジ効果も含めた Millington-Sette 式や FEM/BEM 解析、CATT-Acoustic のような波線追跡シミュレータでの検証が必要になります。

最後に、「RT60 を短くすれば必ず良い」という思い込み。確かに会議室やオフィスでは短い方が明瞭度が上がりますが、音楽用途では響きの長さが感動を生みます。極端に吸音すると音楽は「干からびた」音になり、演奏者も歌いにくくなる。教会の RT60 が 4 秒以上ある理由は、グレゴリオ聖歌やパイプオルガンがその残響を前提に作られているからです。用途と聴き手の要求を理解した上で目標値を決めること、そしてディフューザー（拡散体、QRD/PRD）と吸音体のバランスで「適度に響き、適度に消える」設計を狙うことが、音響設計者の真骨頂です。

使い方ガイド

  1. 室内寸法（縦・横・高さ）をメートル単位で入力し、容積Vを算出
  2. 内装材料（石膏ボード・コンクリート・カーペット・グラスウール等）と人数を選択して等価吸音面積Aを計算
  3. Sabine式（A = 0.161 × V / RT60）とEyring式（より高吸音率環境で正確）の両方のRT60値を比較
  4. オフィス（0.6～0.8s）・会議室（0.4～0.6s）・スタジオ（0.2～0.4s）・教会（2.5～3.5s）などの用途別目標値との差分を確認し、吸音パネル追加数を調整

具体的な計算例

長さ8m×幅6m×高さ3mのオフィス会議室（容積144m³）にコンクリート壁（α=0.02）、石膏ボード天井（α=0.08）、カーペット床（α=0.6）、在席者12名（1人あたり吸音面積0.5m² Sabin）を配置した場合、等価吸音面積A≈42m² Sabineで、Sabine式RT60≈0.62秒、Eyring式RT60≈0.68秒となります。目標値0.6秒に対し、グラスウール100mm吸音パネル（α=0.85）を4枚（8m²）追加するとRT60≈0.47秒に短縮できます。

実務での注意点

  1. 平均吸音率αが0.15未満の低吸音環境ではSabine式が過大評価するため、Eyring式を優先し、拡散材・バッフルの配置で音のこもりを防止
  2. 人数変動が大きい会議室は着席時RT60を基準に設計し、空室時の空洞音対策として段ボール吸音体を常備
  3. スタジオ・映画館はRT60≤0.3秒が必須だが、低周波（125Hz）は吸音パネルでは不十分なため、バスストラップ（α=0.9～1.0 @低域）の増設が必須
  4. 教会・ホールは残響時間が長く設計されるため、可動吸音カーテンで式典と音楽祭など用途切り替え時にRT60を1.5～3.5秒範囲で調整
