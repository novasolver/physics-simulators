# 燃料発熱量・熱効率計算機

燃料LHV/HHVデータベースと熱機関・ボイラーの効率計算。燃料消費量から熱入力・有効出力・SFC・CO₂排出量をリアルタイム計算しエネルギーフローを可視化。

**Category:** 熱解析

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/heat-of-combustion.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/heat-of-combustion.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/heat-of-combustion.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/heat-of-combustion
python -m http.server 8000
# open http://localhost:8000
```
