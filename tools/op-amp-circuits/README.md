# オペアンプ回路シミュレーター

オペアンプ回路シミュレーター「NovaSolver」で、反転・非反転増幅、積分・微分回路の動作をリアルタイムに可視化。ゲインや位相、波形の変化をインタラクティブに操作しながら学べます。仮想短絡の概念も理解できる、初心者からプロまで使える設計・学習ツールです。

**Category:** アナログ電子回路

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/op-amp-circuits.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/op-amp-circuits.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/op-amp-circuits.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/op-amp-circuits
python -m http.server 8000
# open http://localhost:8000
```
