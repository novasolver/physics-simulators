# ジェットポンプ（エジェクタ）シミュレーター

ジェットポンプ（エジェクタ）の流量・圧力・エントレインメント比を簡単に計算できるシミュレーターです。動力流体の条件を調整するだけで動作がリアルタイムに可視化され、混合効率や圧縮比が瞬時にわかります。流体工学の学習やCAE解析の事前検討に最適なツールです。

**Category:** 流体工学

git clone https://github.com/novasolver/physics-simulators

python -m http.server 8000
