# バンドパスフィルタ シミュレーター — 直列 RLC の共振と Q-factor

抵抗 R・インダクタ L・容量 C で構成される直列 RLC バンドパスフィルタの周波数特性をリアルタイム可視化。共振周波数・Q ファクター・帯域幅・ゲインを確認しながら、選択性の高い帯域フィルタの設計感覚を養えます。

**Category:** 信号処理シミュレーター
