理論・主要公式

伝達関数 (R 両端を出力):

$$H(j\omega) = \dfrac{R}{R + j\!\left(\omega L - \dfrac{1}{\omega C}\right)}$$

共振周波数・Q-factor・帯域幅:

$$f_0 = \dfrac{1}{2\pi\sqrt{LC}},\quad Q = \dfrac{1}{R}\sqrt{\dfrac{L}{C}} = \dfrac{\omega_0 L}{R},\quad \mathrm{BW} = \dfrac{f_0}{Q}$$

$f = f_0$ では $|H| = 1$ (0 dB) かつ位相 0°。$f_0$ から外れると両側で -20 dB/decade で減衰し、-3 dB の点が $f_0 \pm \mathrm{BW}/2$ となる。

直列 RLC バンドパスフィルタとは

🙋
バンドパスって、低い周波数も高い周波数もカットして、真ん中だけ通すフィルタですよね？どうしてそんなことができるんですか？
🎓
ざっくり言うと、直列 RLC では L のリアクタンス $\omega L$ と C のリアクタンス $1/(\omega C)$ が逆向きに働く。低周波では C が大きなインピーダンスになって電流が流れず、高周波では L が大きなインピーダンスで電流が流れない。中央の f_0 でだけ両者が打ち消し合って R だけ残るから、電流が最大になり R 両端の電圧も最大になるんだ。
🙋
Q-factor が大きいほど鋭くなるって聞いたんですけど、Q = 1 と Q = 10 ってどのくらい違うんですか？
🎓
Q = 1 だと帯域幅は f_0 と同じ (例: f_0 = 1.6 kHz なら BW ≈ 1.6 kHz) で、なだらかな山。Q = 10 だと BW = 160 Hz、つまり 10 倍鋭くなる。AM ラジオの同調回路なんかは Q = 50〜100 くらいで、隣の放送局を分離できるくらい尖らせる。一方、オーディオのトーンコントロールでは Q = 0.7〜1.5 くらいで自然な山にする。
🙋
実際の回路で高 Q を出すのって難しいんですか？
🎓
そう、コイルには必ず直流抵抗 r_L があって、実効的な R が大きくなる。例えば 10 mH のコイルでも r_L = 2〜5 Ω あるのが普通で、設計上の R が 1 Ω でも実際は数 Ω 込みで Q が計算される。高 Q が必要なら空芯ソレノイドやフェライトコア、または LC を能動素子で代替するアクティブバンドパス (Sallen-Key, multiple-feedback) を使う。

物理モデルと主要な数式

直列 RLC 回路に正弦定常電圧 $V_{in}$ を加え、R 両端の電圧 $V_{out}$ を出力に取ると、合成インピーダンス $Z = R + j(\omega L - 1/(\omega C))$ を用いて伝達関数は次のように書ける。

$$H(j\omega) = \dfrac{V_{out}}{V_{in}} = \dfrac{R}{R + j\!\left(\omega L - \dfrac{1}{\omega C}\right)}$$

共振条件 $\omega L = 1/(\omega C)$ から $\omega_0 = 1/\sqrt{LC}$、すなわち $f_0 = 1/(2\pi\sqrt{LC})$ を得る。$f_0$ で $|H| = 1$ となり、位相は 0° である。

$$|H(f)| = \dfrac{R}{\sqrt{R^2 + \!\left(\omega L - 1/(\omega C)\right)^2}},\quad Q = \dfrac{1}{R}\sqrt{\dfrac{L}{C}},\quad \mathrm{BW} = \dfrac{f_0}{Q}$$

ゲインが $1/\sqrt{2}$ (= -3.01 dB) に落ちる 2 点 $f_L, f_H$ の間隔が帯域幅で、$f_H - f_L = \mathrm{BW}$、また $f_0 = \sqrt{f_L f_H}$ という幾何平均関係が成り立つ。

実世界での応用

無線受信機の同調回路: AM/FM ラジオでは LC 共振回路で特定の搬送波周波数だけを取り出す。可変コンデンサや可変インダクタで f_0 をスキャンする。

センサ前段の選択フィルタ: 50/60 Hz の電源ハムや高周波ノイズを避けて、対象信号 (例: 1 kHz の振動センサ) の帯域だけを抽出する。

音響イコライザ: ミッドレンジ (例: 1 kHz 前後) を強調・抑制するため、Q を調整できるバンドパスを用いる。グラフィック EQ は複数の固定 Q バンドパスを並列接続した構成。

振動・加速度解析: 機械の特定モード周波数を抽出して状態監視 (CBM) に用いる。Q を高くすると解像度が上がるが応答が遅くなるので、用途で使い分ける。

よくある誤解と注意点

誤解 1: 通過帯域内ではゲインが完全に 1。 実際は $|H|$ は $f_0$ でのみ 1 で、両端の $f_L, f_H$ で 0.707、帯域内でも山なりの分布。フラットな通過帯域が必要なら高次のバターワース型などを使う。

誤解 2: Q を上げれば常に良い。 Q を上げると帯域は狭くなるが、立ち上がり/立ち下がり応答が遅くなり (時定数 ~ Q/f_0)、過渡応答でリンギングが残る。パルスや AM 復調では適切な Q (1〜5) が望ましい。

誤解 3: R = 0 にすれば理想バンドパス。 R を小さくすると Q は無限大に向かうが、コイルの r_L、配線抵抗、電源インピーダンスが残り、現実には Q が頭打ちになる。さらに無負荷では信号源インピーダンスも Q を支配する要素になる。

よくある質問

直列 RLC バンドパス (R 出力) は f_0 で電流最大・出力最大。並列 RLC バンドパスは f_0 で合成インピーダンス最大となり、電流源駆動で同様の山型特性を得る。Q の定義も並列では Q = R√(C/L) となり、R を大きくする方向で Q が上がる点が逆になる。
受動 RLC で Q を変えるには R を変えるのが直接的だが、出力電圧レベルも変わるため、ゲイン補正が必要になる。アクティブフィルタ (state-variable / biquad) を使えば、ゲイン・f_0・Q を独立に設計でき、デジタル制御も可能。
目標 f_0, Q を決めたら、まず L を入手可能な値 (例: 10 mH) で固定し、C = 1/(L(2π f_0)^2) で求める。次に R = (1/Q)·√(L/C) = ω_0 L/Q で抵抗を決める。コイルの直流抵抗 r_L を差し引いて外部 R を選ぶ。

使い方ガイド

  1. 抵抗(R)・インダクタンス(L)・キャパシタンス(C)の値をスライダーで設定します。例えばR=50Ω、L=10mH、C=1μFで初期化してください
  2. 観測周波数(f)を変更して、その周波数でのゲイン(dB)の変化を確認します
  3. 出力される共振周波数f₀、Q-factor、帯域幅(BW)の値から、フィルタの選択性と鋭さを評価します

具体的な計算例

R=100Ω、L=50mH、C=0.1μFの直列RLCフィルタの場合、共振周波数f₀=√(1/LC)/(2π)≈2.25kHzとなります。Q-factor=ωL/R=(2π×2250×0.05)/100≈7.07で、帯域幅BW=f₀/Q≈318Hzです。観測周波数を2.25kHzに設定するとゲイン0dB(最大)、±318Hz離れた周波数では-3dB点に到達します。高周波通信機や音声フィルタリング用途ではこのQ値が鋭度を決定します

実務での注意点

  • 低Q値(1～3)を得るにはR値を大きくします。オーディオシステムでR=1kΩ以上にするとフィルタの帯域幅が広がり、複数周波数成分の同時通過が可能になります
  • インダクタの寄生抵抗は実際にはL値に含まれるため、実装時は計測して補正してください。DCR測定で5～20Ωの追加損失が生じることが多いです
  • キャパシタの誘電率温度特性(NPO品で±30ppm/℃)により、f₀が変動します。精密フィルタ設計では温度補償または選別が必須です
  • 高周波帯(10MHz以上)ではプリント基板のレイアウトが共振周波数に影響するため、寄生インダクタンスの最小化が重要です
