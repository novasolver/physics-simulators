# 打抜き・ブランキングのプレス力シミュレーター

円形パンチで板金に穴を開ける（打抜き／ブランキング）ときに必要なプレス力を、パンチ直径・板厚・材料のせん断応力からリアルタイムで計算します。剪角の効果やストリッピング力まで含めた総プレス力が分かるので、必要なプレス機のトン数選定にそのまま使えます。

**Category:** 加工技術
