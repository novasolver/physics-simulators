# 柱座屈モード形シミュレーター

柱座屈モード形シミュレーターで、ピン支持や固定支持など様々な条件での座屈モードをリアルタイムアニメーションで可視化。座屈荷重や有効座屈長さを自動計算し、オイラー座屈理論を視覚的・インタラクティブに学べます。構造力学の理解を深める教育ツールです。

**Category:** 構造安定性・設計

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/buckling-modes.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/buckling-modes.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/buckling-modes.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/buckling-modes
python -m http.server 8000
# open http://localhost:8000
```
