# ISS 微小重力 マランゴニ対流・液滴シミュレーター

国際宇宙ステーション（ISS）の微小重力環境における表面張力駆動のマランゴニ対流を計算。温度差・流体物性・特性長・重力レベルからマランゴニ数 Ma、レイリー数 Ra、動的 Bond 数を求め、ブイヤンシー対流とマランゴニ対流の競合を可視化できる無料シミュレーターです。

**Category:** 宇宙実験・微小重力
