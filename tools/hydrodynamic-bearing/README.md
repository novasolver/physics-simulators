# 流体潤滑ジャーナル軸受設計

流体潤滑ジャーナル軸受の設計を支援する計算ツールです。ゾンマーフェルト数や最小油膜厚さ、摩擦係数をリアルタイムで計算し、Raimondi-Boyd近似による軸受性能の可否判定と最適化を行えます。設計プロセスを効率化する信頼性の高いシミュレーターです。

**Category:** トライボロジー · 流体潤滑
