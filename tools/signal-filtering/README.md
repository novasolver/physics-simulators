# デジタルフィルター周波数応答設計ツール

デジタルフィルター周波数応答設計ツール。Butterworth・Chebyshev・Bessel IIRフィルターのゲイン・位相特性をリアルタイム可視化し、カットオフ周波数や次数をインタラクティブに設計できます。

**Category:** 振動・波動

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/signal-filtering.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/signal-filtering.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/signal-filtering.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/signal-filtering
python -m http.server 8000
# open http://localhost:8000
```
