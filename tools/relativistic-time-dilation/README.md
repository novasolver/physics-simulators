# 相対論的時間遅延シミュレーター

相対論的時間遅延シミュレーターで光速接近時の時間遅延をリアルタイム可視化。ローレンツ因子と特殊相対性理論を直感的に体験、CAE解析に応用。

**Category:** 相対性理論

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/relativistic-time-dilation.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/relativistic-time-dilation.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/relativistic-time-dilation.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/relativistic-time-dilation
python -m http.server 8000
# open http://localhost:8000
```
