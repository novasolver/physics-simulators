# グラウンドアンカーの引抜き耐力シミュレーター

グラウンドアンカーの引抜き耐力を計算する無料シミュレーター。ボアホール直径・定着長・付着強度・設計荷重・安全率を変えると、極限耐力 T_ult と許容耐力 T_allow、利用率 T/T_allow がリアルタイムで分かります。擁壁・土留め・ダム基礎・送電鉄塔のアンカー設計の検討に。

**Category:** 地盤工学
