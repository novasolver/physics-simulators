# 転動接触応力・ヘルツ理論拡張計算機

ヘルツ接触理論に基づく転動接触応力計算機です。球面-平面、球面-球面、円柱-円柱など様々な接触条件の応力分布をリアルタイムに計算・可視化。接触半径や最大せん断応力、疲労判定を無料で簡単に解析できます。設計評価や研究開発に最適なオンラインツールです。

**Category:** 解析ツール
