# エアロゾル粒子動力学計算ツール

エアロゾル粒子の動力学をシミュレーションできるオンラインツール「NovaSolver」です。粒径0.01〜100μmの粒子の沈降速度、拡散係数、ストークス数、空気動力学径をリアルタイムで計算。肺沈着率の予測や粒子挙動の可視化により、研究・教育・環境評価をサポートします。

**Category:** 流体工学

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/aerosol-particle
python -m http.server 8000
# open http://localhost:8000
```
