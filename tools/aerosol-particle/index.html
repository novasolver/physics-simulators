理論・主要公式

ストークス終端沈降速度（重力＝抗力の釣合い）
$v_s = \dfrac{(\rho_p - \rho_f)\,d_p^2\,g\,C_c}{18\mu}$
$\rho_p$=粒子密度, $d_p$=粒径, $\mu$=空気粘度, $C_c$=滑り補正

緩和時間（終端速度への到達時定数。$v(t)=v_s(1-e^{-t/\tau})$）
$\tau = \dfrac{\rho_p\,d_p^2\,C_c}{18\mu}$

Cunningham補正
$C_c = 1 + \dfrac{2\lambda}{d_p}\!\left(1.257 + 0.4\,e^{-1.1d_p/2\lambda}\right)$

粒子レイノルズ数（$Re<1$ でストークス則が成立）
$Re = \dfrac{\rho_f\,v_s\,d_p}{\mu}$

ブラウン拡散係数（微小粒子の支配機構）
$D_p = \dfrac{k_B T\,C_c}{3\pi\mu\,d_p}$

エアロゾル粒子動力学とは

🙋
エアロゾル粒子の「動力学」って何ですか？空気中に浮かぶチリの動きを計算するということですか？
🎓
その通り！大まかに言うと、微細な粒子が空気中でどう動くかを予測する学問だ。例えば、ウイルスを含む飛沫がどれくらいの速さで床に落ちるか、工場の粉塵がどれだけ拡散するか、を計算するんだ。このシミュレーターでは、上の「粒径」スライダーを0.01μmから100μmまで動かすと、粒子の挙動が大きく変わるのがわかるよ。
🙋
え、粒径を変えるだけでそんなに変わるんですか？「ストークス数」って出てくる値も変わりますよね？これって何の指標なんですか？
🎓
いいところに気がついたね。ストークス数（Stk）は、粒子が気流の変化にどれだけついていけるかの目安なんだ。実務では、これが大きい（>1）と粒子は慣性で直進しやすく、小さい（<0.1）と気流に忠実に従う。例えば、自動車のエアフィルターでダストを捕集する設計では、この値が重要になる。シミュレーターで「流速」を変えながらストークス数を見ると、その関係がよくわかるよ。
🙋
「Cunningham補正係数」ってのも出てきます。これがないと計算が合わないということですか？
🎓
そうなんだ。これはサブミクロン（1μm以下）の微粒子で特に重要。粒子が小さすぎると、空気の分子が連続体として扱いにくくなり、普通の流体抵抗の式が使えなくなるんだ。この補正係数がないと、例えば0.1μmの粒子の沈降速度を100倍以上も過小評価してしまう。ツールで「粒径」を0.1μm付近にすると、Ccの値が急激に大きくなるのを確認してみて。

よくある質問

粒子径が0.01μm未満または100μm超の値になっていないかご確認ください。また、粒子密度や流体密度が極端に小さい値（0や負の値）に設定されていないかもご確認ください。数値が正しく入力されていれば、リアルタイムで計算結果が更新されます。
粒子径が1μm以下の微細粒子（特に0.1μm以下）で重要です。この領域では粒子が空気分子の平均自由行程と同程度の大きさになるため、ストークスの抵抗則が成立せず、補正が必要です。本ツールでは自動的にKnudsen数から係数を計算し、沈降速度や拡散係数に反映します。
本ツールの肺沈着率は、代表的なICRPモデルに基づく参考値です。実際の評価には、呼吸条件（流量・頻度）や粒子の形状・吸湿性などを考慮する必要があります。あくまで相対的な傾向把握や教育目的でのご利用を推奨します。
ストークス数は、粒子が流れの変化にどれだけ追従できるかを示す無次元数です。例えば、フィルターやインパクターでの粒子捕集効率の評価、または配管の曲がり部での粒子沈着予測に有用です。値が1より大きいと粒子は流れに追従しにくくなります。

実世界での応用

室内空気質・感染症対策：ウイルスや細菌を含む飛沫・エアロゾルの挙動予測に使われます。換気効率の評価や、空気清浄機の設置位置の最適化において、粒子の沈降速度や拡散係数の計算が基礎データとなります。

大気環境シミュレーション：PM2.5などの大気汚染物質が、発生源からどのように拡散・沈着するかをモデル化する際の核心的な計算です。長期予測モデルに粒子動力学のパラメータが組み込まれています。

産業プロセス・粉体工学：化学プラントでの粉塵爆発のリスク評価、塗装ブースや半導体クリーンルームでの粒子制御、吸入薬のデリバリーシステム設計など、多岐にわたる分野で応用されています。

CAEシミュレーション前処理：流体解析(CFD)で粒子の挙動を追跡するラグランジュ粒子追跡法を用いる際、粒子に働く力のモデルや、ストークス数に基づく衝突・付着モデルの設定パラメータとしてこれらの計算値が直接利用されます。

よくある誤解と注意点

まず、「粒子密度はいつも水と同じ1g/cm³でいいだろう」という思い込み。これ、結構危ないです。例えば、金属酸化物の粉塵（密度~4g/cm³）と花粉（密度~0.5g/cm³）では、同じ10μmの粒子でも沈降速度が数倍違います。肺への沈着挙動も変わってくるので、実在する粒子の密度を調べるのが第一歩です。

次に、「空気の状態は標準状態（20℃, 1気圧）で固定」と考えがちな点。高所（気圧低下）や高温環境では、空気の粘度μや密度ρ_fが変わり、計算結果に影響します。例えば、標高2000mでは空気密度が約80%になるので、浮力が減り、沈降速度は少し速くなります。実環境をシミュレートする時は、温度・圧力パラメータの調整を忘れずに。

最後に、「ストークス数Stkが1より大きい＝すぐに床に落ちる」という短絡的な解釈。Stkは気流の「曲がり角」での挙動指標です。直進性が高くても、初期速度がゼロなら沈降はゆっくり。例えば、換気口の気流に乗った大きな粒子（Stk>1）はダクトの曲がり部で壁に衝突しやすく、一方で同じ粒子が静止空気中では単にストークス沈降します。ツールで計算した各パラメータを、どういう流れ場で適用するのか、セットで考えるクセをつけましょう。

使い方ガイド

  1. 粒径(dp)を0.01〜100μm範囲で入力し、対象粒子(例:PM2.5、ダスト、ウイルス飛沫)を選定
  2. 気体温度(T)を0〜100℃、気圧(P)を50〜150kPaで設定し、空気の粘度と密度を自動計算
  3. 沈降速度計算ではストークス則(粒径<5μm)またはニュートン則(粒径>10μm)を自動選択
  4. 肺沈着率は粒径別に計算（ICRP簡易モデル）:0.1μm前後で約30%、1μm前後で極小、2.5μm超では上気道側の比率が増え本モデルでは0%付近
  5. 空気動力学径(dae)とStokes数(St)から吸入時の気道内沈着位置を予測

具体的な計算例

水滴（密度1000kg/m³）粒径5μm、温度25°C、気圧101.3kPaの既定条件で計算した場合:Cunningham補正Cc≈1.033、沈降速度v≈0.077cm/s、拡散係数D≈4.9×10⁻⁸cm²/sとなります。流速・管径の既定値ではStokes数St≈0.003で、本モデルの肺沈着率は約20%です。一方、粒径20μmでは沈降速度v≈1.20cm/sと大きく上気道で除去されやすくなり、本モデルの肺（肺胞）沈着率は0%付近となります。

実務での注意点

  1. 高温環境(70°C以上)では空気粘度が10%以上低下し沈降速度が減少するため、鉄鋼製造やボイラー室での粉塵評価は温度補正が必須
  2. 気圧低下地域(高地2000m以上)では空気密度が20%低下し、同じ粒径でも沈降が遅延するため、肺沈着率計算は再評価が必要
  3. 湿度による粒子凝集(粒径5μmが2倍に成長)や、イオン化粒子の静電付着はこのツールでは未考慮のため、精密評価には追加実験を推奨
  4. 粒径<0.1μmではブラウン運動が支配的になり計算精度が±30%低下するため、分子動力学シミュレーション併用を推奨
