# 波浪水槽シミュレーター

2D波動方程式を有限差分法でリアルタイムに解きます。クリックで波源を追加し、干渉・回折・反射のパターンが形成される様子を観察できます。

**Category:** 波動・音響

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/wave-tank.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/wave-tank.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/wave-tank.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/wave-tank
python -m http.server 8000
# open http://localhost:8000
```
