# QR 分解シミュレーター — 最小二乗法と Gram-Schmidt

QR分解シミュレーターで3×3行列をGram-Schmidt法を用いてQ・R行列に分解し、最小二乗法による最適解を計算します。数値解析・線形代数の教育向けツール。

**Category:** 数値線形代数シミュレーター

```bash
git clone https://github.com/novasolver/physics-simulators
```
