# 結晶構造・格子定数・ミラー指数ビジュアライザー

結晶構造・格子定数・ミラー指数ビジュアライザーで、SC・BCC・FCC等の単位格子を可視化。X線回折・d面間隔・ブラッグ角をリアルタイム計算できます。材料工学・結晶学の設計・解析に。

**Category:** 材料科学シミュレーター

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/crystallography.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/crystallography.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/crystallography.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/crystallography
python -m http.server 8000
# open http://localhost:8000
```
