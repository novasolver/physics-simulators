# レンズメーカー方程式シミュレーター — 薄レンズの結像

薄レンズの結像をレンズメーカー方程式で計算・可視化。屈折率・曲率半径から焦点距離・像距離・倍率を導出し、光学設計の基礎を習得できるシミュレーターです。

**Category:** 光学シミュレーター

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/lens-maker.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/lens-maker.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/lens-maker.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/lens-maker
python -m http.server 8000
# open http://localhost:8000
```
