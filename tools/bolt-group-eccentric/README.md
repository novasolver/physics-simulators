# 偏心ボルト群シミュレーター

偏心ボルト群シミュレーター：偏心せん断を受けるボルト群の直接せん断、モーメント、最大ボルト力を評価。ボルト設計、強度計算に対応。

**Category:** 対話型シミュレーター

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/bolt-group-eccentric.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/bolt-group-eccentric.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/bolt-group-eccentric.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/bolt-group-eccentric
python -m http.server 8000
# open http://localhost:8000
```
