# heat-sink-designer

NovaSolverの無料オンライン計算機で、ヒートシンクの熱設計を効率化。電子部品のジャンクション温度を、自然対流/強制空冷に対応したフィンアレイ熱抵抗モデルでリアルタイム計算。Bar-Cohenに基づく最適フィンピッチとフィン数の最適化曲線を可視化し、冷却性能を向上させます。

**Category:** 熱解析ツール

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/heat-sink-designer
python -m http.server 8000
# open http://localhost:8000
```
