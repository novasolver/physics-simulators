# 遠心ポンプキャビテーション（NPSH）計算機

遠心ポンプのキャビテーション防止NPSH計算機。NPSHa・NPSHrをQ曲線でリアルタイム比較。流体温度・静揚程・配管損失から飽和蒸気圧を自動計算しキャビテーションリスクを判定。

**Category:** 流体機械
