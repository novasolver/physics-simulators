# 樹木枝 雪冠荷重 たわみ・折損シミュレーター

樹木の枝に積もった雪冠（クラウン雪）と着氷で、枝がどれだけ撓み、いつ折損するかを片持ち梁モデルで評価します。樹種・枝形状・積雪深・雪密度・着氷厚を変えて、林業現場や都市の街路樹、送電線沿いの雪害リスクを直感的に診断できます。

**Category:** 林業・樹木力学
