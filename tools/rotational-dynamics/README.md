# 回転運動ダイナミクスシミュレーター

慣性モーメント・トルク・摩擦トルクを自由に設定して回転運動をリアルタイム解析。角加速度・回転エネルギー・角運動量を瞬時に計算。

**Category:** 機械力学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/rotational-dynamics.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/rotational-dynamics.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/rotational-dynamics.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/rotational-dynamics
python -m http.server 8000
# open http://localhost:8000
```
