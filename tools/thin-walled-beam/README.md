# 薄肉開断面梁の断面定数

薄肉開断面梁の断面定数をリアルタイム計算。断面積、断面二次モーメント、せん断中心、そり定数の自動算出とC形・Z形・L形・I形断面の可視化。

**Category:** 断面特性計算

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/thin-walled-beam.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/thin-walled-beam.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/thin-walled-beam.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/thin-walled-beam
python -m http.server 8000
# open http://localhost:8000
```
