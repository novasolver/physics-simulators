# ポインティングベクトル シミュレーター — 平面波の電力束

真空中を伝わる平面電磁波の電場・磁場・ポインティングベクトルを可視化。電場振幅・周波数・観測位置・時刻を変えて、電磁波がどれだけの電力を運ぶかを直感的に学べます。

**Category:** 電磁気学シミュレーター

python -m http.server 8000
