# 応力腐食割れ・水素脆化リスク評価計算機

応力腐食割れ（SCC）と水素脆化（HE）のリスクを無料で評価できるオンライン計算機です。き裂進展速度や破断寿命の推定、Pourbaixダイアグラム（E-pH図）の描画など、材料の健全性評価に必要な計算を簡単に行えます。NovaSolverの直感的なツールで、信頼性工学と腐食防食の判断をサポートします。

**Category:** 材料・破壊
