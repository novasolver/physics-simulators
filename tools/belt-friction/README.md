# ベルト摩擦シミュレーター — キャプスタン方程式

ベルト摩擦シミュレーターはオイラー・アイテルヴァインの式（キャプスタン方程式）で、ドラムに巻かれたロープの保持力・倍力比・張力分布をリアルタイム計算します。摩擦係数と巻付角を変えて、巻き付けるだけで力が指数的に増幅される仕組みを直感的に学べます。

**Category:** 機械工学シミュレーター
