# プロップ片持梁シミュレーター — 1次不静定梁

プロップ片持梁の1次不静定梁シミュレーター。等分布荷重・集中荷重時の固定端モーメント、支点反力、最大撓み、SFD・BMDをリアルタイム可視化。構造解析・梁計算に。

**Category:** 構造解析シミュレーター

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/propped-cantilever.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/propped-cantilever.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/propped-cantilever.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/propped-cantilever
python -m http.server 8000
# open http://localhost:8000
```
