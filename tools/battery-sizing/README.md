# バッテリー容量計算ツール

NovaSolverのバッテリー容量計算ツールで、最適な蓄電池設計を。負荷電力や使用時間、バックアップ日数から必要なAhやkWhを簡単計算。Li-ion・LiFePO4・鉛蓄電池の比較や温度補正、サイクル寿命の推定まで、信頼性の高いバッテリーシステムの設計を包括的にサポートします。

**Category:** 電気・エネルギー工学

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/battery-sizing
python -m http.server 8000
# open http://localhost:8000
```
