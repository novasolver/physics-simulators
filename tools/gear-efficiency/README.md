# 歯車列・効率・歯元曲げ応力計算機（AGMA）

モジュール・歯数・入力トルクを変えながら、Lewis式・AGMA規格による曲げ応力とヘルツ接触応力、伝達効率をリアルタイムで計算。噛み合い歯車のアニメーション付き。

**Category:** 解析ツール

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/gear-efficiency.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/gear-efficiency.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/gear-efficiency.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/gear-efficiency
python -m http.server 8000
# open http://localhost:8000
```
