# トルク・てこの原理シミュレーター

てこの原理シミュレーターでトルク・モーメント計算をリアルタイム可視化。力・位置・角度をスライダー調整して支点回りの釣り合いを直感的に理解。機械設計・構造解析向け。

**Category:** 力学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/torque-lever.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/torque-lever.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/torque-lever.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/torque-lever
python -m http.server 8000
# open http://localhost:8000
```
