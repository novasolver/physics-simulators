# 自由水面の蒸発速度シミュレーター — ASHRAE / Carrier 式

プール・池・冷却塔等の自由水面からの蒸発速度を、水温・気温・相対湿度・風速から計算。水蒸気圧差と蒸発潜熱から熱流束も同時に表示し、なぜ風があると蒸発が急に増えるのかを直感的に学べます。

**Category:** 熱流体・空調シミュレーター
