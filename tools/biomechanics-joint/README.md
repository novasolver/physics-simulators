# 関節荷重バイオメカニクス計算機

NovaSolverの関節荷重バイオメカニクス計算機は、膝・股関節・肩の筋力と関節接触力をリアルタイム解析。体重や姿勢を変えてスティックフィギュアで力の可視化が可能。義肢設計、スポーツ工学、CAEシミュレーションの入門ツールとして、研究や教育をサポートします。

**Category:** バイオメカニクス

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/biomechanics-joint
python -m http.server 8000
# open http://localhost:8000
```
