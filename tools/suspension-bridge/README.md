# 吊橋・斜張橋ケーブル形状計算ツール

吊橋の放物線ケーブル理論：水平張力 H、最大張力 T_max、サグ比、ケーブル弧長、ハンガー力をリアルタイム計算。スパン・サグ・荷重・主塔高さを変更してCanvasに橋梁プロファイルを描画します。

**Category:** 橋梁工学
