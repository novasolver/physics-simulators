# 等速円運動シミュレーター

等速円運動シミュレーターで速度ベクトルと向心加速度をリアルタイム観察。半径・角速度・質量を変更してシミュレーション。位置波形・エネルギーグラフで円運動を解析。

**Category:** 高校物理 / 回転力学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/circular-motion.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/circular-motion.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/circular-motion.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/circular-motion
python -m http.server 8000
# open http://localhost:8000
```
