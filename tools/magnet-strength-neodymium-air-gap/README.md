# ネオジム永久磁石 磁束密度・吸引力 エアギャップ設計

ネオジム磁石（N42/N52/N35SH）やフェライトを使った磁気回路を設計するツールです。磁石寸法・エアギャップ・温度・継ぎ鉄・Halbach 配列を変えると、エアギャップ磁束密度 B と鉄板への吸引力 F がリアルタイムで分かり、磁石ホルダーやセンサ、リニアモーターの磁気回路を最適化できます。

**Category:** 永久磁石・磁界設計
