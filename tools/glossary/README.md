# CAE・工学用語辞典

CAE・工学用語辞典は、有限要素法(FEM)、CFD、熱解析、制御工学など、工学シミュレーションで頻出する専門用語をアルファベット順に解説する用語集です。各用語から関連するシミュレーターツールへ直接リンク。NovaSolver Projectが提供する、CAE技術者や学習者に役立つリファレンスサイトです。

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/glossary.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/glossary.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/glossary.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/glossary
python -m http.server 8000
# open http://localhost:8000
```
