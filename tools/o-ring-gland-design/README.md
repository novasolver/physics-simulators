# Oリング溝（グランド）設計シミュレーター

Oリングを収める溝（グランド）の寸法を設計するツールです。線径・溝深さ・溝幅・軸径を変えると、シール性を左右する圧縮率（つぶし率）・グランド充填率・内径ストレッチがリアルタイムで分かり、漏れない静的／動的シールの溝寸法を探せます。

**Category:** 機械要素設計
