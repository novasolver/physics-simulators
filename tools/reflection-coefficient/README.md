# 反射係数シミュレーター — 複素 Γ と入力インピーダンス変換

負荷反射係数 Γ_L と電気的距離 d/λ から線路上の Γ(d) を実時間計算。複素平面上の位相回転を見ながら VSWR と入力インピーダンスを理解できます。

**Category:** RF・伝送線路シミュレーター
