# 短絡電流計算機（対称・非対称故障）

三相・一線地絡・線間・二線地絡の短絡電流を対称分法で計算。変圧器%Z・ケーブル長をリアルタイム解析し遮断容量を比較できます。

**Category:** 機械力学

- 🇺🇸 [English](https://novasolver.jp/en/tools/short-circuit.html)

```bash
git clone https://github.com/novasolver/physics-simulators

python -m http.server 8000
```
