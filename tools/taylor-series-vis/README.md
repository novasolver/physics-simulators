# テイラー展開ビジュアライザー

sin・cos・eˣ・ln(1+x) などの関数のテイラー展開を項数を増やしながらリアルタイム可視化する数学シミュレーター。収束半径・誤差・各項の係数をインタラクティブに確認できます。

**Category:** 数値解析・数学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/taylor-series-vis.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/taylor-series-vis.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/taylor-series-vis.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/taylor-series-vis
python -m http.server 8000
# open http://localhost:8000
```
