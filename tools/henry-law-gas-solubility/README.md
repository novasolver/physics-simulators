# ヘンリーの法則 — 気体溶解度シミュレーター

水にどれだけの気体が溶けるかを、ヘンリーの法則で計算するツールです。気体の種類・分圧・水温・液量を変えると、溶解濃度や溶けた気体の総量がリアルタイムで分かり、炭酸飲料や溶存酸素のしくみを直感的に理解できます。

**Category:** 化学工学
