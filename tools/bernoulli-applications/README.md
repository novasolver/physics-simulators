# ベルヌーイの定理応用シミュレーター

ベルヌーイの定理応用シミュレーターで、ベンチュリ管の圧力分布と流体特性をリアルタイム解析。流速・管径・密度パラメータによる感度分析に対応。

**Category:** 流体力学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/bernoulli-applications.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/bernoulli-applications.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/bernoulli-applications.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/bernoulli-applications
python -m http.server 8000
# open http://localhost:8000
```
