# 熱応力・バイメタル反り解析シミュレーター

拘束熱膨張・バイメタル曲げ・2層板界面応力をTimoshenko理論に基づいてリアルタイム計算。電子部品のはんだ応力や温度計バイメタルの設計に活用できます。

**Category:** 計算ツール

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/thermal-stress.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/thermal-stress.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/thermal-stress.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/thermal-stress
python -m http.server 8000
# open http://localhost:8000
```
