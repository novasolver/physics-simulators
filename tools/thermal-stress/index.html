理論・主要公式

$$\sigma_{th} = -E\alpha(T - T_0) \quad \text{（完全拘束）}$$

熱応力 [MPa]：$E$ ヤング率 [GPa]、$\alpha$ 熱膨張係数 [1/K]、$T_0$ 基準温度

$$\sigma_r = \frac{\alpha E}{1-\nu}\frac{1}{r^2}\int_{r_i}^r T r\,dr + C_1 + \frac{C_2}{r^2}$$

円筒体の半径方向熱応力：$\nu$ ポアソン比、$r$ 半径 [mm]

$$\Delta T_{yield} = \frac{\sigma_y(1-\nu)}{E\alpha}$$

降伏限界温度差 [K]：$\sigma_y$ 降伏応力 [MPa]

熱応力・バイメタル反り解析とは

🙋
「熱応力」って何ですか？温度が変わると勝手に応力が発生するんですか？
🎓
大まかに言うと、材料が「伸び縮みしたいけど、周りに邪魔されてできない」ときに発生するストレスだね。例えば、このシミュレーターで「完全拘束」を選んで、温度を上げてみて。材料は熱で膨張したいのに、両端が固定されて動けない。すると、中に大きな圧縮応力が発生するんだ。実際の現場では、橋の継ぎ目や電子基板のはんだ部分でよく問題になるよ。
🙋
え、そうなんですか！じゃあ「バイメタル」って、2種類の金属がくっついた板ですよね。あれはなぜ曲がるんですか？
🎓
その通り！2層の熱膨張率が違うからだよ。上の層（例えば鋼）と下の層（例えばアルミ）をくっつけて温度を上げると、アルミの方が鋼よりよく伸びようとする。でも、くっついているからお互いに引っ張り合って、アルミ側が外側になるように反るんだ。このシミュレーターで、材料の組み合わせを「鋼/アルミ」から「鋼/銅」に変えて、温度差スライダーを動かしてみると、曲がり方の違いが一目瞭然だよ。
🙋
なるほど！でも、この「界面応力」って何が重要なんですか？反りさえ計算できればいい気がするんですが…。
🎓
そこが実務の肝なんだ。反りは見た目の問題だけど、界面応力は「剥がれ」や「破壊」に直結する。例えばスマートフォンの微小な電子部品では、はんだ（接合部分）にこの界面応力が集中して、何度も電源ON/OFFを繰り返すうちに疲労で割れてしまうことがある。このツールの「界面せん断応力」のグラフを確認してみて。材料の厚さの比を変えると、応力の大きさや分布が大きく変わるのがわかるよ。

よくある質問

主な原因は、ヤング率や線熱膨張係数、温度変化ΔTの入力値が実際の材料や条件と大きく異なることです。特に、完全拘束の式σ=-EαΔTでは、Eやαが大きいと応力が過大になります。また、バイメタル解析では、2層の板厚比やヤング率比が極端だと理論適用範囲を超える場合があります。入力値を見直してください。
Timoshenko理論では、熱膨張係数が大きい材料が温度上昇時に伸びようとするため、その材料が外側になるように曲がります。つまり、αの大きい層が凸側、小さい層が凹側になります。温度下降時は逆です。シミュレーターでは、各層のαと温度変化の符号から曲率κの符号で方向が判定できます。
はい、活用できます。はんだと基板や部品間の熱膨張差による応力を、2層板モデルで近似評価できます。ただし、実際のはんだは非線形なクリープ特性を持つため、本ツールは線形弾性の一次近似としてご利用ください。設計初期の傾向把握や材料選定の比較に適しています。
Timoshenko理論では、曲率κは板厚比とヤング率比に依存します。一般に、一方の層が極端に薄いと曲率は小さくなり、両層の板厚が近いほど曲率は大きくなる傾向があります。具体的には、κは(α2-α1)ΔTに比例し、板厚とヤング率の関数で決まる係数が乗じられます。シミュレーターで数値を変えて試すと挙動が掴めます。

実世界での応用

電子機器・半導体パッケージ：スマートフォンやCPUなど、発熱する部品が多数集積しています。はんだ接合部や樹脂封止部で、材料の熱膨張率の不一致による熱応力・反りが発生し、接点不良や破壊の原因となります。寿命予測や信頼性設計に不可欠な解析です。

温度計・サーモスタット（バイメタル素子）：巻き貝状のバイメタルに温度変化を与えると、反りが回転運動に変わり、針を動かしたりスイッチをオンオフしたりします。このシミュレーターで最適な厚さ比や材料組み合わせを探ることで、感度の良い素子を設計できます。

建築・土木構造物：長大な橋梁や送電線は、昼夜や季節による温度差で大きく伸縮します。完全に固定すると巨大な熱応力が発生するため、伸縮継手やローラー支承などを設けて応力を緩和する設計がなされています。

自動車・航空機エンジン部品：エンジンブロックやタービンブレードなど、異種材料（金属とセラミックスなど）を組み合わせた部品では、高温環境下での熱応力による界面剥離が重大な問題です。コーティングや中間層の設計に解析が活用されます。

よくある誤解と注意点

この手の解析で最初にハマるのは、「とにかく熱膨張率の差が大きい材料を選べば感度が上がる」と思い込むことだよ。確かに曲がりは大きくなるけど、界面応力も跳ね上がって剥がれのリスクが増大する。例えば、アルミと樹脂を組み合わせると大きな反りが得られるが、界面せん断応力は鋼とアルミの組み合わせの数倍になることもある。実務では「必要な変位」と「許容応力」のトレードオフを考えて材料を選ぶのが鉄則だね。

次に、シミュレーターの前提である「小変形・線形理論」の限界を忘れがち。温度差が数百℃にもなると、実際の反りは理論値からずれてくるし、材料特性そのものが温度で変化する。あくまで初期設計の目安として使い、詳細設計では非線形解析や実験で検証するステップが必須だ。例えば、バイメタル式サーモスタットの設計では、このツールでおおよその曲率を出した後、有限要素法で接触や大きな変形を考慮した検証を行うのが一般的だよ。

最後に、固定条件の解釈。ツールの「完全拘束」は理想的なケースで、現実には完全に固定されたものは少ない。例えば、基板上のチップ部品のはんだ接合部は、基板自体がわずかに変形するので、計算値より実際の応力は小さめになることが多い。逆に、剛性の高い筐体に組み込まれた部品では、計算値に近い、あるいはそれ以上の応力がかかることもある。境界条件をどう仮定するかが、解析精度を分けるんだ。

使い方ガイド

  1. 材料1の縦弾性係数(lEc)と線膨張係数(lAlpha)を入力。例：銅Ec=130GPa、Alpha=16.5×10⁻⁶/K
  2. 材料2の縦弾性係数(Ec)と線膨張係数(Alpha)を入力。例：鋼Ec=200GPa、Alpha=12×10⁻⁶/K
  3. 各層の厚さ(lNuc、Nuc)をマイクロメートル単位で指定。はんだ層0.2mm、銅箔0.035mm等
  4. 温度変化(lDTc、DTc)をケルビン入力。リフロー工程の250K(室温20℃→270℃)等を設定
  5. Timoshenko二層梁理論により界面曲率κ、反り変位δ、剪断応力τを自動計算

具体的な計算例

PCB基板(厚さ1.6mm、ガラス繊維強化樹脂E=20GPa、α=15×10⁻⁶/K)とはんだ層(厚さ0.15mm、E=55GPa、α=23×10⁻⁶/K)の組合せで、ΔT=200K加熱時：拘束膨張差=Δα×ΔT=(23-15)×200=1600μstrain。中立軸の深さzn=0.74mmで、曲率κ=1.2m⁻¹、反り量δ=2.8mm/100mm。BGA接点での剪断応力τ=18MPa発生。

実務での注意点

  1. はんだクリープ考慮：Pb-freeはんda(SAC305)は高温保持で応力緩和。平衡応力σeq≈0.3τピーク値に低下するため疲労寿命評価時は動的応力のみカウント
  2. 異方性材料注意：銅張積層板のz方向膨張係数がx-y方向と異なる場合(例：αz=50×10⁻⁶/K)は三次元解析に切替え
  3. 冷却速度効果：リフロー冷却時2K/s以上の高速冷却では過冷却応力が定常値の1.4倍に。シミュレーション結果に1.3倍の安全係数を適用
  4. 界面接着層：エポキシ樹脂接着(G=3GPa厚さ10μm)存在時は剪断弾性係数で補正。複合梁のEI値を再計算
