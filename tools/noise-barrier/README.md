# 防音壁挿入損失計算ツール

前川式（Maekawa式）に基づき、防音壁の挿入損失をリアルタイム計算。幾何学的配置と周波数特性グラフで効果を直感的に把握できます。

**Category:** 音響解析

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/noise-barrier.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/noise-barrier.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/noise-barrier.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/noise-barrier
python -m http.server 8000
# open http://localhost:8000
```
