# ホイートストンブリッジシミュレーター — 平衡条件と感度

4抵抗R1〜R4と励起電圧Vinから、ブリッジの開放出力電圧Voutと平衡条件を可視化。ひずみゲージや精密抵抗計測の核心となる原理を体感できます。

**Category:** 計測工学シミュレーター
