理論・主要公式

放物型抗力極曲線：$C_D = C_{D0}+ \dfrac{C_L^2}{\pi AR\, e}$

失速速度：$V_s = \sqrt{\dfrac{2W}{\rho S C_{L\max}}}$

最小抗力速度：$V_{md}= \sqrt{\dfrac{2W}{\rho S}\sqrt{\dfrac{C_{D0}}{\pi AR\, e}}}$

最大揚抗比：$(L/D)_{max}= \dfrac{1}{2}\sqrt{\dfrac{\pi AR\, e}{C_{D0}}}$

上昇率：$RC = \dfrac{(T - D)V}{W}$

航続距離（ブレゲー）：$R = \dfrac{C_L}{C_D}\cdot\dfrac{V}{SFC}\cdot\ln\!\left(\dfrac{W_1}{W_2}\right)$

航空機性能計算とは

🙋
このシミュレーターで計算できる「失速速度」って何ですか？翼の角度が大きすぎて失速する時の速度ですよね？
🎓
その通り！大まかに言うと、機体が浮き続けるために必要な最低速度だ。計算式は $V_s = \sqrt{\frac{2W}{\rho S C_{L\max}}}$ で、パラメータの「重量W」や「最大揚力係数CLmax」が大きく影響するんだ。例えば、上のスライダーで「重量W」を増やすと、グラフ上の失速速度の線が右に動くのが確認できるよ。重いほど失速しやすくなるんだ。
🙋
え、そうなんですか！じゃあ「抗力極曲線」ってグラフは何を見てるんですか？CDとCLの関係ですよね。
🎓
これは航空機設計の特に重要グラフだ。抗力$C_D$と揚力$C_L$のトレードオフを表していて、曲線の形は「零揚力抗力CD0」と「オズワルド効率e」で決まる。実務では、この曲線の接線傾きが最も緩やかな点、つまり$C_L/C_D$（揚抗比）が最大になる点を探すんだ。シミュレーターで「アスペクト比AR」を変えてみると、曲線がどう変わるか体感できるよ。
🙋
「最も燃費効率の良い速度」って、このグラフから決まるんですか？それと「航続距離」はどうやって計算してるんですか？
🎓
いいところに気づいたね！揚抗比が最大になるのは、抗力極曲線で原点から引いた接線の接点だ。その時の速度が「最小抗力速度$V_{md}$」で、理論上最も燃費が良い。航続距離は「ブレゲーの式」$R = \frac{C_L}{C_D}\frac{V}{SFC}\ln\left(\frac{W_1}{W_2}\right)$で計算する。パラメータの「SFC」や「燃料重量比」をいじると、航続距離がリアルタイムで変わるから確認してみて！

よくある質問

翼面積が大きいと失速速度が低下し、離着陸性能が向上します。アスペクト比が大きいと誘導抗力が減り、巡航時の揚抗比が向上するため航続距離が伸びます。ただし構造重量増加とのトレードオフがあります。
抗力極曲線と推力の交点が最大巡航速度、揚抗比最大の速度が最良滑空比速度です。上昇率のピークは最適上昇速度を示し、この速度で飛行すると最も効率よく高度を稼げます。
気温がISAより高いと空気密度が低下し、同じ推力でも発生する揚力と抗力が減少します。その結果、失速速度は上昇し、上昇率と航続距離は低下します。高高度や暑い日の飛行では補正が必要です。
出発時の全備重量と、着陸時の残燃料を含む最終重量を入力してください。燃料消費量は「出発重量－最終重量」で自動計算されます。実際の飛行計画では、離陸・上昇・巡航・降下の各フェーズで燃費が異なるため、あくまで巡航定常状態の近似値です。

実世界での応用

初期機体設計：新規航空機のコンセプト設計段階で、要求性能（航続距離、離着陸速度）を満たすためのおおよその翼面積、アスペクト比、エンジン推力を見積もるために使用されます。

フライトエンベロープの定義：失速速度、最大速度、最大上昇率など、機体が安全に飛行できる速度-高度の範囲（フライトエンベロープ）を決定する基礎計算として活用されます。

CAE解析の前処理・検証：CFD（数値流体力学）や構造解析を行う前に、このような簡易計算で全体のバランスや計算結果のオーダーを確認し、大規模CAE解析の方向性を定めるのに役立ちます。

運航経済性分析：航空会社が特定路線を特定機材で運航する際の燃費コストや、ペイロード（搭載量）と航続距離のトレードオフを分析する際の基礎モデルとして応用されます。

よくある誤解と注意点

抗力極曲線（揚力係数CLと抗力係数CDの関係）は、翼型やレイノルズ数によって変化するため、ツールが標準的に表示する曲線が全ての飛行条件で正しいとは限りません。特に低速度域では層流剥離や遷音速域では衝撃波の影響で実際の抗力が増大するため、表示値より実機の抗力が大きくなる場合がある点に注意が必要です。

巡航速度を最大航続距離の条件と同一視しがちですが、実際には最大航続距離を得る速度は最大揚抗比（L/D max）となる速度であり、巡航速度は運航効率や時間制約からそれより速い速度が選ばれることが一般的です。ツールの計算値は理想的な無風・標準大気条件に基づくため、実際の運航では風向・風速や気温偏差による補正が必要です。

上昇率の計算では、エンジン出力が高度とともに低下することを忘れられがちです。ツールは標準大気モデルに基づきますが、実際のエンジンは吸気温度や過給機の特性により推力が変化するため、高高度での上昇率は計算値より低下する傾向があります。特にターボチャージャー非搭載のエンジンでは、臨界高度を超えると急激な出力低下が生じる点に注意が必要です。

使い方ガイド

  1. 翼面積(S)、縦横比(AR)、重量(W)をkg・m²・無次元数で入力してください
  2. 巡航高度でのISA標準大気密度ρを自動取得し、失速速度Vs=√(2W/ρSCL,max)を計算します
  3. 抗力係数CD=CD0+CL²/(πAR·e)から抗力極曲線を生成し、(L/D)maxの速度で最適巡航条件を決定します
  4. 推力Tと巡航速度からSFC(燃料消費率)を乗じて航続距離R=V·(L/D)max·Wfuel/Pを算出します
  5. 上昇率RC=(T-D)·V/Wからダイアグラムを作成し、性能包络線を可視化します

具体的な計算例

ターボプロップ輸送機(B1900型相当):W=5400kg、S=19.9m²、AR=9.2、CD0=0.028、巡航高度2400m(ISA ρ=0.999kg/m³)の場合、失速速度Vs≈92km/h、最大揚抗比(L/D)max≈13.8(速度≈180km/h)、最大上昇率RC≈4.2m/s(海面)、航続距離R≈1680km(総燃料300L、SFC=0.22kg/h/kW)と算出されます。

実務での注意点

  • CL,maxは主翼形状と失速角に依存(典型値0.9～1.5)するため、CFDまたは風洞試験値で補正してください
  • Oswald効率係数eは実機では0.75～0.95で、矩形翼(e=1.0)よりも低下することを考慮してください
  • 高度による密度変化と気温低下はジェットエンジン推力を減少させるため、エンジンマップで補正が必須です
  • 燃料重量配分(タンク位置)が重心を変化させ、必要揚抗比が変動する場合は重心範囲内でRC値を再計算してください
  • 実測の巡航燃費はWLJ(weight/fuel limit)制約により理論値より悪化するため、安全係数1.1～1.2を適用してください
