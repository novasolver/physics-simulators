# リンク機構・クランクスライダー解析

NovaSolverの無料オンライン計算機で、4節リンク機構とクランクスライダー機構を解析しましょう。リアルタイムアニメーションで動作を確認し、グラスホフ条件の自動判定や出力リンクの角度・角速度・角加速度のグラフ、伝達角の計算が可能です。設計や学習に役立つ直感的なWebツールです。

**Category:** 機械力学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/linkage-mechanism.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/linkage-mechanism.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/linkage-mechanism
python -m http.server 8000
# open http://localhost:8000
```
