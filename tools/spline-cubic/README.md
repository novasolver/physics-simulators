# 自然3次スプライン補間シミュレーター

6点のデータを通る自然3次スプライン曲線をリアルタイム構築。線形補間や理論曲線と比較しながら、なぜトライディアゴナル系で滑らかな曲線が決まるのかを学べます。

**Category:** 数値解析シミュレーター

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/spline-cubic.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/spline-cubic.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/spline-cubic.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/spline-cubic
python -m http.server 8000
# open http://localhost:8000
```
