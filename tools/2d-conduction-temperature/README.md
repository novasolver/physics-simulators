# 2D 伝導の温度分布シミュレーター

2D伝導の温度分布シミュレーターで境界温度を変更し、板内の温度勾配と熱流の向きを可視化。熱伝導解析と温度分布計算を実務レベルで学習できます。

**Category:** 対話型シミュレーター

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/2d-conduction-temperature.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/2d-conduction-temperature.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/2d-conduction-temperature.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/2d-conduction-temperature
python -m http.server 8000
# open http://localhost:8000
```
