# 意思決定分析・期待値計算ツール

確率と価値から期待金銭価値(EMV)を計算し、最適な選択肢を特定。決定木の可視化・確率分布・トルネードチャートによる感度分析をリアルタイムで実行。

**Category:** 意思決定分析ツール

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/decision-analysis.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/decision-analysis.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/decision-analysis.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/decision-analysis
python -m http.server 8000
# open http://localhost:8000
```
