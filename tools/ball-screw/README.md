# ボールねじ駆動シミュレーター

モーターの回転運動をテーブルの直線運動に変換するボールねじを設計するツールです。リード・回転数・駆動トルクを変えると、直線送り速度・推力・リード角・駆動所要動力・搬送体の加速度がリアルタイムで分かり、CNC工作機械やロボット軸の送り機構を検討できます。

**Category:** 機械要素設計
