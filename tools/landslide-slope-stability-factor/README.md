# 地すべり安全率 Bishop 簡便法シミュレーター

円弧すべり面を仮定した斜面の安全率 Fs を、Bishop 簡便法（1955）の反復計算で求めます。斜面高さ・斜面角度・粘着力・内部摩擦角・間隙水圧比・地震係数を変えて、降雨や地震が地すべりに与える影響を体感できます。

**Category:** 地盤工学・防災
