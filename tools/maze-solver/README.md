# 迷路ソルバー — 経路探索アルゴリズム可視化

迷路ソルバー「NovaSolver」は、BFS・DFS・A*・ダイクストラ法などの経路探索アルゴリズムを迷路で可視化・比較できる教育ツールです。探索過程をリアルタイムで確認し、ノード数や計算時間の違いを体感的に学べます。アルゴリズムの理解を深めるインタラクティブなシミュレーターです。

**Category:** 数理・統計

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/maze-solver
python -m http.server 8000
# open http://localhost:8000
```
