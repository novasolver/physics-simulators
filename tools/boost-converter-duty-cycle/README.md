# 昇圧コンバータのデューティ比と電流応力シミュレーター

昇圧コンバータのデューティ比と電流応力シミュレーター。デューティ比曲線、インダクタ電流、素子ストレスを並べて昇圧比変化による負担を確認。スイッチング電源設計。

**Category:** 対話型シミュレーター
