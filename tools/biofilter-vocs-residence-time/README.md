# バイオフィルタ VOC 除去 EBRT 設計シミュレーター

バイオフィルタ（脱臭バイオ）の EBRT（空塔滞留時間）・除去効率・出口濃度・圧力損失をリアルタイム計算。トルエン／アセトン／H2S 等の VOC を、コンポスト・木質チップ・合成樹脂など充填材ごとに評価し、現場で割れない設計を選定できる無料ツールです。

**Category:** 環境工学・脱臭バイオ

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/biofilter-vocs-residence-time
python -m http.server 8000
# open http://localhost:8000
```
