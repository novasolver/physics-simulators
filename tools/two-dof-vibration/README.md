# two-dof-vibration

NovaSolverの無料オンラインシミュレーターで、2自由度連成振動と動吸振器（TMD）の原理を学びましょう。質量比やチューニング周波数をインタラクティブに調整し、反共振による主系の応答低減効果をリアルタイムで可視化・比較できます。Den Hartogの最適チューニング則や、超高層ビル（台北101等）の設計トレードオフも理解できます。

**Category:** 構造解析
