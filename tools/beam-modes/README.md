# 梁の振動モード可視化

単純支持・片持ち・固定梁の固有モードをアニメーション表示。複数モードの重ね合わせと固有振動数スペクトルをリアルタイムで確認できます。

**Category:** 構造・振動解析

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/beam-modes.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/beam-modes.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/beam-modes.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/beam-modes
python -m http.server 8000
# open http://localhost:8000
```
