# ベルヌーイの定理・管路流れ可視化

ベルヌーイの定理と管路流れの速度場・圧力分布をリアルタイム可視化。ベンチュリ管シミュレーション、連続の式・動圧計算で流体解析を支援。

**Category:** 流体解析

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/bernoulli-flow.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/bernoulli-flow.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/bernoulli-flow.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/bernoulli-flow
python -m http.server 8000
# open http://localhost:8000
```
