# ケプラーの法則シミュレーター — 第1・第2・第3法則を可視化

ケプラーの3法則（楕円軌道・面積速度・調和則）を 1 つの軌道アニメで連動表示。離心率と長半径を変えながら、面積速度の一定性と T² ∝ a³ の関係を直感的に学べる教育版です。数値解法を学びたい方は『ケプラー方程式シミュレーター』、衛星設計用途は『軌道力学シミュレーター』へ。

**Category:** 天文・軌道力学
