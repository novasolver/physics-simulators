# fatigue-notch

切欠き疲労係数KfをNeuber法とPeterson法でリアルタイム比較・計算できるシミュレーターです。切欠き係数Ktと半径ρから疲労切欠き係数を算出し、修正疲労限度と修正グッドマン線図を可視化。CAE・機械設計エンジニアの疲労強度評価を支援します。

**Category:** 疲労・破壊力学
