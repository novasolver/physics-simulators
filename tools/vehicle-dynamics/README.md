# 車両運動力学シミュレーター

線形自転車モデル（2DOF）を用いて、車両のヨーレートと横すべり角の過渡応答をシミュレーション。車両パラメータを変更し、アンダーステア・オーバーステア特性の違いをリアルタイムに体験・理解できます。CAEによる車両運動力学の基礎学習に最適なツールです。

**Category:** 機械力学

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/vehicle-dynamics
python -m http.server 8000
# open http://localhost:8000
```
