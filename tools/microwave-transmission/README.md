# マイクロ波伝送線路計算機

同軸線路・マイクロストリップ・ストリップラインの特性インピーダンスZ₀を計算し、反射係数Γ・VSWR・リターンロスをリアルタイム表示。スミスチャートで整合状態を視覚的に確認できます。

**Category:** 振動・波動

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/microwave-transmission.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/microwave-transmission.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/microwave-transmission.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/microwave-transmission
python -m http.server 8000
# open http://localhost:8000
```
