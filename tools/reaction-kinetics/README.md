# 反応速度論シミュレーター・アレニウスの式

反応速度論シミュレーターでアレニウスの式を可視化。反応次数・速度定数・活性化エネルギーの関係をリアルタイム計算し、減衰曲線と半減期をシミュレーション。化学工学設計に必須。

**Category:** 化学工学

git clone https://github.com/novasolver/physics-simulators
