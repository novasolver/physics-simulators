# アンペールの法則 シミュレーター — 直線電流とソレノイドの磁場

無限長直線電流が距離 r に作る磁場 $B = \mu_0 I/(2\pi r)$ と、ソレノイド内部の一様磁場 $B = \mu_0 n I$、平行電流間の単位長あたりの力をアンペール則から実時間に計算します。円形磁力線・ソレノイド断面・対数プロットで同時に可視化。

**Category:** 電磁気シミュレーター
