# 論理ゲート・論理回路シミュレーター

論理ゲート・論理回路シミュレーターで真理値表とゲート動作を可視化。AND・OR・NOT・NAND・NOR・XORを体験し、半加算器・全加算器・フリップフロップの基本回路を学習。

**Category:** ディジタル回路

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/logic-gates.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/logic-gates.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/logic-gates.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/logic-gates
python -m http.server 8000
# open http://localhost:8000
```
