# 光ファイバーリンク設計シミュレーター

光ファイバーリンク設計シミュレーターで損失バジェット・OSNR・分散ペナルティをリアルタイム計算。SMF/MMFの光伝送システム設計に対応した専門ツール。

**Category:** 電磁気・光学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/optical-fiber-design.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/optical-fiber-design.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/optical-fiber-design.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/optical-fiber-design
python -m http.server 8000
# open http://localhost:8000
```
