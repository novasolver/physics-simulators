# AdaBoost シミュレーター — 弱分類器のブースティング

2次元データに対し、深さ1の決定スタンプを弱分類器として AdaBoost を T 回反復。サンプル重みと最終強分類器の決定境界を可視化し、なぜ弱学習器の組合せが高精度になるかを学べます。

**Category:** 機械学習シミュレーター

git clone https://github.com/novasolver/physics-simulators
