# ホール効果 シミュレーター — キャリア密度測定

電流・磁場・キャリア密度・試料厚さから、ホール電圧 V_H をローレンツ力の釣り合い式で実時間計算。半導体のキャリア濃度測定の原理を、ホールバーの模式図と対数スケールのグラフで直感的に学べます。

**Category:** 半導体・電子物性シミュレーター
