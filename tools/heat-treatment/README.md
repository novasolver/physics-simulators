# 熱処理CCT図シミュレーター

熱処理CCT図シミュレーターで炭素量・冷却速度を変えてCCT図を解析。マルテンサイト変態点と推定硬さをリアルタイム確認、鋼の組織制御に活用

**Category:** 材料・熱処理

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/heat-treatment.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/heat-treatment.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/heat-treatment.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/heat-treatment
python -m http.server 8000
# open http://localhost:8000
```
