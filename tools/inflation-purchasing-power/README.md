# インフレと購買力計算ツール

インフレ率・期間・初期金額をスライダーで動かすと、現金の購買力がどれだけ目減りするか、実質金利と「72の法則」による倍化年数が同時に表示されます。日本・米国・主要国の実インフレ率も切り替えて比較可能。

**Category:** 経済・金融

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/inflation-purchasing-power.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/inflation-purchasing-power.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/inflation-purchasing-power.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/inflation-purchasing-power
python -m http.server 8000
# open http://localhost:8000
```
