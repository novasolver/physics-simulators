# 熱電対の過渡応答シミュレーター — 一次遅れ系

温度センサを一次遅れ系としてモデル化し、指示温度の時間変化をリアルタイム可視化。時定数・初期温度・流体温度を変えて測定遅れの挙動を学べます。

**Category:** 熱工学シミュレーター

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/thermocouple-response.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/thermocouple-response.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/thermocouple-response.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/thermocouple-response
python -m http.server 8000
# open http://localhost:8000
```
