# 産業用ロボット 可搬重量 TWR シミュレーター

6軸垂直多関節・SCARA・デルタ・協働ロボットの定格ペイロード・リーチ・ツール条件を入力し、TWR (ペイロード対自重比)、リスト負荷トルク、慣性負荷、サイクル時間を即座に比較できます。FANUC・ABB・Yaskawa・URのカタログを開く前の最初の絞り込みに使えるツールです。

**Category:** 産業ロボット・ペイロード
