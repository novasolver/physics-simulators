# 油圧ジャッキ計算機

油圧ジャッキ計算機でパスカルの原理による力の増幅をリアルタイム計算。ピストン径・入力力から出力力・圧力・流量を即座に可視化するCAEツール。

**Category:** 流体力学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/hydraulic-jack.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/hydraulic-jack.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/hydraulic-jack.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/hydraulic-jack
python -m http.server 8000
# open http://localhost:8000
```
