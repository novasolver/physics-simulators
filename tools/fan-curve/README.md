# ファンカーブ・システム曲線計算機

ファンカーブ・システム曲線計算機でファン特性曲線とダクト系統曲線をリアルタイム描画、動作点・効率・軸動力を自動計算。流体機械の性能解析に。

**Category:** 機械力学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/fan-curve.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/fan-curve.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/fan-curve.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/fan-curve
python -m http.server 8000
# open http://localhost:8000
```
