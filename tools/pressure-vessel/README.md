# pressure-vessel

圧力容器の内圧応力をLamé方程式でリアルタイム計算。薄肉・厚肉自動判定、von Mises応力分布、ASME最小肉厚評価に対応した応力計算機。

**Category:** 構造解析ツール

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/pressure-vessel.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/pressure-vessel.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/pressure-vessel.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/pressure-vessel
python -m http.server 8000
# open http://localhost:8000
```
