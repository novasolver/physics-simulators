# 運動学計算シミュレーター — 1D / 2D 等加速度運動

運動学計算シミュレーター「NovaSolver」は、1次元の直線運動や2次元の放物線運動を簡単に可視化。速度・加速度・変位を瞬時に計算し、v-tグラフも描画します。高校物理の学習からCAE動解析の基礎まで、等加速度運動の理解を深める強力なツールです。

**Category:** 力学・運動学

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/kinematics
python -m http.server 8000
# open http://localhost:8000
```
