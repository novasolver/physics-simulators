# ボルト疲労解析ツール

強度区分・呼び径・剛性比・外荷重からボルトの締付け力と作用応力を算出。Goodman線図上に動作点をプロットし、疲労安全率をリアルタイムで確認できます。

**Category:** 構造・疲労解析

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/bolt-fatigue.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/bolt-fatigue.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/bolt-fatigue.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/bolt-fatigue
python -m http.server 8000
# open http://localhost:8000
```
