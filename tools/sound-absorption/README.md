# 吸音材・残響時間計算機（セービン式）

吸音材・残響時間計算機（セービン式）で、コンサートホールやスタジオ、オフィスの音響設計をサポート。コンクリートやカーペット、音響タイルなど様々な素材を選択し、周波数別の残響時間RT60を簡単計算。最適な残響時間を判定し、理想的な音響空間を実現するためのシミュレーションツールです。

**Category:** 室内音響シミュレーター
