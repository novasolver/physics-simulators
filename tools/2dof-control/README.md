# 2自由度制御シミュレーター — 目標値追従と外乱抑圧の独立設計

PIフィードバックと前置フィルタを別々に設計し、目標値応答と外乱応答を独立に調整。1自由度制御との応答差から、フィードフォワード整形のメリットを学べます。

**Category:** 制御工学シミュレーター
