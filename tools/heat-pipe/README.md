# ヒートパイプ性能計算ツール

ヒートパイプ性能計算ツール「NovaSolver」で、毛細管限界や有効熱伝導率を簡単シミュレーション。水・アンモニア・アセトン・メタノールなど作動流体の性能を温度依存で比較評価し、熱設計の最適化を支援します。CAE熱解析の実務効率化に役立つ信頼性の高い計算ツールです。

**Category:** 熱設計ツール

- 🇺🇸 [English](https://novasolver.jp/en/tools/heat-pipe.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/heat-pipe
python -m http.server 8000
# open http://localhost:8000
```
