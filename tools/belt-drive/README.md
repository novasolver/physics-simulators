# ベルト・チェーン伝動計算機

プーリ径・軸間距離・回転数・動力・摩擦係数を設定してベルト長さ・張力・伝達動力をリアルタイム計算。ベルト駆動幾何をアニメーション可視化。

**Category:** 機械力学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/belt-drive.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/belt-drive.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/belt-drive.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/belt-drive
python -m http.server 8000
# open http://localhost:8000
```
