理論・主要公式

速度比：$i = D_2/D_1$、ベルト速度：$v = \pi D_1 n_1/60$

ベルト長さ（開放掛け）：$L = \dfrac{\pi(D_1+D_2)}{2}+ 2C + \dfrac{(D_2-D_1)^2}{4C}$

巻き付き角：$\theta = \pi \mp 2\arcsin\!\left(\dfrac{D_2-D_1}{2C}\right)$（開放/クロス）

オイラーのベルト式：$\dfrac{F_1}{F_2}= e^{\mu\theta}$

$\Delta F = F_1 - F_2 = P/v$，　$F_1 = \Delta F \cdot \dfrac{e^{\mu\theta}}{e^{\mu\theta}-1}$

ベルト・チェーン伝動計算機とは

🙋
このシミュレーターで「軸間距離」を変えると、何が変わるんですか？
🎓
大まかに言うと、ベルトの長さと巻き付き角が変わるんだ。上のスライダーで「軸間距離C」を大きくしてみて。アニメーションでベルトがピンと張った状態から、少したるんだ状態になるのがわかるかな？実務では、軸間が長すぎるとベルトが振動したり、短すぎるとプーリに過大な負荷がかかるんだ。
🙋
え、そうなんですか！じゃあ「摩擦係数μ」って、どんなベルトを選ぶときに重要なんですか？
🎓
平ベルトかVベルトかで大きく変わるパラメータだね。例えばVベルトは溝に挟まるので見かけの摩擦係数が高く、0.3〜0.5くらい。このツールでμの値を0.2から0.5に変えてみると、同じ伝達動力でも必要な張力がグッと下がるのが計算結果で確認できるよ。これがVベルトが広く使われる理由の一つなんだ。
🙋
アニメーションでプーリをドラッグして径を変えられますけど、これって何の役に立つんですか？
🎓
直感的に速度比を確認できるのが最大の利点だ。例えば、モーター（駆動側）の小さいプーリをマウスでぐっと大きくしてみて。従動側の回転数が下がるでしょ？これが減速比の調整。現場では、求められる回転数に合わせて何度もプーリ径の組み合わせを試算するんだ。このツールならそれが瞬時にできる。

よくある質問

計算式は有効径と軸間距離から理論上のベルト長さを近似しています。実際の市販ベルトは規格化された長さ（例えばVベルトの呼び番号）で販売されており、またベルトのたるみや初期張力の影響も考慮する必要があります。計算値に最も近い規格品を選び、テンショナで調整してください。
オイラーの式は滑り限界時の最大張力比を示します。実際の運転では、安全率を見込んで設計張力を設定する必要があります。また、遠心力による張力低下やベルトの曲げ剛性、プーリとの接触状態も影響します。計算機の結果は理想状態の上限値としてご利用ください。
アニメーションは幾何計算に基づく模式図です。プーリ径や軸間距離の設定が極端な場合（例えば小プーリ径に対して軸間距離が短すぎる場合）、巻き付き角が不足し、ベルトがプーリに正しく接触しない状態を可視化しています。この場合、実用的な設計ではありませんので、パラメータを見直してください。
一般的なゴムベルトと鋳鉄プーリの組み合わせでは0.3～0.5程度が目安です。ただし、潤滑状態や表面処理、経年変化で変動します。安全側の設計には低めの値（0.3）を、高効率を狙う場合は実測値に近い値（0.4～0.5）を推奨します。正確な値はメーカーの技術資料をご確認ください。

実世界での応用

産業機械・コンプレッサー駆動：モーターとコンプレッサーをベルトで連結する最も一般的な応用です。ツールでモーター回転数とコンプレッサー要求回転数を入力し、適切なプーリ径の組み合わせとベルト長さを設計します。軸受けにかかる荷重の計算にも張力値が使われます。

自動車の補機駆動：エンジンのクランクプーリーから、オルタネーター（発電機）、ウォーターポンプ、エアコンコンプレッサーなどをVベルトや多溝ベルトで駆動します。複数の従動プーリを持つセレンテッドベルトの設計では、各プーリの巻き付き角と張力バランスが重要です。

搬送装置・コンベア：工場のラインで製品を運ぶコンベアベルトの駆動部設計に活用されます。大きな慣性を持つコンベアを動かすための起動トルクと、定常運転時の張力を計算し、モーター選定やテンショナー（張力調整装置）の設定に役立てます。

CAEシミュレーションの前処理：マルチボディダイナミクス（MBD）シミュレーションでベルト機構をモデル化する際、初期張力やプーリ間の幾何学的関係を設定する入力パラメータとして、このツールの計算結果を直接利用できます。これにより、現実に近い初期条件からシミュレーションを開始できます。

よくある誤解と注意点

まず、「軸間距離は長ければ長いほど振動防止に良い」という誤解があります。確かに長くするとベルトのたわみが大きくなり、ある程度の振動吸収効果はあります。しかし、長すぎるとベルト自体の重量が増し、特に高速回転時に遠心力でたわみが大きくなり、かえって振動（ベルトウォップ）を引き起こすことがあります。例えば、回転数が3000 rpmを超えるような高速駆動では、軸間距離を必要最小限に抑える設計が一般的です。

次に、摩擦係数μを過信しないこと。ツールでは一定値として入力しますが、実際のμは潤滑油の付着、ベルトの経年劣化、温度、スリップ率によって変化します。設計では安全率を必ず見込む必要があります。Vベルトで計算上μ=0.4を使う場合、実際の伝達能力はその70〜80%程度と想定してモーター容量を選定するのが現場の知恵です。

最後に、「計算された張力は静的状態の値」という点を見落としがちです。このツールで算出する張力は、定常運転時の値。実際には起動時や急停止時には慣性力により、計算値の2〜3倍の張力が瞬間的に発生します。コンベアや大型ファンなど、大きな慣性を持つ機械を設計する際は、この「動的過負荷」を別途考慮し、テンショナーのストロークやベアリングの寿命計算に反映させなければなりません。

使い方ガイド

  1. 駆動プーリ径d1（mm）と従動プーリ径d2（mm）を入力。例：d1=100mm、d2=200mm
  2. 両プーリ中心間距離C（mm）を設定。ベルト長さL=2C+1.57(d1+d2)で自動計算
  3. 駆動軸回転数n1（rpm）と伝達動力P（kW）を入力。速度比i=d2/d1から従動回転数n2を算出
  4. ベルト速度v=πd1n1/60000で張力計算。巻き付き角θから安全率を評価

具体的な計算例

ウェッジベルト駆動で、駆動プーリd1=90mm、従動プーリd2=180mm、軸間距離C=300mm、駆動軸n1=1500rpmの場合：速度比i=2.0、従動回転数n2=750rpm、ベルト速度v=7.1m/s、ベルト長さL≈1031mm。伝達動力5kW、摩擦係数μ=0.5では小プーリ巻き付き角θ≈162.7°、緊張側F₁≈933N、弛み側F₂≈225Nとなります。許容張力F_allow=1500Nと仮定すると安全率S.F.≈1.6です。

実務での注意点

  1. チェーン伝動では軸間距離が短い場合、巻き付き角が小さくなり安全率低下。最小θ=120°を確保する設計が必須
  2. ベルト速度が25m/sを超えると遠心力増加で張力効率が低下。高速駆動は複数ベルト並列配置を検討
  3. 鋳鉄プーリ使用時、直径100mm以下では加工精度による径誤差がベルト寿命に影響。公差は±0.5mm以内を指定
  4. 湿度70%以上の環境ではベルト膨潤によるスリップ発生。定期的な張力調整と防湿カバー設置が必要
