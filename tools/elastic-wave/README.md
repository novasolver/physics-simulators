# elastic-wave

固体中を伝わる縦波（P波）と横波（S波）の速度・波形をリアルタイム可視化。材料の弾性率・密度を変えて超音波探傷や地震波解析の基礎を体感できます。

**Category:** 振動・波動

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/elastic-wave.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/elastic-wave.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/elastic-wave.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/elastic-wave
python -m http.server 8000
# open http://localhost:8000
```
