# 物質拡散シミュレーター — Fick則・Arrheniusモデル

NovaSolverの物質拡散シミュレーターは、Fick則とArrheniusモデルに基づき、鋼中炭素やシリコン中酸素の拡散・浸透挙動を可視化します。拡散係数や温度をスライダーで直感的に操作し、濃度分布のリアルタイム変化を確認できる、材料科学・工学のための学習・研究ツールです。

**Category:** 化学工学

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/diffusion-mass
python -m http.server 8000
# open http://localhost:8000
```
