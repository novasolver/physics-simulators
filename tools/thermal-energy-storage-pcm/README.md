# 相変化材料 PCM 蓄熱システムシミュレーター

パラフィン・塩水和物・脂肪酸・金属系PCMによる潜熱蓄熱システムを設計するツールです。PCM質量・運用温度範囲・カプセル化率を変えると、潜熱と顕熱の貯蔵バランス、エネルギー密度、必要体積、充熱パワーがリアルタイムで分かります。

**Category:** 蓄熱・建築省エネ
