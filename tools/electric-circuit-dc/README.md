# 直流回路シミュレーター

直流回路シミュレーターで直列・並列・混合回路の合成抵抗・電流・電圧をリアルタイム計算。キルヒホッフの法則やオームの法則を視覚化して学習できます。

**Category:** 電気・電子回路

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/electric-circuit-dc.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/electric-circuit-dc.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/electric-circuit-dc.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/electric-circuit-dc
python -m http.server 8000
# open http://localhost:8000
```
