# 空力弾性・フラッター速度計算機

NovaSolverの空力弾性・フラッター速度計算機は、2自由度翼のフラッター速度と静的発散速度をリアルタイムで計算します。V-g線図やV-ω線図を直感的に可視化し、翼の振動解析を支援。コード長や固有振動数、密度比を調整して、航空機・橋梁設計の初期検討に役立つシミュレーションを実現します。

**Category:** 空力弾性シミュレーター
