# ゲーム理論シミュレーター

ゲーム理論シミュレーターで囚人のジレンマ・ナッシュ均衡を計算。利得行列操作と空間進化ゲームのリアルタイム可視化でゲーム論シミュレーションを実践。

**Category:** 数理科学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/game-theory.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/game-theory.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/game-theory.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/game-theory
python -m http.server 8000
# open http://localhost:8000
```
