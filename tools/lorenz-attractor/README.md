# ローレンツアトラクターシミュレーター — バタフライ効果とカオス

ローレンツアトラクターシミュレーターで、カオス理論の象徴「バタフライ効果」をリアルタイムに体験。パラメータを調整して、複雑な軌道の生成から安定した周期解まで、非線形動力学の世界を直感的に学べます。3D可視化でカオス研究の基礎を深めましょう。

**Category:** カオス力学・非線形系

git clone https://github.com/novasolver/physics-simulators

python -m http.server 8000
