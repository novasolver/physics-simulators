# 3径間連続梁シミュレーター — 3モーメント方程式

等径間・等分布荷重を受ける3径間連続梁を、Clapeyronの3モーメント方程式で解析。中間支点モーメント・反力分布・最大撓みと、せん断力図・曲げモーメント図をリアルタイムに可視化します。

**Category:** 構造解析シミュレーター
