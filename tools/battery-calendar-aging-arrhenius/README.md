# 電池カレンダー劣化の Arrhenius 温度依存シミュレーター

電池カレンダー劣化のArrhenius温度依存シミュレーター。温度とSOCが容量維持率に与える影響を劣化マップで可視化。長期保管後の劣化予測と寿命評価に対応。

**Category:** 対話型シミュレーター

- 🇨🇳 [中文](https://novasolver.jp/zh/tools/battery-calendar-aging-arrhenius.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/battery-calendar-aging-arrhenius
python -m http.server 8000
# open http://localhost:8000
```
