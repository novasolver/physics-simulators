# サンプリング定理・エイリアシング可視化

ナイキスト・シャノンのサンプリング定理をインタラクティブに可視化。f_s &lt; 2f_signal のとき折り返し（エイリアシング）がどう現れるかをリアルタイムで確認。

**Category:** 振動・波動

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/signal-sampling.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/signal-sampling.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/signal-sampling.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/signal-sampling
python -m http.server 8000
# open http://localhost:8000
```
