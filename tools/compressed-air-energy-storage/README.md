# 圧縮空気エネルギー貯蔵（CAES）シミュレーター

圧縮空気エネルギー貯蔵（CAES）の貯蔵エネルギーを計算。貯気空間の容積・最高/最低圧力・空気温度・ラウンドトリップ効率を変えて、抽出可能空気質量・理想貯蔵エネルギー・取出し可能電力量・エネルギー密度を等温近似で見積もれる無料シミュレーターです。

**Category:** エネルギー工学
