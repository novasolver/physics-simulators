# 振動疲労PSD応力計算 — Steinberg 3σ法

PSD（パワースペクトル密度）入力から1自由度応答を計算し、RMS応力・ピーク応力・Steinberg法による疲労損傷・期待寿命をリアルタイムに求める。

**Category:** 振動解析
