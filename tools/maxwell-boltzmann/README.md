# マクスウェル・ボルツマン速度分布 シミュレーター

マクスウェル・ボルツマン速度分布シミュレーター：理想気体の分子速度分布を温度・分子量から可視化。最確速度・RMS速度などをリアルタイム計算。温度依存性を直感的に学習できます。

**Category:** 統計力学シミュレーター

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/maxwell-boltzmann.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/maxwell-boltzmann.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/maxwell-boltzmann.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/maxwell-boltzmann
python -m http.server 8000
# open http://localhost:8000
```
