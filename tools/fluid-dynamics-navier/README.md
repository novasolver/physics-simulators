# Navier-Stokes流れ可視化

蓋駆動キャビティ流れのシミュレーションをブラウザ上でリアルタイムに体験。レイノルズ数を変更し、2D非圧縮流れの様子をカラーマップと流線で可視化。流体力学やCFDの直感的な学習に最適なシミュレーターツールです。

**Category:** 流体解析

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/fluid-dynamics-navier
python -m http.server 8000
# open http://localhost:8000
```
