# 合成梁・変換断面法 応力分布計算

合成梁の応力分布をリアルタイム計算。変換断面法で中立軸・二次モーメント・応力分布を可視化。鉄筋コンクリート・FRP複合梁の設計に対応。

**Category:** 構造解析

- 🇺🇸 [English](https://novasolver.jp/en/tools/composite-beam.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/composite-beam.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/composite-beam
python -m http.server 8000
# open http://localhost:8000
```
