# コアンダ効果シミュレーター — 壁面付着噴流の付着角度と反力

円弧曲面に沿うコアンダ噴流の付着角度・剥離点・運動量反力を可視化。噴流厚さ・曲面半径から曲率パラメータ K=b/R を変えて、いつ噴流が剥離するかを学べます。

**Category:** 流体力学シミュレーター
