# 開水路の定常流・マニングの式

NovaSolverの開水路定常流シミュレーターは、マニングの式に基づき矩形・台形・円形・三角形断面の流速・流量を自動計算する無料オンライン計算機です。粗度係数や勾配を入力するだけで、径深やフルード数も即座に算出。Q-y曲線のリアルタイム描画で流れの状態が一目で分かり、水理計算が簡単にできます。

**Category:** 流体解析
