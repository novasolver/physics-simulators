# フーリエ級数可視化ツール

矩形波・鋸波・三角波を回転する円（フェーザー）の重ね合わせで合成。高調波の追加につれて信号が近似される様子をリアルタイムアニメーション。ギブス現象も体験。

**Category:** 信号処理・数学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/fourier-series-vis.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/fourier-series-vis.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/fourier-series-vis.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/fourier-series-vis
python -m http.server 8000
# open http://localhost:8000
```
