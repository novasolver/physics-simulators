理論・主要公式

矩形波：

$$x(t) = \frac{4}{\pi}\sum_{n=1,3,5,...}^{N}\frac{\sin(n\omega t)}{n}$$

奇数次高調波のみ。
N→∞ で完全な矩形波に収束。

フーリエ級数可視化ツールとは

🙋
このシミュレーターで、複雑な波が単純なサイン波の足し算で作れるって本当ですか？
🎓
本当だよ。大まかに言うと、どんな周期的な形の波も、基本となるサイン波と、その整数倍の速さで振動する「高調波」というサイン波を足し合わせることで作り出せるんだ。このツールの「高調波数 N」のスライダーを動かしてみて。N=1から順に増やしていくと、三角波や矩形波がサイン波の積み木のように組み上がっていく様子がわかるよ。「N自動増加」を押せば、合成波形（シアン）が点線の目標波形に近づいていく収束の過程を自動で再生できる。
🙋
画面でくるくる回っている矢印（フェーザー）は何を表しているんですか？
🎓
あれは、それぞれのサイン波を複素平面上の回転ベクトルとして表したものだ。各矢印の長さが振幅、回る速さが周波数に対応している。この矢印たちを、先端から次へとつなげていった、最後の矢印の先端の高さ（y座標）が、今見ている合成波形の瞬間の値になるんだ。先端から右の波形領域へ点線がつながっているのが見えるね。「アニメーション速度」を変えると、この回転の様子がゆっくり観察できるぞ。
🙋
矩形波でNを大きくしても、角のところがピョコンと飛び出してしまうのはなぜですか？
🎓
あれが有名な「ギブス現象」だ。不連続な点（矩形波の角）を滑らかなサイン波だけで無理やり近似しようとすると、どうしても約9%のオーバーシュート（飛び出し）が起きてしまうんだ。上の「オーバーシュート」のライブ数値を見て。Nをどこまで大きくしてもこの値は約9%から下がらない、数学的に面白い現象さ。一方で三角波は連続なのでギブス現象は起きず、RMS誤差もぐっと小さくなる。見比べてみよう。

よくある質問

それはギブス現象です。フーリエ級数で不連続点を近似する際、高調波をいくら増やしても約9%のオーバーシュートが残る現象です。このツールで高調波数を変えながら、その振動が収束せずに尖ったまま残る様子を、ライブの「オーバーシュート」数値とともに確認できます。
矩形波は奇数次正弦波のみ（1,3,5…次）、鋸波は全次数の正弦波（1,2,3…次）、三角波は奇数次正弦波で係数が1/n²と急速に減衰します。パルス波（デューティ25%）は b_n=(2/nπ)(1−cos2πnd) で与えられ、n=4,8…の高調波がゼロになります。この違いにより、三角波は少ない高調波でも滑らかに近似されます。
各円の回転が各高調波の正弦成分に対応します。円の半径がフーリエ係数、回転速度が周波数nωです。すべての円を先端から先端へ連結し、最終端のy座標を時間方向に並べると、それらの和として元の周期波形が再現される仕組みです。
高調波の打ち切り次数と波形の近似精度（RMS誤差）の関係を視覚的に理解できます。例えば、矩形波は多くの高調波が必要で帯域制限時に歪みやすい一方、三角波は少ない次数でも実用可能です。音色設計やフィルタ設計の直感的な参考になります。

実世界での応用

音声合成・電子音楽：三角波、矩形波、鋸波はシンセサイザーの基本波形です。フーリエ級数の原理を用いて、これらの倍音（高調波）成分を制御することで、豊かな音色を作り出しています。

振動・騒音解析：エンジンやモーターの回転から生じる周期的な振動や騒音を測定し、フーリエ級数（フーリエ変換）で周波数成分に分解します。どの周波数の振動が問題かを特定し、対策を講じるために使われます。

交流回路・電力工学：実際の交流電源の波形は完全な正弦波ではなく歪みを含みます。この歪み波形をフーリエ級数で分解し、高調波成分が機器に与える影響を評価・対策します（高調波抑制）。

画像処理（2次元拡張）：フーリエ級数の考え方は2次元に拡張され、JPEGなどの画像圧縮技術の基礎となっています。画像の濃淡パターンを異なる周波数と方向の波の重ね合わせとして表現します。

よくある誤解と注意点

このツールを使い始めるとき、いくつか勘違いしやすいポイントがあるから気をつけてね。まず、「高調波数Nを無限にすれば完全な波形になる」と思いがちだけど、矩形波のように急峻な不連続点を持つ波形では、ギブス現象で約9%のオーバーシュートが残るんだ。これは数学的に消えないもので、N=100にしても1000にしても変わらない。実務では、この「完全には再現できない」という特性を頭に入れて設計する必要があるよ。

次に、「基本波の周波数」と「波形の周期」の関係を混同しないで。例えば、基本周波数 $f_1$ が 50Hz なら、その周期 $T_1$ は $1/50 = 0.02$秒だよね。でも、合成される矩形波の周期も同じ0.02秒になる。基本波1周期分の時間で、合成波形も1周期を完了するんだ。フェーザーの回転速度と波形の繰り返し速度が連動していることを確認してみよう。

最後に、実践的な落とし穴として「打ち切り誤差」がある。無限級数を有限のNで打ち切るから、どうしても誤差が生じる。例えば、N=9の矩形波は、理論式 $$x_{\text{square}}(t) = \frac{4}{\pi}\sum_{n=1,3,5,...}^{\infty}\frac{\sin(n\omega t)}{n}$$ のn=17以降を無視している状態だ。この誤差は、滑らかな三角波では小さく早く収束するけど、矩形波では振動（リンギング）として残りやすい。実務の信号処理では、必要な精度と計算コストのトレードオフを考えてNを決めるんだ。

使い方ガイド

  1. 目標波形（矩形波・鋸波・三角波・パルス波）を選択します
  2. スライダーまたは「N自動増加」で高調波数Nを1～60まで調整し、合成波形（シアン）が点線の目標波形へ収束する過程を観察します
  3. アニメーション速度で回転を制御し、フェーザー先端が波形を描く様子と各高調波の位相関係を観察します
  4. 上部のライブ数値でRMS誤差とギブスのオーバーシュートを、下部のスペクトルで高調波振幅を同時に確認します

具体的な計算例

矩形波（±1、基本周波数10Hz）を近似する場合、基本波の振幅は4/π≈1.27、9次（=第9高調波）まで加算するとRMS誤差は約16%、N=20でも約12%程度残ります（不連続のため）。三角波では奇数次高調波のみが存在し（振幅∝1/n²で急速収束）、N=10でRMS誤差は1%未満まで低下します。矩形波の不連続点ではNを増やしても約9%のオーバーシュート（ギブス現象）が消えないことを「オーバーシュート」のライブ数値で確認できます。

実務での注意点

  1. 電源の高調波歪み測定（矩形波近似）では、電流計の帯域幅がサンプリング周波数の3倍以上必要です。50Hz基本波から250Hz（5次）まで対応する計器を選定してください
  2. ギブス現象により不連続点で±9%のオーバーシュートが発生するため、PWM制御などの急峻な遷移を伴う装置では充分な次数（N≧20）を確保してください
  3. アナログフィルタ設計時は、ナイキスト周波数（最大周波数の2倍）を超える高調波成分を除去し、時間領域でのリンギング現象を防止します

準拠規格・前提条件

準拠/参考：フーリエ級数。矩形波 \(\frac{4}{\pi}\sum_{n\,odd}\frac{\sin n x}{n}\)、鋸波 \(\frac{2}{\pi}\sum_{k\ge1}\frac{(-1)^{k+1}\sin k x}{k}\)、三角波 \(\frac{8}{\pi^2}\sum_{n\,odd}\frac{(-1)^{(n-1)/2}\sin n x}{n^2}\)、パルス波 \(\sum_{n\ge1}\frac{2}{n\pi}(1-\cos 2\pi n d)\sin n x\)。

モデルの前提：周期信号を正弦項の有限和で近似（位相器の重ね合わせ）。不連続点ではGibbs現象（約9%の行き過ぎ）が残る。振幅は単位波形（±1）に正規化。

適用範囲・限界：教育・可視化用。検証：先頭係数 4/π=1.273・2/π=0.637・8/π²=0.811、N=200で矩形波≈1.00、三角波ピーク≈1.00 と本ツールが一致。実信号解析（任意波形のスペクトル）はFFTを用いること。
