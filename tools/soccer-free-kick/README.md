# サッカーフリーキック軌道シミュレーター

サッカーフリーキック軌道シミュレーター｜マグヌス効果・空気抵抗を考慮した物理計算でボール軌道をリアルタイム可視化。スピン・初速度・蹴り角度パラメータでバナナシュート解析。

**Category:** スポーツ力学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/soccer-free-kick.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/soccer-free-kick.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/soccer-free-kick.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/soccer-free-kick
python -m http.server 8000
# open http://localhost:8000
```
