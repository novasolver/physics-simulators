# インダクタ・RL回路の過渡応答

NovaSolverの無料オンライン「インダクタ・RL回路シミュレーター」で、RL直列回路の動作を視覚的に学びましょう。過渡応答や交流応答をリアルタイム計算し、時定数やインピーダンスを自動算出。充電・放電・交流の3モードで、エネルギー蓄積から誘導性リアクタンスまで、回路の挙動を簡単にシミュレーションできます。

**Category:** 電磁気・光学

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/inductor-rl
python -m http.server 8000
# open http://localhost:8000
```
