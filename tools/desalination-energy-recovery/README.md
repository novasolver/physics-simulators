# 海水淡水化エネルギー回収と比消費電力シミュレーター

海水淡水化のエネルギー回収と比消費電力をシミュレーション。高圧ポンプ圧と回収率からSECと濃縮水流量を計算、RO膜設計の最適化に活用。

**Category:** 対話型シミュレーター

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/desalination-energy-recovery
python -m http.server 8000
# open http://localhost:8000
```
