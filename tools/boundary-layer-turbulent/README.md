# 乱流境界層シミュレーター — 平板上の1/7乗則とCf

平板上の乱流境界層を1/7乗則で可視化。流速・位置・動粘度・密度を変えて、境界層厚さ δ・摩擦係数 C_f・壁面せん断応力 τ_w を計算し、Blasius層流解との違いを学べます。

**Category:** 流体力学シミュレーター
