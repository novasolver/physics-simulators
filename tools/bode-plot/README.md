# ボード線図ジェネレーター

伝達関数のゲイン線図・位相線図をリアルタイム描画。ゲイン余裕・位相余裕・交差周波数を自動計算し、制御系の安定性評価が可能。ボード線図解析ツール。

**Category:** 周波数応答

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/bode-plot.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/bode-plot.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/bode-plot.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/bode-plot
python -m http.server 8000
# open http://localhost:8000
```
