# 電気めっき計算シミュレーター

ファラデーの法則に基づき、めっき金属・電流密度・面積・処理時間から膜厚・析出質量・消費電力・電気量をリアルタイム計算。Ni/Cu/Cr/Au/Zn の 5金属対応、膜厚の時間依存性と電流効率の影響を可視化します。

**Category:** 電気化学・表面処理
