# すべり軸受シミュレーター

すべり軸受シミュレーターで、短軸受レイノルズ方程式によるジャーナル軸受の油膜圧力分布・負荷容量・最小油膜厚さをリアルタイム計算。軸受性能とゾンマーフェルト数の関係を視覚化。

**Category:** トライボロジー

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/fluid-bearing.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/fluid-bearing.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/fluid-bearing.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/fluid-bearing
python -m http.server 8000
# open http://localhost:8000
```
