# ポテンシャル流れシミュレーター

NovaSolverのポテンシャル流れ・圧力分布シミュレーターで、円柱まわりの流れを可視化。流線と圧力係数のカラーマップにより、マグヌス効果やダランベールのパラドックスを直感的に理解できます。クッタ・ジュコーフスキーの定理も体感できる、流体力学学習・研究のインタラクティブツールです。

**Category:** 流体解析

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/potential-flow.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/potential-flow.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/potential-flow
python -m http.server 8000
# open http://localhost:8000
```
