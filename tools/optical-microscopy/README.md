# 光学顕微鏡・分解能・焦点深度計算機

NA・波長・浸液媒質・倍率を変えて、レイリー分解能・アッベ限界・焦点深度をリアルタイム計算。エアリーディスクと SEM/TEM 比較表で光学限界を直感的に把握できます。

**Category:** 光学計測シミュレーター
