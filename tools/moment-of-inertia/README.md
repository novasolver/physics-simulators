# 断面二次モーメント・慣性モーメント計算機

断面二次モーメント・慣性モーメント計算機。7種類の断面形状に対応し、Ixx・Iyy・断面係数・回転半径を即座に算出。梁設計と回転体解析に対応。平行軸定理搭載。

**Category:** 構造解析
