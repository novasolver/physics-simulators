# 有効数字・丸め誤差・測定不確かさ計算機

有効数字の自動カウント、丸め処理、誤差伝播計算（和差積商・べき乗・平方根）をステップバイステップで表示。数直線上で不確かさの範囲を可視化します。測定値とその不確かさを入力するだけで、信頼性の高い計算結果とその導出過程を確認できます。科学技術計算の品質向上に役立つツールです。

**Category:** 数理・統計
