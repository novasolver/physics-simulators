# 蒸留塔設計計算機（マッケーブ・シール法）

NovaSolverの無料オンライン蒸留塔設計計算機。マッケーブ・シール法を用いて、二成分蒸留の理論段数・還流比・最小理論段数を簡単計算。VLE曲線と操作線をグラフ描画し、ステップオフによる段数の視覚化で理解を深められます。化学工学の学習やプロセス設計に最適なシミュレーションツールです。

**Category:** 化学工学
