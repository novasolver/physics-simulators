# クーロンの法則 シミュレーター — 点電荷間の電気力

2つの点電荷の間に働くクーロン力 F = k·q_1·q_2 / (ε_r·r²) をリアルタイムに計算。電場 E、ポテンシャルエネルギー U、引力／反発の向きを、電気力線と |F|-r の log-log 曲線で直感的に学べます。

**Category:** 電磁気シミュレーター
