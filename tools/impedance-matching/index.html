インピーダンス整合 シミュレーター — 反射係数と SWR

伝送線路の特性インピーダンス Z_0 と複素負荷 Z_L、トランス比 N を入力し、反射係数 Γ・VSWR・反射率・電力伝達効率をリアルタイム計算します。スミス・チャート上に現在の整合点を表示し、整合の良し悪しを直感的に把握できます。

整合回路の模式図

信号源 → 線路 (Z_0) → トランス (N:1) → 負荷 Z_L。入射波（黄）と反射波（橙）の矢印、各要素のインピーダンス値、一次側から見た等価負荷 Z_in = N²·Z_L をラベル表示。

スミス・チャート

単位円内で正規化インピーダンス z = Z_in/Z_0 を Γ 平面に写像。原点 = 整合点 (z=1)、黄色丸 = 現在の Γ、破線 = SWR 円。実軸右端 = 開放、左端 = 短絡、上半円 = 誘導性、下半円 = 容量性。

理論・主要公式

反射係数（複素数）：

$$\Gamma = \frac{Z_L - Z_0}{Z_L + Z_0}$$

電圧定在波比（VSWR）：

$$\mathrm{SWR} = \frac{1 + |\Gamma|}{1 - |\Gamma|}$$

反射率と電力伝達効率：

$$\eta = 1 - |\Gamma|^2$$

トランス比 N によるインピーダンス変換：

$$Z_{in} = N^2 \, Z_L$$

$|\Gamma| = 0$ かつ $\mathrm{SWR} = 1$ で完全整合（反射ゼロ）。$\mathrm{SWR} \lt 1.5$ が実用整合の目安です。

インピーダンス整合 シミュレーターとは

🙋
無線機の説明書に「アンテナの SWR を 1.5 以下に調整してください」って書いてあるんですけど、SWR ってそもそも何ですか？1.5 と 3 ではそんなに違うんですか？
🎓
いい着眼点だ。SWR は「電圧定在波比 (Voltage Standing Wave Ratio)」の略で、線路上の電圧の最大と最小の比を表す。SWR = 1 が完全整合で、線路上に進行波しかない理想状態。SWR が大きいほど反射が強くなり、波がぶつかり合って定在波（節と腹）ができる。SWR = 1.5 なら反射率 4 %、SWR = 3 なら反射率 25 % まで上がる。電力でいうと SWR = 3 で 1/4 が反射されてアンテナに届かない計算だ。デフォルト値（Z_0=50, R_L=75, X_L=0, N=1）でやってみて。SWR が 1.50 になるはずだ。
🙋
本当に SWR = 1.50 って出ました！反射係数 |Γ| が 0.200 で、反射率が 4.00 %、伝達効率が 96.0 % ですね。これってどう計算してるんですか？
🎓
公式は Γ = (Z_L − Z_0)/(Z_L + Z_0) だ。今回は Z_L = 75 Ω, Z_0 = 50 Ω なので Γ = (75−50)/(75+50) = 25/125 = 0.2 で純実数。|Γ| = 0.2、反射率は |Γ|² = 0.04、伝達効率は η = 1 − |Γ|² = 0.96 = 96 %。SWR は (1+|Γ|)/(1−|Γ|) = 1.2/0.8 = 1.50 。スミス・チャートを見ると、現在の Γ 点（黄色丸）が原点（整合点）から右に 0.2 だけずれている。原点に近いほど整合が良く、外周に近づくほど悪化する。
🙋
トランス比 N っていうスライダーがありますけど、これはどう使うんですか？
🎓
トランス（変成器）でインピーダンスを変換する仕組みだ。一次側から見える等価インピーダンスは Z_in = N²·Z_L になる。今は 75 Ω のアンテナを 50 Ω の線路に繋いでいて整合が悪い。N を √(50/75) ≈ 0.816 にしてみて。Z_in = 0.816² × 75 ≈ 49.9 Ω となり、ほぼ完全整合だ。実際に N を 0.82 ぐらいに合わせると |Γ| が 0.000 に近づくはず。これがインピーダンス整合の核心で、放送局や無線通信では送信機・線路・アンテナの全段で整合をとる。
🙋
負荷リアクタンス X_L を動かすとどうなるんですか？
🎓
X_L はリアクティブ成分で、コイル成分（+）かコンデンサ成分（−）か、を表す。実アンテナは共振周波数からずれるとリアクティブ成分が乗ってきて、純抵抗ではなくなる。X_L を +50 にしてみて。|Γ| が 0.318 ぐらいに上がり、スミス・チャートの黄色丸が上に移動する（上半円は誘導性）。X_L = −50 にすると今度は下半円に移り、容量性になる。アンテナチューナーはこのリアクティブ成分を打ち消す可変リアクタンスを直列／並列に入れて整合点に動かす装置だ。
🙋
スミス・チャートって何ですか？円の中にもっと細かい円が描かれてますけど、これは何を表してるんですか？
🎓
スミス・チャートは反射係数 Γ の複素平面上のグラフで、1939 年に Philip H. Smith が考案した RF 設計の超定番ツールだ。外周の単位円が |Γ| = 1（全反射）、中心が Γ = 0（完全整合）。横方向に並ぶ円は「同じ正規化抵抗 r = R/Z_0 の等位線」、上下の弧は「同じ正規化リアクタンス x = X/Z_0 の等位線」を表す。任意のインピーダンスは一意な点に対応する。R_L や X_L を動かすと黄色丸がどう動くか見てみると、整合作業がチャート上の「ジャンプ」として直感的に理解できる。
🙋
R_L スイープボタンを押すとどんなことが見えるんですか？
🎓
R_L を 1 Ω から 1000 Ω まで自動でスイープして、整合点を通過する様子を観察できる。N = 1 のままなら R_L = Z_0 = 50 Ω のところで完全整合し、|Γ| が 0 に落ちる。50 Ω より小さいと Γ は負（短絡側）、50 Ω より大きいと Γ は正（開放側）に動く。スミス・チャートでは横軸（実軸）上を黄色丸が左右に往復する。N = 2 にしてからスイープすると、整合点は R_L = Z_0/N² = 50/4 = 12.5 Ω に移る。トランスが整合点を「動かしている」ことが視覚的にわかる。

物理モデルと主要な数式

伝送線路（特性インピーダンス $Z_0$）の終端に負荷 $Z_L = R_L + jX_L$ を接続すると、線路の端で電圧波の一部が反射します。入射波の電圧振幅 $V^+$ と反射波の振幅 $V^-$ の比を反射係数 $\Gamma$ といい、境界条件（電圧と電流の連続性）から $\Gamma = (Z_L - Z_0)/(Z_L + Z_0)$ で与えられます。$Z_L$ が複素数なら $\Gamma$ も複素数で、大きさ $|\Gamma| \in [0, 1]$ と位相角 $\arg(\Gamma)$ を持ちます。$\Gamma = 0$ で完全整合（反射ゼロ）、$|\Gamma| = 1$ で全反射（開放・短絡・純リアクティブ負荷）。

線路上では入射波と反射波の干渉により定在波が立ち、電圧の最大値 $|V_{max}| = |V^+|(1 + |\Gamma|)$ と最小値 $|V_{min}| = |V^+|(1 - |\Gamma|)$ ができます。この比が電圧定在波比 $\mathrm{SWR} = (1 + |\Gamma|)/(1 - |\Gamma|)$ です。電力で見ると、入射電力に対する反射電力の比は $|\Gamma|^2$、負荷で消費される電力（伝達効率）は $\eta = 1 - |\Gamma|^2$。理想変成器を一次：二次 $= N:1$ の比で挿入すると、二次側の $Z_L$ は一次側から $Z_{in} = N^2 \cdot Z_L$ として見えるため、巻数比で整合を調整できます。

シミュレーターは既定値 $Z_0 = 50$ Ω, $R_L = 75$ Ω, $X_L = 0$ Ω, $N = 1.0$ で $Z_{in} = 75$ Ω, $\Gamma = 0.200$, $\mathrm{SWR} = 1.50$, 反射率 $= 4.00 \%$, $\eta = 96.0 \%$ を出力します。これは $50$ Ω 同軸ケーブルに $75$ Ω 同軸（テレビ用）を直結したときの典型例で、わずか 25 Ω の差でも 4 % の電力が反射される事実が確認できます。

実世界での応用

無線送信機とアンテナ：送信機の出力段（典型 50 Ω）と同軸ケーブル（50 Ω）、アンテナ（理論 50〜75 Ω）の全段で整合をとる必要があります。アンテナが共振から外れて $X_L \neq 0$ になっていると SWR が上がり、反射波が送信機に戻って終段トランジスタを焼損する危険があります。最近の無線機は SWR ≥ 3 で出力を自動的に絞る保護回路を備えており、移動運用ではアンテナチューナーで SWR を 1 に近づけるのが定番です。

テレビ・ケーブル系統：家庭の地デジは 75 Ω 同軸が標準ですが、業務用の計測機器は 50 Ω が多いため、両者を繋ぐ際は 75/50 整合トランス（バルン）が必要です。$Z_0 = 50, R_L = 75$ では SWR = 1.5 で反射率 4 % なので、テレビ受像では問題になりにくいですが、デジタル伝送では微小な反射でもビット誤りや ISI（符号間干渉）の原因になり、専用バルンが用意されます。

オーディオパワーアンプとスピーカー：真空管アンプの出力インピーダンス（数 kΩ）と 8 Ω スピーカーの間には必ず出力トランスが入ります。整合比は $N^2 = Z_{プレート}/Z_{スピーカー}$ で、例えば 5 kΩ : 8 Ω なら $N = \sqrt{625} = 25$ の昇圧トランス。整合不良だと最大出力が落ち、低域・高域でひずみが増えます。トランジスタアンプは出力インピーダンスがほぼゼロなので電圧駆動でき、整合トランスは不要です。

RF 増幅器の段間整合：マイクロ波 IC では各 FET の入力／出力インピーダンスが 50 Ω からずれているため、段間に LC マッチング回路（L 型、π 型、T 型）を挿入します。スミス・チャート上で出発点（FET の入力インピーダンス）から原点（50 Ω）まで「直列 L → 並列 C」のステップで移動させる作業が、整合回路設計の本質です。本シミュレーターはトランス整合（広帯域だが帯域制限あり）の入門で、LC 整合（狭帯域だが任意のインピーダンスへ移せる）と使い分けます。

よくある誤解と注意点

まず多い誤解が、反射した電力はすべて熱で消えると思うこと。実は反射波は線路を逆走して送信機に戻り、終段の出力インピーダンスで再吸収されるか、内部の保護回路で消費されるかします。長い線路では往復で減衰するため、SWR の値は周波数や線路長によって測定点ごとに違って見えることもあります。SWR メータは設置位置（送信機端／アンテナ端）で値が変わるため、整合作業はアンテナ近傍で測るのが原則です。

次に、SWR が低ければ放射効率が高いと思う罠。SWR は線路と負荷の整合度を表すだけで、負荷（アンテナ）が実際に電波を出しているかは別問題です。例えば 50 Ω 抵抗器を線路の末端に繋ぐと SWR は完璧に 1 になりますが、抵抗が熱になるだけで電波は出ません。「SWR が低い ＝ アンテナが正常」とは限らないので、フィールドストレングス計などで実放射を確認することが必要です。

最後に、トランス整合は周波数に依存しないと思う落とし穴。理想変成器なら $N^2$ 倍の変換は周波数によらずですが、実際のトランスには漏れインダクタンスと巻線間容量があり、高周波では効率が落ち、低周波ではコアが磁気飽和します。広帯域整合には伝送線路トランス（フェライトコア + テフロン同軸）、狭帯域整合には LC マッチング、と帯域要件で手法を選び分けるのが実務です。本ツールは理想変成器を仮定しているため、巻線損失や帯域制限は反映していません。

よくある質問

直列 RLC 回路（ac-impedance-rlc）は R, L, C を直列に接続した集中定数回路の周波数応答（共振点での |Z| 最小化）を扱います。一方、本ツールは伝送線路の終端整合と反射係数を扱うため、対象が「波として進行する電圧」になります。集中定数では電圧位相を一点で議論しますが、伝送線路では位置によって電圧が変わる（定在波）のが大きな違いです。線路長 ≪ 波長／10 なら集中定数近似、それより長ければ伝送線路扱いが基本です。
まず中心（整合点 z=1）を覚え、右端＝開放（z=∞）、左端＝短絡（z=0）、上半円＝誘導性、下半円＝容量性を押さえます。同じ抵抗値を持つ点は実軸右側にある「定 R 円」上に並び、同じリアクタンスを持つ点は上下の弧（定 X 円）上に並びます。R_L や X_L を動かしてシミュレーターで黄色丸の移動を見ると、これら格子の役割が直感的にわかります。本格的な設計では、整合回路の各素子（直列 L、並列 C 等）が黄色丸をどう動かすかを暗記すると、紙のスミス・チャート 1 枚で整合回路が設計できます。
許容 SWR は機器の規格次第ですが、目安は次の通り。SWR < 1.5（反射 4 %）：理想的、業務用送信機の規定値。SWR < 2.0（反射 11 %）：実用的、市販無線機の連続運用範囲。SWR < 3.0（反射 25 %）：限界、多くの送信機が出力を絞り始める保護領域。SWR > 3.0：終段焼損の危険があり、保護回路が出力を大きく落とすか停止します。なお SWR が下がっても伝達効率が 100 % になるわけではなく、線路損失（ケーブル抵抗、誘電体損）は別途あり、長い同軸では数 dB の追加損失が常にあります。
本ツールは理想変成器によるインピーダンス変換のみをモデル化しており、以下は対象外です。(1) λ/4 整合線路：特性インピーダンス $Z_T = \sqrt{Z_0 \cdot Z_L}$ の 1/4 波長線路で整合する手法。周波数依存性が強く、狭帯域。(2) LC 整合回路（L 型、π 型、T 型）：集中定数 L, C で任意の Z_L から Z_0 に移す手法。スミス・チャート上で直列 L／並列 C などのジャンプを設計する。(3) スタブ整合：並列接続の短絡または開放スタブで整合をとる手法。マイクロストリップ線路でよく使われる。これらは別ツール（例：transmission-line, microwave-transmission）と組み合わせて学ぶと体系的に理解できます。

使い方ガイド

  1. 特性インピーダンスZ0（50Ω～600Ω）を設定し、負荷インピーダンスの抵抗成分RLと反応成分XLを入力します
  2. シミュレーターが反射係数Γ、VSWR、反射率|Γ|²をリアルタイム計算し、スミス・チャートに負荷点をプロットします
  3. マッチング不一致時は電力伝達効率の低下を確認し、λ/4スタブやL字マッチング回路の必要性を判定します

具体的な計算例

50Ω同軸ケーブルに75Ω＋j25Ωの負荷を接続した場合：反射係数|Γ|=0.372、VSWR=2.18、反射率18.2%となり、電力伝達効率は81.8%です。L字マッチング回路で32Ωの直列インダクタンスと47Ωの並列キャパシタンスを追加すると、|Γ|≈0.02以下に改善され、伝達効率は99.9%に達します。アンテナ給電線（特性Z0=75Ω）でRL=50Ω+j0Ωの場合、VSWR=1.5、反射率4%です。

実務での注意点

  • 高周波回路設計では周波数依存性を考慮し、目標周波数帯域全域でVSWR≤1.5以下を確保してください。75Ω映像ケーブルでは50Ωキャリブレーション測定が無効になります
  • 反射係数が-20dB以下でも整合度不足による信号品質低下が発生する場合があります。デジタル変調信号ではEVM特性で検証が必要です
  • スタブ長はVNA測定で物理長を確認し、PCBトレース速度係数0.67を乗算して設計長を算出してください
  • マイクロ波帯（>1GHz）では寄生成分を含むS11パラメータ測定で実測値との誤差を補正します
