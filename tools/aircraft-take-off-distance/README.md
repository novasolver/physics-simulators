# 航空機 離陸距離・V1/Vr シミュレーター

機種・離陸重量・気温・標高・向かい風・フラップ・滑走路勾配を変えると、TORA / TODA / BFL の滑走路長要求と V1・Vr・V2 速度がリアルタイムで分かります。High Hot Heavy 条件での性能低下や、空港選定・荷重制限の検討に使えます。

**Category:** 航空機・性能解析
