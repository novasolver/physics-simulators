# ラングミュア吸着等温線シミュレーター — 被覆率と平衡定数

ラングミュア吸着等温線シミュレーター — 被覆率と平衡定数の関係をθ=Kp/(1+Kp)で可視化。圧力・温度・吸着熱を変動させ、単分子層吸着の遷移挙動と温度依存性を学習できるCAEツール。

**Category:** 表面化学シミュレーター
