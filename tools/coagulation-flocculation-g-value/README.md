# 凝集フロック形成の G 値と接触時間シミュレーター

凝集フロック形成のG値と接触時間シミュレーター。撹拌条件のGt値、単位体積動力、投入エネルギーを同時確認。凝集・沈殿処理設計に必須。

**Category:** 対話型シミュレーター
