# Blasius 境界層シミュレーター — 平板層流の δ と C_f

平板上の層流境界層について、Blasius 解で 99% 厚さ δ_99・排除厚さ δ*・運動量厚さ θ・局所摩擦係数 C_f をリアルタイム計算。流速・位置・動粘度を変えて、なぜ厚さが √x で増えるのかを学べます。

**Category:** 流体力学シミュレーター
