# フィン効率・温度分布シミュレーター

フィン効率・温度分布をリアルタイム計算。矩形・三角形・放物線フィンの効率η、温度分布T(x)、熱流束を可視化し最適設計を探索。伝熱工学シミュレーション。

**Category:** 熱解析

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/fin-efficiency.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/fin-efficiency.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/fin-efficiency.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/fin-efficiency
python -m http.server 8000
# open http://localhost:8000
```
