# 弾道→軌道 遷移シミュレーター — Newton's Cannonball 教育版

速度増加による弾道から軌道への遷移を視覚化する教育シミュレーター。放物線・円軌道・楕円・双曲線軌道をNewton's Cannonballで体験。軌道力学・ケプラー運動's Cannonball 教育版: 速度をゼロから増やすと、放物弾道 → 周回円軌道 → 楕円 → 双曲線脱出へと連続的に切り替わる教育シミュレーターです。Newton's Cannonball の思考実験を 1 画面で体験。実在天体は『ケプラー軌道』、脱出速度の…'s Cannonball 教育版: 速度をゼロから増やすと、放物弾道 → 周回円軌道 → 楕円 → 双曲線脱出へと連続的に切り替わる教育シミュレーターです。Newton's Cannonball の思考実験を 1 画面で体験。実在天体は『ケプラー軌道』、脱出速度の…'s Cannonball 教育シミュレーター。ケプラーの法則・軌道周期・離心率・脱出速度の関係を 1 つの画面で体験できます。実在天体軌道は『ケプラー軌道』、脱出速度のみは『脱出速度』を併用してください。

**Category:** 物理シミュレーター
