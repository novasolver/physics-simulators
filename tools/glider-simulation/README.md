# glider-simulation

NovaSolverの無料オンライン計算機で、グライダーの性能をシミュレーション。極曲線に基づき最良滑空速度や最小沈下速度をリアルタイム計算。サーマル強度や風速を設定し、マクレディ理論によるクロスカントリー速度を最適化できます。設計パラメータを変更して、滑空比の理論式を体感しましょう。

**Category:** 航空宇宙

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/glider-simulation
python -m http.server 8000
# open http://localhost:8000
```
