# 波の基本量ビジュアライザ

周波数・波長・振幅・位相を自由に設定して横波アニメーションをリアルタイム描画します。2 波の干渉パターンも可視化できます。

**Category:** 物理シミュレーター

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/wave-basics.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/wave-basics.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/wave-basics.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/wave-basics
python -m http.server 8000
# open http://localhost:8000
```
