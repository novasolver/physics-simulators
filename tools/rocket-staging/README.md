# rocket-staging

多段ロケットの設計と性能計算をオンラインで無料シミュレーション。段数、質量比、比推力から総ΔVやペイロード比をリアルタイム計算できます。サターンVやファルコン9等の実機プリセットで学習や比較も可能。直感的な操作で宇宙機設計の基礎を体験しましょう。

**Category:** 航空宇宙

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/rocket-staging
python -m http.server 8000
# open http://localhost:8000
```
