# プラズマエッチング選択比・異方性シミュレーター

SiO₂・Si・poly-Si・Al などの薄膜を RIE（反応性イオンエッチング）でパターニングするツールです。ガス種・プラズマパワー・バイアス・圧力を変えると、エッチ速度・選択比・異方性度・エッチ深さ・マスク消費・アスペクト比がリアルタイムに分かり、半導体プロセスのレシピを設計できます。

**Category:** 半導体プロセス・ドライエッチ
