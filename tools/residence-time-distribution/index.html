滞留時間分布（RTD）シミュレーター

流れ反応器に入った流体が「どれだけの時間、中にとどまるか」を表す滞留時間分布 E(t) を計算するツールです。理想CSTR・PFR・槽列モデル・層流反応器を切り替え、平均滞留時間や分散、等価槽数、一次反応の転化率がリアルタイムで分かります。

入口で投入したトレーサーパルスが反応器を流れ、出口から出てくる様子と、そこから描かれる E(t) 曲線を表示します。CSTRは広く拡散、PFRは鋭いプラグ、槽列モデルはN段で広がります。

RTD関数 E(t)
累積分布 F(t)
理論・主要公式

$$E_{CSTR}(t)=\frac{1}{\tau}e^{-t/\tau},\qquad E_{tanks}(t)=\frac{N}{\tau}\frac{(Nt/\tau)^{N-1}}{(N-1)!}e^{-Nt/\tau}$$

RTD関数 E(t)。τ：平均滞留時間、N：槽列モデルの槽数。E(t)·dt は滞在時間 t〜t+dt の流体割合を表し、全積分は 1。

$$\sigma^2_{tanks}=\frac{\tau^2}{N},\qquad X=1-\int_0^\infty E(t)\,e^{-kt}\,dt$$

槽列モデルの分散 σ² と、分離流れモデルによる一次反応の転化率 X。k：一次反応速度定数。N が大きく RTD が狭いほど押し出し流れに近づく。

滞留時間分布（RTD）とは

🙋
「滞留時間分布」って言葉、反応工学の授業で出てきたんですけど、結局なんの分布なんですか？
🎓
ざっくり言うと「反応器に入った流体が、何秒その中にいたか」のバラつきを表す分布だよ。連続式の反応器って、入口から入って出口から出ていくよね。でも全部の分子が同じ時間だけ中にいるわけじゃない。近道してさっさと出る分子もあれば、隅のよどみに巻き込まれて長居する分子もある。その滞在時間のヒストグラムが E(t)、つまり滞留時間分布なんだ。
🙋
分子1個ずつの時間なんて、どうやって測るんですか？
🎓
そこがうまくできていてね。入口で一瞬だけトレーサー——例えば食塩水とか着色剤を「パッ」と入れる。これをパルス入力という。あとは出口の濃度を時間で測るだけ。出てきた濃度カーブを規格化すれば、それがそのまま E(t) になるんだ。上のアニメーションで「理想CSTR」を選んでみて。トレーサーが入った瞬間に槽全体へ混ざって、出口濃度がいきなりピークになってから指数関数でダラダラ減っていくだろう。これが完全混合のサインだよ。
🙋
じゃあ「理想PFR」を選ぶと、E(t) の形はどうなるんですか？
🎓
PFR、つまり押し出し流れだと、全員が一列に並んで進むイメージだ。追い越しも混ざりもないから、入口で入れたトレーサーは τ 秒後にぴったり全員まとまって出てくる。E(t) は t=τ に立つ針みたいな鋭いパルスになって、分散はゼロ。CSTR と PFR はちょうど両極端で、CSTR は混ざりすぎ、PFR は全く混ざらない。現実の反応器はこの間のどこかにいる、と考えるのが RTD 解析の出発点なんだ。
🙋
「現実の反応器はこの間」って、どうやって数字で表すんですか？
🎓
よく使うのが「槽列モデル」だ。実在の反応器を、小さな完全混合槽（CSTR）を N 個直列につないだものとみなす。N=1 なら CSTR そのもの、N をどんどん増やすと RTD がだんだん鋭くなって、N→∞ で PFR に一致する。トレーサー実験で分散 σ² を測れば、N_eq=τ²/σ² で「この反応器は CSTR 何個ぶん相当か」が一発で分かる。左で槽数 N を動かして、E(t) のピークが鋭くなっていくのを見てみて。
🙋
RTD が分かると、結局なにが嬉しいんですか？グラフがきれいになるだけ…？
🎓
いやいや、本番はここから。RTD に反応速度モデルを組み合わせると「この反応器でどこまで転化が進むか」が予測できるんだ。一次反応なら、各流体要素を独立した小さなバッチ反応器とみなして、滞在時間 t に応じて exp(−k·t) だけ未反応で残る、と考える。それを E(t) で重み付け平均すれば出口の転化率 X が出る。同じ平均滞留時間でも、PFR のほうが CSTR より転化率が高くなる——その差を定量化できるのが RTD の一番おいしいところだよ。

よくある質問

滞留時間分布（RTD）E(t) は、流れ反応器に入った流体の各要素が「どれだけの時間、反応器の中に滞在したか」の確率密度関数です。入口でトレーサー（着色剤など）をパルス状に投入し、出口の濃度を時間で測ると、その応答曲線がそのまま E(t) になります。E(t)·dt は、滞在時間が t〜t+dt の流体要素の割合を表し、∫E(t)dt は 1 になります。RTD を見れば、その反応器が理想押し出し流れ（PFR）にどれだけ近いか、それとも完全混合（CSTR）に近いかが定量的に分かります。
理想CSTR（完全混合槽）では、入った流体が瞬時に全体へ混ざるため E(t)=(1/τ)·exp(−t/τ) という指数減衰になります。入った直後に出ていく要素もあれば、いつまでも残る要素もあり、分散 σ²=τ² と非常に広い分布です。理想PFR（押し出し流れ）では、全要素がぴったり τ だけ滞在するため、E(t) は t=τ に立つ鋭いパルス（理想的には σ²=0）になります。実在の反応器はこの2つの極限のあいだにあり、槽列モデルの槽数 N がその中間を表します。
槽列モデル（tanks-in-series）は、同じ大きさの理想CSTRを N 個直列につないだものとして実在反応器を近似します。N=1 なら単独のCSTR、N→∞ ならPFRに収束します。分散は σ²=τ²/N となり、トレーサー実験で測った σ² から N_eq=τ²/σ² を逆算すると、その反応器が「CSTR何個ぶんの混合特性を持つか」が1つの数字で分かります。N が大きいほど RTD が鋭くなり押し出し流れに近づき、N が小さいほど混合が激しく転化率が下がります。
分離流れ（segregated flow）モデルでは、各流体要素を独立した小さなバッチ反応器とみなし、その滞在時間で進む反応量を RTD で重み付け平均します。一次反応では各要素が exp(−k·t) の割合で未反応のまま残るので、出口の未反応割合は ∫E(t)·exp(−k·t)dt、転化率は X=1−∫E(t)·exp(−k·t)dt です。槽列モデルではこの積分が解析的に解けて X=1−(1+k·τ/N)^(−N) になります。一次反応では分離流れと完全微視混合の結果が一致するため、この式はモデルに依らず正確です。

実世界での応用

連続式反応器の設計・スケールアップ：化学プラントの連続槽型反応器や管型反応器を設計するとき、まずトレーサー実験で実機の RTD を測り、槽列モデルや分散モデルにフィットさせます。ベンチスケールで N_eq=8 だった反応器が、大型化で配管のよどみや偏流のせいで N_eq=3 に落ちれば、同じ平均滞留時間でも転化率が大きく下がります。RTD はスケールアップ時の「混合の劣化」を早期に検出する標準ツールです。

非理想流れ・故障の診断：反応器の性能が設計値より低いとき、RTD を測ると原因が見えます。E(t) に予定より早いピークが立てばショートカット（バイパス流れ）、長い尾を引けばデッドゾーン（よどみ域）、ピークが二山ならチャネリングやバッフルの不良が疑われます。撹拌槽のインペラ位置、配管の取り回し、充填層の偏流など、図面では分からない実機の流れ異常を RTD は数値で炙り出します。

上下水処理・環境プロセス：浄水場の塩素接触槽や下水処理の曝気槽では、消毒や生物処理に「十分な接触時間」を確保することが規制で求められます。実際には短絡流れで一部の水が想定より早く抜けると、その分が未処理で出てしまいます。RTD（特に F(t) の t10、つまり10%が抜ける時刻）を測ることで、接触槽が規定の消毒性能を満たしているかを検証します。

医薬・食品の連続生産：連続晶析、押出機による混練、連続殺菌（HTST）などでは、製品の均一性や安全性が滞在時間のバラつきに直結します。連続製造に移行する医薬プロセスでは、RTD が原薬の濃度追跡や逸脱バッチの切り分けに使われ、規制当局への品質保証の根拠になります。RTD は単なる教科書の概念ではなく、現場の品質管理に直接使われる道具です。

よくある誤解と注意点

まず多いのが、「RTD が同じなら転化率も同じ」という誤解です。これは一次反応に限って正しい話で、二次反応や複雑な反応では成り立ちません。一次反応では各分子の反応が他の分子の濃度に依存しないため、分離流れ（各要素が独立にバッチ反応）でも完全微視混合（分子レベルで混ざる）でも結果が一致します。しかし二次反応では「同じ滞在時間でも、濃い場所にいたか薄い場所にいたか」で反応量が変わるため、RTD が同じでも微視混合の度合いで転化率が変わります。RTD はマクロ混合の情報しか持たず、ミクロ混合は別問題、という限界を理解しておく必要があります。

次に、「平均滞留時間 τ さえ合わせれば十分」という思い込み。τ=V/Q は反応器の「平均」を表すだけで、分布の広がり（分散 σ²）は別物です。同じ τ でも、PFR（σ²=0）と CSTR（σ²=τ²）では転化率がまったく違います。一次反応では PFR が常に最高、CSTR が最低の転化率を与え、その差は反応が速い（k·τ が大きい）ほど開きます。設計では平均だけでなく分散、つまり「どれだけ押し出し流れに近いか」まで見る必要があります。本ツールで CSTR と PFR を切り替え、同じ τ・k でも転化率が変わることを確かめてください。

最後に、トレーサー実験そのものの落とし穴。RTD を正しく測るには、トレーサーが反応せず・吸着せず・主流体と同じように流れること（理想トレーサー）が前提です。密度や粘度が大きく違うトレーサーを使うと、主流体とは別の流れ方をして RTD が歪みます。また、パルス入力が「一瞬」でないと（投入に時間がかかると）、その入力幅の影響を脱コンボリューションで除く必要があります。出口での測定遅れや配管デッドボリュームも τ の見かけを増やします。きれいな E(t) 曲線が得られても、入力と検出系が理想から外れていれば、その RTD は実機の真の姿ではない可能性があります。

使い方ガイド

  1. 平均滞留時間τ（秒）を設定します。例えば連続撹拌槽反応器（CSTR）で処理量100L/minの場合、容積500Lならτ=5sです
  2. 槽数N（又はPFR/CSTR比）を選択します。N=1はCSTR、N→∞でPFR特性に近づき、N=3～5は実装置の槽列モデルに相当します
  3. 一次反応速度定数k（min⁻¹）を入力します。例：k=0.2min⁻¹の場合、E(t)曲線とともに転化率Xの時間変化が計算されます
  4. シミュレーション結果から平均滞留時間τ、分散σ²、ピーク時間t_peakを確認し、反応器の混合特性を評価します

具体的な計算例

容積1000Lの攪拌槽に流量200L/minで液体が流入する場合、τ=5s。槽列数N=3でモデル化すると、CSTR単独（N=1）の分散σ²=25s²に対してN=3では σ²≈8.3s²となり、より栓流に近づきます。一次反応k=0.15s⁻¹を設定すると、τ=5sの槽列で転化率X≈53%が得られ、CSTR単独のX≈42%より改善されます。ピーク時間はN=3でt_peak≈2.8sとなります。

実務での注意点

  1. 撹拌の均一性不足や死体積がある場合、実測RTD曲線から逆算してNを決定してください。理論値より分散が大きければ短絡流が発生しています
  2. 高速反応（k≫1/τ）では滞留時間分布の影響が顕著です。医薬品合成でk=0.5s⁻¹、τ=2sの場合、槽列化でX向上率は20%以上になります
  3. 温度制御不可の場合、低k値での長時間滞留は不要な副反応を促進するため、τを短縮または槽数Nを増やしてRTD幅を狭めてください
  4. スケールアップ時、実験スケールのN値を保持しないと収率が5～10%低下することがあります
