# 量子スピンシミュレーター

量子スピンシミュレーター「NovaSolver」で、スピン1/2系の量子状態をブロッホ球上に可視化。磁場中のラーモア歳差運動やスピン期待値の計算、ラビ振動の確率変動をリアルタイムでシミュレーション。量子力学の核心を直感的に学べる教育ツールです。

**Category:** 物理シミュレーター

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/quantum-spin.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/quantum-spin.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/quantum-spin.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/quantum-spin
python -m http.server 8000
# open http://localhost:8000
```
