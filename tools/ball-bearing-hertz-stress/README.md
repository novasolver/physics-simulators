# 玉軸受の接触応力シミュレーター — Hertz 接触と内輪・外輪応力

玉と内輪・外輪軌道のヘルツ接触応力をリアルタイム計算。Stribeck の荷重分布から1玉最大荷重を求め、凹面側の内輪と凸面側の外輪それぞれの最大接触圧を可視化します。

**Category:** 機械要素シミュレーター
