# 単スリット回折シミュレーター

スリット幅 a と波長 λ を操作してフラウンホーファー回折パターンをリアルタイム可視化。強度分布、暗帯位置、中央明帯幅、可視光のカラー表示を一画面で確認できます。

**Category:** 波動光学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/single-slit-diffraction.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/single-slit-diffraction.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/single-slit-diffraction.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/single-slit-diffraction
python -m http.server 8000
# open http://localhost:8000
```
