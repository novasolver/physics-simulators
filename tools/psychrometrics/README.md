# 湿り空気線図（サイクロメトリクス）

湿り空気線図（サイクロメトリクス）の状態値を瞬時に計算・可視化するオンラインツールです。乾球温度と相対湿度を入力するだけで、絶対湿度・露点温度・比エンタルピー・比容積をリアルタイムに算出。空調設計やCAEシミュレーションの効率的な基礎計算を支援します。

**Category:** 熱流体・空調
