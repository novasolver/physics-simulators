# RC柱 P-M相互作用図シミュレーター

RC柱のP-M相互作用図をACI 318基準でリアルタイム計算。断面寸法・コンクリート強度・鉄筋量を調整し、強度相互作用曲線と設計安全マージンを確認できるシミュレーター。

**Category:** 構造解析ツール

- 🇺🇸 [English](https://novasolver.jp/en/tools/column-interaction.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/column-interaction
python -m http.server 8000
# open http://localhost:8000
```
