# 流量計設計・オリフィス/ベンチュリ計算機

差圧式流量計（オリフィス・ベンチュリ・ピトー管）の流量計算をリアルタイム実行。ISO 5167準拠でQ-ΔP特性曲線・永久圧力損失比較・GUM法による不確かさ推定を可視化します。

**Category:** 流体解析

- 🇺🇸 [English](https://novasolver.jp/en/tools/flow-measurement.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/flow-measurement
python -m http.server 8000
# open http://localhost:8000
```
