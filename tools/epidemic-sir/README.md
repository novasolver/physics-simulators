# 感染症SIRモデルシミュレーター — 集団免疫と感染拡大

感染症SIRモデルシミュレーターで、基本再生産数や集団免疫閾値を理解。COVID-19やインフルエンザなどの感染拡大を、ワクチン効果も考慮しながらリアルタイムに可視化します。NovaSolverの直感的なシミュレーションで、疫学の基礎を学びましょう。

**Category:** 感染症モデル・数理生物学
