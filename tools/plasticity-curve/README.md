# plasticity-curve

NovaSolverの無料オンライン計算機で、金属材料の弾塑性応力-ひずみ曲線をシミュレーション。Ramberg-Osgood則による塑性モデルと、真応力-真ひずみへの変換をリアルタイムに可視化し、降伏から加工硬化、最終破断までの挙動を対話的に学べます。材料力学の理解を深める強力なツールです。

**Category:** 材料・破壊
