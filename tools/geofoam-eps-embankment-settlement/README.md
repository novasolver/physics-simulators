# ジオフォーム EPS 軽量盛土 沈下抑制シミュレーター

軟弱地盤の上に道路や橋台背面の盛土を作るとき、通常土ではゆっくりと長年にわたって沈下していきます。EPS（発泡スチロール）を盛土材に使うと、自重が1/100になり沈下を大幅に抑えられます。盛土高・EPS密度・軟弱層厚を変えて、Terzaghi圧密理論で沈下量と通常土比の抑制率を比較できます。

**Category:** 軟弱地盤・EPS 工法
