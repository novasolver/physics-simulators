# ワイブル解析・信頼性寿命推定

故障時間データからワイブルパラメータ（β・η）を推定し、B10寿命・MTTF・信頼性関数・ハザードレートをリアルタイム計算。製品寿命設計・信頼性解析ツール。

**Category:** 機械力学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/weibull-analysis.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/weibull-analysis.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/weibull-analysis.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/weibull-analysis
python -m http.server 8000
# open http://localhost:8000
```
