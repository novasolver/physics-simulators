# 大気圏層構造シミュレーター

国際標準大気（ISA）モデルで高度ごとの気圧・気温・密度・音速をリアルタイム計算。対流圏・成層圏・中間圏・熱圏の各層をグラフで比較し、大気科学の基礎を学べます。

**Category:** 大気科学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/atmosphere-layers.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/atmosphere-layers.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/atmosphere-layers.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/atmosphere-layers
python -m http.server 8000
# open http://localhost:8000
```
