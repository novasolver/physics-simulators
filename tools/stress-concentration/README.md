# stress-concentration

円孔・段付き軸・切り欠きなど代表的な形状の応力集中係数 Kt をリアルタイム計算。形状パラメータを変えて Kt と応力分布を即座に可視化します。

**Category:** 計算ツール

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/stress-concentration.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/stress-concentration.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/stress-concentration.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/stress-concentration
python -m http.server 8000
# open http://localhost:8000
```
