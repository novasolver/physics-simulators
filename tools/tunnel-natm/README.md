# NATMトンネル支保設計計算機

NATMトンネルの支保設計を支援する計算ツールです。地盤反力曲線（GRC）と支保特性曲線（SCC）をリアルタイムで描画し、塑性域半径や壁面圧力、収束変位を自動計算。弾塑性解析に基づく設計プロセスを可視化し、効率的なトンネル支保計画をサポートします。

**Category:** 地盤工学
