# ポンプキャビテーションの NPSH 余裕評価シミュレーター

ポンプキャビテーション対策に必須のNPSH余裕評価シミュレーター。圧力損失や温度感度を解析し、キャビテーション発生リスクを予測します。

**Category:** 対話型シミュレーター

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/cavitation-npsh-margin-detail.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/cavitation-npsh-margin-detail.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/cavitation-npsh-margin-detail.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/cavitation-npsh-margin-detail
python -m http.server 8000
# open http://localhost:8000
```
