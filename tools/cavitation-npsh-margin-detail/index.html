物理モデルと主要式

$$NPSH_a=\frac{p_s-p_v}{\rho g}+H_s-h_f,\qquad \text{余裕}=NPSH_a-NPSH_r,\qquad \text{余裕比}=\frac{NPSH_a}{NPSH_r}$$

NPSHa（有効NPSH）は吸込側で液体が蒸発せずにポンプへ入れる余裕を表します。要求NPSH（NPSHr）はポンプ羽根車側で必要な値です。NPSHa < NPSHr になると入口で局所圧が蒸気圧まで低下し、キャビテーション気泡が発生・崩壊します。一般に余裕比 NPSHa/NPSHr ≥ 1.3 を安全側の目安とし、1.0 未満は危険です。蒸気圧は温度に強く依存するため、温水や高所では急に余裕が減ります。$H_s$ は吸込静ヘッド（液面がポンプより高ければ正）です。

読み取り方

ゲージ図では NPSHa（青）と NPSHr（赤）のバーを並べ、その差を「余裕バンド」として表示します。バンドが正なら安全、負に転じるとキャビテーションです。

吸込ライン図では、NPSHa が NPSHr に近づくほど配管入口に気泡が発生し、NPSHa<NPSHr で気泡が一気に増えて成長します。

流量カーブ図では、流量を上げると NPSHr（要求）が増え NPSHa（有効、損失増）が減るため、交点より右で余裕が負になる様子を読みます。

会話で学ぶポンプキャビテーションの NPSH 余裕評価

🙋
ポンプキャビテーションの NPSH 余裕評価では、まずどこを見ればいいですか？吸込絶対圧を動かすと図も数値も同時に変わるので、少し迷います。
🎓
最初は NPSHa と NPSHr のゲージで「余裕バンド」が正か負かを見ます。バンドが縮むと吸込ライン図に気泡が出てくるので、余裕の大小が一目で分かります。内訳としては吸込圧から蒸気圧と損失を差し引く流れを追ってください。
🙋
吸込絶対圧を大きくするとNPSHaが変わりそうなのは分かります。では、蒸気圧はどのくらい効いていると考えればいいですか？
🎓
蒸気圧を少しずつ動かして余裕バンドの幅を見ると、支配している項が見えてきます。NPSHaは吸込側で液体が蒸発せずにポンプへ入れる余裕を表します。蒸気圧は温度に強く依存するため、温水や高所では急に余裕が減り、気泡発生のしきい値に近づきます。1点の計算で終わらせず、実際にばらつきそうな範囲を往復させるのが大事です。
🙋
余裕 vs 流量カーブは何を見るための図ですか？普通のグラフだけでも判断できそうに見えます。
🎓
流量を上げると NPSHr が増え NPSHa が下がるので、両線が交わる流量より右では余裕が負になります。その交点が安全運転の上限です。例えばポンプ選定時の吸込条件チェックでは、単一点の値より「流量や条件が少しずれたらどうなるか」が効きます。
🙋
では、NPSHaが基準内なら、この条件をそのまま採用してよいですか？
🎓
ここでは初期検討として扱います。余裕比 NPSHa/NPSHr ≥ 1.3 を目安に、配管変更後の吸込損失影響確認や温度上昇時のキャビテーション余裕レビューには役立ちますが、最終判断では規格値、実測値、詳細解析、メーカー条件で確認してください。

NPSH 余裕の物理（詳細）

NPSHa（有効NPSH）はポンプ吸込口で利用できる、液体の蒸発に対する余裕ヘッドです。大気圧/タンク圧 $p_s$ から飽和蒸気圧 $p_v$ を引き、吸込静ヘッド $H_s$ を足し、吸込配管損失 $h_f$ を引いて求めます。

NPSHr（要求NPSH）はポンプ羽根車入口での圧力降下に打ち勝つために機器が必要とする値で、メーカーが流量ごとに規定します。流量とともに増加します。

キャビテーションの判定は NPSHa と NPSHr の比較です。NPSHa ≥ NPSHr なら気泡は発生せず、NPSHa < NPSHr では羽根車入口で局所圧が蒸気圧を下回り、気泡が発生・崩壊して性能低下・振動・壊食を招きます。

NPSH余裕比 NPSHa/NPSHr は安全側の指標です。重要機器では 1.3 以上、一般用途でも 1.1〜1.2 以上を確保し、温度上昇や流量増・配管劣化に対する余地を残します。

実務での使い方

ポンプ選定時の吸込条件チェック（余裕比1.3以上の確認）。

配管変更後の吸込損失影響確認。

温度上昇時のキャビテーション余裕レビュー。

よくある質問

NPSHaとNPSH余裕を先に見ます。次にNPSH内訳で前提の状態を確認し、キャビテーション危険度で分布や変化の偏りを読みます。内訳図では吸込圧から蒸気圧と損失を差し引く流れを見ます。
吸込絶対圧を単独で動かしたあと、蒸気圧も同じ幅で動かしてNPSHaの変化量を比べます。損失感度曲線を見ると、どの組み合わせで余裕や性能が急に変わるかを把握できます。
ポンプ選定時の吸込条件チェックに使います。単一点の数値ではなく、入力範囲を少し広げてNPSHaの余裕が保てるかを確認すると、詳細解析へ進む前の論点整理に役立ちます。
NPSHaは吸込側で液体が蒸発せずにポンプへ入れる余裕を表します。蒸気圧は温度に強く依存するため、温水や高所では急に余裕が減ります。最終判断では規格値、実測値、詳細解析、メーカー条件を確認してください。
一般にはNPSH余裕比 NPSHa/NPSHr ≥ 1.3 を安全側の目安とします。1.1〜1.3は限界域でキャビテーション初生に注意し、1.0未満ではNPSHaがNPSHrを下回るため気泡が発生・成長してキャビテーションに至ります。重要機器ほど大きな余裕を確保します。

使い方ガイド

  1. 吸込絶対圧(pressure)をkPaで入力。常圧吸込はおよそ101kPa、タンク底部吸込時は静圧を加算（スライダー範囲20～800kPa）
  2. 飽和蒸気圧(vapor)をkPaで入力。水の場合は温度依存：20℃≈2.3kPa、60℃≈19.9kPa、80℃≈47.4kPa
  3. 吸込配管の圧力損失(loss)をヘッドm（メートル）で入力。直管100m+肘管5個のスチール管φ100では約1.5m
  4. ポンプ所要NPSH(required)をmで入力。遠心ポンプ5kW級は0.5～0.8m、大型ポンプ100kW級は1.2～2.0m
  5. 入力に応じてNPSHa値と安全余裕がリアルタイム表示されます。NPSH比(NPSHa/NPSHr)が1.3未満は危険の目安です

具体的な計算例

給水ポンプの事例：吸込絶対圧200kPa、蒸気圧20kPa、吸込損失2m、ポンプ所要NPSH 4mの場合、NPSHa=(200−20)×1000/(1000×9.81)−2≈16.35m。NPSH余裕=16.35−4≈12.35m（十分に安全）。一方、加熱で蒸気圧が上がり吸込圧が下がった条件（吸込絶対圧120kPa、蒸気圧80kPa、損失3m）ではNPSHa=(120−80)×1000/(1000×9.81)−3≈1.08m、余裕=1.08−4≈−2.92m（要求NPSHを下回り危険）

実務での注意点

  1. 配管経年劣化で圧力損失が+30%増加するため、初期設計値に0.9係数を乗じて評価
  2. 吸込揚程が負(液面がポンプより下)の場合、静圧ヘッドを差し引く。深さ2mなら約20kPa(=約2m)分を吸込絶対圧から減算
  3. 夏季運転時は液温上昇で蒸気圧が急増。NPSH余裕は0.5m以上を確保するのが目安(設備規格による)
  4. キャビテーション兆候：振動増加、騒音変化、流量低下時はNPSH値を即座に再計算
