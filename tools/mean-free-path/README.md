# 平均自由行程 シミュレーター — 気体分子運動論

温度 T・圧力 P・分子直径 d・分子量 M_g から、剛球気体の平均自由行程 λ・平均速さ ⟨v⟩・衝突頻度 ν・数密度 n を実時間で計算します。分子箱の動的描画と λ vs P 対数プロットで、気体分子運動論を直感的に学べます。

**Category:** 統計力学シミュレーター
