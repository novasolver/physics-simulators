理論・主要公式

気体分子運動論では、分子を剛球と見なし、マクスウェル–ボルツマン速度分布から平均速さ・衝突頻度・平均自由行程が導かれます。圧力の理想気体状態方程式と組み合わせて以下の閉じた式が得られます。

平均自由行程（剛球モデル、相対速度補正 √2 を含む）：

$$\lambda = \frac{k\,T}{\sqrt{2}\,\pi\,d^2\,P}$$

マクスウェル分布の平均速さ：

$$\langle v\rangle = \sqrt{\frac{8\,k\,T}{\pi\,m}}$$

衝突頻度と数密度：

$$\nu = \frac{\langle v\rangle}{\lambda},\qquad n = \frac{P}{k\,T}$$

$k = 1.380649\times10^{-23}$ J/K は Boltzmann 定数、$d$ は分子直径 [m]、$P$ は圧力 [Pa]、$T$ は温度 [K]、$m = M_g \times 10^{-3} / N_A$ は1分子の質量 [kg] で、$M_g$ は分子量 [g/mol]、$N_A = 6.02214076\times10^{23}$ は Avogadro 数です。

平均自由行程 シミュレーターとは

🙋
高校で「気体分子は四方八方に飛び交っている」と習いましたが、実際の分子って次の衝突までどのくらい走れるんですか？空気の中だと数 mm くらいですか？
🎓
いい質問だね。常温常圧の窒素では平均自由行程は約 67 nm — つまり可視光の波長より少し短いくらいで、mm の何万分の1だ。直感より遥かに短いんだよ。剛球モデルでは λ = kT/(√2 π d² P) と書けて、温度に比例し圧力に反比例する。このシミュレーターで T = 300 K、P = 101.32 kPa、d = 370 pm（窒素分子の有効直径）、M_g = 28 を入れて計算結果を見てごらん。
🙋
じゃあ高真空にすると平均自由行程はどのくらい長くなるんですか？半導体工場の真空チャンバって 1 m もないですよね？
🎓
圧力スライダーを 0.01 kPa（10 Pa）まで下げてみて。λ は 1/P で伸びるから 10⁵/10 = 10⁴ 倍、つまり 67 nm × 10⁴ = 0.67 mm。さらに高真空（10⁻³ Pa）まで行くと λ ≈ 6.7 m に達するんだ。これより装置壁の方が近くなると、分子はもう「気体」ではなく「壁から壁へ独立に飛ぶ粒子の集まり」になる。これが分子流の領域で、半導体プロセスや電子顕微鏡の世界そのものだよ。
🙋
衝突頻度 ν が 7 GHz って書いてありますが、本当に 1 秒間に 70 億回も衝突してるんですか？
🎓
本当だよ。ν = ⟨v⟩/λ = 476 m/s ÷ 67 nm ≈ 7×10⁹ Hz。窒素分子は秒速 470 m で飛んでるけど、平均自由行程が 67 nm しかないから、1 ns に数回ぶつかる計算になる。だから常圧の気体は実質的に「常に衝突しっぱなし」で、これがマクロな粘性・熱伝導・拡散係数を生み出してる。逆に高真空ではぶつからないから「分子流」になって、流体力学が使えなくなるんだ。
🙋
分子直径 d を変えると結果も大きく変わるんですか？d ってどうやって決めるんですか？
🎓
λ ∝ 1/d² だから、d を 2 倍にすると λ は 1/4 になる効きが強い。d は分子間ポテンシャルから定義される「衝突直径」で、Lennard-Jones パラメータの σ から推定したり、実験的には粘性係数 η の温度依存性から逆算する。代表値は H₂ ≈ 270 pm、N₂ ≈ 370 pm、O₂ ≈ 360 pm、CO₂ ≈ 460 pm、CH₄ ≈ 410 pm。本ツールの 50〜800 pm のレンジで主要な分子をほぼカバーできる。

よくある質問

注目している分子だけが動いて他の分子が止まっていると仮定すると、衝突体積率は ⟨v⟩ × π d² × n となり、λ = 1/(π d² n) です。しかし実際は他の分子も同じマクスウェル分布で動いており、相対速度の平均は √2 × ⟨v⟩ になります。これにより衝突頻度が √2 倍に増え、平均自由行程は 1/√2 倍に短くなります。最終的に λ = kT/(√2 π d² P)（理想気体状態方程式 P = nkT を代入）が得られます。マクスウェルが導出したこの √2 因子により、ガス粘性・熱伝導の実験値とよく一致するようになりました。
マクスウェル–ボルツマン速度分布から3つの代表速度が定義されます。最確速さ v_p = √(2kT/m)、平均速さ ⟨v⟩ = √(8kT/(πm))、rms速さ v_rms = √(3kT/m) で、その比は v_p : ⟨v⟩ : v_rms = 1 : √(4/π) : √(3/2) ≈ 1 : 1.128 : 1.225 です。本ツールでは衝突頻度の計算に必要な「平均速さ」を表示しています。300 K の窒素では v_p ≈ 422 m/s、⟨v⟩ ≈ 476 m/s、v_rms ≈ 517 m/s となり、すべて音速（約 350 m/s）より大きいことが分かります。
本ツールは理想気体（P = nkT）と剛球分子（衝突直径 d は速度に依存しない）の二重近似を使っています。実在気体ではこれらが破れる場面があります。一つは高圧で分子間相互作用が無視できなくなる領域（van der Waals 補正が必要）。もう一つは低温で衝突直径が温度依存性を持つ領域（Sutherland モデル：d² ∝ 1/(1 + S/T)）。常温常圧から数気圧、100〜1000 K の範囲では本ツールの近似は数%以内の精度で、ガス工学・空気力学の実用設計に十分使えます。極端な条件（液化点近傍、超臨界、極高圧）では PVT データやエンスコグ理論を使う必要があります。
気体分子運動論では粘性係数 η ≈ (1/3) n m ⟨v⟩ λ、熱伝導率 κ ≈ (1/3) n c_v ⟨v⟩ λ という近似式が得られます。興味深いのは n と λ の積が n × (1/(√2 π d² n)) = 1/(√2 π d²) と圧力に依存しないことで、結果として粘性係数は圧力に依存しません（マクスウェルが理論予測し、実験で確認された有名な事実）。一方、熱伝導率も同様に圧力非依存ですが、両者とも温度には √T 依存性があります。本ツールで T を変えると ⟨v⟩ ∝ √T が確認でき、粘性・熱伝導の温度依存性の起源が分かります。

実世界での応用

半導体プロセスの真空設計：スパッタ、CVD、エピタキシャル成長などの半導体製造プロセスは、平均自由行程が装置寸法と同程度かそれ以上になる「分子流」領域で運転します。例えば PVD スパッタチャンバ（直径約 30 cm）では、λ < 10 cm にするためにアルゴンを 0.5〜2 Pa（5〜20 mTorr）に保ちます。本ツールで P = 0.001 kPa（1 Pa）に設定すると λ ≈ 7 mm が得られ、ターゲットから基板までの飛程内で適度に衝突する設計条件が確認できます。さらに低圧の e-beam リソグラフィや MBE では λ がメートルオーダーに達し、完全な分子流条件で運転されます。

真空ポンプの選定基準：真空システムの設計では、λ と装置寸法 L の比（Knudsen 数 Kn = λ/L）に応じてポンプ機構が変わります。Kn < 0.01（粘性流）では油回転ポンプやドライポンプ、Kn ≈ 0.1〜10（遷移流）ではターボ分子ポンプ、Kn > 10（分子流）ではイオンポンプやチタンサブリメーションポンプが必要です。本ツールで Kn を計算すれば、各圧力域でどのポンプが効率的かが直感できます。

断熱・断熱真空（魔法瓶）：魔法瓶（デュワー瓶）の二重壁内部は約 10⁻³ Pa 以下の真空に保たれ、平均自由行程が壁間距離（数 mm〜cm）を超えるため、気体による熱伝導がほぼゼロになります。本ツールで P = 10⁻⁶ kPa（10⁻³ Pa）を設定すると λ ≈ 6.7 m で、壁間距離 1 cm に対して Kn ≫ 1 となり完全な分子流条件が成立します。残された熱伝達経路は放射のみとなり、銀メッキで放射率を下げることで全熱損失を最小化できます。

ナノ粒子のブラウン運動と DLS：動的光散乱法（DLS）でナノ粒子サイズを測定する際、粒子の拡散係数 D = kT/(6π η r) を使いますが、これは Kn ≪ 1 の連続体近似です。ガス中では粒径が λ と同程度になると Cunningham 補正係数 C = 1 + Kn(1.257 + 0.4 exp(-1.1/Kn)) が必要になります。本ツールの λ を粒径 r で割った Kn から、いつ補正が必要かが判断できます。エアロゾル測定や PM2.5 の挙動解析で重要です。

よくある誤解と注意点

最も多い誤解は、「気体の平均自由行程は気体の種類によらず一定」と思い込むことです。実際には λ ∝ 1/d² で、分子直径の2乗に逆比例するため、H₂（d ≈ 270 pm）と CO₂（d ≈ 460 pm）では同じ条件下で約 3 倍も異なります。本ツールで d スライダーを 270 pm と 460 pm に切り替え、λ がどう変わるか必ず確認してください。同様に、温度依存性 λ ∝ T も忘れがちです。室温の値を高温（1000 K 以上）にそのまま外挿すると 3〜4 倍の誤差が生じます。

次に多いのが、「平均自由行程が長い＝分子が遅く動いている」と勘違いするケースです。実際は逆で、λ は衝突間距離、⟨v⟩ は速さ、衝突頻度 ν = ⟨v⟩/λ という独立な3つの量です。平均速さは温度のみで決まり（⟨v⟩ ∝ √T）、圧力には依存しません。例えば常圧の窒素 ⟨v⟩ ≈ 476 m/s と高真空 10⁻³ Pa の窒素 ⟨v⟩ ≈ 476 m/s は同じ温度なら全く同じ速さで、違うのは衝突間隔だけです。本ツールで T 一定で P を変えても ⟨v⟩ が変わらないことを確認してください。

最後に、「剛球モデルだから現実の気体には使えない」という過度な不信も誤りです。確かに分子はソフトな相互作用を持ちますが、衝突の有効断面積を等価な剛球直径 d で表す近似は、常温常圧から中真空・数気圧までの領域で粘性係数・熱伝導率・拡散係数の実験値と数%以内で一致します。CFD・空力設計・半導体プロセスのほとんどがこの近似で十分実用的です。極端な条件（液化点近傍、超高圧、化学反応性ガス）では Lennard-Jones や Chapman–Enskog 理論が必要になりますが、本ツールの値は良い出発点になります。

使い方ガイド

  1. 温度スライダー（slTVal）を250～500Kの範囲で調整し、気体の熱運動エネルギーを変更します
  2. 圧力スライダー（slPVal）を0.1～10気圧で設定し、分子の密集度を制御します
  3. 分子直径スライダー（slDVal）を1～5Åで変更して、衝突断面積σ=πd²への影響を観察します
  4. 数密度n、平均速さ⟨v⟩＝√(8kT/πm)、衝突頻度ν＝√2·n·σ·⟨v⟩から平均自由行程λ=1/(√2·n·σ)の変化をリアルタイム追跡します

具体的な計算例

窒素ガス（N₂、分子直径d=3.7Å）が298K、1気圧の条件下：数密度n≒2.46×10²⁵m⁻³、平均速さ⟨v⟩≒475m/s、衝突断面積σ=πd²≒4.3×10⁻¹⁹m²、衝突頻度ν≒7.1×10⁹s⁻¹、平均自由行程λ≒66.8nm。圧力を10気圧に上昇させると数密度が10倍となり、λは約6.7nmに短縮されます。温度を上げるとλ∝Tで伸びますが、⟨v⟩∝√Tも増えるため衝突頻度νの変化は緩やかです。

実務での注意点

  1. 真空ポンプ設計時：λが装置特性長より大きい場合は分子流領域（Knudsen数Kn＞1）であり、連続体仮定は破綻します
  2. 高温ガスタービン翼周辺の希薄気体解析では、T=1200K超での平均自由行程変化と熱伝達係数の関係を確認してください
  3. マイクロ流体デバイスではチャネル高さとλの比較によりレジーム判定（Kn＜0.01で連続流、0.01＜Kn＜0.1で遷移流）が必須です
  4. 分子直径データは参考文献によって±10%の差異があるため、実験値との比較検証を推奨します
