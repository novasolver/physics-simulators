# 水・水蒸気物性値計算（蒸気表）

温度または圧力を指定して飽和水・飽和蒸気・過熱蒸気の比体積・エンタルピー・エントロピーをリアルタイム計算。乾き度 x の設定にも対応し、T-s 線図・飽和曲線をリアルタイム可視化。蒸気タービン・ボイラー・ランキンサイクル解析に活用できます。

**Category:** 熱力学・蒸気工学
