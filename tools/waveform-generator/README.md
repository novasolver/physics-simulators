# 波形生成・合成シミュレーター

波形生成・合成シミュレーターで、正弦波・矩形波・三角波・のこぎり波を自由に組み合わせて合成波形を作成できます。RMS値やピーク値、高精度なFFT解析による周波数スペクトルをリアルタイムで計算・表示。音響・電気工学の学習や信号解析に最適なツールです。

**Category:** 信号解析

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/waveform-generator
python -m http.server 8000
# open http://localhost:8000
```
