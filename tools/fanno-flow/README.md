# ファンノー流れ シミュレーター — 断熱摩擦付きダクト流とチョーキング

断熱・摩擦付き・一定断面ダクトを流れる圧縮性流れを可視化。入口マッハ・比熱比・ダーシー摩擦係数・L/D を変えながら、出口マッハ、温度比、圧力比、ファンノー線図上の状態点の動きを直感的に学べます。

**Category:** 圧縮性流体シミュレーター
