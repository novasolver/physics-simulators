# デジタル PID の離散化方式比較シミュレーター

デジタルPIDの離散化方式を比較し、サンプリング周期の影響をステップ応答やゲイン特性から検証できるシミュレーター。制御系設計と離散化手法の最適化に。

**Category:** 対話型シミュレーター

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/digital-pid-discretization.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/digital-pid-discretization.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/digital-pid-discretization.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/digital-pid-discretization
python -m http.server 8000
# open http://localhost:8000
```
