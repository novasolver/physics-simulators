# 自己相関関数シミュレーター — 周期検出

バイアス自己相関 R_xx[k] でノイズに埋もれた周期信号の周期を検出。振幅・周波数・ノイズ・サンプル数を変えて、自己相関による周期推定の仕組みを学べます。

**Category:** 信号処理シミュレーター

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/autocorrelation.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/autocorrelation.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/autocorrelation.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/autocorrelation
python -m http.server 8000
# open http://localhost:8000
```
