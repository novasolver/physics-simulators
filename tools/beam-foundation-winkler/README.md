# Winkler 地盤上梁の反力分布と最大曲げシミュレーター

Winkler 地盤ばね上の梁について、荷重、曲げ剛性、地盤反力係数からたわみ・最大反力度・許容比を同時に評価します。

**Category:** 対話型シミュレーター

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/beam-foundation-winkler.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/beam-foundation-winkler.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/beam-foundation-winkler.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/beam-foundation-winkler
python -m http.server 8000
# open http://localhost:8000
```
