# 土質力学シミュレーター

モール円とクーロン破壊包絡線をリアルタイム可視化。粘着力・内部摩擦角を調整して浅い基礎のテルツァギ極限支持力と圧密沈下をインタラクティブに計算できます。

**Category:** 地盤工学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/soil-mechanics.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/soil-mechanics.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/soil-mechanics.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/soil-mechanics
python -m http.server 8000
# open http://localhost:8000
```
