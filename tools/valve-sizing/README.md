# バルブ選定・Cv値シミュレーター

バルブ選定・Cv値シミュレーターで液体・気体のISA/IEC流量方程式によるCv/Kv計算、チョーク流れ判定、圧力損失曲線から最適バルブサイズを選定。

**Category:** 流体解析

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/valve-sizing.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/valve-sizing.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/valve-sizing.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/valve-sizing
python -m http.server 8000
# open http://localhost:8000
```
