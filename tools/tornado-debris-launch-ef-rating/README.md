# 竜巻被害 EF スケール・デブリ飛距離シミュレーター

EF（Enhanced Fujita）スケールごとの風速、デブリ（飛翔物）の抗力・飛翔臨界風速・終端速度・衝撃エネルギーをリアルタイム計算。質量・投影面積・形状・高さを変えて、住宅や建物に与えるデブリ被害を評価できる無料シミュレーターです。

**Category:** 気象災害・耐風建築
