# 音響インピーダンスチューブ計算機

音響インピーダンスチューブ計算機で吸音率・NRC値をリアルタイム計算。材料厚さや空気層の周波数特性を可視化し、インピーダンス解析に活用できます。

**Category:** 建築音響 / 騒音工学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/acoustic-impedance-tube.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/acoustic-impedance-tube.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/acoustic-impedance-tube.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/acoustic-impedance-tube
python -m http.server 8000
# open http://localhost:8000
```
