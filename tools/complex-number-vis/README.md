# 複素数ビジュアライザー

2つの複素数を複素平面上でリアルタイム操作。和・差・積・商・共役・絶対値・極形式・ド・モアブルの定理・オイラーの公式を直感的に探求できます。

**Category:** 数学・工学基礎

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/complex-number-vis.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/complex-number-vis.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/complex-number-vis.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/complex-number-vis
python -m http.server 8000
# open http://localhost:8000
```
