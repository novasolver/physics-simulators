# バルブ・配管圧力損失計算ツール

バルブ・管継手の圧力損失をKv値とΔP式でリアルタイム計算。ゲートバルブ・玉形弁・ボールバルブ・バタフライ弁・逆止弁の複数直列配置に対応。流速・全圧損・Kv合計を即時算出。流体工学・配管設計に活用できる無料ツール。

**Category:** 流体工学ツール
