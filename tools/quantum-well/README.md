# 量子井戸エネルギー準位計算ツール

量子井戸エネルギー準位計算ツール：GaAs/AlGaAsの束縛状態と波動関数をリアルタイム可視化。井戸幅・障壁高さ調整で量子化エネルギーと発光波長を即座に計算できるCAEツール

**Category:** 物理シミュレーター
