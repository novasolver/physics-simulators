# フーリエ変換ビジュアライザー

信号タイプ・窓関数・周波数をスライダーで操作しながら、時間域・振幅スペクトル・位相スペクトルをリアルタイムで確認。FFTの本質を直感的に理解できます。

**Category:** 信号処理

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/fourier-transform.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/fourier-transform.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/fourier-transform.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/fourier-transform
python -m http.server 8000
# open http://localhost:8000
```
