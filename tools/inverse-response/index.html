逆応答シミュレーター — 右半平面零点（RHP zero）のステップ応答

RHP零点を含むプロセスはステップ入力に対し、最初に目標と反対方向へ動く「逆応答」を示します。プロセスゲインや零点時定数を変えて、その挙動とPI制御の振る舞いを学べます。

青＝閉ループ出力 y_cl(t)／灰色破線＝目標値 r = 1。K_c=0.3, T_i=5 s 固定。逆応答が一時的に目標と反対方向へ振れる様子に注目。

理論・主要公式

RHP零点を含む2次プロセスの伝達関数：

$$G(s) = \frac{K\,(-T_z\,s + 1)}{(T_1\,s + 1)(T_2\,s + 1)},\quad T_z\gt 0$$

ステップ入力に対する時間応答（T_1 ≠ T_2 の場合）：

$$y(t) = K + \frac{K}{T_2 - T_1}\left[(T_1 + T_z)\,e^{-t/T_1} - (T_2 + T_z)\,e^{-t/T_2}\right]$$

初期傾き（t=0+）は負：

$$\left.\frac{dy}{dt}\right|_{t=0^+} = -\frac{K\,T_z}{T_1\,T_2} \lt 0$$

経験的な閉ループ帯域の上限（RHP零点による制約）：

$$\omega_{BW} \lesssim \frac{1}{2\,T_z}$$

$T_z$ が大きいほど初期傾きが急になり、反転深さが大きくなります。逆に $T_z$ が小さいと反転は浅く、ほぼ通常の1次応答に近づきます。

逆応答シミュレーターとは

🙋
「逆応答」って何ですか？ステップを入れたのに最初に下がってから上がるって、不思議な動きですね。
🎓
ざっくり言うと、ある種のプロセスは伝達関数の分子に「右半平面零点（RHP zero）」を持っていて、ステップを入れた瞬間は出力が目標とは逆向きに動くんだ。式で言うと $G(s)=K(-T_z s+1)/((T_1 s+1)(T_2 s+1))$ の $-T_z s$ がそれ。上のシミュレーターで T_z を 0.1 から 5 まで動かしてみて。T_z が大きいほど反転がぐっと深くなるはずだよ。
🙋
え、現実にもそんな変な系があるんですか？
🎓
むしろ実プロセスではよく出てくる。代表例が沸騰水型原子炉（BWR）の出力。制御棒を引き抜くと、まず核反応で出力が上がる前に、ボイド（蒸気泡）の急膨張で熱中性子が減って一時的に出力が下がる現象がある。あとボイラドラムの水位もそう。給水を絞ると、水位は最初「上がる」んだ。蒸気泡が冷やされて潰れるから。スワール現象ともいう。
🙋
なるほど。これって、フィードバック制御で何が困るんですか？
🎓
RHP零点は制御帯域の「物理的な天井」を作る。経験則として、達成可能な閉ループ帯域はだいたい $1/(2T_z)$ までだ。これを超えてゲインを上げると、最初の逆方向の動きが増幅されて、制御器が「足りない」と判断してさらにアクセルを踏み、結果として暴れる。下の閉ループグラフで K_c, T_i は固定にしてあるけど、開ループで T_z を上げて反転を大きくすると、閉ループの整定も遅くなる様子が見える。
🙋
じゃあ、PIを攻めて速くしたい時はどうすればいいんですか？
🎓
基本は「諦める」のが正解だ。IMC（Internal Model Control）設計法では、フィルタ時定数 τc を T_z と同程度かそれ以上に取ることが推奨される。Skogestadのチューニング則も同じ思想で、T_z 由来のむだ時間として扱う。攻めすぎると不安定化するから、現場では「速さよりロバストさ」が定石。BWRの制御もそういう保守的な設計になっているよ。

よくある質問

非最小位相系（Non-minimum phase system）は、伝達関数に右半平面（実部が正）の零点や極、あるいはむだ時間を含む系の総称です。RHP零点はその一種で、特に「逆応答」を引き起こす要因として知られています。RHP極は不安定極で別の問題（系自体が発散）になります。むだ時間 $e^{-Ls}$ も非最小位相要素で、制御上は RHP零点と似た「先読み不能」の制約を生みます。
蒸気負荷が急増すると、ドラム圧力が瞬時に低下します。すると沸騰点が下がり、ドラム水中にもともと存在していた蒸気泡（ボイド）が急膨張するため、見かけの水位は一時的に上昇します。本来は水量が減っているので水位は下がるはずですが、ボイド膨張の高速応答が逆向きに作用するため、初期は上向き、その後下向きという典型的な逆応答になります。給水制御では3要素制御（水位・蒸気流量・給水流量）でこれを克服します。
完全には消せません。フィードフォワードは外乱や目標値の変化を「先読み」して補正する手法ですが、RHP零点を持つプロセスを完全に打ち消す逆系 $1/G(s)$ は RHP極を含み不安定になります。実用的にはモデル予測制御（MPC）や、目標値フィルタで急峻なステップを丸めて逆応答を励起しないようにする工夫が取られます。逆応答の存在は「物理的事実」なので、消そうとせず「許容する」設計が王道です。
RHP零点を持つプロセスでは、IMC設計のフィルタ時定数 τc は $T_z$ と同程度以上、典型的には $τc \geq 1.7\,T_z$ 程度に取ります。これにより閉ループ帯域がおよそ $1/τc \lesssim 1/(2T_z)$ 以下に抑えられ、逆応答による不安定化を回避できます。Skogestad の SIMC 則では、RHP零点を実効むだ時間 $\theta_{eff} \approx T_z$ として扱い、PI ゲインを $K_c = (1/K)\cdot τ_1/(τc+\theta_{eff})$ で与える指針が普及しています。

実世界での応用

沸騰水型原子炉（BWR）の出力制御：制御棒を引き抜いた直後、ボイド係数の負のフィードバックで核出力が一時的に下がってから上昇する逆応答が観測されます。これを無視して速い制御を試みると、ボイド振動と結合して不安定化する恐れがあるため、運転員訓練と制御系設計では逆応答の存在が大前提として教えられます。

ボイラドラムの水位制御：火力・発電プラントのドラム水位は典型的な逆応答系です。蒸気需要が増えるとドラム水中の蒸気泡が膨張して水位が一時的に上昇するスワール現象が起こります。1要素制御では発散しやすいため、水位・蒸気流量・給水流量を組み合わせた3要素制御が標準的な対策として広く採用されています。

航空機の高度・姿勢制御：機首上げピッチコマンドに対して、エレベータ操舵で水平尾翼の揚力が一瞬下方向へ働き、機体が瞬間的に降下してから上昇する現象が知られています。これも RHP零点による逆応答で、フライバイワイヤの制御則設計では応答性と安定性のトレードオフとして扱われます。

蒸留塔の組成制御：還流量を増やしたとき、塔頂組成が一時的に重質側へ振れてから軽質化するなど、複数の物理機構が競合するプロセスで逆応答が観測されます。化学プラントのモデル予測制御（MPC）では、こうした非最小位相挙動を内部モデルに組み込み、過度な制御アクションを抑制する設計が一般的です。

よくある誤解と注意点

最も多い誤解は、逆応答を「制御器が悪い」せいだと思ってしまうことです。実際にはこれはプロセスそのものに RHP零点が組み込まれた物理的特性で、どんな制御器を設計しても完全には消せません。シミュレーターで K_c, T_i を固定したまま T_z を増減してみてください。閉ループ応答の整定時間は確実に悪化します。「制御器をいじって治す」のではなく、「逆応答が物理的に存在することを前提に設計する」のが正しいアプローチです。

次に多いのが、ゲインを上げれば速くなる、と思い込むことです。RHP零点を持つ系では、PIゲインを上げ過ぎると逆応答が増幅され、最初の負ピークが深くなり、結果として整定時間が悪化したり発散したりします。本シミュレーターでは安全側の K_c=0.3, T_i=5 を採用していますが、実機ではこの「攻めすぎない」設計こそが安定運転の鍵です。経験則として、閉ループ帯域は $1/(2T_z)$ 程度に抑えるのが安全です。

最後に、反転深さ y_min と反転時刻 t* は独立に動くものではない点に注意してください。両者は同じプロセスパラメータ K, T_z, T_1, T_2 の組合せで決まり、トレードオフ関係にあります。T_z を大きくすると反転は深くなる一方、t* は短くなる傾向にあります（初期傾き $-K T_z/(T_1 T_2)$ が急になるため）。スライダーで T_z を動かしながら両 stat の値を見比べてみてください。プロセス設計の段階で T_z を小さくできれば制御は楽になりますが、それは多くの場合、プラントの再設計を意味します。

使い方ガイド

  1. スライダー「ゲイン K」(0.5～5.0)でプロセス静的ゲインを設定。化学反応器の濃度制御では K=2.0 mol/L/%CV が標準。
  2. 「RHP零点時定数 Tz」(0.1～5.0 s)を調整。蒸留塔のリボイラー熱入力制御では Tz=0.8～1.2 s が典型値。負のピーク振幅が増加する非最小位相特性を観察。
  3. 「第1極時定数 T1・第2極時定数 T2」(0.1～10 s)を入力。反応釜では T1=2.0 s(内容物)、T2=3.0 s(計測遅延)のように配置し、反転ピーク y_min と整定時間 t_s の変化を確認。

具体的な計算例

液液抽出プロセス(K=1.5、Tz=0.6 s、T1=2.0 s、T2=0.4 s)のステップ応答シミュレーション：RHP零点により初期段階で y_min≈-0.16(負反転ピーク、t*≈0.8 s)が発生。その後 y(∞)=1.5に収束し、5%整定時間は t_s≈7.0 s。零点を持たない通常の一次遅れには負反転がなく、同じゲインでも制御応答性が大きく異なる。

実務での注意点

  • RHP零点を含むプロセス(気液平衡応答遅延、熱交換器バイパス制御など)では、ゲイン過剰設定時に初期過度応答で目標値を大きく超過してから戻る逆振動が発生。PI制御では積分ゲイン Ki を Tz の1.5～2倍の時定数で保守的に設定し、発散を防止。
  • 蒸留塔リボイラー温度制御(T_ref=95℃、ステップ入力+5℃)では、RHP零点の反転ピークにより一時的に92℃まで低下してから上昇するため、下限アラーム設定を加味した マージン確保が必須。
  • 整定時間 t_s の延長は T1・T2増加時に顕著。熱応答の遅い蒸発濃縮装置では T1=5.0 s を超え、フィードバック応答より前給制御併用を検討。
