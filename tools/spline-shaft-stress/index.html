スプライン軸の強度シミュレーター

理論・主要公式

$$T=\frac{9549\,P}{N},\quad F=\frac{2T}{d_m},\quad d_m=\frac{D+d}{2}$$

伝達トルク T [N·m]（P:動力 kW、N:回転数 rpm）、平均径 d_m 上の接線力 F [N]。D:大径、d:小径。

$$p=\frac{F}{z\,h\,L\,k_a},\quad n=\frac{\sigma_y}{p}$$

歯面の面圧 p と安全率 n。z:歯数、h＝(D−d)/2:歯の有効高さ、L:かみ合い長さ、σ_y:降伏応力。荷重分担率 k_a≈0.75 は、加工誤差により全歯のうち実質約75%だけが荷重を負担することを表す係数。

スプライン軸とは

🙋
「スプライン軸」って、軸の外周に細かい歯がたくさん並んでいる、あの軸のことですか？歯車みたいに見えますけど。
🎓
そう、それだ。歯車と見た目は似ているけど役割が違う。歯車は別の歯車とかみ合って回転を「伝える」もので、スプラインは軸とハブ（穴側）を「結合する」ためのもの。軸とハブの両方に同じ歯形を切って、はめ合わせると、軸が回るとすべての歯が一斉に相手を引っかけてトルクが伝わる。要するに「キーをたくさん並べて軸と一体にしたもの」と思えばイメージしやすいよ。
🙋
キーをたくさん並べたもの…ということは、普通の平行キーよりずっと強いんですか？
🎓
そのとおり。平行キーは1本で全トルクを受けるけど、スプラインは標準で6〜10枚の歯が荷重を分け合う。だから同じ軸径でも数倍のトルクを伝えられるし、トルクが正逆にガチャガチャ変動する用途でもガタが出にくい。自動車のドライブシャフトやトランスミッションの内部、建設機械のPTOなんかでスプラインが使われるのは、まさにこの「大トルク・変動荷重に強い」という理由なんだ。
🙋
なるほど。でもこのツール、「面圧」っていう値が主役になってますね。キーのときに習った「せん断」じゃないんですか？
🎓
いい質問だ。スプラインの歯はキーに比べて「低くて幅広」なんだ。だから歯を真っ二つにスパッと切るより先に、歯の側面が押し潰される「面圧（つぶれ）」のほうが先に効いてくる。実際、スプラインの故障のほとんどは歯面の塑性変形・摩耗・フレッチングで、せん断破断はめったに起きない。だからこのツールは面圧 p ＝ F/(z·h·L·k_a) を主指標にして、降伏応力に対する安全率 n を出しているんだ。
🙋
式の中の「k_a」って何ですか？0.75って書いてありますけど。
🎓
荷重分担率と呼ぶものだよ。理屈の上では z 枚の歯が全部均等に荷重を受けそうだけど、現実には加工誤差で歯のピッチや歯面位置がわずかにばらつく。すると当たりの強い歯ばかりが先に荷重を受けて、ぴったり当たっていない歯はサボる。経験的に「実質的に効いている歯は全体の7割くらい」とされていて、それを k_a≈0.75 として面圧を厳しめに見積もる。これを1.0で計算すると、実際より2〜3割小さい面圧になって危険側の設計になってしまうんだ。
🙋
安全率が足りないときは、どこをいじればいいんですか？
🎓
まず効くのは「かみ合い長さ L を伸ばす」ことだね。面圧は L に反比例するから、下の「面圧とかみ合い長さ」グラフを見ると、L を伸ばすほど面圧がすっと下がる。次が「歯数 z を増やす」。これも荷重を分担する歯が増えるので効く。ただし L も z も無限には増やせない。L はハブ幅で頭打ちになるし、長すぎると軸のねじれで入口側に荷重が偏る。z を増やすと1枚あたりの歯が小さくなって加工が難しくなる。それでも足りなければ、軸径そのものを大きくするか、SCM440のような強い材質に変えるんだ。

よくある質問

まず伝達トルク T から平均径 d_m＝(D+d)/2 上の接線力 F＝2T/d_m を求めます。D は大径、d は小径です。スプラインの歯面が受ける面圧（接触圧力）は p＝F/(z·h·L·k_a) で計算します。z は歯数、h＝(D−d)/2 は歯の有効高さ、L はかみ合い長さ、k_a は荷重分担率です。歯面が全周で均等に荷重を受けるわけではないため、加工誤差を考慮して k_a≈0.75（実際に荷重を負担する歯は約75%）とします。本ツールはこの p を材料の許容値と比較して安全率を表示します。
はい。平行キーは1本のキーで荷重を受けますが、スプラインは多数の歯（標準で6〜10歯）が同時に荷重を分担します。そのため同じ軸径でも数倍のトルクを伝達でき、トルクが正逆に変動する用途でもガタが出にくいのが利点です。さらにキー溝のような深い切り欠きがないため、軸の応力集中も小さく、ねじり疲労に強くなります。代わりに加工コストが高く、専用の歯切り・ブローチ加工が必要です。
目標安全率を S とすると、面圧で決まる必要かみ合い長さは L_req＝2T·S/(d_m·z·h·k_a·σ_y) です。σ_y は降伏応力、d_m は平均径、z は歯数、h は歯の有効高さ、k_a は荷重分担率です。一般にスプラインのかみ合い長さは小径 d の0.75〜1.25倍程度が目安で、それで足りない場合は歯数を増やす、軸径を大きくする、より強い材質にする、などの対策をとります。長くしすぎても軸のねじれで荷重が入口側に偏るため効果は頭打ちです。
スプラインの歯はキーに比べて高さが低く幅が広いため、歯を真っ二つにせん断するより先に、歯面が押し潰される面圧（圧縮）のほうが先に問題になります。標準的な角形スプラインの破損のほとんどは、歯面の塑性変形・摩耗・フレッチングであり、歯がせん断破断する例はまれです。そのため設計では面圧を基準に許容値を定め、安全率を確保します。本ツールも面圧を主指標として安全率を計算します。

実世界での応用

自動車のパワートレイン：ドライブシャフト（プロペラシャフト）の両端、トランスミッション内部のギヤと軸の結合、デフのサイドギヤなど、自動車の駆動系は多数のスプライン結合で成り立っています。エンジンのトルク変動、変速時の衝撃、路面からの逆入力など荷重が激しく変動するため、1本のキーでは持たず、荷重を多数の歯で分担できるスプラインが選ばれます。摺動式のスプライン（軸方向に動けるもの）はサスペンションのストロークを吸収する役割も担います。

建設・産業機械：油圧モータや減速機の出力軸、PTO（パワーテイクオフ）軸、コンベヤやミキサーの駆動軸など、大トルクを確実に伝える箇所でスプラインが多用されます。これらは始動・停止が頻繁で、過負荷もかかりやすいため、面圧の安全率を十分にとった設計が求められます。点検時に着脱できることも、メンテナンス性の面で重要な利点です。

工作機械・回転機械：主軸の工具ホルダ結合、スピンドルとモータの連結、タレットの割り出し機構など、高い回転精度とガタの少なさが要求される箇所に使われます。スプラインはキーに比べて軸とハブの芯出し精度が高く、回転バランスを崩しにくいため、高速回転する部位に向いています。

強度検証とトラブル解析：「歯車が軸上で空転する」「異音・ガタが出る」といった回転機械の不具合では、スプライン歯面の面圧オーバーによる摩耗やフレッチング、塑性変形が原因のことが多くあります。本ツールのような簡易計算で面圧レベルと安全率を確認し、潤滑改善で済むのか、歯数・かみ合い長さ・材質の見直しが必要なのかを判断します。詳細にはFEMで歯元の応力集中や荷重分布の偏りも検討します。

よくある誤解と注意点

まず最大の落とし穴が、「全歯が均等に荷重を受けると仮定して面圧を計算する」ことです。理論上は z 枚の歯が等しく荷重を分担しそうですが、現実には歯のピッチ誤差・歯面位置のばらつき・組立時の片当たりにより、当たりの強い数枚の歯が先に荷重を負担します。本ツールでは荷重分担率 k_a≈0.75 でこれを補正していますが、加工精度が低い場合や軸とハブの芯ずれが大きい場合は、実質的に効く歯がさらに減り、局所面圧が計算値を大きく上回ることがあります。安全率に余裕を持たせ、歯面の硬化処理（高周波焼入れ・浸炭）で耐摩耗性を確保してください。

次に、「伝達トルクは定格トルクでよい」という思い込み。スプラインが使われるのは、まさにトルクが激しく変動する駆動系です。モータの始動トルクは定格の2〜3倍、車両の発進やショックロード、急停止時の慣性トルクではピークがさらに大きくなります。カタログの定常トルクをそのまま入力すると、ピーク荷重で歯面が面圧オーバーを起こします。実務では負荷の種類に応じた使用係数（サービスファクタ、おおむね1.5〜3.0）を掛けた設計トルクで検討してください。本ツールに入力する動力も、この割り増しを含めた値にすべきです。

最後に、「かみ合い長さを長くすればいくらでも強くなる」という誤解。確かに面圧は L に反比例しますが、長いスプラインでは軸のねじれによって長さ方向に荷重が均等に分布せず、トルク入力側の端部に荷重が集中します。目安としてかみ合い長さは小径 d の1.25倍程度までが有効で、それ以上長くしても入口側の局所面圧は下がりません。必要長さがこの範囲を超えるなら、歯数を増やす、軸径を大きくする、クラウニング（歯面を樽形にして当たりを均す）などへ設計を切り替えるべきサインです。あわせて、スプラインは芯出し方式（大径合わせ・小径合わせ・歯面合わせ）によって精度と荷重分布が変わる点にも注意してください。

使い方ガイド

  1. スプライン歯数（pNum）と歯幅範囲（pRange）を入力。一般的な動力伝達用は歯数12～20が標準です。
  2. モジュール（nNum）と圧力角範囲（nRange）を設定。標準モジュール1.5～2.5mm、圧力角20°を推奨。
  3. 大径（dMajNum）と小径（dMinNum）を指定。平均径d_m = (大径+小径)/2で自動計算されます。
  4. 目標トルク値を入力すると、接線力F、面圧p、安全率nがリアルタイム更新。
  5. 面圧がSC45H熱処理材の許容値550MPa以下になるよう、必要なかみ合い長さL_reqを確認。

具体的な計算例

角形スプライン軸、歯数14、モジュール2.0mm、大径20mm、小径16mm（平均径d_m = 18mm）にトルクT = 50N·mを伝達する場合：接線力F = 2T/d_m = 2×50/18 = 5.56kN。必要かみ合い長さを12mmと設定すれば、面圧p = F/(Z×L×m) = 5560/(14×12×2) = 16.6MPa。安全率n = 550/16.6 = 33.1で十分な余裕があります。

実務での注意点

  • 鋳鋼部品への圧入時は、面圧が200MPaを超えると永久変形リスク。かみ合い長さを増加させて分散荷重化。
  • 自動車変速機用スプライン（トルク変動±30%）は、最大トルク時で安全率1.5以上を確保。
  • SC45H素材の硬度がHRC35未満の場合、許容面圧を450MPaに低下。熱処理証明書確認必須。
  • 潤滑不良環境では面圧250MPa上限推奨。EP添加剤付き機械油を使用してもバックラッシュ増加率を年1%で見込む。
