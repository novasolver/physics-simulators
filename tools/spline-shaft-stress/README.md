# スプライン軸の強度シミュレーター

軸からハブ（歯車・カップリング）へ大きなトルクを伝える角形スプライン軸を設計するツールです。動力・回転数・大径・小径・歯数・かみ合い長さを変えると、歯面に生じる面圧・安全率・必要なかみ合い長さがリアルタイムで分かります。

**Category:** 機械要素設計

- 🇯🇵 [日本語](https://novasolver.jp/tools/spline-shaft-stress.html)

- 🇨🇳 [中文](https://novasolver.jp/zh/tools/spline-shaft-stress.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/spline-shaft-stress
python -m http.server 8000
# open http://localhost:8000
```
