# 杭基礎支持力計算機（単杭・群杭）

NovaSolverの杭基礎支持力計算機は、α法、β法、SPT-N法を用いて単杭の周面摩擦抵抗と先端支持力を自動算出。全支持力や群杭効率（Converse-Labarre式）も即時計算できる無料オンラインツールです。設計・施工確認に最適です。

**Category:** 地盤工学
