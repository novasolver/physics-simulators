# 熱交換器 ε-NTU 法シミュレーター — 対向流・並流・クロスフロー

熱容量流量 C_h, C_c と UA、入口温度差 ΔT から NTU と効率 ε を計算。対向流・並流・クロスフロー（両流体非混合）の ε を比較できます。

**Category:** 熱工学シミュレーター
