# 海水淡水化シミュレーター

海水淡水化シミュレーター：逆浸透膜の浸透圧・回収率・エネルギー消費をリアルタイム計算。RO膜・MSF・MED方式の比較解析ツール。

**Category:** 水処理工学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/seawater-desalination.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/seawater-desalination.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/seawater-desalination.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/seawater-desalination
python -m http.server 8000
# open http://localhost:8000
```
