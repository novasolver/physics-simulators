# Arrhenius 加速寿命モデルと使用温度換算シミュレーター

Arrhenius加速寿命モデルの温度換算シミュレーター。反応速度曲線と寿命曲線から使用温度での製品寿命を予測。加速試験設計と寿命推定に。

**Category:** 対話型シミュレーター

- 🇯🇵 [日本語](https://novasolver.jp/tools/accelerated-life-arrhenius-model.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/accelerated-life-arrhenius-model.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/accelerated-life-arrhenius-model.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/accelerated-life-arrhenius-model
python -m http.server 8000
# open http://localhost:8000
```
