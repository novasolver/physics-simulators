# 接着継手応力解析シミュレーター

接着継手応力解析シミュレーター：Volkersen・Hart-Smith モデルでラップジョイントのせん断・ピーリング応力を計算。継手設計・接着剤特性の解析ツール

**Category:** 解析ツール

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/adhesive-joint
python -m http.server 8000
# open http://localhost:8000
```
