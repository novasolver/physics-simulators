# ゴム弾性・超弾性構成則シミュレーター

NovaSolverのゴム弾性・超弾性構成則シミュレーターは、Neo-HookeanやMooney-Rivlin、Ogdenモデルを用いて、ゴムやエラストマーの応力-伸び挙動をリアルタイムで計算します。一軸、二軸、純粋せん断変形に対応し、材料設計や解析を強力に支援する直感的なツールです。

**Category:** 構造解析

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/rubber-elasticity.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/rubber-elasticity.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/rubber-elasticity.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/rubber-elasticity
python -m http.server 8000
# open http://localhost:8000
```
