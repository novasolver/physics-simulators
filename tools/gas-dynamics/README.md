# 気体力学・圧縮性流れシミュレーター

NovaSolverの気体力学シミュレーターは、ノズル設計や超音速流れの解析に役立つ無料オンライン計算機です。マッハ数や臨界条件、総圧比の計算から、垂直衝撃波・レイリー流・ファノー流のシミュレーションまで対応。風洞計算や等エントロピー流れの可視化を即時に行え、研究・学習を強力にサポートします。

**Category:** 流体解析

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/gas-dynamics
python -m http.server 8000
# open http://localhost:8000
```
