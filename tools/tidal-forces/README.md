# 潮汐力シミュレーター — ロッシュ限界・引力差による変形

潮汐力シミュレーターで、天体の引力差が引き起こす潮汐現象をビジュアルに理解。月や太陽の影響による地球の潮の満ち引き、大潮と小潮のメカニズム、さらには衛星が破壊されるロッシュ限界までを対話的なアニメーションで学べるCAEシミュレーションツールです。

**Category:** 物理シミュレーター
