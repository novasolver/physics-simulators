# 自然対流熱伝達係数計算ツール

垂直板・水平板・水平円筒の自然対流熱伝達係数を Nu-Ra 相関式で計算。形状・温度差・流体種類を変えながら、対流強度と熱伝達係数をリアルタイムで比較できます。

**Category:** 流体解析
