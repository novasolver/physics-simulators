# 爆風波シミュレーター

爆風波シミュレーターで、爆発現象の物理を可視化。Sedov-Taylorスケーリングとホプキンソン・クランツスケーリングに基づき、爆風の過圧・インパルス・被害レベルをリアルタイムに計算・シミュレーションできます。NovaSolverのインタラクティブツールで、複雑な爆風波の挙動を直感的に理解しましょう。

**Category:** 爆発工学

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/blast-wave
python -m http.server 8000
# open http://localhost:8000
```
