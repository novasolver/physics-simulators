# 量子調和振動子の波動関数 — Hermite 多項式

1次元量子調和振動子のエネルギー固有関数 ψ_n(x) と確率密度を、量子数・質量・角振動数・ℏから可視化。エネルギー準位と古典反転点の関係を直感的に学べます。

**Category:** 量子力学シミュレーター
