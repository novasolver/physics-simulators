# 制御系ステップ応答・伝達関数シミュレーター

制御系ステップ応答・伝達関数シミュレーター：固有角周波数と減衰比をリアルタイム調整して2次遅れ系の応答を可視化。極配置とボード線図で過減衰・臨界減衰・不足減衰を比較。

**Category:** 制御工学シミュレーター

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/control-step.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/control-step.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/control-step.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/control-step
python -m http.server 8000
# open http://localhost:8000
```
