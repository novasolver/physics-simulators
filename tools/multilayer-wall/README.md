# 多層壁面熱抵抗・U値シミュレーター

多層壁面熱抵抗・U値シミュレーター | コンクリート・断熱材など最大5層の熱貫流率と界面温度をリアルタイム計算・可視化。断熱設計・省エネ計算に活用。

**Category:** 熱解析

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/multilayer-wall
python -m http.server 8000
# open http://localhost:8000
```
