# 斜張橋ケーブル張力計算ツール

スパン長・タワー高・ケーブル本数・荷重を入力すると、各ケーブルの張力と必要断面積をリアルタイムで算出。橋梁の立面図を色分け表示します。

**Category:** 橋梁構造

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/cable-stayed-bridge.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/cable-stayed-bridge.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/cable-stayed-bridge.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/cable-stayed-bridge
python -m http.server 8000
# open http://localhost:8000
```
