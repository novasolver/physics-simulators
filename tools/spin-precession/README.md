# スピン歳差シミュレーター — Larmor 歳差と NMR/MRI 基礎

静磁場中の磁気モーメントが行う Larmor 歳差を可視化。B_0・γ・T_1・T_2 を変えて、MRI で陽子が 63.85 MHz で歳差する仕組みと緩和現象を直感的に学べます。

**Category:** 量子・磁気共鳴シミュレーター
