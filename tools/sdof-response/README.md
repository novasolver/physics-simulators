# 1自由度系 周波数応答解析シミュレーター

1自由度系の周波数応答解析をリアルタイム可視化。減衰比・固有振動数を変更してFRFと共振メカニズムを直感的に学習できるシミュレーター。

**Category:** 振動解析ツール

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/sdof-response.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/sdof-response.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/sdof-response.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/sdof-response
python -m http.server 8000
# open http://localhost:8000
```
