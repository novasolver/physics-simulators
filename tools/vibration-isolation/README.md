# vibration-isolation

装置質量と加振周波数から必要マウント剛性を逆算するシミュレーター。振動伝達率・挿入損失・静的変位をリアルタイム計算し、共振領域の危険性を周波数応答曲線で可視化します。

**Category:** 振動解析ツール
