# 平行キー強度設計シミュレーター

軸からハブ（歯車・プーリ）へトルクを伝える平行キー（沈みキー）を設計するツールです。動力・回転数・キー寸法を変えると、キーに生じるせん断応力と面圧、安全率、必要なキー長さがリアルタイムで分かります。

**Category:** 機械要素設計

- 🇺🇸 [English](https://novasolver.jp/en/tools/parallel-key-stress.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/parallel-key-stress
python -m http.server 8000
# open http://localhost:8000
```
