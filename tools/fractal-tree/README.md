# フラクタルツリー・雪片ジェネレーター

フラクタルツリー・雪片ジェネレーターで自己相似パターンをリアルタイム生成。コッホ雪片やドラゴン曲線のフラクタル次元を計算し、構造設計やシミュレーション解析に活用できます。

**Category:** フラクタル・自己相似

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/fractal-tree.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/fractal-tree.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/fractal-tree.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/fractal-tree
python -m http.server 8000
# open http://localhost:8000
```
