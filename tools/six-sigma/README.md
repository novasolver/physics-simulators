# シックスシグマ・DMAIC ツール集

シックスシグマのDMAICプロジェクトを強力に支援する無料オンラインシミュレーターです。DPMOやσレベル計算、工程能力Cpk、パレート図の作成から、ゲージR&R(MSA)による測定システム分析まで、主要ツールを一括で利用可能。データ分析と品質改善を効率的に進められます。

**Category:** 数理・統計

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/six-sigma
python -m http.server 8000
# open http://localhost:8000
```
