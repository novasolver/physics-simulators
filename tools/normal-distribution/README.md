# 正規分布計算機・可視化

正規分布の確率計算をオンラインで簡単に。平均と標準偏差を自由に設定し、確率密度関数（PDF）や累積分布関数（CDF）をリアルタイムにグラフで可視化。特定の範囲やZスコア、百分位数の計算も即座に実行できる無料ツールです。統計学習やデータ分析に最適。

**Category:** 数理・統計

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/normal-distribution
python -m http.server 8000
# open http://localhost:8000
```
