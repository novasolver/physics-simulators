# 浮力計算機

物体の形状・密度・流体種類・水没率を設定して浮力・重力・見かけ重量をリアルタイム計算。アルキメデスの原理をビジュアルで確認。

**Category:** 流体解析

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/buoyancy.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/buoyancy.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/buoyancy.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/buoyancy
python -m http.server 8000
# open http://localhost:8000
```
