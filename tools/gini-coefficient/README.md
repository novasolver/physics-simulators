# ジニ係数・ローレンツ曲線シミュレーター

所得分布のジニ係数・ローレンツ曲線をリアルタイム計算。不平等度の可視化と国際比較が可能なシミュレーターで、経済格差分析をサポート。

**Category:** 経済学・統計

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/gini-coefficient.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/gini-coefficient.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/gini-coefficient.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/gini-coefficient
python -m http.server 8000
# open http://localhost:8000
```
