# 大気圏再突入・空力加熱計算機

大気圏再突入時の空力加熱をシミュレーションする計算ツールです。アポロ、スペースシャトル、スターシップのプリセットで比較したり、速度・角度・弾道係数を自由に変更して、最大G、熱流束、平衡壁面温度を計算・探索できます。再突入の物理をシンプルな式で体験しましょう。

**Category:** 航空宇宙工学シミュレーター
