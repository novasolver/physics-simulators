# IV 点滴速度・薬剤希釈シミュレーター

点滴流量 mL/hr と滴下数 gtt/min、薬剤投与量 mcg/kg/min を同時計算する臨床看護・薬剤師向けシミュレーター。マクロ・マイクロ点滴セット、体重・濃度・目標投与量から、ドパミン・ヘパリンなど重症薬の安全な輸液速度を確認できます。

**Category:** 臨床看護・薬剤師
