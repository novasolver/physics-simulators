# 磁力線シミュレーター — 磁極配置・磁場可視化

N極・S極を自由配置して磁力線をリアルタイム描画。双極子・四重極子・多極子配置を可視化し、電磁FEM解析やモーター・トランス設計の基礎検討に使えます。

**Category:** 電磁気・光学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/magnetic-field-lines.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/magnetic-field-lines.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/magnetic-field-lines.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/magnetic-field-lines
python -m http.server 8000
# open http://localhost:8000
```
