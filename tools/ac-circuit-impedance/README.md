# 交流回路インピーダンス計算シミュレーター

交流回路インピーダンス計算シミュレーターで、RLC直列・並列回路の共振周波数・Q値・位相角をリアルタイム計算。ボード線図とフェーザーダイアグラムで交流回路特性を視覚化します。

**Category:** 電気回路

- 🇯🇵 [日本語](https://novasolver.jp/tools/ac-circuit-impedance.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/ac-circuit-impedance.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/ac-circuit-impedance.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/ac-circuit-impedance
python -m http.server 8000
# open http://localhost:8000
```
