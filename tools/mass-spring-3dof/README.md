# 3自由度質量バネ系・動吸振器シミュレーター

3自由度質量バネ系・動吸振器シミュレーターで固有振動数と周波数応答をリアルタイム解析。DVA追加による共振ピーク消去を可視化・検証できます。

**Category:** 構造振動シミュレーター

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/mass-spring-3dof.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/mass-spring-3dof.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/mass-spring-3dof.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/mass-spring-3dof
python -m http.server 8000
# open http://localhost:8000
```
