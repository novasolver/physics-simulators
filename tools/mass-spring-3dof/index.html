3自由度質量バネ系・動吸振器とは

🙋
「動吸振器」って何ですか？普通のバネと何が違うんですか？
🎓
大まかに言うと、振動を“吸い取る”ための小さなサブシステムだね。例えば、高層ビルが風で揺れる時、最上階に大きな質量ブロックをバネで取り付けて、ビルの揺れと逆位相で振動させて揺れを打ち消すんだ。このシミュレーターでは、右側の「DVA質量 mₐ」のスライダーを0kgから増やしてみると、吸振器が追加される様子がわかるよ。
🙋
え、振動を消せるんですか？でも、吸振器を付けたら、かえってシステムが複雑になって振動モードが増えたりしないんですか？
🎓
良いところに気づいたね！その通りで、吸振器を付けると自由度が1つ増えるから、固有振動数も1つ増えるんだ。でも、うまくチューニングすると、メインのシステム（主系）の共振点の振動を、吸振器に“肩代わり”させられる。画面上の周波数応答グラフで、mₐを増やしながら「k₄」のバネ定数を動かしてみて。主系の一番低い共振ピークが分裂して、その間に深い谷（ノッチ）ができるのが見えるはずだよ。
🙋
なるほど！でも、その「うまくチューニング」ってどう決めるんですか？勘でパラメータをいじるんですか？
🎓
実務では理論的な最適値からスタートするんだ。動吸振器の固有振動数 $f_a$ と主系の固有振動数 $f_1$ の比を、質量比 $\mu = m_a / m_1$ を使って $f_a / f_1 = 1/(1+\mu)$ に合わせるのが基本だ。シミュレーターの「理論メモ」にもあるこの式に従って、m₁とmₐからk₄を逆算して設定すれば、主系の振幅を理論的にゼロにできる。まずは「減衰比 ζ」を0にして、この関係が成り立つようにパラメータを設定して、周波数応答の谷がどこに現れるか確認してみよう。

よくある質問

はい、スライダーを動かすたびにリアルタイムで周波数応答グラフが更新されます。共振ピークの移動や動吸振器による消去効果を、数値変更と同時に視覚的に確認できます。
DVAの固有振動数を、消したい共振ピークの周波数に合わせて設定します。目安として、DVAの質量は主系の1/10〜1/20程度、バネ定数は目標周波数から計算すると効果的です。
直列に連結された3つの質量ブロックを想定しています。例えば、多層構造物や機械の多段振動系を模擬しており、各質量間のバネ・減衰を個別に調整できます。
本ツールは線形モデルであり、実際の材料非線形性や摩擦、接触などを考慮していません。設計の目安として活用し、実機検証や非線形解析を併用することを推奨します。

実世界での応用

建築・土木構造物：超高層ビルやタワー、長大橋の風や地震による振動制御に応用されます。建物上部に設置した巨大な質量（チューニッドマスダンパー）が動吸振器として機能し、居住者の揺れの不快感や構造疲労を軽減します。

自動車・航空機エンジン：エンジンのクランクシャフトやプロペラの回転に伴う振動（トーショナル振動）を低減するために、ダンパー（ねじり振動動吸振器）が組み込まれています。これにより、騒音低減と部品の耐久性向上を図っています。

精密機械・製造装置：半導体製造装置や精密測定機は、微小な振動でも精度が大きく低下します。装置本体や振動源となるモーターなどに小型の動吸振器を取り付けることで、不要な共振を抑え、加工・測定精度を確保します。

家電・民生品：洗濯機の脱水時の振動や、ドローン・カメラの手ぶれ補正機構にも原理は応用されています。限られたスペースとコストの中で、最も効果的な質量とバネの組み合わせをCAEシミュレーションで事前に設計します。

よくある誤解と注意点

動吸振器を使い始める際、いくつかつまずきやすいポイントがあるよ。まず、「動吸振器は振動を完全に消す魔法の装置」と思いがちだけど、それは厳密には違う。理論的に振幅ゼロにできるのは、単一の周波数、かつ減衰ゼロの理想的な場合だけだ。実際には減衰があるし、加振力の周波数が少しでもずれると効果が急激に落ちる。このシミュレーターで「減衰比 ζ」を0.01や0.05に上げてみると、せっかく深かった谷（ノッチ）が浅くなってしまうのが確認できるはず。実務では、想定外の周波数変動にもある程度対応できるよう、あえて最適値から外して設計することもあるんだ。

次に、質量比 μ の設定。動吸振器の質量 mₐ は、主系の質量 m₁ に対して十分に小さいと思いがちだけど、実は軽すぎると効果が薄い。例えば m₁=100kg のシステムに mₐ=1kg (μ=0.01) の吸振器をつけても、効果は限定的だ。かといって重すぎると今度はシステム全体が巨大化する。自動車のエンジンなどでは μ=0.05〜0.2 (5〜20%) 程度が現実的な範囲だ。このツールで m₁=10kg のまま mₐ を 0.1kg→1kg→5kg と変えて、周波数応答の谷の幅と深さがどう変わるか試してみると、トレードオフが体感できるよ。

最後に、「チューニング」はバネ定数だけじゃないということ。最適なバネ定数 k₄ は $k_a = m_a (2\pi f_1)^2 / (1+\mu)^2$ で決まるけど、減衰係数 cₐ も特に重要。減衰が小さすぎると、谷は深いけど幅が狭くて実用的じゃない。逆に大きすぎると、谷は消えて単に全体の振動が抑えられるだけ。このバランスを「固定点理論」を使って最適化する方法がある。シミュレーターで k₄ を最適値に固定し、cₐ（減衰比ζに反映）だけをスライドさせて、周波数応答曲線の形状がどう変わるか観察してみて。

使い方ガイド

  1. 主系の質量m1（kg）、バネ定数k1（N/m）を入力し、基本の1自由度系の固有振動数f₁を確認します
  2. 動吸振器（ダイナミックバイブレーションアブソーバ：DVA）の質量m2と取付バネk2を調整し、f₂がターゲット周波数に一致するよう設定します
  3. さらに3質量目を追加して複数の共振ピークを制御し、周波数応答グラフでピーク値の低下を確認します

具体的な計算例

鋼製機械フレーム：m1=50kg、k1=1.2×10⁵N/mの場合、f₁≈24.6Hzです。このフレームの24.6Hz共振を抑制するためm2=5kg、k2=1.2×10⁴N/mの動吸振器を装着すると、f₂≈24.6Hzで同調し、元の周波数応答の共振ピーク（振幅18mm）が二つの小ピーク（各6mm）に分裂します。さらにm3=2kgを追加すると全帯域で最大ピークが4mm以下に低減されます

実務での注意点

  1. 動吸振器の質量比（m2/m1）は通常0.05～0.2の範囲で設定し、比が小さすぎるとピーク低減効果が薄れます
  2. DVAの同調誤差が±2%を超えるとピーク分裂が非対称になり、一方のピークが逆に増幅される危険があります
  3. 機械の運転周波数が変動する場合（例：モータ起動時1000～3000rpm）、単一DVAでは対応困難なため、複数周波数帯域用の多段吸振器設計が必要です
  4. 取付部の剛性不足やダンピング（減衰比ζ≈0.05程度）を無視すると、シミュレーション値と実測値で10～20%の誤差が生じます
