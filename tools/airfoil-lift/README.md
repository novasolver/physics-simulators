# 翼型揚力計算 — 薄翼理論による揚力・抗力係数

薄翼理論によるNACA翼型の揚力・抗力係数計算。迎角・速度変化でCL・CD・揚抗比をリアルタイム解析し、空力極曲線と失速特性を可視化します。

**Category:** 空気力学シミュレーター
