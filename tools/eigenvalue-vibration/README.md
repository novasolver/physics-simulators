# 固有値・振動解析インタラクティブシミュレーター

NovaSolverの固有値・振動解析シミュレーターは、バネ質量系の固有振動数とモード形状をリアルタイムで計算し、アニメーション表示する無料オンライン計算機です。2〜5自由度の振動解析を直感的に操作でき、周波数応答や共振点の可視化により、工学設計や学習を強力にサポートします。

**Category:** 振動解析ツール

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/eigenvalue-vibration.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/eigenvalue-vibration
python -m http.server 8000
# open http://localhost:8000
```
