# ヒートポンプ・冷凍機COP計算機

ヒートポンプ・冷凍機COP計算機で成績係数（COP）をリアルタイム計算。高温側・低温側温度を入力するだけで、熱量や年間電気代を即時にシミュレーション。エアコンや冷凍機の省エネ性能を簡単に比較・評価できます。効率向上とランニングコスト削減に役立つ無料ツールです。

**Category:** 熱工学シミュレーター
