# ベベルギア（かさ歯車）の歯面荷重シミュレーター

交差軸の動力伝達に使う直歯ベベルギア（かさ歯車）の歯面に発生する3つの力（接線力・軸方向力・半径方向力）をリアルタイム計算します。ピッチ角と圧力角を変えると、スラスト軸受の選定に必要な軸方向力の大きさが直感的に分かります。

**Category:** 機械要素
