# 捕食者-被食者モデル（ロトカ-ボルテラ）シミュレーター

捕食者-被食者モデル（ロトカ-ボルテラ）シミュレーターで、ウサギとキツネの個体数変動をリアルタイムに可視化。時系列グラフと位相平面で生態系のダイナミクスを学べます。ロジスティック成長など拡張モデルにも対応。NovaSolverでインタラクティブにシミュレーションを体験しましょう。

**Category:** 数理生態学・生物数学

## Live demos

- 🇺🇸 [English](https://novasolver.jp/en/tools/population-dynamics.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/population-dynamics
python -m http.server 8000
# open http://localhost:8000
```
