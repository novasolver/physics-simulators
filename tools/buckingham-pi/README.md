# バッキンガムπ定理シミュレーター — 次元解析と模型相似則

円柱周りの抗力を例に、5変数を2つの無次元π群（Re と C_D）にまとめる手順を可視化。模型と実機を動的相似で結びつけ、模型試験の力から実機の力を予測する原理を学べます。

**Category:** 流体力学シミュレーター

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/buckingham-pi.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/buckingham-pi.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/buckingham-pi
python -m http.server 8000
# open http://localhost:8000
```
