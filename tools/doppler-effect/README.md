# ドップラー効果シミュレーター

ドップラー効果シミュレーター：音源速度と観測者速度をリアルタイム操作して周波数変化をシミュレーション。波面アニメーション・グラフ・衝撃波解析で音声周波数とマッハ数を可視化' = f·(c±vo)/(c∓vs) をリアルタイム計算。波面歪みとマッハ円錐を可視化する音響解析ツール。

**Category:** 高校物理 / 音響工学
