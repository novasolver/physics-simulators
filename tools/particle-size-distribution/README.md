# 粒子径分布・ロジン-ラムラー分布解析

Rosin-Rammler・対数正規・GGS分布のパラメータを調整しながら、累積通過曲線・頻度分布・d10/d50/d90・ザウター平均径・比表面積をリアルタイム計算します。

**Category:** 流体工学

- 🇯🇵 [日本語](https://novasolver.jp/tools/particle-size-distribution.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/particle-size-distribution.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/particle-size-distribution.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/particle-size-distribution
python -m http.server 8000
# open http://localhost:8000
```
