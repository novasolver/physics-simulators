# 2次元衝突・運動量保存シミュレーター

2次元衝突・運動量保存シミュレーター｜質量・速度・反発係数をリアルタイム設定し衝突現象を可視化。運動量保存則と弾性係数の効果を衝突アニメーション・速度ベクトル・エネルギー収支で検証。

**Category:** 力学・衝突

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/momentum-2d-collision.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/momentum-2d-collision.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/momentum-2d-collision.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/momentum-2d-collision
python -m http.server 8000
# open http://localhost:8000
```
