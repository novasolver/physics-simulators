# 定水位透水試験シミュレーター

砂や礫のような透水性の高い土の透水係数を求める定水位透水試験をシミュレートします。供試体の寸法・水位差・採水量・経過時間を変えると、ダルシー則に基づく流量・動水勾配・ダルシー流速・透水係数がリアルタイムで分かります。

**Category:** 地盤工学
