# 鋼接合部設計ツール

鋼構造接合部設計ツール「NovaSolver」は、高力ボルト(F8T/F10T)や隅肉溶接の耐力計算を支援。軸力・せん断・曲げに対する利用率を自動算出し、ボルト配置図と溶接線を可視化します。CAEを活用した信頼性の高い構造設計と効率的な検証を実現。

**Category:** 鋼構造設計

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/steel-connection
python -m http.server 8000
# open http://localhost:8000
```
