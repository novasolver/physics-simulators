# ジェットコースター・エネルギー保存シミュレーター

コースアニメーション、PE/KE変化グラフ、速度メーターの3タブを切り替えながら、高さ・質量・摩擦係数を動かすと、ジェットコースター上の位置エネルギーと運動エネルギーがどう入れ替わっていくかが視覚的に追えます。

**Category:** 力学・エネルギー

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/roller-coaster-energy.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/roller-coaster-energy.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/roller-coaster-energy.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/roller-coaster-energy
python -m http.server 8000
# open http://localhost:8000
```
