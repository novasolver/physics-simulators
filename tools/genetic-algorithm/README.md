# 遺伝的アルゴリズム最適化シミュレーター

遺伝的アルゴリズム最適化シミュレーターでRastrigin・Ackley関数など難関ベンチマークの最適化過程をリアルタイム可視化。GA探索アルゴリズムの適応度収束を解析できます。

**Category:** 進化計算・最適化

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/genetic-algorithm.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/genetic-algorithm.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/genetic-algorithm.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/genetic-algorithm
python -m http.server 8000
# open http://localhost:8000
```
