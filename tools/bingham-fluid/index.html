ビンガム塑性流体 シミュレーター — 降伏応力を持つ非ニュートン流体

ビンガム塑性モデル $\tau = \tau_y + \mu_p\,\dot{\gamma}$ に基づき、せん断応力 $\tau$、見かけ粘性 $\mu_{\text{app}}$、ビンガム数 $Bi$、BP Reynolds 数を実時間計算します。降伏応力 $\tau_y$、塑性粘性 $\mu_p$、せん断速度 $\dot{\gamma}$、流体密度 $\rho$ をスライダーで変えて、歯磨き粉・ペンキ・生コンクリート・ドリリングマッドのような降伏応力流体の流動曲線とプラグ流を含む円管速度プロファイルを可視化します。

理論・主要公式

ビンガム塑性の構成式（$\tau_y$＝降伏応力 Pa、$\mu_p$＝塑性粘性 Pa·s、$\dot{\gamma}$＝せん断速度 1/s）：

$$\tau = \tau_y + \mu_p\,\dot{\gamma}\quad(\tau \ge \tau_y)$$

$\tau < \tau_y$ では $\dot{\gamma} = 0$（流動なし、剛体的挙動）。見かけ粘性は $\mu_{\text{app}} = \tau / \dot{\gamma}$：

$$\mu_{\text{app}} = \dfrac{\tau_y}{\dot{\gamma}} + \mu_p$$

ビンガム数（降伏応力 vs 粘性応力）と BP Reynolds 数（$\mu_p$ で定義）：

$$Bi = \dfrac{\tau_y}{\mu_p\,\dot{\gamma}},\qquad Re_{BP} = \dfrac{\rho\,U\,D}{\mu_p}$$

本ツールの既定値（$\tau_y = 20$ Pa、$\mu_p = 0.5$ Pa·s、$\dot{\gamma} = 10$ 1/s、$\rho = 1500$ kg/m³、$D = 10$ mm、$U = 1$ m/s）では $\tau = 25.0$ Pa、$\mu_{\text{app}} = 2.50$ Pa·s、$Bi = 4.00$、$Re_{BP} = 30.0$ となります。

ビンガム塑性流体とは

🙋
「ビンガム塑性流体」って言葉、レオロジーの本で見たんですが、ニュートン流体や冪乗則流体と何が違うんですか？
🎓
いちばんの違いは「降伏応力 $\tau_y$ を持つ」ことだ。ニュートン流体は応力をかければどんなに小さくても流れる、冪乗則流体も同じ。ところがビンガム流体は $\tau < \tau_y$ のあいだは剛体みたいに変形しない。応力が降伏応力を超えてはじめて流れ始め、その後は $\tau = \tau_y + \mu_p \dot{\gamma}$ という直線関係になる。$\mu_p$ は塑性粘性と呼ぶ。このツールの既定値（$\tau_y = 20$ Pa、$\mu_p = 0.5$ Pa·s、$\dot{\gamma} = 10$ 1/s）で計算結果を見ると、$\tau = 25.0$ Pa、見かけ粘性 $\mu_{\text{app}} = 2.50$ Pa·s、ビンガム数 $Bi = 4.00$、$Re_{BP} = 30.0$ が出ているはず。
🙋
身近な例だと、どんな流体がビンガム塑性なんですか？
🎓
いちばん有名なのは歯磨き粉。チューブから絞り出さないと自分では出てこないし、出た瞬間に形を保つ。あれが「降伏応力がある」状態だ。ほかにペンキ（未撹拌）、生コンクリート、ドリリングマッド、マヨネーズ、トマトケチャップの一部、グリースなんかも近い挙動を示す。建築現場で生コンが「自重ですべて崩れない」のはまさにビンガム性のおかげで、スランプ試験はこの $\tau_y$ をざっくり測る試験になっている。
🙋
「プラグ流」って速度プロファイルの真ん中が四角くなるやつですか？なぜ起きるんですか？
🎓
そう、中央が塊として一緒に動く「rigid core」のことだ。円管内の応力分布 $\tau(r) = (\Delta p / 2L)\, r$ は中心ゼロ・壁面最大で、$\tau(r) < \tau_y$ になる中心領域では流体は変形条件を満たせない。だからそこは全体が同じ速度で動き、外側だけが普通にせん断流動する。下のキャンバスで「プラグ流 (rigid core)」と書かれた帯がそれだ。スライダーで $\tau_y$ を上げるか $\dot{\gamma}$ を下げると、プラグの幅 $r_p/R$ がじわじわ広がっていくのが見える。Bi が無限大に近づくと、最終的に管全体が動かなくなる。
🙋
ビンガム数 $Bi$ ってどう使えばいいんですか？数字の感覚がまだ薄くて……
🎓
$Bi = \tau_y / (\mu_p \dot{\gamma})$ は「降伏応力 vs 粘性応力」の比だ。ざっくり言うと Bi < 1 ならニュートン流体に近い、$1 \le Bi \le 10$ で混合的なプラグ流、$Bi > 10$ で強い降伏応力支配。既定値の $Bi = 4$ は中央のプラグが目に見える程度に出るが、壁付近のせん断もはっきり残る典型的な「ビンガムらしい」状態だ。プロセス設計では、攪拌・搬送・押出のせん断速度から $Bi$ を見積もって、どのスケールの流動になるかをまず把握する。

よくある質問

いずれも降伏応力を持つ流体のモデルですが、降伏後のせん断応力—せん断速度関係が違います。ビンガムは線形 $\tau = \tau_y + \mu_p \dot{\gamma}$ で 2 パラメータ、最もシンプル。Herschel-Bulkley は冪乗 $\tau = \tau_y + K \dot{\gamma}^n$ で 3 パラメータ、降伏後にも非線形性を持つ流体（ペンキ、ドリリングマッド、ヨーグルトなど）に最適。Casson は $\sqrt{\tau} = \sqrt{\tau_y} + \sqrt{\mu_C \dot{\gamma}}$ で、血液や印刷インクのような微弱な構造を持つ流体に使われます。広いせん断速度域を 1 つのモデルで覆いたいときは Herschel-Bulkley が標準的な選択肢です。
代表的なのは 3 通り。第 1 は応力スイープ：応力を段階的に上げて、せん断速度が突然立ち上がる点を $\tau_y$ とします。第 2 は剪断速度プロットを直線フィットして、低 $\dot{\gamma}$ 側の y 切片を $\tau_y$ とする方法。第 3 は静的法（vane rheometer や slump test）で、機械的に動き始める応力を直接測ります。同じ材料でも測定法によって 2 〜 3 割違う値になることが普通で、これは「動的降伏応力」と「静的降伏応力」の区別に対応します。報告時はどの定義で測ったかを明示するのが定石です。
厳密なビンガム式は $\dot{\gamma} \to 0$ で粘性が発散するため、そのままでは数値計算がほぼ不可能です。実務では Papanastasiou 正則化 $\mu_{\text{eff}} = \mu_p + \tau_y (1 - e^{-m \dot{\gamma}}) / \dot{\gamma}$ を使い、$m = 100 \sim 1000$ s で滑らかな粘性関数に置き換えます。OpenFOAM の BinghamPlastic、ANSYS Fluent の Bingham option はいずれもこの種の正則化を内蔵。$m$ を大きくしすぎると数値振動、小さすぎると物理を再現しないので、典型値 $m = 500$ s から始めて収束履歴を見ながら調整するのが安全です。
本ツールが表示する $Re_{BP} = \rho U D / \mu_p$ は $\mu_p$ を分母にとった最も単純な定義で、層流域の概算には十分ですが、降伏応力の効果は含まれていません。乱流遷移を予測したい場合は Hedstrom 数 $He = \rho D^2 \tau_y / \mu_p^2$ と併用し、Hanks の判定式 $Re_c = 4 \alpha (1 - 4\alpha/3 + (4\alpha/3)^4/3)$（$\alpha$ は $He$ から決まる関数）で遷移 Re を求めます。$He$ が大きいほど層流域が広くなり、$\tau_y$ が大きい流体は乱流に遷移しにくい性質があります。実務 CFD（OpenFOAM、Fluent）は内部で同等の処理を行います。

実世界での応用

生コンクリートの流動：生コンクリートはセメント・水・骨材・添加剤の混合物で、典型的に $\tau_y = 100 \sim 2000$ Pa、$\mu_p = 10 \sim 200$ Pa·s。ポンプ圧送、型枠への打設、スランプフローはすべてこの 2 パラメータでほぼ説明できます。スランプ試験のスランプ値は降伏応力と直接相関し、自己充填コンクリート（SCC）の設計では $\tau_y$ を下げて流動性を確保しつつ材料分離を防ぐバランスが鍵です。本ツールで $\tau_y$ を 100 〜 500 Pa の範囲で動かすと、プラグ半径と見かけ粘性が大きく変化することが分かります。

ドリリングマッドと油田流体：石油・地熱井で使うドリリングマッドはベントナイト懸濁液で、典型値は $\tau_y = 5 \sim 50$ Pa、$\mu_p = 0.01 \sim 0.1$ Pa·s。掘削屑（カッティングス）の運搬では、井戸停止時にカッティングスが落下しないよう $\tau_y$ を高めに設計します。一方、循環中のポンプ動力は $\mu_p$ で決まるため、両者のバランスを取るのが現場最適化のポイント。本ツールで $\tau_y$ を上げて $\dot{\gamma}$ を下げると、プラグ流が拡大して輸送効率が改善する様子が見えます。

歯磨き粉・化粧品・食品ペースト：歯磨き粉は典型 $\tau_y = 100 \sim 300$ Pa、$\mu_p = 1 \sim 10$ Pa·s。チューブから絞り出す圧力で初めて流れ、ブラシ上では形を保ち、口の中では唾液で粘性が下がる──この複雑な挙動は降伏応力で説明できます。マヨネーズ、ケチャップ、フェイスクリーム、リップスティックも同様の設計指針で、$\tau_y$ が低すぎると容器内で液状化し、高すぎると塗布感が悪化します。製品レオロジーは官能評価と直結する重要なパラメータです。

血液の粘弾性とバイオメカニクス：血液は微弱な降伏応力（$\tau_y \approx 0.005 \sim 0.05$ Pa）を持つ Casson 型流体ですが、簡易モデルとしてビンガム塑性で近似することもあります。毛細血管のような低せん断域では赤血球の凝集（ルロー形成）により実効的な降伏応力が現れ、流動停止のリスクが増えます。動脈瘤や狭窄部の CFD では、ニュートン近似より降伏応力を考慮した方が壁面せん断応力分布が実測に近づきます。本ツールで $\tau_y$ を小さな値（0.1 Pa）に設定し、$\dot{\gamma}$ を変えて見かけ粘性が変化する範囲を確認できます。

よくある誤解と注意点

最も多い誤解は、「降伏応力さえあれば、応力がそれを下回るとき流体は完全に固体である」と考えることです。実際の材料には「クリープ」と呼ばれる微小な変形が常に存在し、$\tau < \tau_y$ でも長時間スケールでは緩やかに変形します。歯磨き粉が長期間チューブ内で固まらず、生コンが打設後にわずかにレベリングする理由はこれ。CFD で完全な剛体扱いをするとシミュレーションが破綻するため、Papanastasiou 正則化や Bercovier-Engelman 正則化で「非常に高粘性の流体」として扱うのが定石です。本ツールも教育目的のシンプルなモデルを採用しており、極低せん断域の物理を厳密に再現してはいません。

次に多いのが、「塑性粘性 $\mu_p$ がニュートン流体の粘性係数と同じ意味」と思い込む ことです。$\mu_p$ は「降伏応力を引いたあとのせん断応力—せん断速度関係の傾き」であって、ニュートン粘性とは別物。見かけ粘性は $\mu_{\text{app}} = \tau_y / \dot{\gamma} + \mu_p$ で、せん断速度が小さいほど大きくなります。本ツールの既定値では $\mu_p = 0.5$ Pa·s に対し $\mu_{\text{app}} = 2.5$ Pa·s と 5 倍違うので、配管圧損計算で $\mu_p$ をそのまま使うと過小評価する点に注意。実プロセスの $\dot{\gamma}$ における $\mu_{\text{app}}$ を使うか、Buckingham-Reiner 式を直接解く必要があります。

最後に、「ビンガム塑性ですべての降伏応力流体を表せる」という思い込みです。実際の歯磨き粉やペンキは、降伏後にも非線形性（shear-thinning）を持つことが多く、線形ビンガムでは流動曲線がうまく合いません。広いせん断速度域でデータを取ったら、Herschel-Bulkley（$\tau = \tau_y + K \dot{\gamma}^n$）を試すのが標準です。ビンガムが有効なのはせん断速度範囲が狭い場合か、初期推定として使う場合に限ります。$\dot{\gamma}$ をスイープボタンで動かして、本ツールのモデルが「直線」を仮定しているのを実感できます。実材料はそれより緩やかなカーブを描くのが普通です。

使い方ガイド

  1. 降伏応力τ_y（Pa）をスライダーで設定します。歯磨き粉は5～50 Pa、生コンは100～300 Paが典型値です
  2. 塑性粘性μ_p（Pa·s）を調整します。ペンキ0.5～2 Pa·s、ドリリングマッド10～50 Pa·sの範囲で入力してください
  3. せん断速度γ̇（s⁻¹）と流体密度ρ（kg/m³）を設定後、シミュレーターが自動的にせん断応力τ、見かけ粘性μ_app、ビンガム数Bi、BP Reynolds数を計算表示します

具体的な計算例

生コン（スランプ150 mm）をφ100 mm円管に流す場合：τ_y=150 Pa、μ_p=25 Pa·s、γ̇=10 s⁻¹、ρ=2400 kg/m³と入力するとτ=150+25×10=400 Pa、μ_app=400/10=40 Pa·s、Bi=150/(25×10)=0.6、BP Re=(2400×10×0.1²)/(25×(1+0.6))≈240となり、層流領域での部分プラグ流形成を可視化できます

実務での注意点

  1. ドリリングマッド（τ_y=50～200 Pa）のように高降伏応力流体では、せん断速度が低いと見かけ粘性が急増し、パイプラインの圧力損失が過大評価される傾向があります
  2. ペンキやコーティング材（τ_y<10 Pa）は温度依存性が強いため、現場温度での粘性再測定が必須です
  3. ビンガム数Bi>1の高降伏応力流体では、円管中心部にプラグ流領域が形成され、境界層幅（h_plug）の算定が重要になります
