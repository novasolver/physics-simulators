# Crank-Nicolson 法シミュレーター

Crank-Nicolson法シミュレーターで拡散方程式の数値解析を実践。時間刻み・空間刻みの影響を可視化し、FDM・陰解法の精度を検証できます。

**Category:** 対話型シミュレーター

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/crank-nicolson.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/crank-nicolson.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/crank-nicolson.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/crank-nicolson
python -m http.server 8000
# open http://localhost:8000
```
