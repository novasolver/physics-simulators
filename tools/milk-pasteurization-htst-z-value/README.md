# 牛乳殺菌 HTST D値・Z値シミュレーター

牛乳の HTST／UHT 殺菌設計を D値・Z値・F0値・PU値で評価する無料シミュレーター。Coxiella・Listeria・E.coli など標的微生物・温度・保持時間・流量を変えて、達成 log 減少と熱交換面積をリアルタイム計算します。

**Category:** 食品加工・殺菌設計
