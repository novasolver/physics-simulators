# フィン配列シミュレーター — ヒートシンクの総熱伝達

矩形ストレートフィンを N 本並べたヒートシンクをモデル化し、総熱伝達量と全体表面効率をその場で算出。フィン高さ・本数・材料熱伝導率・対流熱伝達率を変えるだけで、CPU クーラーや LED 放熱器の効きが体感的に分かります。

**Category:** 熱工学シミュレーター
