# ローレンツ変換 シミュレーター — 特殊相対論の時間遅れと長さ収縮

特殊相対性理論のローレンツ変換に基づき、速度比 β = v/c、固有時間 t_0、固有長 L_0、静止エネルギー E_rest からローレンツ因子 γ、時間遅れ t、長さ収縮 L、相対論的運動エネルギー KE を実時間計算します。ロケットの収縮と γ(β) 曲線を同時に可視化し、光速 c に近づくほど時空が歪む様子を直感的に体感できる教育用シミュレーターです。

**Category:** 相対性理論シミュレーター
