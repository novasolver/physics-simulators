# 振動解析・固有値解析シミュレーター（多自由度）

NovaSolverの振動解析・固有値解析シミュレーターは、多自由度（1〜3DOF）の質量バネ系を簡単操作で解析します。質量とばね定数をスライダーで直感的に調整でき、固有振動数と振動モードをリアルタイム計算。各モードの振動アニメーションと周波数応答グラフを可視化する、直感的なCAEツールです。

**Category:** 振動・構造動解析

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/vibration-analysis
python -m http.server 8000
# open http://localhost:8000
```
