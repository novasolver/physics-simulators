# 大気境界層プロファイル計算

大気境界層プロファイル計算:地表粗度と基準風速から対数則・べき乗則による風速鉛直分布をリアルタイムに比較。乱流強度・風エネルギー密度を同時算出するCAE解析ツール。

**Category:** 流体解析

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/atmospheric-boundary.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/atmospheric-boundary.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/atmospheric-boundary.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/atmospheric-boundary
python -m http.server 8000
# open http://localhost:8000
```
