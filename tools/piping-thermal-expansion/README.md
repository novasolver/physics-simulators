# 配管熱膨張・熱応力計算機

運転温度上昇による配管の熱伸び量・拘束熱応力をASME B31.3基準で計算。膨張ループ・Lベンドの必要寸法を設計し、熱応力vsΔT曲線をリアルタイム可視化。

**Category:** 配管工学 · 熱応力解析
