# 圧縮機サージマージンと運転マップシミュレーター

圧縮機サージマージンと運転マップシミュレーターで、運転点とサージ線の関係を可視化。流量・圧力比変化による余裕度の低下を診断し、安定運転を確保するCAE解析ツール。

**Category:** 対話型シミュレーター

- 🇺🇸 [English](https://novasolver.jp/en/tools/compressor-surge-margin-map.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/compressor-surge-margin-map.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/compressor-surge-margin-map
python -m http.server 8000
# open http://localhost:8000
```
