# 対流セルシミュレーター — レイリー–ベナール対流

ベナール対流セル（レイリー・ベナール不安定）の発生と対流ロールの形成を、リアルタイムでシミュレーションできる無料ツールです。レイリー数やアスペクト比を自由に調整し、底面加熱による浮力対流のダイナミックな様子を可視化。教育や研究に役立つインタラクティブシミュレーターです。

**Category:** 熱流体シミュレーター
