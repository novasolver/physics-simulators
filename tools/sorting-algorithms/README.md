# ソートアルゴリズム可視化

バブルソート、クイックソート、マージソートなど主要なソートアルゴリズムをアニメーションで直感的に学べるシミュレーター。比較回数や計算量をリアルタイムで確認でき、アルゴリズムの仕組みと効率の違いが一目でわかります。プログラミング学習やCAE前処理の理解に最適です。

**Category:** アルゴリズム・データ構造

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/sorting-algorithms.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/sorting-algorithms.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/sorting-algorithms.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/sorting-algorithms
python -m http.server 8000
# open http://localhost:8000
```
