# 自転車ギア比・速度計算ツール

自転車ギア比・速度計算ツール。フロント歯数とリア歯数からケイデンス、ロールアウト、登坂能力をリアルタイム計算。ロードバイクMTB対応。

**Category:** 機械・スポーツ工学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/bicycle-gear-ratio.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/bicycle-gear-ratio.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/bicycle-gear-ratio.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/bicycle-gear-ratio
python -m http.server 8000
# open http://localhost:8000
```
