# 薄肉レンズ光線追跡シミュレーター

薄肉レンズの光線追跡をリアルタイムシミュレーション。凸レンズ・凹レンズの像位置・倍率・実像虚像を視覚化。光学設計・教育向けツール。

**Category:** 光学・レンズ設計

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/lens-ray-tracer.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/lens-ray-tracer.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/lens-ray-tracer.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/lens-ray-tracer
python -m http.server 8000
# open http://localhost:8000
```
