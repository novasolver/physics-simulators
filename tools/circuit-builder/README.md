# 電気回路シミュレーター

NovaSolverの電気回路シミュレーターで、オームの法則や直並列回路を視覚的に学びましょう。電子の流れをアニメーションで確認でき、キルヒホッフの法則や消費電力の計算もリアルタイムで可能。直列・並列・混合回路からRC回路まで、初心者からプロまで使える学習・設計ツールです。

**Category:** 電気回路

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/circuit-builder
python -m http.server 8000
# open http://localhost:8000
```
