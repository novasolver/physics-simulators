# ヘスの法則・反応エンタルピー計算

ヘスの法則・反応エンタルピー計算ツール。生成エンタルピーから反応熱を求め、エネルギー図をリアルタイム表示。燃焼反応・中和反応などプリセット搭載。

**Category:** 化学熱力学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/hess-law.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/hess-law.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/hess-law.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/hess-law
python -m http.server 8000
# open http://localhost:8000
```
