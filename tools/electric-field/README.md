# 電場・電位シミュレーター

電場・電位シミュレーター - 点電荷の配置からクーロン力による電場ベクトル・電位分布をリアルタイム可視化。等電位線・断面グラフで電磁気学の計算検証に対応。

**Category:** 電磁気学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/electric-field.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/electric-field.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/electric-field.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/electric-field
python -m http.server 8000
# open http://localhost:8000
```
