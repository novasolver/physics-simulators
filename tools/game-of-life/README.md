# コンウェイのライフゲーム — セルオートマトンシミュレーター

コンウェイのライフゲームの無料シミュレーターです。ブラウザで直感的に操作できるセルオートマトンシミュレーターツールで、グライダーやパルサーなどの複雑なパターンを簡単に作成・観察できます。生命の誕生から死滅までのダイナミックな過程をリアルタイムで体験し、単純なルールから生まれる驚くべき秩序を発見しましょう。

**Category:** セルオートマトン・複雑系

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/game-of-life.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/game-of-life.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/game-of-life.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/game-of-life
python -m http.server 8000
# open http://localhost:8000
```
