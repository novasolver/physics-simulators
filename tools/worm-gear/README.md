# ウォームギア効率・自己ロック設計計算機

ウォームギアの効率計算と自己ロック条件の判定が無料でできるオンライン計算機です。リード角と摩擦角を入力するだけで、正転効率・逆転効率を即座に算出。直感的なグラフで効率曲線を確認でき、設計や学習に役立ちます。AGMA標準にも対応した信頼性の高いツールです。

**Category:** 機械力学
