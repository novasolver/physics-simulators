# 海洋構造物・波力・流力計算

海洋構造物の波力・流力計算を解説。モリソン方程式による慣性力・抗力・合力のリアルタイム算出、エアリー波理論に基づく速度場の可視化、転倒モーメントやKC数の自動計算手法を紹介。分散関係式や水平速度の理論式を用いた解析により、抗力支配・慣性力支配の判別も可能です。

**Category:** 流体解析
