# 透水係数計算ツール

透水係数計算ツール：定水頭・変水頭試験のデータからダルシー則で土の透水係数kを算出。土質別典型値比較とリアルタイム表示で地盤解析に活用できます。

**Category:** 地盤工学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/soil-permeability.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/soil-permeability.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/soil-permeability.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/soil-permeability
python -m http.server 8000
# open http://localhost:8000
```
