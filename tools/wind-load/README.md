# 風荷重・風圧計算機（建築基準法・ASCE7）

建築基準法・ASCE7に準拠した風荷重・風圧計算機。基準風速・建物寸法・地形カテゴリから設計風圧・基底せん断力・転倒モーメントを自動算出。風速プロファイル可視化対応。

**Category:** 構造・風工学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/wind-load.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/wind-load.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/wind-load.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/wind-load
python -m http.server 8000
# open http://localhost:8000
```
