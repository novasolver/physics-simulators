# アンテナ放射パターン可視化ツール

アンテナ放射パターン可視化ツール。ダイポール・モノポール・パッチ・八木宇田アンテナの指向性をリアルタイム計算し、HPBW・前後比を自動解析。極座標グラフで可視化。

**Category:** 電磁気学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/antenna-radiation.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/antenna-radiation.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/antenna-radiation.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/antenna-radiation
python -m http.server 8000
# open http://localhost:8000
```
