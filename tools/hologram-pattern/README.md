# ホログラム干渉縞シミュレーター

ホログラム干渉縞シミュレーターで、コヒーレント光の干渉パターンを可視化。レーザー光源の位置や波長を自由に調整し、ヤングの実験やゾーンプレートなど多彩な干渉縞をリアルタイムで生成できます。光学実験の理解を深める無料シミュレーションツールです。

**Category:** 振動・波動

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/hologram-pattern
python -m http.server 8000
# open http://localhost:8000
```
