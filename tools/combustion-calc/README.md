# 燃焼計算機・空燃比・断熱火炎温度

NovaSolverの燃焼計算機は、メタンや水素など様々な燃料の燃焼をオンラインでシミュレーション。空燃比や断熱火炎温度、CO・NOxなどの排出傾向まで、リアルタイムに計算可能です。無料で簡単に燃焼解析が行えるツールです。

**Category:** 化学工学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/combustion-calc.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/combustion-calc.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/combustion-calc.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/combustion-calc
python -m http.server 8000
# open http://localhost:8000
```
