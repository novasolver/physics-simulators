# 液液抽出シミュレーター

水溶液に溶けた溶質を、混じり合わない第2の溶媒へ移しとる「液液抽出」を設計するツールです。供給液濃度・溶媒量・分配係数・段数を変えると、抽出率やラフィネート濃度がリアルタイムで分かり、溶媒を分割するクロスカレント多段抽出が単段よりどれだけ有利かを比較できます。

**Category:** 化学工学
