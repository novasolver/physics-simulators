理論・主要公式

リサジュー曲線（Lissajous figure）は、互いに直交する2つの単振動を合成したときに描かれる平面曲線です。パラメトリック方程式で表すと：

$$x(t) = A_x \sin(f_x\, t), \quad y(t) = A_y \sin(f_y\, t + \delta)$$

ここで \(f_x, f_y\) は各軸の角周波数、\(A_x, A_y\) は振幅、\(\delta\) は位相差です。

曲線が閉じる条件は周波数比が有理数であることです：

$$\frac{f_y}{f_x} = \frac{p}{q} \quad (p, q \text{ は互いに素な自然数})$$

このとき曲線は周期 \(T = 2\pi q / f_x\) で閉じます。X軸境界への接触回数 \(n_x\) と Y軸境界への接触回数 \(n_y\) の比は：

$$\frac{n_x}{n_y} = \frac{f_y}{f_x}$$

特に \(f_x = f_y\) のとき（1:1比）、リサジュー曲線は次の楕円方程式と一致します：

$$\frac{x^2}{A_x^2} - \frac{2xy\cos\delta}{A_x A_y} + \frac{y^2}{A_y^2} = \sin^2\!\delta$$

\(\delta = 0\) または \(\pi\) で直線に退化し、\(\delta = \pi/2\) かつ \(A_x = A_y\) で完全な円になります。

理論メモ — リサジュー曲線の数学

対話で学ぶ — リサジュー曲線

🙋
リサジュー曲線ってきれいな図形だなとは思うんですけど、実際の工学でどう使うんですか？
🎓
一番身近なのはオシロスコープのX-Yモードだね。2つの信号をそれぞれX軸・Y軸に入力すると、リサジュー図形が現れる。その形を見るだけで「2信号の周波数比はいくらか」「位相はどれだけずれているか」が一瞬でわかる。アナログ時代のエンジニアはこれを日常的に使ってたんだ。
🙋
1:1の周波数比で位相差を変えると形が変わりますよね。δ = 0°で直線、90°で円、その中間で楕円になるのはなぜですか？
🎓
δ = 0° は「x と y が完全に同期」してる状態で、x 増えたら y も増える、だから 45° の直線。δ = 90° は「y が x より1/4周期先に行く」状態。実はこのとき x² + y² = A² という円の方程式になるんだ。中間の δ はその中間なので楕円。数式で確認すると \(\frac{x^2}{A^2} - \frac{2xy\cos\delta}{A^2} + \frac{y^2}{A^2} = \sin^2\delta\) という楕円方程式が出てくる。
🙋
1:2の比だと8の字になりますね。シミュレーターで「X軸節点数 = 2、Y軸節点数 = 1」と表示されてますが、これは何ですか？
🎓
曲線が左端・右端の境界に「触れる回数」と「上端・下端に触れる回数」だよ。1:2 の図形をよく見ると、横の壁には2回、縦の壁には1回接触している。この比が \(n_x : n_y = f_y : f_x\) になる、つまり周波数比と逆になるのが面白いポイント。未知の曲線が描かれたとき、節点数を数えれば逆算で周波数比がわかる。
🙋
位相差スイープのタブが面白いです。位相が変わると図形がぐにゅっと変形していくのが見えます。これってδの連続的な変化を一覧にしてる？
🎓
そう。0°から180°まで等間隔に並べた20枚を一度に表示してる。実はδとδ+180°は上下反転の関係だから、0〜180°の半区間を見るだけで全形状が把握できる。オシロスコープで基準信号の位相をゆっくりずらしたとき、画面の図形が「回転」するように見える現象も、これで直感的に理解できるよ。
🙋
回転機械の診断にも使うと聞きましたが、どういう仕組みですか？
🎓
軸受の近くに 90° 方向の変位センサー2本を取り付けて、それぞれの出力を X・Y に入力するんだ。正常な回転軸は（不釣合いがあれば）きれいな楕円を描く。ところがミスアライメントがあると 8 の字になったり、軸のひびが入ると「バナナ形」に崩れたりする。この軌道形状を「オービットプロット」と呼んで、工場の予知保全で現役で使われてる手法だよ。
🙋
3:5みたいに複雑な比だと軌跡がかなりごちゃごちゃに見えますが、それでも理論的には閉じた曲線なんですか？
🎓
適切に閉じる。3:5（既約）なら \(q = 5\) だから \(2\pi \times 5 = 10\pi\) 後に元の点に戻ってくる。複雑に見えるのは閉じるまでに「ストローク」を何度も繰り返すから。逆に \(\sqrt{2} : 1\) みたいな無理数比だと永遠に閉じなくて、十分時間を経たら矩形領域を隙間なく埋め尽くすエルゴード軌道になる。シミュレーターで軌跡を長くして確かめてみよう。

リサジュー曲線シミュレーターとは

本シミュレーターの物理モデルは、互いに直交する二つの単振動の合成に基づく。x軸方向の変位を \( x(t) = A_x \sin(2\pi f_x t + \phi_x) \)、y軸方向の変位を \( y(t) = A_y \sin(2\pi f_y t + \phi_y) \) と定義する。ここで \( A_x, A_y \) は振幅、\( f_x, f_y \) は周波数、\( \phi_x, \phi_y \) は初期位相である。リサジュー図形の形状は主に周波数比 \( f_x : f_y \) と位相差 \( \Delta\phi = \phi_y - \phi_x \) によって決定される。例えば周波数比が有理数 \( p/q \) の場合、軌跡は閉曲線となり、位相差が \( \pi/2 \) のとき楕円や円が現れる。本モデルでは位相差を時間的に連続変化させるスイープ機能により、図形の動的変形を観察可能である。また、周波数比マップでは各整数比に対応する安定な図形を一覧でき、オシロスコープ波形表示と併せて位相空間上の軌道を直感的に理解できる。

実世界での応用

産業での実際の使用例
自動車業界では、エンジンのクランクシャフトやトランスミッションのギア比設計において、リサジュー曲線シミュレーターが振動解析ツールとして活用されています。例えば、トヨタや日産の開発現場では、2軸の振動を合成してギアの噛み合い周波数とエンジン回転数の位相差を可視化し、騒音・振動（NVH）の原因特定に利用。また、電子機器メーカーでは、オシロスコープの校正やスピーカーのコーン振動の位相調整に応用され、製品品質の安定化に寄与しています。

研究・教育での活用
大学の物理学実験や電気電子工学の講義では、リサジュー図形が波動の合成や位相差の概念を直感的に理解する教材として広く採用されています。特に、東京工業大学や東北大学の基礎実験では、本シミュレーターを用いて周波数比と図形形状の関係をリアルタイムで観察し、フーリエ解析や共振現象の学習効率を向上。また、音響工学の研究では、2つの音波の干渉パターンを視覚化し、楽器の調律や音場設計の基礎データとして活用されています。

CAE解析との連携や実務での位置付け
本シミュレーターは、CAE（Computer-Aided Engineering）ツールのプリプロセス段階で、振動モードや位相特性の事前検証に使用されます。例えば、ANSYSやAbaqusによる構造解析の前に、リサジュー曲線を用いて入力波の周波数比や位相差を最適化し、共振回避や減衰設計の初期条件を導出。実務では、設計者が直感的にパラメータを調整できるため、CAE解析の試行錯誤を削減し、製品開発のリードタイム短縮に貢献。特に、MEMSデバイスや精密機械の微振動制御において、シミュレーション結果と実機計測の整合性を高める役割を果たしています。

よくある誤解と注意点

「リサジュー図形は周波数比が整数比の場合のみ閉じる」と思いがちですが、実際には整数比でなくても軌跡は安定したパターンを描くことがあります。ただし、非整数比では図形が完全に閉じず、時間経過とともに位相がずれて描画が重なるため、見かけ上「閉じた図形」に見えない場合が多い点に注意が必要です。

「位相差は図形の形にしか影響しない」と思いがちですが、実際には位相差が0°や180°のとき直線に、90°や270°で真円や楕円になるなど、図形の傾きや開き方に決定的な影響を与えます。特に位相差スイープ機能では、わずかな変化で図形が大きく変形するため、スイープ速度が速すぎると変化の過程を見落としやすい点に注意が必要です。

「周波数比マップに表示される図形はすべて独立したパターン」と思いがちですが、実際には同じ周波数比でも初期位相が異なれば全く別の形状になります。シミュレーター上で表示される図形は特定の位相条件下の一例に過ぎず、位相を変化させると同じ比でも多様なバリエーションが存在することを理解しておく必要があります。

使い方ガイド

  1. fxInput（水平周波数）とfyInput（垂直周波数）に値を入力します。例えばfx=3Hz、fy=2Hzで3:2のリサジュー曲線が生成されます
  2. phaseSlider（位相差）を0°～360°で調整し、2つの正弦波間の時間ズレを設定します。位相差0°では同位相、90°で直交します
  3. axSlider（水平振幅）とaySlider（垂直振幅）で各軸の振幅を0～100の範囲で制御し、曲線の形状と大きさをリアルタイムで変更します

具体的な計算例

オシロスコープのXY測定モードでfx=5kHz、fy=3kHz、位相差=45°、ax=80mV、ay=60mVの信号を入力した場合、5:3のリサジュー曲線が表示されます。位相差45°により楕円は時計回り方向に傾斜し、交点数（周波数比を判定する指標）は水平8点、垂直6点となります。振幅80mVと60mVの比は4:3で、描画範囲内での曲線サイズに反映されます

実務での注意点

  • 周波数比が整数比（1:1、2:3、5:7など）でない場合、曲線は閉じずに軌跡が満たされます。位相ロック検出用途ではfxとfyの比を正確に設定してください
  • 位相差測定では、楕円の長軸と短軸の比から sin(δ)=短軸/長軸で位相差を逆算できます。ただし±90°の判別にはトレース方向の確認が必須です
  • 周波数比が高い場合（例：fx=7Hz、fy=11Hz）は描画フレームレートの影響で若干のエイリアシングが生じる可能性があるため、計測値検証時は理論値と照合してください
