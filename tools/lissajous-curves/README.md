# リサジュー曲線シミュレーター

2つの直交する正弦振動を合成し、美しいリサジュー図形の形成過程をリアルタイムCanvasアニメーションで観察。オシロスコープ波形・位相差スイープ・周波数比マップを搭載。

**Category:** 振動・波動

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/lissajous-curves.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/lissajous-curves.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/lissajous-curves.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/lissajous-curves
python -m http.server 8000
# open http://localhost:8000
```
