# パワーエレクトロニクス変換器計算機

DC-DCコンバータの設計を支援する無料オンライン計算機です。バック、ブースト、バックブースト回路のデューティ比や電流・電圧リプル、動作モード、効率をリアルタイムで計算。波形グラフで視覚的に確認でき、パワーエレクトロニクスの学習や回路設計に最適です。

**Category:** 電磁気・光学
