# 抗力係数・空気抵抗計算機

抗力係数・空気抵抗計算機で、形状・流体条件から抗力FDやレイノルズ数をリアルタイム計算。CFD解析やドラッグ係数CDの検証に必要な流体力学ツール。

**Category:** 航空宇宙

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/drag-coefficient.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/drag-coefficient.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/drag-coefficient.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/drag-coefficient
python -m http.server 8000
# open http://localhost:8000
```
