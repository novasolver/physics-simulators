# AHU 熱バランスシミュレーター

AHU熱バランスシミュレーターで空調機の温度変化・負荷計算・バイパスファクタを解析。コイル性能評価と熱収支確認に必須のCAE工具。

**Category:** 対話型シミュレーター

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/ahu-heat-balance.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/ahu-heat-balance.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/ahu-heat-balance.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/ahu-heat-balance
python -m http.server 8000
# open http://localhost:8000
```
