# ディスクブレーキの温度上昇シミュレーター

ブレーキは車両の運動エネルギーを摩擦熱に変える装置です。車両質量・制動前の速度・ディスク枚数・材質を変えると、1回の制動でディスクがどれだけ熱くなるか、連続制動でブレーキフェードの危険域へ迫るかをリアルタイムで確認できます。

**Category:** 機械設計
