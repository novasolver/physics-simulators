# 三角関数と単位円アニメーション

角度θを動かして、単位円上の点P・sin・cos・tanがどう変化するかをリアルタイムで確認。波形グラフと関数比較タブで「なぜそうなるのか」を直感的に理解できます。

**Category:** 高校数学・三角関数

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/trig-unit-circle-anim.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/trig-unit-circle-anim.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/trig-unit-circle-anim.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/trig-unit-circle-anim
python -m http.server 8000
# open http://localhost:8000
```
