# タイヤ動特性シミュレーター

パチェイカ魔法公式でタイヤの横力-横滑り角特性と摩擦楕円をリアルタイム可視化。B・C・D・E パラメータを調整しながら、コーナリング剛性とグリップ限界への影響を直感的に確認できます。

**Category:** 車両動特性

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/tire-dynamics.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/tire-dynamics.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/tire-dynamics.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/tire-dynamics
python -m http.server 8000
# open http://localhost:8000
```
