# 溶接残留応力シミュレーター

熱入力・継手種類・板厚・材料・拘束条件を変えて残留応力分布・角変形・縦収縮をリアルタイム計算。PWHT（溶接後熱処理）による応力低減効果も確認できます。

**Category:** 溶接・構造解析

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/welding-residual.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/welding-residual.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/welding-residual.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/welding-residual
python -m http.server 8000
# open http://localhost:8000
```
