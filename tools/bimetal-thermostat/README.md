# バイメタルサーモスタット シミュレーター — 二層帯の熱変形

バイメタルサーモスタット シミュレーターは、熱膨張係数の異なる二層帯がティモシェンコの式でどれだけ曲がるかをリアルタイム計算します。温度変化・帯の長さ・厚さ・膨張係数差を変えて、曲率・先端変位・先端角度を可視化し、温度スイッチが動く原理を学べます。

**Category:** 材料・熱工学シミュレーター
