# 波の重ね合わせシミュレーター

波の重ね合わせシミュレーターで2つの正弦波の干渉現象をリアルタイム観察。周波数・振幅・位相を操作してうなりと合成波を可視化。スペクトラム・リサジュー図形対応。

**Category:** 高校物理 / 音響工学

## Live demos

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/wave-superposition
python -m http.server 8000
# open http://localhost:8000
```
