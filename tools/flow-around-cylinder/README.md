# 円柱まわりの流れシミュレーター

ポテンシャル流れ理論に基づいて円柱まわりの流線を可視化。カルマン渦の周波数、マグナス効果による揚力、経験則に基づく抗力をリアルタイム計算します。レイノルズ数が流れの剥離に与える影響を探求できます。

**Category:** 流体力学
