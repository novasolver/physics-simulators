# バイオマスエネルギー変換計算機

バイオマスエネルギー変換計算機でHHV/LHV・燃焼効率・バイオガス収量をリアルタイム計算。木質・農業残渣など多種バイオマスのエネルギー変換性能評価に対応。

**Category:** 環境・エネルギー

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/biomass-energy.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/biomass-energy.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/biomass-energy.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/biomass-energy
python -m http.server 8000
# open http://localhost:8000
```
