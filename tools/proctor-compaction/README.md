# 土の締固め試験（プロクター）シミュレーター

盛土や路盤を確実に固めるための土の締固め試験を扱うツールです。締固めモールド1点の測定値（湿潤質量・容積・含水比・比重）を入力すると、乾燥密度やゼロ空気間隙密度、間隙比・飽和度・空気間隙率がリアルタイムで分かり、プロクター締固め曲線と最適含水比の意味を直感的につかめます。

**Category:** 地盤工学
