# フライバックコンバータ シミュレーター

絶縁型DC-DCの基本トポロジ、フライバックコンバータの出力電圧・出力電流・一次側ピーク電流・境界モードの一次インダクタンス・蓄積エネルギーを計算。入力電圧・デューティ比・巻数比・周波数・出力電力を変えて電源回路を設計できる無料シミュレーターです。

**Category:** 電力工学

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/flyback-converter
python -m http.server 8000
# open http://localhost:8000
```
