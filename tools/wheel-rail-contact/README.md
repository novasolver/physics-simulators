# 車輪・レール接触シミュレーター — 楕円Hertz接触と粘着限界

鉄道車輪とレール頭部の楕円Hertz接触を可視化。輪重・車輪半径・レール頭部曲率・摩擦係数を変えて、接触楕円の寸法と最大接触応力、粘着限界の接線力を学べます。

**Category:** 鉄道工学シミュレーター
