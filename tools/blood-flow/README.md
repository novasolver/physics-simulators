# 血流・血管力学シミュレーター（ポアズイユ流）

血流・血管力学シミュレーター（ポアズイユ流）でハーゲン・ポアズイユ式による血流量・壁面せん断応力を計算。狭窄・粘度変化による動脈硬化リスク評価に対応。

**Category:** 流体解析

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/blood-flow.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/blood-flow.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/blood-flow.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/blood-flow
python -m http.server 8000
# open http://localhost:8000
```
