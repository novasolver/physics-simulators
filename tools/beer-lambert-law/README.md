# ランベルト-ベールの法則シミュレーター

ランベルト-ベールの法則シミュレーターで吸光度・透過率をリアルタイム計算。モル吸光係数・光路長・濃度の関係を可視化。分析化学・分光測定の基礎学習に

**Category:** 分析化学・光学

git clone https://github.com/novasolver/physics-simulators
