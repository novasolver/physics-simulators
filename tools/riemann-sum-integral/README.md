# リーマン和・数値積分シミュレーター

リーマン和と数値積分の5つの手法（左端・右端・中点・台形・シンプソン則）を視覚的に比較するシミュレーター。分割数による誤差収束を直感的に理解できるCAE学習ツール。

**Category:** 数学・微積分

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/riemann-sum-integral.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/riemann-sum-integral.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/riemann-sum-integral.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/riemann-sum-integral
python -m http.server 8000
# open http://localhost:8000
```
