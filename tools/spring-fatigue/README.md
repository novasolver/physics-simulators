# コイルばね疲労設計計算ツール

コイルばね疲労設計計算ツール：Wahl補正係数とねじり応力をリアルタイム計算し、修正Goodman線図で疲労安全率を視覚化。ばね設計の疲労余裕確認に。

**Category:** 構造・疲労解析

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/spring-fatigue.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/spring-fatigue.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/spring-fatigue.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/spring-fatigue
python -m http.server 8000
# open http://localhost:8000
```
