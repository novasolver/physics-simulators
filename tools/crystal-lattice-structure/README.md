# 結晶格子構造ビジュアライザ

結晶格子構造ビジュアライザでSC・BCC・FCC・HCPの3D構造を可視化。充填率・配位数・格子定数をリアルタイムで探索し、結晶学習や材料設計に活用できます。

**Category:** 材料科学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/crystal-lattice-structure.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/crystal-lattice-structure.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/crystal-lattice-structure.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/crystal-lattice-structure
python -m http.server 8000
# open http://localhost:8000
```
