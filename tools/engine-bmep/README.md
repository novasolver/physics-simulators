# 正味平均有効圧力（BMEP）シミュレーター

エンジンの出力・回転数・総排気量を変えると、正味平均有効圧力（BMEP）・ブレーキトルク・比出力がリアルタイムで分かります。排気量がまったく違うエンジンを同じ土俵に並べ、過給度や設計の作り込みレベルを評価できます。

**Category:** 自動車工学
