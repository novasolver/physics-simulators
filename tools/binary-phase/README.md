# 二元系状態図・レバー則計算機

二元系状態図・レバー則計算機は、等晶系・共晶系・包晶系の状態図をリアルタイムに描画し、任意の温度・組成でのレバー則による相分率と平衡組成を自動計算します。二相共存領域の計算や、シャイル方程式を用いた非平衡凝固による偏析（後退偏析など）の理解を支援するCAE学習ツールです。

**Category:** 材料・破壊
