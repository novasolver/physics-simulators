# 飛行船 ヘリウム浮力シミュレーター

Zeppelin リジッド飛行船・Goodyear ブリンプ・成層圏 HAPS など、ヘリウムを使う軽空気機（LTA）の浮力と有効ペイロードを ISA 大気モデルで計算します。ガス容量・高度・純度・外皮質量を変えて、上昇余裕と運用限界を可視化します。

**Category:** 航空・LTA 軽空気機

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/earth-airship-buoyancy-helium.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/earth-airship-buoyancy-helium
python -m http.server 8000
# open http://localhost:8000
```
