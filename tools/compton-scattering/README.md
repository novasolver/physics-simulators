# コンプトン散乱 シミュレーター — 光子-電子散乱の波長シフト

コンプトン散乱シミュレーターは、入射光子エネルギー・散乱角・標的質量から散乱光子のエネルギー、波長シフト Δλ、反跳電子の運動エネルギーと散乱角をリアルタイム計算します。Δλ(θ) 曲線と散乱幾何模式図で量子的な光子-電子衝突を直感的に理解できます。

**Category:** 素粒子・量子物理シミュレーター
