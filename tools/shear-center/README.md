# せん断中心計算ツール

せん断中心計算ツール：チャンネル・Z形・T形・L形・I形断面のせん断中心位置をリアルタイム計算。せん断流れとねじり挙動を可視化し、構造解析に必要な断面特性を即座に把握。

**Category:** 構造解析ツール

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/shear-center.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/shear-center.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/shear-center.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/shear-center
python -m http.server 8000
# open http://localhost:8000
```
