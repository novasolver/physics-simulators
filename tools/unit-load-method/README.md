# 単位荷重法シミュレーター — 片持梁のたわみと回転角

単位荷重法シミュレーターで片持梁のたわみと回転角を可視化。モール積分による仮想仕事の原理を使用した変位計算を体感できます。曲げ剛性・荷重条件を変更して構造解析を学習。

**Category:** 構造力学シミュレーター

git clone https://github.com/novasolver/physics-simulators
