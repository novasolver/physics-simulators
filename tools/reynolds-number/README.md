# Reynolds数計算機・流れ場マップ

NovaSolverの無料オンライン「レイノルズ数計算機」で、配管設計を最適化。給水配管（内径25mm）を水（20°C）が流れる際のレイノルズ数を即座に計算。乱流時の圧力損失と熱伝達促進のトレードオフを考慮した、効率的な設計判断をサポートします。

**Category:** 流体解析

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/reynolds-number
python -m http.server 8000
# open http://localhost:8000
```
