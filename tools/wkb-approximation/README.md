# WKB近似シミュレーター — 量子トンネル確率

古典的には越えられないポテンシャル障壁を、粒子が量子的にすり抜ける「トンネル効果」を体験するツールです。粒子のエネルギー・障壁の高さと幅・質量を変えると、WKB近似による透過確率 T と障壁内部の減衰定数 κ がリアルタイムで分かります。

**Category:** 量子力学
