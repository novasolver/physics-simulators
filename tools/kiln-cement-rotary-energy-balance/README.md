# セメント ロータリーキルン 熱物質収支シミュレーター

セメント ロータリーキルンの比熱消費量・燃料消費・CO2 排出（燃料起源とプロセス起源）をリアルタイムに計算。NSP/SP/湿式の3形式、石炭・石油コークス・天然ガス・RDF・バイオマスを切替え、年間 CO2 排出量まで一気に試算できる無料エンジニアリングシミュレーターです。

**Category:** セメント工業・キルン
