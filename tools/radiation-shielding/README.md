# 放射線遮蔽計算機（半価層・十価層）

Beer-Lambert則でガンマ線の透過強度・線量率・半価層（HVL）・十価層（TVL）をリアルタイム計算。鉛・コンクリート・水・鉄・ポリエチレンの材料データ内蔵。

**Category:** 熱解析
