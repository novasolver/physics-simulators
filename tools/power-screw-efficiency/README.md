# 送りねじ（パワースクリュー）の効率シミュレーター

回転運動を強力な直線推力へ変える送りねじ（パワースクリュー）を設計するツールです。呼び径・ピッチ・条数・軸方向荷重・摩擦係数を変えると、リード角・引上げトルク・効率・セルフロック判定がリアルタイムで分かります。

**Category:** 機械要素設計
