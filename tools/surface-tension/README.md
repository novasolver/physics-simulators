# 表面張力・毛細管現象計算ツール

表面張力・管半径・接触角から毛細管上昇高さ、Laplace 圧、Bond 数をリアルタイム計算。液滴の接触角変化を Canvas 描画でアニメーションし、水・エタノール・水銀・液体金属の挙動の違いまで一画面で確認できます。

**Category:** 流体力学・界面化学
