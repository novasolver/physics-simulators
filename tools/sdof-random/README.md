# ランダム振動解析シミュレーター（PSD入力）

1自由度系（SDOF）のランダム振動応答を数値計算。PSD入力から応答スペクトルと応答RMS・3σ値をリアルタイム算出。宇宙・航空・車載振動試験の設計に活用できます。

**Category:** 計算ツール

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/sdof-random.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/sdof-random.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/sdof-random.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/sdof-random
python -m http.server 8000
# open http://localhost:8000
```
