# 引張試験・応力ひずみ曲線シミュレーター

引張試験・応力ひずみ曲線シミュレーター。工学応力と真応力を同時表示し、降伏強度・UTS・延性を材料ごとに検証。機械設計・材料選定に。

**Category:** 材料・破壊

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/tensile-test.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/tensile-test.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/tensile-test.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/tensile-test
python -m http.server 8000
# open http://localhost:8000
```
