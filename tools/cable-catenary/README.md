# 懸垂線（カテナリー）計算機

懸垂線（カテナリー）計算機で、ケーブルやワイヤーの張力・たわみ・弧長を簡単に解析。送電線、橋梁、ロープウェイなどの設計に役立つ、温度変化を考慮した高精度なシミュレーションツールです。無料で今すぐ計算を始めましょう。

**Category:** 構造解析

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/cable-catenary.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/cable-catenary.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/cable-catenary
python -m http.server 8000
# open http://localhost:8000
```
