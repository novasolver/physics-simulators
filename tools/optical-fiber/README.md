# 光ファイバーリンク損失・帯域幅計算ツール

光ファイバーリンクの損失・受信電力・帯域幅をリアルタイム計算。SMF-28（1550nm）・OM3マルチモード（850nm）に対応。ファイバー長・スプライス・コネクタ損失を入力してリンクパワーマージンと最大伝送距離を算出。

**Category:** 光通信ツール
