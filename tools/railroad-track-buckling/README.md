# 鉄道 CWR 線路 太陽座屈シミュレーター

鉄道のロングレール（CWR：Continuous Welded Rail）に夏期高温時に生じる温度応力と太陽座屈（sun kink）をシミュレーション。レール温度・中立温度・道床抵抗・曲率半径から圧縮力・座屈臨界力・安全率・最大許容温度を計算する無料ツール。

**Category:** 鉄道工学・軌道設計
