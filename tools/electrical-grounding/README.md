# 接地抵抗計算（IEEE 80・Wenner法）

大地抵抗率・電極形状・本数から接地抵抗・接触電圧・歩幅電圧・対地電位上昇（GPR）を算出。IEEE 80安全基準チェック機能付きの実務向け接地設計ツール。

**Category:** 電磁気
