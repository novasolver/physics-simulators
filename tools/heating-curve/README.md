# 加熱曲線シミュレーター

物質に熱を加え続けたときの温度変化をリアルタイムで可視化。固体→液体→気体の相変化で温度が止まる『潜熱のプラトー』を水・エタノール・鉄・液体窒素・アルミ・銅で比較できます。

**Category:** 熱力学・相変化

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/heating-curve.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/heating-curve.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/heating-curve
python -m http.server 8000
# open http://localhost:8000
```
