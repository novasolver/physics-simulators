# RLC回路共振シミュレーター

RLC回路共振シミュレーターで、直列・並列回路の動作を視覚的に理解。インピーダンスやQ値、帯域幅をリアルタイムに解析し、共振周波数での特性を簡単にシミュレーション。AMラジオ同調などの実用例で学べる、教育・設計に最適なインタラクティブツールです。

**Category:** 電気回路・共振

python -m http.server 8000
