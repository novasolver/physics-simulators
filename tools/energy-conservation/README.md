# エネルギー保存則・力学的エネルギーシミュレーター

エネルギー保存則を直感的に学べる無料オンラインシミュレーターです。ローラーコースターのようなトラック上で物体を動かし、位置エネルギーと運動エネルギーの移り変わりをリアルタイムで可視化。摩擦の影響もグラフで確認でき、力学の理解を深められます。NovaSolverで物理を楽しく学びましょう。

**Category:** 物理シミュレーター

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/energy-conservation
python -m http.server 8000
# open http://localhost:8000
```
