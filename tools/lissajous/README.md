# リサージュ図形・振動合成

2つの正弦波振動を合成してリサージュ図形をブラウザ上でリアルタイム描画。周波数比・振幅・位相差をスライダーで調整し、開曲線/閉曲線の判定、X・Y側面投影、位相スイープまでをワンクリックで観察できる無料CAE学習シミュレータです。

**Category:** 振動解析

git clone https://github.com/novasolver/physics-simulators

python -m http.server 8000
