# 太陽系シミュレーター — 惑星の公転と宇宙スケール

太陽系シミュレーターで8惑星の実際の公転周期・軌道データをリアルタイム表示。ケプラーの法則と宇宙スケールを直感的に学習でき、天体物理シミュレーション・軌道計算の基礎理解に最適。

**Category:** 天体物理・宇宙

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/solar-system
python -m http.server 8000
# open http://localhost:8000
```
