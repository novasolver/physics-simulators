# ヒステリシス損失・磁気回路設計ツール

NovaSolverの無料オンライン計算機で、ヒステリシス損失を考慮した磁気回路設計を効率化。トロイダルコアやEコア、ソレノイドの磁束・磁束密度・インダクタンスをリアルタイム計算。フリンジング補正やRogowski因子も自動考慮する高精度シミュレーターで、開発時間を短縮できます。

**Category:** 解析ツール

python -m http.server 8000
