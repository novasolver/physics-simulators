# 水処理・浄水計算ツール

NovaSolverの水処理・浄水計算ツールは、凝集沈殿、砂ろ過、塩素消毒のプロセスをシミュレーション。濁度除去率や薬品注入量、CT値の計算をリアルタイムでグラフ表示し、ジアルジア不活化率も確認できる無料Webツールです。浄水場設計の初期検討や学習に最適です。

**Category:** 環境工学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/water-treatment.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/water-treatment.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/water-treatment.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/water-treatment
python -m http.server 8000
# open http://localhost:8000
```
