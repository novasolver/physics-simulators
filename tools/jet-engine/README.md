# ジェットエンジン性能計算ツール

ジェットエンジン性能計算ツール「NovaSolver」で、ブレイトンサイクルの熱効率や比推力、TSFCを簡単シミュレーション。圧縮比・燃焼温度・バイパス比を入力するだけで、T-s線図と主要性能をリアルタイム計算。ターボジェット・ターボファンエンジンの設計解析や航空宇宙工学学習に最適なシミュレーターです。

**Category:** 航空宇宙工学

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/jet-engine
python -m http.server 8000
# open http://localhost:8000
```
