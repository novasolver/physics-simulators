理論・主要公式
$$v_1' = \frac{(m_1 - e m_2)v_1 + (1+e)m_2 v_2}{m_1 + m_2}$$ $$v_2' = \frac{(m_2 - e m_1)v_2 + (1+e)m_1 v_1}{m_1 + m_2}$$

$e=1$：完全弾性（KE保存），$e=0$：完全非弾性（くっついて一体化）

運動量保存：$m_1 v_1 + m_2 v_2 = m_1 v_1' + m_2 v_2'$（常に成立）

1次元衝突（弾性・非弾性）とは

🙋
「はね返り係数」って何ですか？教科書で「e」って見たけど、実際の衝突でどう決まるんですか？
🎓
大まかに言うと、衝突の「跳ね返り具合」を0から1の数字で表したものだよ。e=1はボールが床に完全に跳ね返るような理想的な衝突（弾性衝突）。e=0は粘土同士がぶつかってくっついてしまう衝突（完全非弾性衝突）だ。実務では、自動車のバンパー衝突や部品の落下試験で、材料の組み合わせごとに実験で決めた値を使うことが多いね。このシミュレーターの上のスライダーでeを0から1に動かしてみると、衝突後の速度がどう変わるか一目瞭然だよ。
🙋
え、そうなんですか！じゃあ、eが1の時だけエネルギーが保存されるということ？でも、運動量はいつも保存されるんですか？
🎓
その通り！運動量保存則は、外力が働かない限り、eの値に関係なく常に成り立つ、衝突の大原則なんだ。一方で運動エネルギーは、e=1の完全弾性衝突の時だけ保存される。eが1より小さいと、その分のエネルギーが熱や音、変形のエネルギーに変わって失われる（非弾性衝突）。シミュレーターで質量と速度を同じにして、eだけを1と0.5で比べてみて。グラフで運動エネルギーの減り方が大きく異なるのがわかるよ。
🙋
CAEソフト（LS-DYNAとか）でもこの「e」を設定するんですか？現場ではどんな風に使われてるんですか？
🎓
もちろん！LS-DYNAの接触（contact）定義で「はね返り係数」は特に重要なパラメータなんだ。例えば、自動車がコンクリート壁に衝突するシミュレーションでは、eを小さく（0.05とか）設定してエネルギーを大きく吸収させる。逆に、ボールが跳ね返るアニメーションではeを0.8とか1に近い値にする。このツールで色々なeを試す感覚が、そのままCAEのパラメータ設定の感覚に直結するんだ。

よくある質問

はい、可能です。速度の符号は向きを表し、正の値を右方向、負の値を左方向として扱います。質量に負の値を入力すると物理的に意味をなしませんが、計算自体は行われます。現実的なシミュレーションには正の質量を推奨します。
はね返り係数が0.5の場合、衝突後に運動エネルギーの一部が失われます。完全弾性衝突（e=1）と比較して、失われたエネルギーは主に熱や変形に変換されます。画面上部のエネルギー表示で、衝突前後の数値変化を確認できます。
シミュレーション速度を調整するスライダー（通常は画面下部）を「低速」側にドラッグしてください。また、衝突後に「リセット」ボタンを押さずに、速度や質量を変更して再度「実行」すると、同じ条件で繰り返し再生できます。
e=0の場合、衝突後は2つの物体が同じ速度で移動します。この共通速度は運動量保存則から計算され、式は v' = (m1*v1 + m2*v2) / (m1+m2) となります。シミュレーターでは、一体化した物体が1つのブロックとしてアニメーション表示されます。

実世界での応用

自動車衝突安全解析：LS-DYNAなどの衝突解析では、車体と障害物（壁、歩行者ダミー）間の接触にはね返り係数を設定します。eを小さく設定することで、現実の車体のつぶれ（塑性変形）によるエネルギー吸収をモデル化し、衝撃力を評価します。

スポーツ工学：ゴルフボールやテニスボールの反発性の設計、ラケットとボールの衝突シミュレーションに利用されます。素材や空気圧を変えることで反発係数eが変化し、飛距離や打球感が決まります。

ロボット・メカトロニクス：ピッキングロボットの把持動作や、部品がコンベアで輸送中にぶつかる際の挙動予測に使われます。物体が跳ねない（e≈0）ように設定することで、安定した制御を実現します。

破砕・粉体シミュレーション：SPH法やDEM法を用いて、岩石の破砕や穀物の流動をシミュレーションする際、粒子同士の衝突パラメータとしてはね返り係数が必須です。材料の脆さや摩擦を表現するために調整されます。

よくある誤解と注意点

まず、「はね返り係数eは材料固有の定数」と思い込むこと。実は、衝突速度や物体の形状、温度によっても変わるんだ。例えば、同じゴムボールでも、猛烈な速さで壁にぶつかると（高速衝突）、内部で発熱が大きくなってeは低下する。シミュレーターでは固定値だけど、実務では「この速度範囲ではこのe」と条件付きで使うことが多いよ。

次に、「1次元だから簡単」と油断すること。このツールはあくまで「質点」の衝突を扱っている。現実の部品にはサイズと形があるから、衝突の瞬間に回転が生じたり、接触点が変わったりする。例えば、長い棒が端から衝突すると、並進運動と回転運動がカップルして、1次元の式だけでは予測できない動きになる。まずは質点モデルで感覚を掴み、その限界も理解するのがステップアップのコツだ。

最後に、CAE設定での落とし穴。LS-DYNAなどで接触条件にeを設定する時、「どのペアに設定するか」を間違えないこと。部品Aと部品Bの接触、部品Bと部品Cの接触…と、全ての接触ペアに対して適切なeを割り当てる必要がある。デフォルト値（例えば0.1）を全てに適用すると、現実とかけ離れた跳ね返り方になるから要注意だ。このシミュレーターで「2物体間」のeの影響を体感しておくと、CAEでの設定イメージが湧きやすい。

使い方ガイド

  1. 物体1の質量(m1)と速度(v1)を入力します。例：鋼球2kg、初速5m/s
  2. 物体2の質量(m2)と速度(v2)を設定します。例：固定壁の場合はm2を∞またはv2=0に設定
  3. はね返り係数e(0～1)を選択：e=1.0で完全弾性衝突、e=0で完全非弾性衝突
  4. 「シミュレート」ボタンを押すと、衝突後の速度v₁'とv₂'、運動量変化Δp、エネルギー損失が自動計算されます
  5. アニメーション表示で衝突プロセスを可視化し、LS-DYNAのCONTACT_SURFACESパラメータ調整の参考にします

具体的な計算例

アルミ製品(m1=1.5kg, v1=6m/s)が鋼製障壁に衝突する場合：m2=100kg(障壁), v2=0m/s, e=0.6を設定すると、衝突後v₁'=-2.4m/s（跳ね返り）、v₂'=0.18m/s、運動量変化Δp₁=-12.6N·s、エネルギー損失=13.5J、KE保存率=62%と算出されます。弾性衝突(e=1.0)ではエネルギー損失0Jで保存率100%となります。

実務での注意点

  • 現実のゴム・プラスチック衝突ではe=0.4～0.7の範囲；素材密度と硬度で値が変動するため材料試験データを参照してください
  • 高速衝突(v>10m/s)ではひずみ率効果でeが速度に依存し、このシミュレータの定定数仮定が成立しなくなるため検証が必要です
  • 衝突時間が短いため接触力の立ち上がり時間(接触アルゴリズムのDTCYCL)をLS-DYNAで適切に設定し、剛体仮定の妥当性を確認してください
