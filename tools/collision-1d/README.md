# 1次元衝突シミュレーター（弾性・非弾性）

NovaSolverの無料オンライン「1次元衝突シミュレーター」で、弾性衝突や非弾性衝突をアニメーションで可視化。質量と速度、はね返り係数を設定するだけで、衝突後の速度や運動量、エネルギーの変化を即座に計算します。LS-DYNAのパラメータ設定の理解にも役立つ直感的な学習ツールです。

**Category:** 機械力学

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/collision-1d
python -m http.server 8000
# open http://localhost:8000
```
