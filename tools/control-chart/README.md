# 管理図（X-bar・R図・p図・c図）SPCシミュレーター

管理図（X-bar・R図・p図・c図）のSPCシミュレーター。UCL/LCL自動算出、Western Electric判定、Cp/Cpk算出で工程管理を実現。品質管理・統計的プロセス管理ツール。

**Category:** 制御工学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/control-chart.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/control-chart.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/control-chart.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/control-chart
python -m http.server 8000
# open http://localhost:8000
```
