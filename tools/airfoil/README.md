# 翼型（NACA 4桁）シミュレーター

NACA 4桁翼型の形状を生成し、揚力係数・抗力係数・揚力曲線をリアルタイム計算。薄翼理論による揚力・失速特性を可視化。翼型設計の基礎を学習。

**Category:** 空気力学・航空工学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/airfoil.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/airfoil.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/airfoil.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/airfoil
python -m http.server 8000
# open http://localhost:8000
```
