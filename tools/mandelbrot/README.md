# マンデルブロ集合エクスプローラー — フラクタル幾何学

クリックでズーム、ドラッグでパン。マンデルブロ集合の無限に続く自己相似構造をリアルタイムで探索。ジュリア集合モードでは対応するジュリア集合をマウスで操作できる。

**Category:** フラクタル・複雑系数学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/mandelbrot.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/mandelbrot.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/mandelbrot.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/mandelbrot
python -m http.server 8000
# open http://localhost:8000
```
