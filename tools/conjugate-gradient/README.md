# 共役勾配法シミュレーター — CG 法と最急降下法の収束比較

共役勾配法シミュレーターで対称正定値行列の線形方程式を解く。CG法と最急降下法の収束性を比較し、反復法の効率を実験的に学習。数値解析、大規模連立方程式。

**Category:** 数値線形代数シミュレーター
