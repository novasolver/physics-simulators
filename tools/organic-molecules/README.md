# 有機分子構造ビューアー

主要な有機分子の構造式・官能基・沸点・溶解度を一覧で確認。3D風表示で構造と性質の関係を視覚的に比較できる有機化学シミュレーターです。

**Category:** 有機化学・高校・大学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/organic-molecules.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/organic-molecules.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/organic-molecules.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/organic-molecules
python -m http.server 8000
# open http://localhost:8000
```
