# 地震波到達時刻シミュレーター

地震波到達時刻シミュレーターで、P波・S波の速度差から震源距離を推定。大森公式と緊急地震速報の仕組みを視覚的に理解できるツール。地震波シミュレーション。

**Category:** 地球科学・地震工学

git clone https://github.com/novasolver/physics-simulators
