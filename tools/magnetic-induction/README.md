# 電磁誘導シミュレーター

電磁誘導シミュレーターでファラデーの法則を視覚的に理解。コイル巻数や磁束密度を操作し、誘導起電力(EMF)と磁束の位相差をリアルタイムに可視化。最大EMFや実効値も即時計算できる物理学習ツールです。

**Category:** 電磁気シミュレーター

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/magnetic-induction
python -m http.server 8000
# open http://localhost:8000
```
