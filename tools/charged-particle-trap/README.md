# 荷電粒子トラップシミュレーター（ポールトラップ）

NovaSolverの荷電粒子トラップシミュレーターで、ポールトラップの原理をリアルタイムに可視化。電圧や周波数を調整し、荷電粒子の捕捉・脱出の動きを体験しながら、イオントラップや質量分析の基礎を学べます。直感的な操作で科学技術を理解できる学習ツールです。

**Category:** 電磁気・プラズマシミュレーター

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/charged-particle-trap
python -m http.server 8000
# open http://localhost:8000
```
