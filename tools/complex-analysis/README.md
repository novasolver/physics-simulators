# 複素関数・等角写像可視化ツール

複素関数と等角写像を可視化。ドメインカラーリングでジュコーフスキー変換や留数計算をリアルタイム探索できるCAEツール。複素解析・流体力学解析に対応。

**Category:** 数理・統計

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/complex-analysis.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/complex-analysis.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/complex-analysis.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/complex-analysis
python -m http.server 8000
# open http://localhost:8000
```
