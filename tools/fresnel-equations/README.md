# フレネル反射式 シミュレーター — 偏光別反射率とブリュースター角

屈折率 n₁・n₂、入射角 θ、s 偏光比率 β から、s 偏光反射率 R_s・p 偏光反射率 R_p・非偏光反射率・ブリュースター角を実時間に計算します。入射光・反射光・屈折光の幾何模式図と、入射角に対する反射率曲線を可視化します。

**Category:** 光学シミュレーター
