# 渦形成シミュレーター

クリック/ドラッグで流体を撹拌して渦構造を生成。ランキン渦モデルによる速度場計算と粒子トレーサー可視化。カルマン渦列・渦対プリセット搭載。

**Category:** 流体解析

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/vortex-formation.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/vortex-formation.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/vortex-formation.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/vortex-formation
python -m http.server 8000
# open http://localhost:8000
```
