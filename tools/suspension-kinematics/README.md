# サスペンション運動学シミュレーター

サスペンション運動学シミュレーターでダブルウィッシュボーン・マクファーソンストラットのジオメトリをリアルタイム解析。キャンバー角・ロールセンター・トレッド変化を可視化します。

**Category:** 自動車工学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/suspension-kinematics.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/suspension-kinematics.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/suspension-kinematics.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/suspension-kinematics
python -m http.server 8000
# open http://localhost:8000
```
