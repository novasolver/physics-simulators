# コンデンサの充放電シミュレーター

コンデンサの充放電をRC回路で学べるシミュレーター。時定数τ=RCを理解し、電圧変化をリアルタイムに可視化。カメラフラッシュや心臓除細動器など実用例のプリセットで、理論を応用まで体験できます。直感的な操作で電子回路の基礎が身に付く教育ツールです。

**Category:** 電気回路シミュレーター
