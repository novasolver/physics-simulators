# アレニウス式・反応速度計算ツール

アレニウス式・反応速度計算ツール。活性化エネルギーと頻度因子から温度依存性・アレニウスプロット・Q10値をリアルタイム可視化。反応速度論の解析に。

**Category:** 化学・反応速度論

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/reaction-rate-arrhenius.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/reaction-rate-arrhenius.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/reaction-rate-arrhenius.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/reaction-rate-arrhenius
python -m http.server 8000
# open http://localhost:8000
```
