# 舞台照明 LED ルーメン・色温度シミュレーター

PAR・ムービングヘッド・エリプソイダル等の舞台 LED 灯具を選び、消費電力・ビーム角・投光距離・灯数を変えると、1 灯あたりの光束、舞台中央のビーム強度（光度）、投光面の照度、舞台全体の平均照度がリアルタイムで分かります。会場サイズと必要照度から「あと何灯必要か」を即座に見積もるためのツールです。

**Category:** ステージ・LED 照明
