# 風圧力・風荷重計算機

設計風速・露出区分・建物形状から高さ方向の風圧力分布をリアルタイム計算。底部せん断力と転倒モーメントを可視化し、構造設計の初期検討に活用できます。

**Category:** 建築構造・流体

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/wind-pressure.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/wind-pressure.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/wind-pressure.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/wind-pressure
python -m http.server 8000
# open http://localhost:8000
```
