# クランクスライダー機構シミュレーター

クランクスライダー機構のピストン運動をリアルタイムシミュレーション。位置・速度・加速度の波形を可視化し、内燃機関設計に活用できます。機械力学 シミュレーター

**Category:** 機構解析シミュレーター

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/crank-slider.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/crank-slider.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/crank-slider.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/crank-slider
python -m http.server 8000
# open http://localhost:8000
```
