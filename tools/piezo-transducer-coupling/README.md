# 圧電トランスデューサ結合係数 k シミュレーター

圧電トランスデューサ（超音波・センサー・アクチュエータ）の機電結合係数 k を共振周波数 f_r と反共振周波数 f_a から IEEE 176 規格で算出。厚み振動・長さ振動・半径振動モードに対応し、最大出力・変換効率・帯域幅も同時計算できる無料シミュレーターです。

**Category:** 電気音響・センサー
