# 転がり接触疲労・ピッティング強度計算機

ヘルツ接触理論で接触圧力・最大せん断応力・疲労寿命 L10 をリアルタイム計算。軸受や歯車のピッティング設計を直感的に理解できるCAEツール。

**Category:** 接触疲労解析

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/rolling-contact-fatigue.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/rolling-contact-fatigue.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/rolling-contact-fatigue.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/rolling-contact-fatigue
python -m http.server 8000
# open http://localhost:8000
```
