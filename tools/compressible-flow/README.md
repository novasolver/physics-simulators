# 圧縮性流れ・マッハ数関係式計算機

圧縮性流れのオンライン計算機で、マッハ数や比熱比を入力するだけで、等エントロピー流れや衝撃波の状態変化をリアルタイムに計算・可視化。ノバソルバーの無料ツールで、圧縮性流体力学の学習や設計検討をサポートします。

**Category:** 流体解析

```bash
git clone https://github.com/novasolver/physics-simulators

python -m http.server 8000

```
