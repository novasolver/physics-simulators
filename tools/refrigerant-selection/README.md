# 冷媒選定・環境特性比較ツール

20種類の冷媒（R-22、R-410A、R-32、R-1234yf、CO2、アンモニア等）のGWP・ODP・安全クラス・沸点を比較。EU F-Gas規制・EPA SNAP適合チェック、COP比較、R-22/R-134a/R-404A代替経路表示。

**Category:** 熱解析
