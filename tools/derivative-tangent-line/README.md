# 微分・接線ビジュアライザー

関数を選んで接点をスライダーで動かすと、接線の傾き（微分係数）・二階微分・凹凸がリアルタイムで更新。「極限としての微分」を動的に体験しながら微積分の直感を養う。

**Category:** 解析学・微積分

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/derivative-tangent-line.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/derivative-tangent-line.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/derivative-tangent-line.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/derivative-tangent-line
python -m http.server 8000
# open http://localhost:8000
```
