# チョーク流れ シミュレーター — 収束ノズルの臨界条件と質量流量

収束ノズルや絞り部で流れが音速に達する「チョーク」現象を可視化。全圧・全温度・喉部面積・背圧を調整して、臨界圧力比・最大質量流量・喉部音速がどう変わるかを直感的に学べます。

**Category:** 圧縮性流体シミュレーター

python -m http.server 8000
