# アッターベルグ限界と塑性指数シミュレーター

細粒土（粘土・シルト）が固体・半固体・塑性・液体の各状態を行き来する境界含水比を扱うツールです。液性限界・塑性限界・自然含水比を変えると、塑性指数・液性指数とカサグランデ塑性図上の土の分類がリアルタイムで分かります。

**Category:** 地盤工学
