# すみ肉溶接・溶接継手強度計算

AWS D1.1 / ISO 5817 / JIS規格対応。脚長・溶接長・荷重からのど厚・応力・安全率をリアルタイム算出。溶接断面の可視化とChart.jsによる応力グラフ付き。

**Category:** 構造解析

```bash
git clone https://github.com/novasolver/physics-simulators

python -m http.server 8000
# open http://localhost:8000
```
