# すべり軸受のゾンマーフェルト数シミュレーター

回転する軸を油膜で支える流体潤滑のすべり軸受（ジャーナル軸受）を設計するツールです。軸径・軸受長さ・すきま・回転数・油の粘度・荷重を変えると、ゾンマーフェルト数と軸受圧力、油膜が成立するかどうかの判定がリアルタイムで分かります。

**Category:** 機械要素設計
