# アーチ構造・推力線・反力計算

アーチ構造・推力線・反力計算：3ヒンジアーチの水平推力・反力を解析解で計算し推力線をリアルタイム描画。断面力分布の可視化ツール。

**Category:** 構造解析

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/arch-structure.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/arch-structure.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/arch-structure.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/arch-structure
python -m http.server 8000
# open http://localhost:8000
```
