理論・主要公式

3ヒンジアーチ（等分布荷重）：

$$H = \frac{wL^2}{8f}$$ $$V_A = V_B = \frac{wL}{2}$$

推力線の縦距：

$$y_{TL}(x) = \frac{M_0(x)}{H}$$

アーチ構造・推力線・反力計算とは

🙋
アーチって、橋や教会の屋根で見るあの形ですよね。どうしてあんな形をしているんですか？
🎓
その通り！大まかに言うと、アーチは「圧縮力」だけで荷重を支える天才的な形なんだ。真っ直ぐな梁だと下にたわんで曲げモーメントが発生するけど、アーチはその力を両端に押し出す「水平推力」に変える。このシミュレーターで「形状」を半円から放物線に変えてみると、荷重の伝わり方が大きく異なるのがわかるよ。
🙋
「推力線」って何ですか？画面に描かれる赤い線のことですか？
🎓
そう、あの赤い線だ。推力線は、アーチの各断面を通過する圧縮合力の作用点を結んだ線なんだ。実務では、この線がアーチの断面内、特に中心付近（核）を通っているかが特に重要。例えば石積みのアーチ橋だと、推力線が石の外にはみ出ると、その部分が引張力を受けて崩壊してしまうんだよ。「荷重種別」を集中荷重に変えて、荷重位置をスライダーで動かすと、推力線が大きく変形する様子が観察できる。
🙋
え、そうなんですか！じゃあ、このツールで計算してる「水平推力H」が大きすぎると、両端の支えが押し出されてしまうということですか？
🎓
鋭いね！まさにその通り。水平推力Hはアーチが安定するために絶対必要な力だけど、これを支える頑丈な橋台や地盤が必要になる。例えば、ライズfを小さく（アーチを浅く）すると、Hは非常に大きくなるんだ。上のパラメータで「ライズ f」を小さくしてみて。反力のHが急激に増えるのがわかるでしょ？歴史的な石橋は、この巨大な推力に耐えるために両岸を大きく石積みしているんだ。

よくある質問

現状は等分布荷重のみ対応しています。集中荷重が作用する場合、頂点ヒンジの曲げモーメントゼロ条件から水平推力Hを解析的に求める必要があり、別途計算式が必要です。今後のアップデートで対応予定です。
推力線とアーチ形状のずれは、その位置に曲げモーメントが生じていることを意味します。ずれが大きいほど断面力が増大するため、設計上は推力線がアーチ内に収まるよう形状を調整することが理想的です。
水平推力Hはライズfに反比例するため、ライズを小さくすると推力が急増します。これにより支点やアーチ部材に大きな水平力が作用し、基礎や部材の設計が厳しくなるため、実用的な範囲（スパンの1/10〜1/5程度）を推奨します。
VA、VBは支点に作用する鉛直反力です。これらを基に基礎の設計やアーチリブの断面算定に使用できます。また、水平推力Hと合わせて支点の合力を求め、滑動や転倒に対する安定性検討にも活用可能です。

実世界での応用

歴史的建造物（石橋・煉瓦造ドーム）の保存調査：既存のアーチ構造にひび割れが生じた場合、推力線が断面内に収まっているかをシミュレーションで確認します。不同沈下や荷重条件の変化により推力線が移動し、一部に引張力が生じていることが原因と判明することがあります。

アーチ橋の設計：景観に配慮した浅いアーチ（ライズが小さい）を設計する際、水平推力Hが非常に大きくなるため、それを支える橋台や地盤改良の設計が最重要課題となります。このツールでパラメータを変えながら、推力と形状の関係を直感的に理解できます。

シェル構造の力学理解：コンクリートシェル屋根やトンネルの覆工は、現代のアーチ構造と言えます。これらの構造物が主に軸力で荷重を伝達するメカニズムを、推力線の概念を通じて学ぶことができます。

カテナリー形状との比較：アーチの自重のみが荷重の場合、理想形状はカテナリー（懸垂線）曲線です。このツールの「カテナリー比較」機能を使うことで、放物線との微妙な違いを視覚的に確認し、形状最適化の基礎を理解できます。

よくある誤解と注意点

まず、このツールは「静定3ヒンジアーチ」という理想的なモデルで計算していることを頭に入れておこう。実物はヒンジがなく、材料も連続体だから、ここで出てくる推力線や反力は「第一近似」に過ぎないんだ。例えば、ツールで放物線アーチに等分布荷重をかけると推力線がピタリ一致して美しいけど、実際のコンクリートアーチは材料自体の重さ（自重）が形状に沿って分布する「等分布荷重」じゃなくて「等線分布荷重」になる。この違いを無視すると、実際の応力は計算値とズレるから注意が必要だよ。

次に、パラメータ設定で陥りがちなのが「ライズfを小さくしすぎる」こと。確かに浅いアーチはスタイリッシュだけど、ツールでfをスパンLの1/10以下にしてみてごらん。水平推力Hが桁違いに大きくなるでしょ？例えば、スパン20m、等分布荷重10kN/mでライズを2mにすると、H=250kN。これを1mにすると、H=500kNと倍増する。実務では、この巨大な推力を受け止める橋台の設計や、地盤の許容支持力がプロジェクトの成否を分ける。見た目だけで浅いアーチを選ぶのは危険なんだ。

最後に、ツールの結果をそのまま「安全」と判断しないこと。推力線が断面の中心（核）内に収まっていても、それはあくまで弾性状態での話。長期のクリーープや温度変化、支点の不同沈下が起きれば、推力線は動く。歴史的な石橋のひび割れは、まさにこれが原因だ。ツールは「もしも」の条件を試すためのもの。集中荷重をいろんな位置にかけて、推力線がどうアーチ輪郭からはみ出すか、その「感度」をチェックする癖をつけよう。

使い方ガイド

  1. スパン長（spanL）とライズ（riseF）を入力してアーチ幾何形状を定義する。スパン8m・ライズ2mの典型的な放物線アーチを想定
  2. 分布荷重（wLoad）と集中荷重（pLoad）を設定。スパン当たり均等荷重15kN/mを想定する場合は分布荷重欄に入力
  3. シミュレータが3ヒンジアーチの解析解を実行し、支点A・Bの水平推力H、鉛直反力VA・VBを自動計算。推力線がリアルタイム描画される
  4. 断面力分布グラフで軸力・曲げモーメント・せん断力を確認し、最大値ラベルを参照する

具体的な計算例

スパン10m・ライズ3mの放物線アーチに、分布荷重20kN/m（等分布死荷重）と中央集中荷重30kNが作用する場合を想定。解析解により、支点での水平推力H≈85kN、支点Aの鉛直反力VA≈65kN、支点Bの鉛直反力VB≈65kN、最大圧縮軸力N≈130kN（スプリングラインライン近傍）、最大曲げモーメント≈45kN·mが算出される。推力線はアーチ断面内に収まり、安定した構造形態を示す

実務での注意点

  • 3ヒンジアーチモデルは中央で1ヒンジを持つため、斜張橋やエクストラドーズ橋との混同に注意。本ツールは純粋な放物線・円弧アーチに限定
  • 推力線がアーチ部材断面外に出る場合は引張応力が発生するため、コンクリートアーチでは許容できない。鋼アーチなら設計可能だが、座屈検討が必須
  • 非対称荷重（片側集中荷重）を入力すると、支点反力が非対称となり推力線が偏心する。設計時は荷重ケースごとの最大応力を包絡図で管理
  • アーチ高さ（ライズ）を過度に低くするとスパン比f/L<0.1となり、水平推力が急増（H→無限大）するため、最小ライズ制限を設ける
