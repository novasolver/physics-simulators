# 流体潤滑・ストライベック曲線計算

流体潤滑・ストライベック曲線シミュレーターで、ジャーナル軸受の潤滑状態を可視化。粘度・荷重・回転速度をスライダーで簡単調整し、流体潤滑から境界潤滑までの領域をグラフで即座に確認できます。無料で使えるオンライン計算ツールで、設計や学習に役立ちます。

**Category:** 解析ツール
