# 等エントロピーノズル流れ計算機

MachまたはA/A*を指定して等エントロピーノズル流れの圧力・温度・密度・マッハ角をリアルタイム計算。垂直衝撃波の影響も可視化でき、超音速インテークや推力ノズルの設計理解に活用できます。

**Category:** 流体解析

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/nozzle-flow.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/nozzle-flow.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/nozzle-flow.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/nozzle-flow
python -m http.server 8000
# open http://localhost:8000
```
