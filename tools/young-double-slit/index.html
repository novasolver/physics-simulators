ヤングの二重スリット実験とは？

1801年、イギリスの物理学者トーマス・ヤングは、2本の細いスリットを通した光がスクリーン上に明暗の縞模様（干渉縞）を作ることを発見しました。これは光が「波」として振る舞うことを示す決定的な証拠となり、物理学の歴史を変えた実験です。

2つのスリットを通り抜けた光は、それぞれ新たな球面波（ホイヘンスの原理）として広がります。この2つの波が出合う場所で波の重ね合わせ（干渉）が起きます。山と山が重なれば明るい明線、山と谷が重なれば暗い暗線ができます。

縞間隔の公式

隣り合う明線の間隔 \(\Delta y\) は次の式で与えられます：

$$\Delta y = \frac{\lambda L}{d}$$

  • \(\lambda\)：光の波長（nm）— 波長が長い赤ほど縞が広い
  • \(L\)：スリットからスクリーンまでの距離（m）— 遠いほど縞が広い
  • \(d\)：2つのスリットの間隔（mm）— 間隔が狭いほど縞が広い

この公式はスライダーを動かすと即座に確認できます。例えばλを380nm（紫）から750nm（赤）に変えると、縞間隔がほぼ2倍になるのが見えます。

明線・暗線の発生条件

  • 明線（強め合い）：2つのスリットからの光路差 = \(m\lambda\)（mは整数）
  • 暗線（弱め合い）：光路差 = \((m + \tfrac{1}{2})\lambda\)

中央（m=0）が最も明るく、両側に m=±1, ±2, … と明線が並びます。シミュレーターで各次数の位置にラベルが表示されています。

波長の測定への応用

逆にこの実験は光の波長を精密に測定するためにも使えます。縞間隔を定規で測り、Δy・L・dが分かれば λ = Δy×d/L で波長を計算できます。これは分光学の基礎であり、現代のレーザー干渉計・半導体リソグラフィの原理にもつながります。

💬 理解を深める会話

🙋
スリット間隔 d を小さくしたら縞がどんどん広がりました。なんで間隔が狭いと縞が広くなるんですか？逆じゃないんですか？
🎓
直感と逆に感じるよね。でも Δy = λL/d を見れば納得できる。dが小さいほど Δy が大きい——つまり縞が広がる。物理的に言うと、スリット間隔が狭いほど2つの波源が「ほぼ同じ場所」にあるから、遠くのスクリーンまで来てもほんの少しの角度差しかつかない。その分、同じ位相になる点が遠く離れるんだ。回折格子で d を極限まで小さくすると、1次光が極端に横に飛ぶのと同じ原理だよ。
🙋
なるほど！じゃあ単色光じゃなくて白色光を使ったらどうなりますか？
🎓
いい質問だ。白色光は虹のようにさまざまな波長を含んでいる。中央の 0次線（m=0）は全波長が同じ位置に来るから白い明線になる。でも m=1 以上では、波長ごとに縞の位置がズレるから、虹みたいなカラーバンドが見える。これが「白色光干渉縞」で、紫が内側・赤が外側に広がる。実際にシミュレーターで波長を380→750nmに変えながら見ると、縞位置が変わる様子が確認できるよ。
🙋
光路差って具体的にどこの距離の差のことですか？
🎓
スクリーン上の1点Pに着目する。スリット1からPまでの距離を r₁、スリット2からPまでの距離を r₂ とすると、光路差は |r₁ − r₂| だ。Pが中央にあれば r₁ = r₂ → 光路差0 → 明線。Pが上にずれるにつれて光路差が増えて、波長の半分になると暗線、波長1つ分になると次の明線……という繰り返しだ。Pがスクリーンの端（大きな角度）になると近似式 Δy = λL/d が成り立たなくなって、厳密な計算が必要になる。

ヤングの二重スリット干渉シミュレーターでは、単色光の波長\(\lambda\)、二つのスリット間隔\(d\)、スリットからスクリーンまでの距離\(L\)をパラメータとして設定できる。光源から放射されたコヒーレントな平面波は、各スリットを通過した後、ホイヘンスの原理に従って球面波として広がる。スクリーン上の任意の点における光の強度は、二つのスリットからの波の重ね合わせによって決まり、その経路差\(\Delta\)が干渉条件を決定する。スクリーン中央から距離\(y\)の点における経路差は、\(L \gg d\)の近似のもとで\(\Delta = d \sin\theta \approx d \frac{y}{L}\)と表される。強め合う条件は\(\Delta = m\lambda\)（\(m\)は整数）であり、このとき明線が生じる。逆に、弱め合う条件は\(\Delta = (m+\frac{1}{2})\lambda\)であり、暗線が生じる。したがって、明線の間隔\(\Delta y\)は\(\Delta y = \frac{\lambda L}{d}\)で与えられ、波長が長いほど、スリット間隔が狭いほど、またスクリーンが遠いほど干渉縞の間隔が広がることを、シミュレーション上でリアルタイムに確認できる。この現象は光が波であることの直接的な証拠であり、位相差に基づく干渉の基本原理を直感的に理解するのに役立つ。

よくある質問

干渉縞の間隔は、スリット間隔dが小さいほど、また波長λが長いほど広がります。具体的には、明線の間隔はλL/dで決まり、dを大きくすると縞が狭く、λを大きくすると縞が広くなります。
スクリーン中央からの距離yは、強め合い条件dsinθ=mλ（m=0,1,2...）から求まります。L≫dの近似ではy=mλL/dとなります。m=0が中央の明線で、mが増えるほど外側に明線が現れます。
このシミュレーターは単色光を前提としています。白色光では波長ごとに干渉縞の位置がずれるため、中央は白色、外側は虹色の縞になりますが、本ツールでは単一波長の干渉パターンのみ表示されます。
スリット幅が広すぎると、回折効果により干渉縞の明暗がぼやけます。本シミュレーターではスリット幅を十分に狭い理想的な点光源として扱っているため、鮮明な干渉縞が得られます。実際の実験ではスリット幅を波長程度にすると良いです。

実世界での応用

産業での実際の使用例
半導体露光装置（ASML製EUVリソグラフィ）では、ナノメートル単位の微細パターンを形成する際にヤングの干渉原理を応用しています。スリット間隔を極小化することで高解像度の干渉縞を生成し、最先端のCPUやメモリチップの回路をウェハ上に焼き付けます。また、光ファイバー通信の波長多重技術でも、干渉縞の位相制御が信号分離に不可欠です。

研究・教育での活用
大学の物理学実験では、本シミュレーターを用いて光の波動性を直感的に理解させます。特に、スリット間隔や波長を変えた際の縞間隔の変化をリアルタイムで観察できるため、ヤングの実験式の導出や誤差解析の教育効果が高まります。研究現場では、メタマテリアルやフォトニック結晶の設計において、干渉パターンの事前検証ツールとして活用されています。

CAE解析との連携や実務での位置付け
本シミュレーターは光学系CAEの前段階として位置づけられ、設計パラメータの初期検討を効率化します。例えば、レーザー加工機の光学ヘッド設計では、スリット形状と干渉縞の関係をCAEソフト（Zemaxなど）で詳細解析する前に、本ツールで大まかな条件を絞り込みます。これにより、試作回数と計算リソースを大幅に削減し、実務での開発期間短縮に貢献します。

よくある誤解と注意点

「明線の間隔は波長にのみ依存する」と思いがちですが、実際にはスリット間隔とスクリーン距離にも強く依存します。干渉縞の間隔は波長に比例し、スリット間隔に反比例するため、スリット間隔を狭めると縞間隔が広がる点に注意が必要です。

「中央の明線が最も明るく、外側ほど暗くなるのは回折の影響ではない」と思いがちですが、実際には二重スリットの各スリット自体による単スリット回折の包絡線が重なるため、外側の干渉縞は次第に暗くなります。この回折効果を無視すると、縞の強度分布を誤解する原因になります。

「スクリーンを遠ざければ縞がはっきり見える」と思いがちですが、実際にはスクリーン距離を大きくすると縞間隔は広がりますが、光の広がりにより明線自体の明るさが低下します。観察には適切な距離の選択が重要で、あまり遠すぎると暗くて識別困難になる点に注意が必要です。

使い方ガイド

  1. 波長スライダーを532nm（緑色レーザー）から633nm（赤色He-Neレーザー）の範囲で調整し、lambda-displayに表示される値を確認します
  2. スリット間隔d-sliderを0.1mmから1.0mmの間で変更して、干渉縞のパターン変化をリアルタイム観察します
  3. スクリーン距離L-sliderを500mmから3000mmまで調整し、縞間隔Δyの計算結果を確認してから[シミュレート実行]を押します

具体的な計算例

波長λ=532nm、スリット間隔d=0.5mm、スクリーン距離L=1500mmの場合、干渉縞の間隔はΔy = λL/d = 532×10⁻⁹ × 1.5 / 0.5×10⁻³ = 1.60mmとなります。同じ条件でd=0.2mmに変更するとΔy=4.0mmに拡大し、d=1.0mmではΔy=0.80mmに縮小します。産業用精密測定ではこの縞間隔をCCDカメラで検出し、0.01mm単位の距離測定を実現しています。

実務での注意点

  • 可視光域での測定：赤色(633nm)は回折が小さく狭い縞になり、紫外線領域では波長が短いため高い空間分解能が得られます。材料の微細構造解析では365nmのUVレーザーが使用されます
  • スリット間隔とスクリーン距離の比率が重要：L/d比が大きいほど遠視野条件を満たし、理論値との誤差が±2%以下になります。工業用では最低L/d≥500を確保してください
  • 環境振動対策：μm単位の測定精度が必要な場合、防振台上に装置を設置し、気流による位相ずれを防ぐため恒温室(±0.5℃)での測定を推奨します
