# ヤングの二重スリット干渉シミュレーター

ヤングの二重スリット干渉シミュレーター。波長・スリット間隔・スクリーン距離をリアルタイム変更して干渉縞の変化を確認。光の波動性を可視化。干渉パターン、光学シミュレーション。

**Category:** 高校物理・波動

- 🇯🇵 [日本語](https://novasolver.jp/tools/young-double-slit.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/young-double-slit.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/young-double-slit.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/young-double-slit
python -m http.server 8000
# open http://localhost:8000
```
