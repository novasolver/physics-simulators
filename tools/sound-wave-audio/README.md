# 🔊 音波シミュレーター

音波シミュレーターで周波数・波形をリアルタイム操作。粒子振動アニメーションと音を同時体験し、音響CAEの物理モデルを直感的に学習できるツール。

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/sound-wave-audio.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/sound-wave-audio.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/sound-wave-audio.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/sound-wave-audio
python -m http.server 8000
# open http://localhost:8000
```
