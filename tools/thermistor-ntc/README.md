# NTC サーミスタ シミュレーター — 抵抗-温度特性

NTC サーミスタの抵抗-温度特性を β パラメータモデルでリアルタイム可視化。R0・B 定数・温度を変えて、抵抗・分圧電圧・感度の挙動と温度計測回路の動作を直感的に学べます。

**Category:** センサシミュレーター

## Live demos

- 🇺🇸 [English](https://novasolver.jp/en/tools/thermistor-ntc.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/thermistor-ntc.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/thermistor-ntc
python -m http.server 8000
# open http://localhost:8000
```
