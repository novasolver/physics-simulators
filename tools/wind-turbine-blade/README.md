# 風力タービンブレード設計（BEM法）

風力タービンブレード設計ツール「NovaSolver」で、BEM法（翼素運動量理論）を用いたシミュレーションを実行できます。最適な弦長とねじれ角を計算し、出力係数Cpやベッツ限界との比較、詳細な可視化を実現。風力発電のCAE設計や研究開発に最適な計算機です。

**Category:** 解析ツール

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/wind-turbine-blade
python -m http.server 8000
# open http://localhost:8000
```
