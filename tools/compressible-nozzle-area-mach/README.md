# 等エントロピー流れの面積比と Mach 数シミュレーター

等エントロピー流れの面積比とMach数シミュレーター。ノズル設計でMach数から面積比、静圧比、流速を計算。圧縮性流体解析に必須。

**Category:** 対話型シミュレーター

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/compressible-nozzle-area-mach.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/compressible-nozzle-area-mach.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/compressible-nozzle-area-mach.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/compressible-nozzle-area-mach
python -m http.server 8000
# open http://localhost:8000
```
