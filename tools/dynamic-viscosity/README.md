# 粘性・レオロジーシミュレーター

粘性・レオロジーシミュレーターで非ニュートン流体の粘度曲線とクエット流れを可視化。ニュートン流体からべき乗則流体まで4種類のレオロジーモデルに対応。レイノルズ数計算・温度補正機能付き。

**Category:** 流体力学

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/dynamic-viscosity
python -m http.server 8000
# open http://localhost:8000
```
