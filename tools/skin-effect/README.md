# 表皮効果 シミュレーター — AC 電流の表面集中

周波数 f・電気伝導率 σ・比透磁率 μ_r・導線半径 R から、表皮深さ δ と円形導体の AC/DC 抵抗比を実時間で計算します。導体断面の電流密度分布と δ vs 周波数の両対数グラフで、高周波での表皮効果と抵抗増加の物理を直感的に学べます。

**Category:** 電磁気シミュレーター
