# 相変化材料（PCM）熱解析シミュレーター

エンタルピー法（有限差分）による1D溶融前線シミュレーション。氷・パラフィン・硝酸塩溶融塩の相変化挙動をアニメーションで可視化。Stefan問題の解析解とも比較できます。

**Category:** 材料・破壊

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/pcm-melting.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/pcm-melting.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/pcm-melting.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/pcm-melting
python -m http.server 8000
# open http://localhost:8000
```
