# 地震波伝播シミュレーター

P波・S波の地球内部での伝播・反射・屈折をリアルタイムアニメーション。地球の層構造（地殻・マントル・外核・内核）とシャドーゾーンを可視化。

**Category:** 地球科学・地震工学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/seismic-wave-prop.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/seismic-wave-prop.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/seismic-wave-prop.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/seismic-wave-prop
python -m http.server 8000
# open http://localhost:8000
```
