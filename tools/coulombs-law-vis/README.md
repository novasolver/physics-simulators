# クーロンの法則ビジュアライザー

クーロンの法則ビジュアライザーで静電気力・電場・電位をリアルタイム計算。点電荷の引力・斥力をアニメーション表示し、クーロン力の理論を直感的に理解できるCAEツール。

**Category:** 電磁気学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/coulombs-law-vis.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/coulombs-law-vis.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/coulombs-law-vis.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/coulombs-law-vis
python -m http.server 8000
# open http://localhost:8000
```
