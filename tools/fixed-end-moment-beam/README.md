# 固定端モーメント シミュレーター — 両端固定梁の FEM 法基本

固定端モーメント シミュレーター — 両端固定梁の FEM 法基本: 両端固定梁に集中荷重と等分布荷重を作用させ、固定端モーメント・反力・中央撓みをリアルタイム計算します。たわみ角法・固定法の出発点となる FEM の挙動を、スライダー操作で直感的に学べます。

**Category:** 構造解析シミュレーター
