固定端モーメント シミュレーター — 両端固定梁の FEM 法基本

荷重が増減すると梁が撓み、固定端は勾配ゼロ（水平）のまま。BMD は両端で負（ホギング）、スパン中央で正となります。

理論・主要公式

両端固定梁に集中荷重 P が位置 $a$（$b = L - a$）に作用するときの固定端モーメント:

$$M_A = -\frac{P\,a\,b^2}{L^2},\quad M_B = -\frac{P\,a^2\,b}{L^2}$$

M_A, M_B：左右支点の曲げモーメント [kN·m]、P：集中荷重 [kN]、L：梁長 [m]

等分布荷重 $w$ が全長に作用するときの固定端モーメント:

$$M_A = M_B = -\frac{w\,L^2}{12}$$

w：等分布荷重 [kN/m]。両端で同符号・同値となるのが等分布の特徴です。

中央 $x = L/2$ における代表撓み（等分布のみ・集中 a=L/2 のみ）:

$$\delta_{c,w} = \frac{w\,L^4}{384\,EI},\quad \delta_{c,P} = \frac{P\,L^3}{192\,EI}$$

本ツールではこれらを線形重ね合わせ、任意位置 a の集中荷重についても解析式で評価しています。

固定端モーメント シミュレーターとは

🙋
「固定端モーメント」って、両端を壁にがっちり留めた梁の支点に出てくる曲げモーメントのことですか？
🎓
そう、ざっくり言うとそれで合ってる。両端が回転できないように固定された梁に荷重をかけると、支点で梁が回らないように押さえ込む向きにモーメントが発生するんだ。これを Fixed End Moment、略して FEM と呼ぶ。上のシミュレーターで「集中荷重 P」を増やしてみると、左右の支点モーメント M_A・M_B のカードがすぐ変わるよ。
🙋
あ、本当だ。でも値がマイナスになってるんですけど、これは間違いじゃないんですか？
🎓
大丈夫、符号の決め方の問題だ。このツールでは「梁を下に押し下げる荷重で、梁の上面が引っ張られる向きのモーメント」を正と決めている。両端固定だと支点では梁が逆向きに反るから、スパン中央とは逆符号、つまり負で出てくるんだ。BMD の図を見ると、両端で曲線が下に振れてるのが負のモーメントだよ。実務でも「ホギング（hogging）モーメント」と呼んで負号で扱うことが多い。
🙋
なるほど。じゃあ集中荷重と等分布荷重を同時にかけてるのは、ただ重ねて足してるだけなんですか？
🎓
その通り、線形弾性なら重ね合わせで OK。P 単独の FEM ($-P a b^2/L^2$ など) と、w 単独の FEM ($-w L^2/12$) をそれぞれ計算して、最後に足してる。実務でも自重・積載・風・地震といった荷重ケースを別々に解いて組み合わせるのが普通だ。デフォルト値 (L=6, P=30, a=2, w=10) でやってみて：M_A は約 -56.7 kN·m、M_B は約 -43.3 kN·m になるはずだよ。
🙋
なんで両端固定の方が単純支持より撓みが小さくなるんですか？
🎓
両端で支点モーメントが「曲がろうとする力に逆らう向き」に効いてるからだよ。等分布荷重で比べると、単純支持の最大撓みは $5wL^4/(384EI)$、両端固定だと $wL^4/(384EI)$ で 1/5。シミュレーターで w=10 にすると、δ_c が約 0.68 mm 程度になるはず。これがもし単純支持なら 3.4 mm くらいになる。代わりに支点モーメントが発生するから、その分支持部の設計には注意が必要だね。

固定端モーメント（FEM）の公式一覧

固定端モーメント（Fixed-End Moment, FEM）は、両端を完全固定した梁に荷重を作用させたときに固定端に生じる曲げモーメントです。たわみ角法・固定法（モーメント分配法）の出発点となる基本量です。スパン $L$ に対する代表値は次の通りです。

荷重固定端モーメント $|M|$中央たわみ $\delta$
等分布荷重 $w$$wL^2/12$（両端）$wL^4/384EI$
中央集中荷重 $P$$PL/8$（両端）$PL^3/192EI$
任意位置の集中荷重 $P$（$a, b=L-a$）$M_{AB}=Pab^2/L^2$, $M_{BA}=Pa^2b/L^2$—

等分布荷重では両端とも $wL^2/12$ で大きさが等しく、中央では $wL^2/24$ の正モーメントになります。任意位置の集中荷重では、荷重に近い端のFEMが大きくなります（$a=b=L/2$ で両式とも $PL/8$ に一致）。

FEMとたわみ角法・固定法（モーメント分配法）

不静定骨組を解くたわみ角法や固定法（モーメント分配法）は、次の手順でFEMを起点にします。

  1. 全部材を固定：すべての節点を回転拘束したと仮定し、各部材のFEMを上表から求めます。
  2. 不釣合いモーメント：各節点でFEMの総和（不釣合いモーメント）を計算します。実際の節点は回転できるので、これを解放します。
  3. 分配：不釣合いモーメントを、各部材の剛比 $K=I/L$ に比例した分配率で分配します。
  4. 到達：分配したモーメントの1/2が他端へ到達（到達モーメント）します。
  5. 反復：分配と到達を不釣合いが十分小さくなるまで繰り返し、各端の最終モーメントを得ます。

このようにFEMは不静定構造解析の基礎単位です。本シミュレーターで荷重・位置を変えながらFEMの挙動を体感すると、骨組解析の理解が深まります。

よくある質問

FEM は Fixed End Moment の略で、有限要素法（Finite Element Method）と同じ略号ですが、構造力学の文脈ではほぼ確実に固定端モーメントを指します。たわみ角法 (Slope Deflection Method) や固定法 (Moment Distribution Method, Hardy Cross 法) で、各部材の両端を一時的に固定した仮想状態のモーメントとして繰り返し参照されるため、設計実務では FEM 表（標準荷重ケースに対する固定端モーメントの一覧表）が頻繁に使われます。
本ツールは「固定端モーメントと反力の挙動」を学ぶことを主目的としており、これらは EI に依存しません（M と R は荷重と幾何だけで決まります）。中央撓み δ_c のみが EI に依存しますが、教育目的では現実的な梁の代表値として固定値を採用しました。EI の影響を学びたい場合は「梁のたわみ・応力解析シミュレーター」を併用してください。
a が 0 や L に近いと、集中荷重が支点上に乗る極端な状況になり、解析的には固定端モーメントが急激に小さくなる一方、可視化と数値表示が支点と重なって読みにくくなります。教育用に挙動が見やすい範囲として 0.1·L〜0.9·L の自動クランプを採用しました。境界値の挙動を確認したい場合は L を変えて相対的な位置で試してください。
線形重ね合わせを使い、解析式で評価しています。等分布荷重については $w x^2 (L-x)^2 / (24 EI)$ を $x = L/2$ で評価し、集中荷重については位置 a に対する両端固定梁の標準解 $y = P b^2 x^2 (3aL - 3ax - bx) / (6 L^3 EI)$（$x \le a$）または対称式（$x \ge a$）を用いています。a = L/2 で集中荷重のみの場合、δ_c = $P L^3 / (192 EI)$ という有名な式に一致します。

実世界での応用

剛接合ラーメン構造の設計：柱と梁を剛接合した RC や鉄骨ラーメン構造では、各部材を「両端固定梁」とみなして固定端モーメントを求め、たわみ角法または固定法で節点回転を解いて全体応力を求めます。本ツールが示す M_A・M_B は、まさにこの繰り返し計算の入り口となる「初期固定モーメント」です。

橋梁の連続桁解析：多径間連続橋では、各径間を両端固定とみなした FEM 表をベースに、節点剛性比に応じてモーメントを分配します。本ツールで a を変えて M_A・M_B の比率が変わるのを観察すると、荷重位置によって両端のモーメント分担が変わる感覚がつかめます。

機械要素の片持ち・両端固定軸：工作機械の主軸やプーリ間の伝動軸など、両端をベアリングで保持する軸の曲げモーメント評価にも同じ式が使えます。等分布荷重として軸自重、集中荷重としてプーリやギアの荷重を重ね合わせ、軸受位置でのモーメントから曲げ応力 $\sigma = Mc/I$ を求めます。

FEM ソフトのサニティチェック：商用有限要素ソフト（Ansys, Abaqus 等）で梁要素モデルの境界条件を設定したあと、簡単な両端固定 + 集中/等分布荷重ケースを本ツールで手計算し、ソフトの出力と比較するのは、入力ミス検出の定番手法です。±5% 以内で一致しなければ、支持条件や荷重単位の入力を見直す必要があります。

よくある誤解と注意点

最も多い誤解は、「両端固定 = 完全な剛体支持」と無条件に仮定してしまうことです。実際の構造で完全な固定支持は稀で、コンクリート壁に埋め込まれた鉄骨梁ですら、わずかな回転は許容します。実務では「固定度 (fixity)」を 0（ピン）〜1（完全固定）の係数として扱い、本ツールのような完全固定の結果と単純支持の結果との間で補間することがあります。設計の安全側に倒すなら、固定端モーメントは小さめ、スパン中央モーメントは大きめに見積もるのが定石です。

次に、固定端モーメントが「材料強度」だけで決まると思い込む誤解です。固定端モーメントの式 $M_A = -P a b^2/L^2$ や $M_A = -w L^2/12$ には材料定数 E も断面定数 I も登場しません。これは荷重 P・w とスパン L、荷重位置 a という幾何だけで決まる量で、剛性 EI を変えてもモーメント自体は変わりません（変わるのは撓みと支点反力分配だけ）。本ツールで EI を固定値にしているのもこの理由です。

最後に、符号規約と図の向きを混同する点に注意してください。本ツールでは「下向き荷重で梁上面が引張になる向き」を正としているため、両端固定梁の M_A・M_B は負値で出力されます。BMD では負のモーメントを上向き（梁の上側に膨らむ向き）に描いているので、両端で BMD が上に振れ、スパン中央付近で下に振れる形になります。教科書によって符号や図示方向が逆の場合があり、必ず自分の使う規約を明示してから議論することが、現場での誤解防止には不可欠です。

使い方ガイド

  1. 梁長 L（m）をスライダーで設定します。標準値は2～5m範囲を想定しています
  2. 集中荷重 P（kN）と作用位置 a（m）を入力し、反力と固定端モーメントの変化を観察します
  3. 等分布荷重 w（kN/m）を加算し、複合荷重時の固定端モーメント M_A、M_B、中央撓み δ_c をリアルタイム表示で確認します
  4. たわみ角法の出発点となる固定端モーメントの理論値と FEM 数値解の一致性を検証します

具体的な計算例

本ツールの固定EI=50000 kN·m²で、L=4.0m、集中荷重P=25kN（a=2.0m）と等分布荷重w=5.0kN/mを作用させると、固定端モーメントは M_A≈-19.17kN·m、M_B≈-19.17kN·m、左反力R_A≈22.50kN、中央撓みδ_c≈0.233mmです。符号は本ツールの規約（端部のhoggingを負）に従います。

実務での注意点

  • 梁長が短い（L＜1m）場合、相対たわみが大きくなり2次効果を考慮する必要があります
  • 集中荷重位置 a=L/2（中央）では M_A=M_B となり、対称性が確認できます
  • 等分布荷重のみの場合、固定端モーメント M=wL²/12 の公式検証に活用できます
  • 実構造物では支持部の曲げ剛性低下を考慮し、この理想値から10～15%割り引く必要があります
