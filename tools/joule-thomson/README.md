# ジュール・トムソン効果 シミュレーター — 絞り膨張による温度変化

ジュール・トムソン効果シミュレーター。van der Waals 気体の絞り膨張で、温度 T・圧力降下 ΔP・vdW定数 a, b からジュール・トムソン係数 μ_JT、温度変化 ΔT、反転温度 T_inv、冷却／昇温領域を実時間計算します。

**Category:** 熱力学シミュレーター
