# 音の大きさ・デシベルスケール

音圧レベル（dB SPL）のリアルタイム計算ツール。距離減衰・複数音源合成を可視化し、騒音規制値と比較。音響工学・騒音解析に対応。

**Category:** 音響・波動

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/sound-decibel-scale.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/sound-decibel-scale.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/sound-decibel-scale.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/sound-decibel-scale
python -m http.server 8000
# open http://localhost:8000
```
