# コンクリートポンプ車 配管圧損計算 — DIN 18218

生コンクリートを高層階・遠距離へ圧送する際の配管圧損を、Buhrau式系の経験式で即時計算します。スランプ・配管径・水平距離・垂直揚程を変えると、必要ポンプ吐出圧とブーム車（M28〜M70）の機種選定がリアルタイムで分かり、打設計画の事前検討に使えます。

**Category:** コンクリート工事・圧送
