# フーリエ円（エピサイクル）シミュレーター

フーリエ円（エピサイクル）シミュレーターで描画曲線をDFTで分解し回転円で再現。円数調整で近似精度をリアルタイム確認できる教育用ツール。

**Category:** 振動・波動

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/fourier-epicycles.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/fourier-epicycles.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/fourier-epicycles.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/fourier-epicycles
python -m http.server 8000
# open http://localhost:8000
```
