# エレベータロープ プリテンション・サグシミュレーター

高層建築用エレベータの主索（ロープ）について、張力・安全率・自重伸び・サグ（垂れ）をリアルタイム計算します。昇降距離・ロープ本数・径・カウンタウェイト比率を変えると、標準鋼・高張力・CF UltraRopeの違いと、EN 81-50（安全率≥12）に対する余裕がすぐに分かります。

**Category:** エレベータ・高層建築
