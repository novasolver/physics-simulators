# 港湾共振・固有振動数計算機

開口端・閉鎖端の矩形港湾モデルに対応した固有振動数計算ツールです。長波（津波・高潮）の増幅率と周波数応答をリアルタイムに計算し、定在波パターンを可視化します。浅水波理論に基づく共振周期の公式を活用し、港湾防災や沿岸設計に役立つ直感的な解析を提供します。

**Category:** 機械力学
