# 二相流シミュレーター（気液流動）

気液二相流シミュレーター：ベーカー図によるフローパターン判定と圧力損失計算。ロックハート-マルチネッリ相関式で配管設計・熱交換器解析に対応

**Category:** 流体工学・化学工学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/two-phase-flow.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/two-phase-flow.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/two-phase-flow.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/two-phase-flow
python -m http.server 8000
# open http://localhost:8000
```
