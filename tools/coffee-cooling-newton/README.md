# コーヒーの冷め方・ニュートン冷却シミュレーター

ニュートン冷却法則に基づくコーヒー冷却シミュレーター。初期温度・室温・冷却定数を調整し、飲み頃到達時間をリアルタイム計算。指数関数的冷却の物理現象を直感的に学習できるCAEツール。

**Category:** 熱伝達

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/coffee-cooling-newton
python -m http.server 8000
# open http://localhost:8000
```
