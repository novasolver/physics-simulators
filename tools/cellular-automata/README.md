# セルオートマトン

セルオートマトンのシミュレーターで、1次元のウォルフラムルール（全256種）と2次元のコンウェイのライフゲームをブラウザ上で実行できます。グライダーやパルサーなどの有名なパターンで遊びながら、複雑系の神秘を体験しましょう。直感的な操作で生命の誕生と進化を観察できます。

**Category:** 複雑系

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/cellular-automata.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/cellular-automata.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/cellular-automata.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/cellular-automata
python -m http.server 8000
# open http://localhost:8000
```
