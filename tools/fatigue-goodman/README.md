# 疲労寿命・Goodmanダイアグラムツール

σa/Se + σm/Su = 1——3 つの破壊規準（Goodman 直線、Gerber 放物線、Soderberg 線）を 1 つの線図に重ね、動作点が安全領域内かを瞬時に判定。設計の保守性を視覚化。

**Category:** 疲労解析ツール
