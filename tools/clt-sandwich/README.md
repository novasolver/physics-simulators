# サンドイッチパネル解析（等価剛性・コアせん断・破壊モード）

曲げ剛性・コアせん断変形・面材応力・しわ座屈限界（Hoff-Mautner式）をリアルタイム計算。せん断変形の過小評価リスクをたわみ内訳で可視化します。

**Category:** 構造解析ツール

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/clt-sandwich.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/clt-sandwich.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/clt-sandwich.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/clt-sandwich
python -m http.server 8000
# open http://localhost:8000
```
