# サンドイッチ板の曲げ剛性・重量計算機

面材（CFRP・アルミ・鋼）とコア（ハニカム・フォーム・バルサ）の厚みと材料を変えて、曲げ剛性D・比剛性・単位面積重量・最大たわみをリアルタイム比較。ソリッド板との比較表付き。

**Category:** 軽量構造 · サンドイッチ理論
