# サンドイッチ構造設計計算

面材とコア材の組み合わせを選択し、曲げ剛性・最大たわみ・面材応力・コアせん断応力・安全率をリアルタイムで計算。航空宇宙・船舶・風力ブレード設計に対応。

**Category:** 構造解析

- 🇯🇵 [日本語](https://novasolver.jp/tools/composite-sandwich.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/composite-sandwich.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/composite-sandwich.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/composite-sandwich
python -m http.server 8000
# open http://localhost:8000
```
