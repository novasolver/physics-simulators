# 量子調和振動子シミュレーター

量子調和振動子シミュレーターで波動関数・エネルギー準位を可視化。量子力学の基本モデルを対話的に学習し、確率密度分布を解析。

**Category:** 量子力学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/quantum-harmonic.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/quantum-harmonic.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/quantum-harmonic.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/quantum-harmonic
python -m http.server 8000
# open http://localhost:8000
```
