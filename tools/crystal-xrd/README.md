# X線回折（XRD）計算ツール

結晶構造（FCC/BCC/SC/HCP/ダイヤモンド）とX線波長を選び、許容反射・d間隔・2θ・Scherrer幅をリアルタイム計算。回折パターンを可視化。

**Category:** 材料科学 / 結晶解析

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/crystal-xrd.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/crystal-xrd.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/crystal-xrd.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/crystal-xrd
python -m http.server 8000
# open http://localhost:8000
```
