# 空気ばねの剛性シミュレーター

封入した空気の「圧縮されにくさ」で荷重を支える空気ばねを設計するツールです。受圧面積・ゲージ圧・空気室容積を変えると、ばね定数・固有振動数・静的たわみ相当がリアルタイムで分かり、振動を遮断する柔らかいばねを検討できます。

**Category:** 機械要素設計
