# 複合材料破壊基準シミュレーター

CFRP・GFRPの複合材料破壊基準シミュレーター。プライ応力からTsai-Wu・Hashin基準で破壊判定し、繊維/マトリクス破壊モードをリアルタイム表示。強度設計解析に最適。

**Category:** 構造解析 / 複合材料

- 🇺🇸 [English](https://novasolver.jp/en/tools/composite-failure.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/composite-failure
python -m http.server 8000
# open http://localhost:8000
```
