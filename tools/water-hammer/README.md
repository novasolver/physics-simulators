# 水撃圧力計算ツール（ウォーターハンマー）

水撃圧力計算ツール（ウォーターハンマー）：ジュコフスキー式によるリアルタイム計算、急閉緩閉判定、波速比較。配管設計・流体解析に必須。

**Category:** 流体・配管解析

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/water-hammer.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/water-hammer.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/water-hammer.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/water-hammer
python -m http.server 8000
# open http://localhost:8000
```
