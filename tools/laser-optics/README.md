# レーザー光学設計・ガウシアンビーム計算

NovaSolverは、ガウシアンビームの伝播特性をリアルタイムで計算するレーザー光学設計ツールです。レイリー長や発散角、集光スポットサイズをインタラクティブに設計・解析。CO2、Nd:YAG、HeNe、UVレーザーなど各種光源に対応し、光学設計を強力に支援します。

**Category:** 電磁気

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/laser-optics
python -m http.server 8000
# open http://localhost:8000
```
