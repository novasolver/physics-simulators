# 黒体放射スペクトルシミュレーター

黒体放射スペクトルシミュレーター：プランクの法則に基づいた温度変化による分光分布の可視化。ウィーンの変位則やステファン-ボルツマン則との比較も可能。

**Category:** 熱物理・量子

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/black-body-radiation.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/black-body-radiation.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/black-body-radiation.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/black-body-radiation
python -m http.server 8000
# open http://localhost:8000
```
