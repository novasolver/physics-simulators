# ローン返済シミュレーター

借入金額・年利・返済期間をスライダーで動かすだけで、毎月の返済額・総利息・返済スケジュールが即更新。元利均等返済と元金均等返済を棒グラフで並べて比較できるので、ライフプランに合った返済方法を選びやすくなります。

**Category:** 金融・経済

- 🇯🇵 [日本語](https://novasolver.jp/tools/loan-amortization.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/loan-amortization
python -m http.server 8000
# open http://localhost:8000
```
