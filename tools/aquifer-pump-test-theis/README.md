# Theis 井戸揚水試験と透水係数推定シミュレーター

Theis井戸揚水試験シミュレーターで透水係数を推定。時間-水位低下曲線の読み取り方から実務応用まで、観測条件の影響を確認できます。

**Category:** 対話型シミュレーター
