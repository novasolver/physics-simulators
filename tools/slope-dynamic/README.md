# 動的斜面安定解析（ニューマーク法）

動的斜面安定解析ツール「NovaSolver」では、ニューマーク法を用いて地震時の斜面崩壊リスクを評価します。斜面角や粘着力などのパラメータを入力するだけで、静的安全率や地震時永久変位をリアルタイム計算。地盤の動的安定性を迅速に解析し、防災・減災対策に役立ちます。

**Category:** 地盤・構造
