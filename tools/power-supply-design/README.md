# スイッチング電源設計ツール

スイッチング電源の設計を支援するDC-DCコンバータ設計計算ツールです。Buck、Boost、Buck-Boost回路のインダクタンスやキャパシタンス、デューティ比をリアルタイムで計算。インダクタ電流波形と効率カーブを可視化し、効率的な電源設計を実現します。NovaSolverで最適な設計を。

**Category:** 電源エレクトロニクス
