# 波動-粒子二重性シミュレーター

粒子の質量・速度からド・ブロイ波長を計算し、二重スリット干渉パターンを可視化。電子顕微鏡の分解能まで一気通貫で扱い、量子の不思議を数字とグラフで体感できます。

**Category:** 量子力学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/wave-particle-duality.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/wave-particle-duality.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/wave-particle-duality.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/wave-particle-duality
python -m http.server 8000
# open http://localhost:8000
```
