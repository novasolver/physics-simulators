# 抵抗減衰器パッド（T型 / π型）シミュレーター

特性インピーダンス Z₀ にマッチしたまま信号を一定のdBで減衰させる抵抗減衰器パッド（T型 / π型）を設計するツール。減衰量・Z₀・入力電力を変えて、3本の抵抗値・出力電力・消費電力・電圧比をリアルタイム計算できる無料RF設計シミュレーターです。

**Category:** RF・高周波

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/attenuator-pad
python -m http.server 8000
# open http://localhost:8000
```
