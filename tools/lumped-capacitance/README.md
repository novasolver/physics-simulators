# 集中容量法・冷却/加熱曲線シミュレーター

非定常熱伝導の温度履歴をリアルタイム可視化するシミュレーター。ビオ数の妥当性確認、鋼・アルミ・セラミックの時定数比較が可能。集中容量法・冷却加熱曲線解析に対応。

**Category:** 熱解析

- 🇺🇸 [English](https://novasolver.jp/en/tools/lumped-capacitance.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/lumped-capacitance.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/lumped-capacitance
python -m http.server 8000
# open http://localhost:8000
```
