# 回折・ヤングの二重スリット干渉計算機

ヤングの二重スリット実験における干渉縞と回折パターンをシミュレーション。波長・スリット間隔・スクリーン距離を自由に設定して強度分布をリアルタイム計算。

**Category:** 振動・波動

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/diffraction.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/diffraction.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/diffraction.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/diffraction
python -m http.server 8000
# open http://localhost:8000
```
