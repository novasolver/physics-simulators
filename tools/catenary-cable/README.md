# カテナリー曲線・ケーブル張力計算機

カテナリー曲線（懸垂線）の計算をオンラインで無料実行。スパン・たわみ・重量を入力するだけで、ケーブルの水平張力・最大張力・ケーブル長を即座に算出。吊り橋や架空送電線、カーテンウォールの設計に役立つ、エンジニア必携のシミュレーターツールです。

**Category:** 構造解析
