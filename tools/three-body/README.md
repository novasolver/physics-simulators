# 三体問題 シミュレーター

三体問題シミュレーターで重力相互作用をリアルタイム可視化。figure-8周期解、ラグランジュ点、カオス現象を体験できるCAEツール。軌道計算・N体シミュレーション対応。

**Category:** 物理シミュレーター

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/three-body.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/three-body.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/three-body.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/three-body
python -m http.server 8000
# open http://localhost:8000
```
