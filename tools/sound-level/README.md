# 音圧レベル・騒音計算（デシベル合成）

複数音源のデシベル合成・距離減衰計算・A特性補正をリアルタイム対応。騒音基準との比較で設計検証に活用でき、音圧レベル・騒音解析に最適なCAEツール。

**Category:** 振動・波動

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/sound-level.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/sound-level.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/sound-level.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/sound-level
python -m http.server 8000
# open http://localhost:8000
```
