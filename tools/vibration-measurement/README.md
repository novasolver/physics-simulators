# 振動測定・解析ツール

振動測定データの加速度・速度・変位を瞬時に相互換算。ISO 10816規格に基づき機械振動の評価ゾーン（A～D）を自動判定し、健全性評価をサポート。A特性重み付けフィルタの特性も視覚的に確認できる、現場エンジニアのための振動解析ツール「NovaSolver」です。

**Category:** 振動解析

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/vibration-measurement
python -m http.server 8000
# open http://localhost:8000
```
