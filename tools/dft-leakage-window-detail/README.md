# 漏れスペクトルと窓関数の補正シミュレーター

DFT周波数ビンずれと窓関数の漏れスペクトル補正をシミュレーション。スカロッピング損失、ENBW、等価雑音帯域を評価し、信号解析精度を向上させます。

**Category:** 対話型シミュレーター

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/dft-leakage-window-detail.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/dft-leakage-window-detail.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/dft-leakage-window-detail.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/dft-leakage-window-detail
python -m http.server 8000
# open http://localhost:8000
```
