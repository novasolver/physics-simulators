# アンテナアレイ・ビームフォーミング計算機

アンテナアレイのビームフォーミングを無料でシミュレーション。素子数や間隔、走査角を設定し、Hann窓などの窓関数を適用することで、ビームパターンを極座標と直交座標で直感的に可視化します。NovaSolverのオンライン計算機で、最適なアレイ設計をサポートします。

**Category:** 電磁気・光学
