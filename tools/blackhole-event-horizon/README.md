# ブラックホール事象の地平面シミュレーター

質量とスピン（Kerr パラメータ）からブラックホールの Schwarzschild 半径・事象の地平面・ISCO・光子球・Hawking 温度・蒸発寿命をリアルタイム計算します。恒星質量から超大質量ブラックホールまで、一般相対論と量子効果の両面で構造を可視化できます。

**Category:** 天体物理学・一般相対論
