# オイラー座屈荷重シミュレーター

オイラー座屈荷重シミュレーター：断面形状・端末条件・柱長さを変えてリアルタイム計算。臨界荷重とP_cr–L関係を可視化。座屈モード解析に。

**Category:** 座屈解析ツール

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/euler-buckling.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/euler-buckling.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/euler-buckling.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/euler-buckling
python -m http.server 8000
# open http://localhost:8000
```
