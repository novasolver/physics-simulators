# pH計算シミュレーター

強酸・弱酸・緩衝液・強塩基・弱塩基の pH をリアルタイム計算。Henderson-Hasselbalch 式と二次方程式の厳密解を併用し、滴定曲線と pH-濃度関係をグラフで可視化できます。

**Category:** 化学・環境工学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/acid-base-ph.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/acid-base-ph.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/acid-base-ph.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/acid-base-ph
python -m http.server 8000
# open http://localhost:8000
```
