# 体感温度（風冷指数）計算ツール

気温と風速を設定して体感温度をリアルタイム計算。凍傷リスクの確認や、風速別・気温別の体感温度グラフで冬の防寒対策に役立てよう。

**Category:** 気象・熱工学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/wind-chill-calculator.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/wind-chill-calculator.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/wind-chill-calculator.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/wind-chill-calculator
python -m http.server 8000
# open http://localhost:8000
```
