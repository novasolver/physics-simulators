# トーションバーばねシミュレーター

真っ直ぐな丸棒を「ねじる」だけでエネルギーを蓄えるトーションバーばねを設計するツールです。ロッド直径・長さ・材料を変えると、表面の最大せん断応力、ねじれ角、ねじり剛性、ひずみエネルギーがリアルタイムで分かり、車両懸架やボンネット・ガレージドア用の効率的なばねを検討できます。

**Category:** 機械要素
