# 脱出速度シミュレーター

脱出速度シミュレーターで天体の質量・半径からリアルタイム計算。地球・中性子星・ブラックホールの脱出速度を比較、物理シミュレーション・計算ツール。

**Category:** 天文・宇宙物理

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/escape-velocity.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/escape-velocity.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/escape-velocity.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/escape-velocity
python -m http.server 8000
# open http://localhost:8000
```
