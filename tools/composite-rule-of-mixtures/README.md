# 複合材料の複合則（混合則）シミュレーター

炭素繊維やガラス繊維で強化した複合材料の弾性率を予測するツールです。繊維と母材のヤング率・体積含有率を変えると、繊維方向（長手方向）と直交方向（横方向）のヤング率、異方性比、繊維の荷重負担割合がリアルタイムで分かり、繊維配向が剛性に与える影響を直感的に理解できます。

**Category:** 材料工学
