# 平面トラスFEMソルバー

直接剛性法（Direct Stiffness Method）で2次元ピン結合トラスを解析。プラット・ウォーレン・カンチレバーなど5種類から選んで、部材の引張・圧縮力と変形形状をリアルタイム可視化。

**Category:** 有限要素法・構造解析

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/fem-truss.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/fem-truss.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/fem-truss.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/fem-truss
python -m http.server 8000
# open http://localhost:8000
```
