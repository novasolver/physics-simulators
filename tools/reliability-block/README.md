# 信頼性ブロック図・システム信頼性計算

信頼性ブロック図（RBD）によるシステム信頼性計算。直列・並列・k-out-of-n構成のMTTF・R(t)・可用性をリアルタイム解析。Birnbaum重要度分析対応。

**Category:** 機械力学

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/reliability-block
python -m http.server 8000
```
