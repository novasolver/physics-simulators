# 2次元波動干渉シミュレーター

最大4点波源による2次元波動干渉パターンをリアルタイム可視化。波長・周波数・位相差・減衰を自由に調整し、ヤングの二重スリットや位相反転源、4隅グリッドアレイなどのプリセットも検証できます。

**Category:** 波動・音響・光学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/wave-2d.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/wave-2d.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/wave-2d
python -m http.server 8000
# open http://localhost:8000
```
