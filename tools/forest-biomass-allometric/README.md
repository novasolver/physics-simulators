# 森林バイオマス アロメトリー式シミュレーター

Chave 2014 pantropical アロメトリー式で、胸高直径 (DBH)・樹高・林相・立木密度から森林の地上部バイオマス、炭素貯留量、年間 CO₂ 吸収量、カーボンクレジット価値をリアルタイム推定します。REDD+ や J-クレジットの事前検討、IPCC NGGI 報告用の概算値の試算にお使いください。

**Category:** 林業・カーボンクレジット
