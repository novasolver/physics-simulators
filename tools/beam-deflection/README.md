# 梁の撓み・応力解析シミュレーター

梁の撓み・応力解析シミュレーター。単純支持梁・片持梁の撓み、曲げモーメント、せん断力をリアルタイム計算。FEM解析、構造設計に対応。

**Category:** 構造解析ツール

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/beam-deflection.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/beam-deflection.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/beam-deflection.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/beam-deflection
python -m http.server 8000
# open http://localhost:8000
```
