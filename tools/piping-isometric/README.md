# 配管重量・熱膨張計算ツール

配管システムの重量と熱膨張量をリアルタイム計算。DN15〜DN200×SCH10/40/80/XXSの肉厚をASME B36.10テーブルから自動参照。炭素鋼・SUS304・SUS316・合金鋼に対応。最大8セグメントの積算重量をグラフ表示。

**Category:** 構造解析
