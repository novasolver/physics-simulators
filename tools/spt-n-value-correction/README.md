# SPT N値の補正シミュレーター

標準貫入試験（SPT）の実測N値を、ハンマー効率によるエネルギー補正・ロッド長補正・有効上載圧による補正で換算し、N₆₀ と (N₁)₆₀ をリアルタイム計算。液状化判定や相対密度評価に使える正しい補正N値を求める無料の地盤工学ツールです。

**Category:** 地盤工学
