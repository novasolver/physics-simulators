電磁石の吸引力シミュレーター

コイルに電流を流したホースシュー型電磁石が、鉄板をどれだけの力で吸い付けるかをリアルタイムに計算するツールです。コイル巻数・電流・空隙・磁極面積・鉄心の比透磁率を変えると、起磁力 NI から磁束 Φ・磁束密度 B・Maxwell引力 F = B²A/(2μ₀) までが連動して動き、空隙を詰めることがなぜ最大の設計変数なのかが体感できます。

ホースシュー電磁石 — 磁束ループのアニメーション

コイル（青）→鉄心（灰）→空隙（橙）→被吸着物→反対側の空隙→鉄心、と閉じた磁気回路を磁束が周回します。流れの密度は B に比例して変化します。

空隙 g に対する吸引力 F(g)
磁極面積 A に対する磁束密度 B(A)
理論・主要公式

$$F = \frac{B^{2}\,A}{2\,\mu_{0}} \quad\text{(磁極1面あたり)}, \qquad F_{\text{total}} = 2F = \frac{B^{2}\,A}{\mu_{0}}$$

Maxwell の引力公式。B：空隙の磁束密度 [T]、A：磁極断面積 [m²]、μ₀ = 4π×10⁻⁷ H/m。ホースシュー型は両極で引くため2倍。

$$\Phi = \frac{N\,I}{\mathcal{R}_{\text{total}}}, \qquad \mathcal{R}_{\text{gap}} = \frac{2g}{\mu_{0}\,A}, \qquad \mathcal{R}_{\text{iron}} = \frac{\ell_{\text{Fe}}}{\mu_{r}\,\mu_{0}\,A}$$

磁気回路のオームの法則。N·I が起磁力、R が磁気抵抗（リラクタンス）。空隙は2ヶ所直列。本ツールでは鉄心長 ℓ_Fe = 0.2 m と仮定。

$$B = \frac{\Phi}{A}$$

磁束密度は磁束を磁極断面積で割ったもの。線形モデルは B < 約1.6〜2 T で有効、それを超えると鉄心が飽和し μ_r が急減する。

電磁石の吸引力とは

🙋
電磁石って、コイルに電流を流すだけで鉄を吸い付けるアレですよね？スクラップ工場のクレーンで鉄板を持ち上げる映像をよく見ます。あれって、どれくらい強い力が出てるんですか？
🎓
そう、リフティングマグネットだね。実は計算式自体はシンプルで、磁極の面に発生する吸引力は F = B²·A /(2·μ₀)（Maxwell引力）一発で決まる。B が磁束密度、A が磁極の面積、μ₀ は真空の透磁率。試しに左で B = 1 T、A = 5 cm² を想像してみると、片側で約 200 N、両極で 400 N — つまり 40 kgf くらいの鉄板を持ち上げられる電磁石になる、というイメージだよ。
🙋
じゃあ、B さえ大きくすれば力もどんどん上がる？コイルの電流をガンガン流せばよさそうですが…。
🎓
そこが「磁気回路」を理解しないと外す典型ポイントなんだ。B は「電流」では決まらず「起磁力 NI を全リラクタンスで割って得た磁束 Φ を A で割ったもの」で決まる。電気回路でいう Ohm の法則と同じ構造で、mmf = N·I が電圧、R_mag = ℓ/(μA) が抵抗、Φ = mmf / R_total が電流に対応する。電磁石ではこの R_total の中身がかなり偏っていて、ほとんどが「空隙」のリラクタンスなんだ。
🙋
空隙って、磁極と鉄板の間のすきま 0.5 mm とかですよね？たった 0.5 mm がそんなに効くんですか？
🎓
これがびっくりするくらい効く。空気の透磁率は鉄の数千分の一しかないから、0.5 mm の空気は「鉄なら 1〜2 m 分」の磁気抵抗に相当するんだ。左で空隙 g を 0.5 → 0.25 mm に半分にしてみて。Φ がほぼ倍になり、B も倍、力 F は B²に比例するから ほぼ4倍に跳ね上がる。逆に、鉄板に錆や塗装で 0.1 mm の浮きがあるだけで、設計値の半分の力しか出ない、なんてことが現場ではよくあるんだ。
🙋
じゃあ、コイル巻数を増やしたり電流を上げたりするのは何のため？
🎓
「空隙が決まった後で、必要な B を作るために起磁力を盛る」役目だね。N·I を増やせば Φ が比例して増えるけど、B が 1.6〜2 T を超えると鉄心が「飽和」して比透磁率 μ_r がガクッと落ちる。すると鉄のリラクタンスが急増して Φ がもう伸びない。だから「空隙を詰める」が第1の設計手段、「鉄心断面を太くする」が第2、「N·I を盛る」は最後、というのが定石だよ。右のグラフで A を増やしたとき B が下がるのも、同じ磁束を太い断面に通すから当然の話。
🙋
なるほど！じゃあ、計算で B が 2.5 T と出たら危ない設計だと一目で分かるんですね。判定が赤になるのを見て驚きました。
🎓
そう、そこが線形モデルの限界。実際の電磁石は B-H 曲線の非線形領域に入ると、計算値の半分しか力が出ない、ということも普通にある。だから飽和警告が出たら、まずは磁極面積 A を増やして B を 1.5 T 以下に戻すのが第一手。FEM電磁界解析（FEMM とか Ansys Maxwell）に進む前に、本ツールのような磁気回路の概算で当たりをつけておくと、メッシュ作りや材料カーブ設定の前に形状の妥当性を確認できるよ。

よくある質問

磁極1面あたりの吸引力は Maxwell の引力公式 F = B²·A / (2·μ₀) で求めます。B は空隙の磁束密度 [T]、A は磁極の断面積 [m²]、μ₀ = 4π×10⁻⁷ H/m は真空の透磁率です。ホースシュー型のように2つの磁極で被吸着物（ヨーク）を吸い付ける構造では両極が引くため、総吸引力は F_total = 2·F = B²·A / μ₀ になります。本ツールはこの式で N→ kgf も併記します。
磁気回路をオームの法則のアナロジーで解きます。コイルが起磁力 mmf = N·I [A·T] を発生し、これを磁気抵抗（リラクタンス）R_mag の総和で割ったものが磁束 Φ = mmf / R_total [Wb] です。各セグメントのリラクタンスは R_mag = ℓ /(μ·A) で計算し、空隙と鉄心を直列に足します。最後に B = Φ / A で磁束密度に変換します。電磁石では鉄心の透磁率が大きく、空隙のリラクタンスが圧倒的に支配するのが特徴です。
空隙のリラクタンス R_gap = 2g /(μ₀·A) は空隙長 g に比例し、しかも空気の透磁率が鉄の数千分の一しかないため、たった 0.5 mm の空隙でも鉄心 200 mm 分よりずっと大きな抵抗になります。空隙を半分にすると Φ がほぼ倍になり、F は B²に比例して4倍近く跳ね上がります。リフティングマグネットで吸い付ける鉄板の表面を研磨して隙間を 0.1 mm 以下にする、サビや塗装を嫌う、といった現場の常識はすべてこの式から来ています。
使えません。線形モデルが破綻しています。一般的な軟鋼の飽和磁束密度はおよそ 1.6〜2.0 T で、これを超えると鉄心の比透磁率 μ_r が一気に低下し、リラクタンスが急増します。実際の磁束は計算値より大幅に少なくなり、吸引力も頭打ちになります。本ツールは B > 2.0 T で「飽和」警告を出します。設計上は B を 1.5〜1.7 T 以下に抑えるよう、コイル巻数や磁極面積を増やしてください。

実世界での応用

リフティングマグネット（製鉄・スクラップ）：スクラップヤードや製鉄所のクレーン先端に取り付けられた円形リフティングマグネットは、まさにこのツールと同じ式で設計されています。直径1 m級のものは数十トンの鉄スクラップを吸着しますが、被吸着面の凹凸や錆により実効空隙が大きくなると性能が一気に落ちます。カタログ値は「平板＋クリーン面」の理想条件で、現場では 30〜50%の余裕を見るのが普通です。

電磁ブレーキ・電磁クラッチ：サーボモータの電源OFF時にブレーキを掛ける無励磁作動形ブレーキ、産業ロボットの関節保持、エレベーターの非常制動など、安全関連で必須の機構です。求められる保持トルクから必要な吸引力を逆算し、磁極面積と空隙を決めます。応答時間（msec オーダー）が重要なため、コイルのインダクタンスと電流立ち上がり時間も同時に検討します。

ソレノイドバルブ・継電器（リレー）：家電・自動車・産業機器に無数に使われる比例ソレノイドやON/OFFソレノイドも、空隙が動く電磁石です。ストロークの初期（空隙大）と終端（空隙小）で吸引力が桁違いに変化するのが特徴で、本ツールでスライダーを動かして空隙 g を 5 mm → 0.1 mm と振ると、その急峻な力カーブを目で確認できます。

磁気浮上・磁気軸受：磁気軸受やマグレブ（リニアモーターカー）は、電磁石の吸引力をフィードバック制御して非接触で物体を支える応用です。Maxwell引力は B²に比例して空隙に対して急峻に変化する「不安定」な力なので、kHz帯の高速電流制御が必須。設計の出発点はやはり「目標保持荷重 → 必要 B → 必要 NI と磁極面積」の磁気回路計算です。

よくある誤解と注意点

最大の落とし穴が、「カタログ吸引力をそのまま信じる」ことです。リフティングマグネットや電磁チャックのカタログ値は、被吸着物が「JIS規定の平板・厚さ十分・表面 Ra 6.3 以下・常温」という理想条件での値です。現場で実際に持ち上げるのは反り・サビ・塗装・ペンキ厚 0.1 mm を含む鉄板で、これだけで実効空隙が 0.5 mm 増えることがあります。本ツールで g = 0.1 mm と g = 0.5 mm の差を見れば一目瞭然ですが、4倍以上の力差になります。重量物の吊り上げには法定の安全率2〜5倍を必ず確保してください。

次に、「線形磁気回路モデルで設計を完結する」こと。本ツールは μ_r を一定とする線形モデルで、B < 約1.5 T の領域では実機と±10%以内で合います。しかし B > 1.7 T になると鉄心の B-H 曲線が急に寝てきて（飽和）、計算値より20〜40%少ない磁束しか得られません。さらに、磁路の角部や磁極端のフリンジング（磁束漏れ）も無視しています。最終設計は必ず2D/3DのFEM電磁界解析（FEMM、Ansys Maxwell、JMAG等）で B-H 非線形・漏れ磁束を含めて検証してください。本ツールは「FEMの前の当たり付け」と「FEM結果のサニティチェック」に使うのが正しい使い方です。

最後に、「DC電磁石とAC電磁石の違いを忘れる」点。本ツールは直流（DC）励磁を仮定しています。商用周波（50/60 Hz）のAC電磁石では、磁束が瞬時に0になる瞬間が存在するため、平均吸引力はピーク値の半分（実効値ではなく、F ∝ B²の時間平均）になります。さらに渦電流損による発熱、短絡環（shading coil）による2重磁路の必要性など、まったく別の設計上の配慮が要ります。AC電磁石を設計したい場合は、本ツールの結果を「ピーク値の目安」として扱い、実効吸引力は別途検討してください。

使い方ガイド

  1. コイル巻数（例：500巻）と電流値（例：2A）を入力して起磁力NI（A·T）を確定する
  2. 磁極面積（例：鋼板用電磁石で0.01 m²）と空隙距離（例：1mm）を設定し、空隙のリラクタンスを計算する
  3. 鉄心比透磁率（軟鋼で600～1200）を指定すると、磁束Φ（mWb）と磁束密度B（T）が自動算出される
  4. Maxwell応力張（F = B²A/(2μ₀)）から吸引力（N）および保持質量（kgf）を表示

具体的な計算例

ホースシュー型電磁石（軟鋼鉄心、比透磁率1000）にコイル1000巻、電流3Aを流した場合：起磁力NI = 3000 A·T、磁極面積A = 0.015 m²、空隙g = 0.5mm（μ₀ = 4π×10⁻⁷）とすると、空隙リラクタンス ≒ 2.65×10⁶ A/Wb、磁束Φ ≒ 1.13 mWb、磁束密度B ≒ 0.753 T、吸引力F ≒ 6.75 Nで約0.69 kgf相当の保持力が得られます。

実務での注意点

  • 産業用自動搬送装置では空隙0.3～1.0mmが標準で、0.1mm以下に縮めるとB²に比例して吸引力が急増するため飽和領域を避ける
  • コイル抵抗とDC抵抗損失により連続通電時の実効電流は定格値より低下するため、シミュレーション値は瞬時吸引力として解釈する
  • 軟鋼以外の材質（ステンレス304など非磁性材）では比透磁率が1に近く吸引力がほぼ発生しないため、磁性材料の確認が必須
  • 室温20℃での特性値であり、高温環境（100℃以上）では鉄心の比透磁率が15～20%低下するため補正が必要
