# ランキンサイクル・冷凍サイクルシミュレーター

蒸気動力（ランキン）サイクルと冷凍サイクルをT-s線図・P-h線図でリアルタイム可視化。熱効率・COP・各状態量を自動計算。

**Category:** 熱工学・熱力学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/rankine-cycle.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/rankine-cycle.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/rankine-cycle.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/rankine-cycle
python -m http.server 8000
# open http://localhost:8000
```
