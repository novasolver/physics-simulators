# Little の法則による処理能力計画シミュレーター

Little の法則による処理能力計画シミュレーターで、到着率と処理時間からWIPと能力余裕を評価。リードタイム最適化とボトルネック解析に活用。

**Category:** 対話型シミュレーター

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/capacity-planning-little-law.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/capacity-planning-little-law.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/capacity-planning-little-law.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/capacity-planning-little-law
python -m http.server 8000
# open http://localhost:8000
```
