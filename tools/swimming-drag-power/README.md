# 水泳・水中抵抗力・所要パワー計算ツール

泳法・体型・速度を設定して水中抵抗力・Reynolds数・推進パワーをリアルタイム計算。速度二乗則と所要パワーの速度三乗依存性をインタラクティブに体感。

**Category:** スポーツ流体力学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/swimming-drag-power.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/swimming-drag-power.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/swimming-drag-power.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/swimming-drag-power
python -m http.server 8000
# open http://localhost:8000
```
