# カプラン水車シミュレーター

船のプロペラのような軸流水車「カプラン水車」を設計するツールです。有効落差・流量・効率・ランナ直径・回転数を変えると、発電所の出力、比速度、ランナ周速、速度比がリアルタイムで分かり、低落差・大流量の水力発電がどう成り立つかを学べます。

**Category:** 流体力学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/kaplan-turbine.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/kaplan-turbine.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/kaplan-turbine.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/kaplan-turbine
python -m http.server 8000
# open http://localhost:8000
```
