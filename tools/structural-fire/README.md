# 火災時構造設計シミュレーター

Eurocode EN 1992-1-2の500°C等温線法を用いて、ISO 834標準火災を受けるコンクリート梁の温度分布と残存耐力を計算します。R30〜R120の耐火等級に対応します。

**Category:** 構造解析

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/structural-fire.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/structural-fire.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/structural-fire.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/structural-fire
python -m http.server 8000
# open http://localhost:8000
```
