# ステッピングモーターシミュレーター

ステッピングモーターの設計・選定を支援する無料オンラインシミュレーターです。ステップ角や保持トルク、トルク速度曲線からマイクロステッピング分解能まで、主要な特性をリアルタイムに計算・可視化。ブラウザ上で直感的に動作確認でき、装置開発や設計検討の効率化に最適です。

**Category:** 電磁気・光学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/stepper-motor.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/stepper-motor.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/stepper-motor
python -m http.server 8000
# open http://localhost:8000
```
