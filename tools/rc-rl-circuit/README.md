# RC/RL回路の過渡応答解析シミュレーター

RC/RL直列回路のステップ応答をτ=RC/L・Rで解析解と数値積分で比較。時定数・インピーダンス・エネルギーをリアルタイム計算し、過渡現象の本質を体感できます。

**Category:** 電気回路

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/rc-rl-circuit.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/rc-rl-circuit.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/rc-rl-circuit.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/rc-rl-circuit
python -m http.server 8000
# open http://localhost:8000
```
