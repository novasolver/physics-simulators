# ヒートポンプ・冷凍サイクル計算機

ヒートポンプと冷凍サイクルの性能を無料でシミュレーション。蒸発温度、凝縮温度、圧縮機効率を入力するだけで、COPや熱負荷をリアルタイム計算。R-410A、R-134a、R-32など主要冷媒に対応し、直感的なP-h線図も表示。設計評価や学習に最適なオンライン計算ツールです。

**Category:** 熱解析
