# ヒートポンプ・冷凍サイクルシミュレーター

ヒートポンプと冷凍サイクルの性能を、直感的なシミュレーションで分析。R134a、R410A、R290など冷媒を選び、蒸発温度や凝縮温度を自在に調整してCOP（成績係数）をリアルタイム計算。p-h線図で状態変化を可視化し、効率的なシステム設計をサポートします。

**Category:** 熱力学 / 冷凍工学
