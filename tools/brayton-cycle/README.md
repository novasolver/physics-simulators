# ブレイトンサイクル シミュレーター — ガスタービンの熱効率

ブレイトンサイクル シミュレーターは、空気標準サイクルとして圧力比・比熱比・吸気温度・タービン入口温度から熱効率・圧縮機出口温度・タービン出口温度・ネット仕事をリアルタイム計算します。なぜ圧力比を上げると効率が上がるのかをT-s線図で直感的に学べます。

**Category:** 熱機関シミュレーター
