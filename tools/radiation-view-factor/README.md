# 放射ビュー係数シミュレーター

平行矩形板・垂直交差板・同軸円板などのビュー係数 F₁₂ をリアルタイム計算。相反則 A₁F₁₂ = A₂F₂₁ の検証とパラメトリック曲線を可視化します。

**Category:** 熱解析

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/radiation-view-factor.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/radiation-view-factor.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/radiation-view-factor.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/radiation-view-factor
python -m http.server 8000
# open http://localhost:8000
```
