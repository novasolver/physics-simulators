# ボルト継手設計計算機

ボルト等級・径・締付けトルクを入力すると軸力・疲労安全率・剪断強度をリアルタイム計算。グッドマン線図で疲労余裕度を可視化します。

**Category:** 機械設計

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/bolted-connection.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/bolted-connection.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/bolted-connection.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/bolted-connection
python -m http.server 8000
# open http://localhost:8000
```
