# 需要と供給曲線シミュレーター

需要曲線・供給曲線のシフトをリアルタイム操作し、均衡価格・均衡数量の変化を可視化。価格弾力性・消費者余剰・生産者余剰・死荷重を直感的に探求できます。

**Category:** 経済学・ミクロ経済

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/supply-demand-curve.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/supply-demand-curve.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/supply-demand-curve.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/supply-demand-curve
python -m http.server 8000
# open http://localhost:8000
```
