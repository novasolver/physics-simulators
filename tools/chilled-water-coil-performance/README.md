# 冷水コイルの顕熱・潜熱能力と出口空気シミュレーター

冷水コイルの顕熱・潜熱能力シミュレーター。ε-NTU法と負荷マップで風量・UA値の不足箇所を特定、HVAC設計の出口空気条件を精密計算。

**Category:** 対話型シミュレーター
