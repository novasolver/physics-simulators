# 原子炉中性子拡散シミュレーター — 1群拡散理論

原子炉中性子拡散シミュレーター：1群拡散理論で炉心半径・反射体厚さを操作し中性子束分布とkeffをリアルタイム計算。臨界設計・反射体節約量の最適化に。

**Category:** 物理シミュレーター
