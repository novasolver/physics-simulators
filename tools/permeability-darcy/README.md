# ダルシー流れ計算

多孔質媒体と流体を選択し、圧力勾配・断面積を設定するだけで、ダルシー流速・体積流量・水理伝導率・浸透 Reynolds 数をリアルタイム算出。3 媒体の流量比較チャートで地下水と石油工学のスケール感が直感的に掴めます。

**Category:** 解析ツール
