# 冷却コイル熱負荷シミュレーター — 顕熱・潜熱・除湿

入口と出口の空気状態から、冷却コイルが処理する顕熱負荷・潜熱負荷・全熱負荷・除湿量・顕熱比SHFをリアルタイム計算。空気線図上に冷却過程を描画し、空調設計の基本を直感的に学べます。

**Category:** 熱流体・空調シミュレーター
