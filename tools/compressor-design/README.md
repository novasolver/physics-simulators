# 圧縮機設計計算機

NovaSolverの圧縮機設計計算機は、等エントロピー圧縮・ポリトロープ圧縮の出口温度や比仕事、断熱効率をリアルタイムで計算します。遠心・軸流・往復式圧縮機に対応し、T-s線図やP-v線図をインタラクティブに可視化。設計プロセスを効率化するシミュレーションツールです。

**Category:** 熱力学

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/compressor-design
python -m http.server 8000
# open http://localhost:8000
```
