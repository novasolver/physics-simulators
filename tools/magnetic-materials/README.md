# 磁性材料・透磁率・B-H特性計算機

磁性材料のB-H特性をオンラインで計算できる無料ツールです。軟鉄・珪素鋼・フェライト・パーマロイのヒステリシスループ、コア損失、透磁率曲線をリアルタイムに可視化。周波数や温度の影響も評価でき、材料選定やCAEシミュレーションの事前検討に最適です。

**Category:** 解析ツール
