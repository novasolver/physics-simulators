# 静力学的平衡 — 力とモーメントのつり合い計算機

支持条件・荷重・モーメントを設定すると未知反力を自動計算。自由体図をリアルタイムに描画し、つり合いを数値で検証します。

**Category:** 構造解析ソルバー

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/static-equilibrium.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/static-equilibrium.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/static-equilibrium.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/static-equilibrium
python -m http.server 8000
# open http://localhost:8000
```
