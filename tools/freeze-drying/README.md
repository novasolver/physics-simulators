# 凍結乾燥工程計算機

製品種別・棚温度・チャンバー圧力を設定して、昇華速度・一次/二次乾燥時間・エネルギー消費量をリアルタイム計算。温度-時間プロファイルと水分推移チャートを可視化します。

**Category:** 熱工学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/freeze-drying.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/freeze-drying.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/freeze-drying.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/freeze-drying
python -m http.server 8000
# open http://localhost:8000
```
