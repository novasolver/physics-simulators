# 核燃料燃焼度 Burnup シミュレーター

原子炉燃料（UO₂）の燃焼度・U-235 消費率・Pu 生成量・核分裂生成物の蓄積量・サイクル末期反応度をリアルタイム計算します。濃縮度・熱出力・運転日数・炉型を変えて、燃料サイクル設計の初期検討ができるツールです。

**Category:** 原子力工学
