# 歯車設計計算ツール

歯車設計計算ツール「NovaSolver」は、インボリュート歯形の描画からかみあい率、曲げ強度、面圧強度の計算までをリアルタイムで実行。モジュールや歯数を変更するだけで、歯車設計と強度計算の結果が視覚的に確認できます。機械設計やCAE解析の基礎を学び、実務に活かせる歯車解析ツールです。

**Category:** 機械設計ツール

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/gear-tooth
python -m http.server 8000
# open http://localhost:8000
```
