# 騒音・振動 dB 計算ツール

騒音・振動dB計算ツール。音圧レベル・距離減衰・A特性補正・複数音源合成をリアルタイム計算。点音源・線音源減衰グラフと振動dBレベル変換に対応したNVHエンジニア向けツール。

**Category:** 解析ツール

git clone https://github.com/novasolver/physics-simulators

python -m http.server 8000
# open http://localhost:8000
