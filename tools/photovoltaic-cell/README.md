# 太陽電池セル特性シミュレーター

太陽電池セル特性シミュレーター：I-V曲線とP-V曲線をリアルタイムで可視化。照射強度・温度・理想因子・抵抗値を調整してMPP・変換効率を解析。太陽電池設計の検証に。

**Category:** 電磁気

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/photovoltaic-cell
python -m http.server 8000
# open http://localhost:8000
```
