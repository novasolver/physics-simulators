# 結晶構造シミュレーター — SC/BCC/FCC/HCP/ダイヤモンド

結晶構造シミュレーターで充填率・配位数・格子定数をリアルタイム計算。ブラッグ回折角やミラー指数の解析に対応。SC/BCC/FCC/HCP構造の比較に最適。

**Category:** 材料科学シミュレーター

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/crystal-structure.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/crystal-structure.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/crystal-structure.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/crystal-structure
python -m http.server 8000
# open http://localhost:8000
```
