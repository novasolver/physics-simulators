# 黒体放射・プランク分布シミュレーター

プランクの輻射法則による黒体放射スペクトルを複数温度で同時表示。ウィーンの変位則・ステファン-ボルツマン則をリアルタイム計算。太陽・白熱電球・人体の色温度を体験。

**Category:** 熱放射・量子論

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/blackbody-radiation.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/blackbody-radiation.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/blackbody-radiation.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/blackbody-radiation
python -m http.server 8000
# open http://localhost:8000
```
