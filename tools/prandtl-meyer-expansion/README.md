# プラントル・マイヤー膨張 シミュレーター — 圧縮性流れ

プラントル・マイヤー関数で、超音速流れが凸角を回るときの膨張ファンを可視化。上流マッハ数・下流マッハ数・比熱比・上流静圧を変えて、流れの偏向角や下流の静圧・温度比がどう変化するかを学べます。

**Category:** 圧縮性流体シミュレーター
