# 熱分解反応速度シミュレーター

熱分解反応速度シミュレーター｜アレニウス式で転化率・TGA曲線をリアルタイム計算。木材・高分子・バイオマスの設計に対応。反応速度定数シミュレーション。

**Category:** 化学工学
