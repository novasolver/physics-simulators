# 陰極防食・防食電流・犠牲アノード設計計算機

ICCP・SACP陰極防食システムの防食電流・犠牲アノード設計計算。Dwight式・土壌比抵抗対応、配管電位分布をリアルタイム描画する専門計算ツール。

**Category:** 材料・破壊

- 🇺🇸 [English](https://novasolver.jp/en/tools/cathodic-protection.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/cathodic-protection
python -m http.server 8000
# open http://localhost:8000
```
