# 歯車列シミュレーター（平歯車・遊星歯車）

歯車列シミュレーターで平歯車・遊星歯車の動作をアニメーション確認。歯数比・回転速度・トルク比を自動計算し、増速・減速・逆転を体験できます。歯車設計・機械解析に最適。

**Category:** 機械設計・機構学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/gear-train.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/gear-train.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/gear-train
python -m http.server 8000
# open http://localhost:8000
```
