# 衝撃波管シミュレーター

衝撃波管シミュレーター「NovaSolver」は、1次元リーマン問題の厳密解をリアルタイムに計算・可視化します。衝撃波、接触不連続、希薄波の挙動を直感的に解析可能。ソッド衝撃波管から強い衝撃波、爆風波まで、圧縮性流体シミュレーションを簡単に実行できるCAEツールです。

**Category:** 流体解析

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/shock-tube
python -m http.server 8000
# open http://localhost:8000
```
