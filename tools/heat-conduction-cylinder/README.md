# 非定常熱伝導ヒーズラー線図計算機

非定常熱伝導ヒーズラー線図計算機は、平板・無限円筒・球の非定常熱伝導を1次近似（ヒーズラー線図）で解析します。ビオ数やフーリエ数から中心温度・表面温度・総熱移動量をリアルタイム計算。熱伝導問題の迅速な初期評価を支援するオンラインツールです。

**Category:** 熱工学
