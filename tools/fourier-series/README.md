# フーリエ級数シミュレーター

フーリエ級数シミュレーターで方形波・三角波・のこぎり波の高調波合成をリアルタイム観察。ギブス現象と周波数スペクトル解析に対応。

**Category:** 信号処理 / 数学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/fourier-series.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/fourier-series.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/fourier-series.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/fourier-series
python -m http.server 8000
# open http://localhost:8000
```
