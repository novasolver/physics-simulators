# 軸ねじり設計ツール

軸ねじり設計ツール「NovaSolver」は、動力と回転数からトルクを自動計算し、せん断応力・ねじれ角・必要軸径・危険速度を瞬時に算出します。中実/中空円形、正方形、矩形断面に対応した直感的なシミュレーターで、機械設計の軸ねじり計算を効率化。信頼性の高い設計をサポートします。

**Category:** 機械設計

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/torsion-shaft
python -m http.server 8000
# open http://localhost:8000
```
