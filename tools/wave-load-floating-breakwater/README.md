# 浮防波堤 波浪荷重・係留設計シミュレーター

浮防波堤（フローティングブレイクウォーター）の透過係数・反射係数・水平波力・係留索張力・ヒーブ固有周期をリアルタイム計算。Pontoon／Caisson／Catamaran／Mat の形式別性能と Macagno (1953) 理論で、マリーナや養殖場の波浪低減を設計できる無料シミュレーターです。

**Category:** 港湾・浮防波堤
