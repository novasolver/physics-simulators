# 波の回折・港湾内波浪計算

ソマーフェルト回折理論（Penney-Price）を用い、半無限防波堤背後での波浪回折係数K_D分布をリアルタイム計算。港湾内の波高分布と波エネルギーフラックスを可視化するCAE技術を解説。フレネル積分による簡易解から波浪エネルギーの伝播を詳細に評価します。

**Category:** 流体解析
