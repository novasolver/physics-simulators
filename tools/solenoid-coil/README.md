# ソレノイド・コイル設計計算機

ソレノイド・コイル設計計算機は、コイル形状・線径・コア材質を設定するだけで、インダクタンス・中心磁界・抵抗・蓄積エネルギーをリアルタイム計算。軸上磁界分布グラフも描画し、長ソレノイド近似やビオ・サバール式に基づく詳細解析をサポートします。効率的なコイル設計を実現。

**Category:** 電磁気・光学
