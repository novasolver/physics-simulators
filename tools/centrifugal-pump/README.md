# 遠心ポンプ特性曲線シミュレーター

遠心ポンプの特性曲線(H-Q曲線)とシステム曲線をリアルタイムでシミュレーション。羽根車径や回転数、配管抵抗を変更して最適な運転点と最高効率点(BEP)を自動解析。ポンプ選定や相似則(親和則)の確認に役立つ直感的なシミュレーターツールです。

**Category:** 流体機械シミュレーター
