# 最大酸素摂取量（VO₂max）推定シミュレーター

激しい運動中に身体が取り込める酸素の最大速度（VO₂max）を、心拍数比法で推定するツールです。安静時心拍数と最大心拍数を変えると、推定VO₂max・絶対VO₂max・最大METs・心拍予備能がリアルタイムで分かり、有酸素的な体力レベルを評価できます。

**Category:** バイオメカニクス
