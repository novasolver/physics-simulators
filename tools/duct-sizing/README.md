# HVAC ダクトサイジング シミュレーター — 矩形ダクトの圧損計算

風量・幅・高さ・長さから、矩形ダクトの水力直径・平均風速・単位長圧損・総圧損を実時間で算出。空調設計でのダクトサイズ決定と送風機静圧の見積もりに使えるツールです。

**Category:** HVAC 設計シミュレーター
