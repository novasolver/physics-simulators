たわみ角法シミュレーター

連続梁モデル — 荷重とたわみ形状

A（ピン）・B（中間支点）・C（ローラー）の3支点をもつ2スパン連続梁。各スパンの等分布荷重と、節点回転を含むたわみ形状を表示します。

曲げモーメント図（BMD）
中間支点モーメント vs スパン比 L2/L1
理論・主要公式

$$M_{ij}=\frac{2EI}{L}\,(2\theta_i+\theta_j)+M^{F}_{ij},\qquad M^{F}=\frac{wL^2}{12}$$

たわみ角法の基本式。M_ij：節点 i から部材 ij への端モーメント、θ：節点回転角、M^F：固定端モーメント。等分布荷重 w・スパン長 L の固定端モーメントは wL²/12。

$$M_{BA}+M_{BC}=0$$

中間節点 B のモーメントつり合い条件。両端の単純支持は回転を拘束しないため M_AB = M_CB = 0 という境界条件を課し、合計3式から3つの未知回転角 θ_A・θ_B・θ_C を解きます。

たわみ角法とは

🙋
「たわみ角法」って、不静定の梁を解くための方法なんですよね？でも、そもそも「不静定」だと何が難しいんですか？
🎓
いい質問だね。静定の梁なら、力のつり合いの式（鉛直方向とモーメント）だけで反力が全部決まる。ところが、この連続梁みたいに支点が3つ以上あると、つり合いの式の数より未知の反力の数のほうが多くなる。つまり「式が足りない」。これが不静定だ。足りない分は、梁が実際にどう変形するか——たわみや回転——を考えに入れないと解けないんだ。
🙋
なるほど。じゃあ、たわみ角法はその「変形」をどう使うんですか？
🎓
ざっくり言うと、発想を逆転させるんだ。ふつう「力（モーメント）」を未知数にしたくなるけど、たわみ角法では「節点がどれだけ回転するか」——回転角 θ——を未知数にする。各部材の端モーメントを M = (2EI/L)(2θ_i+θ_j) + 固定端モーメント という θ の一次式で書く。あとは各節点で「モーメントの合計はゼロ」というつり合いを立てれば、θ についての連立方程式になる。それを解けば、回転角が決まり、モーメントも反力も全部芋づる式に出てくる。
🙋
式の中に出てくる「固定端モーメント」って何ですか？左のスライダーで荷重を変えると結果が動くので、これが効いてそうですけど。
🎓
固定端モーメント（FEM）は、いったん「両端をガッチリ固定したと仮定したとき」に荷重が生む端モーメントのことだよ。等分布荷重なら大きさは wL²/12。たわみ角法の手順は2段階で、まず全節点を固定した仮想状態を考え、次にその固定をゆるめて節点が回転するのを許す。FEM は最初の「固定状態」の取り分で、回転による (2EI/L)(2θ_i+θ_j) の項が「ゆるめた補正」にあたるんだ。だから荷重 w を変えれば FEM が変わり、結果も変わる。
🙋
デフォルトの設定だと B点の回転角がほぼ0になっています。これはバグじゃなくて、ちゃんと意味があるんですか？
🎓
それは正しい結果だよ。2つのスパンが同じ長さで、同じ等分布荷重を受けている——つまり左右対称だね。対称な構造に対称な荷重がかかると、真ん中の節点 B は「左に回ろうとする力」と「右に回ろうとする力」が完全に釣り合うので、まったく回転しない。だから θ_B = 0 になる。このとき中間支点モーメントは M_B = wL²/8 という、教科書でおなじみの値になる。左右のスパン長や荷重を非対称にしてごらん、B がちゃんと回り始めるから。
🙋
この方法って、実務でも使うんですか？それともコンピュータ解析に取って代わられた古い手法ですか？
🎓
手計算としては大きな構造には使わなくなったけど、考え方そのものは今でも現役だよ。たわみ角法は「変位（回転）を未知数にして、剛性の式を立て、つり合いで解く」という流れだろう？これはまさに、今の構造解析ソフトが使っているマトリックス変位法＝有限要素法と同じ考え方なんだ。たわみ角法は、いわばFEMの手計算版・直接の祖先。だから、これを理解しておくと、ソフトが内部で何をやっているかが腑に落ちる。教育的にも実務の素養としても、知っておく価値は大きい。

よくある質問

たわみ角法（slope-deflection method）は、不静定構造を「節点の回転角」を未知数として解く変位法（剛性法）です。各部材の端モーメントを、節点回転角と固定端モーメントの一次式 M_ij = (2EI/L)(2θ_i+θ_j) + M^F_ij で表し、各節点でモーメントのつり合いを立てて回転角を求めます。回転角が分かれば、すべての端モーメント・反力・曲げモーメント図が決まります。現代の有限要素法（マトリックス変位法）の直接の祖先にあたる手法です。
固定端モーメント（Fixed-End Moment）は、両端を完全固定した状態でその部材に荷重を載せたときに、固定端に生じるモーメントです。たわみ角法では、まず「全節点を固定した仮想状態」での端モーメントとしてFEMを使い、その後に節点回転を許して補正します。等分布荷重 w・スパン長 L の場合、FEMの大きさは wL²/12 です。本ツールは時計回りを正とし、左端側を負・右端側を正の符号で扱います。
単純支持（ピン・ローラー）は回転を拘束しないため、その端で部材が曲げモーメントを受け取れません。よって連続梁の両端Aと点Cが単純支持なら、端モーメントは M_AB = 0、M_CB = 0 という境界条件になります。この2式と中間節点Bのつり合い M_BA + M_BC = 0 を合わせて3つの式となり、3つの未知回転角 θ_A・θ_B・θ_C を決定できます。本ツールはこの連立方程式を内部で解いています。
2つのスパンが等しい長さで、等しい等分布荷重を受ける対称な連続梁では、中間節点Bは回転しません（θ_B = 0）。このとき中間支点モーメントは M_B = wL²/8、両端の回転角は θ_A = wL³/(48EI)、スパン中央付近の最大正曲げモーメントは 9wL²/128、中間支点反力は R_B = 1.25wL となります。本ツールにデフォルト値（L1=L2=6m, w1=w2=10kN/m）を入れると、これらの教科書値が再現されることを確認できます。

実世界での応用

連続梁を持つ橋梁の設計：道路橋・歩道橋・高架橋の桁は、複数の橋脚にまたがる連続梁として設計されることが多くあります。連続梁は単純梁の連なりに比べて中央のたわみが小さく、桁を低くできる利点があります。一方で支点上に大きな負（ハギング）の曲げモーメントが発生するため、その断面の鉄筋・鋼材の配置が設計の要所になります。たわみ角法は、こうした支点モーメントを手計算で見積もる古典的な手段です。

建築の床梁・基礎梁：鉄筋コンクリート造や鉄骨造の建物では、柱の列に支えられた床の大梁が連続梁になります。連続梁では支点上で上側に引張が生じるため、RC梁では上端筋を支点付近で増やします。本ツールのようにスパン比や荷重を変えて支点モーメントの増減を確かめておくと、配筋計画の感覚が養えます。

マトリックス変位法・FEMの教育的導入：たわみ角法は「変位（回転）を未知数とし、剛性係数で力と変位を結び、つり合いで解く」という変位法の骨格を、もっとも素朴な形で示します。この流れは、現代の構造解析ソフトが内部で行っているマトリックス変位法とまったく同じです。FEMを学ぶ前にたわみ角法を手で解いておくと、剛性マトリックスや境界条件の処理が直感的に理解できます。

CAE結果のサニティチェック：梁要素を使った構造解析ソフトで連続梁モデルを組んだとき、支点モーメントや反力が妥当かどうかを、たわみ角法の概算と比べて検証できます。対称モデルなら θ_B≈0、M_B≈wL²/8 といった既知解と一致するはずで、もし桁違いの値が出ていれば、支点条件や荷重入力のミスを疑う手がかりになります。

よくある誤解と注意点

まず多いのが、符号規約の取り違えです。たわみ角法では「部材端モーメントは時計回りを正」とする規約が一般的ですが、この符号は「曲げモーメント図で下側に凸（サギング）を正とする」材料力学の規約とは別物です。固定端モーメントの符号、つり合い式の立て方、最後にBMDを描くときの読み替え——どこか一箇所で規約を混同すると、符号が反転して支点モーメントの正負が逆になります。本ツールは時計回り正・左端負/右端正で一貫させています。手計算で照合するときは、必ず自分の使う規約を最初に固定してください。

次に、「不静定次数」と「未知数の数」の混同です。この2スパン連続梁は反力が4つ、つり合い式が2つなので不静定次数は2ですが、たわみ角法で実際に解く未知数は回転角3つ（θ_A・θ_B・θ_C）です。変位法では「自由度（回転できる節点の数）」が未知数の数を決めるのであって、不静定次数そのものではありません。逆に応力法（たわみ角法と対をなす力法）では不静定次数の分だけ未知力を立てます。同じ問題でも、選ぶ手法によって未知数の数も種類も変わる点に注意してください。

最後に、このモデルの適用範囲です。本ツールは、支点沈下がなく、部材が直線で一様な曲げ剛性 EI を持ち、変形が微小で線形弾性にとどまる、という前提で解いています。実際の橋や建物では、支点の不等沈下が支点モーメントを大きく変えますし、温度変化やクリープ、軸力の影響（座屈や P-δ 効果）も無視できないことがあります。たわみ角法は支点沈下を θ に加える項として扱う拡張も可能ですが、本ツールは沈下なしの基本形に限定しています。結果はあくまで理想化されたモデルの値である点を理解して使ってください。

使い方ガイド

  1. 左パネルでスパン1長さ(l1)、スパン2長さ(l2)、曲げ剛性EI、分布荷重(w1)を設定する
  2. スライダーまたは数値入力欄でパラメータを変更するとリアルタイムで中間支点モーメントM_B、回転角θ_A・θ_B、最大曲げモーメント、支点反力R_Bが自動計算される
  3. 出力結果パネルで各値の符号と大きさを確認し、不静定次数1の連続梁解析の変位法計算過程を追跡できる

具体的な計算例

既定の対称2スパン連続梁：スパン1=スパン2=6m、EI=20000kN·m²、等分布荷重w1=w2=10kN/mの場合、中間支点モーメントM_B≈-45.0kN·m（=−wL²/8）、A点回転角θ_A≈0.00225rad（=wL³/48EI）、対称のため中間節点B回転角θ_B≈0、スパン1最大正曲げ≈25.3kN·m（=9wL²/128）、中間支点反力R_B≈75.0kN（=1.25wL）となる。たわみ角方程式と節点つり合いを連立させた教科書解と一致する。

実務での注意点

  • 支点沈下やサポート変位がない完全固定条件を仮定している。実構造で支点移動がある場合は境界条件を修正すること
  • 各スパンの等分布荷重w1・w2を個別に扱う。集中荷重や移動荷重ケースはパラメータ追加が必要。連続梁の曲げモーメントは支点位置で不連続になるため、詳細設計時は局部応力も確認すること
  • 曲げ剛性EIの値が小さすぎるとたわみが過大になる。鋼(E=200GPa)、RC梁(E=27GPa程度)、木材(E=10GPa程度)で適切なI値を入力すること
