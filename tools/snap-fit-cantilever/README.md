# スナップフィット設計シミュレーター

樹脂部品の「パチンとはまる」片持ち梁スナップフィットを設計するツールです。梁の長さ・付け根の厚さ・かかり量を変えると、組み立て時に発生する最大ひずみと挿入力がリアルタイムで分かり、爪が割れない安全な形状を探せます。

**Category:** 機械要素・樹脂設計

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/snap-fit-cantilever.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/snap-fit-cantilever.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/snap-fit-cantilever.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/snap-fit-cantilever
python -m http.server 8000
# open http://localhost:8000
```
