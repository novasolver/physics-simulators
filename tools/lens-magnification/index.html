理論・主要公式

$\dfrac{1}{a} + \dfrac{1}{b} = \dfrac{1}{f}$

倍率：$m = \dfrac{b}{a}$

b > 0 → 実像　b < 0 → 虚像
m < 0 → 倒立（実像）　m > 0 → 正立（虚像）

理解を深める対話

🙋
先生、ルーペで物を拡大して見るとき、スクリーンもないのに像が見えるのが不思議で。像ってどこにあるんですか？
🎓
ルーペで見える像は「虚像」だよ。物体をレンズの焦点距離より内側（a < f）に置くと、光線は実際には収束しないんだけど、レンズを通して見ると延長線上に拡大された像がある。スクリーンには映らないけど、目の水晶体がさらに収束させて網膜に実像を作るから「見える」んだ。位置としては物体と同じ側、でも遠い位置に拡大されて見える感じだよ。
🙋
じゃあカメラはどうなんですか？センサーに像が映っているから、そっちは実像ですよね？
🎓
その通り！カメラは実像を使っている。遠くの景色（a ≫ 2f）をレンズで縮小された実像としてセンサーに作る。例えば焦点距離50 mmのレンズで10 m先の人を撮ると、像距離は b = 1/(1/50 - 1/10000) ≈ 50.25 mm。倍率は b/a ≈ 0.005 で元の200分の1の大きさになる。これをデジタルで拡大して表示しているんだ。
🙋
映写機やプロジェクターはカメラの逆ですよね？フィルムを大きくスクリーンに映すから拡大実像？
🎓
まさに！プロジェクターはカメラを「逆向きに」使っている。フィルムを焦点距離 f とその2倍 2f の間（f < a < 2f）に置くと、反対側の遠い位置に拡大された実像ができる。プリセットの「映写機」では f=15 cm、a=18 cm（fと2fの間）で設定してあるから、試してみると大きく拡大された実像ができるのが確認できるよ。
🙋
物体を焦点上（a = f）に置くと「像なし」になりますが、なぜですか？
🎓
公式の 1/a + 1/b = 1/f に a = f を代入すると 1/b = 0、つまり b = ∞ になるんだ。焦点から出た光はレンズを通ると平行光になって無限遠で「交わる」けど、有限の場所では交点を作らない。懐中電灯やサーチライトの集光がこの原理で、光源を焦点に置くことで光を平行に遠くまで飛ばしているよ。
🙋
凹レンズはいつも虚像しかできないって本当ですか？近視の眼鏡に使われるって聞きましたが。
🎓
そう、凹レンズはどこに物体を置いても常に縮小された虚像しかできない。近視用の眼鏡はこの凹レンズで遠くから来た平行光を少し発散させる。本来なら網膜の手前で結像してしまう（だからぼやける）のを、凹レンズで発散させて結像点を後ろにずらし、ちょうど網膜上に合わせる。面白いのは、凹レンズは目に入る光を縮小して見せるので、近視の人が眼鏡をかけると景色が少し小さく見えることがあるんだよ。

よくある質問

$\dfrac{1}{a} + \dfrac{1}{b} = \dfrac{1}{f}$ という式です。a：物体距離（常に正）、b：像距離（実像は正・虚像は負）、f：焦点距離（凸レンズは正・凹レンズは負）。 倍率は $m = b/a$ で求められ、|m| > 1 なら拡大、< 1 なら縮小、m < 0 なら倒立像（実像）、m > 0 なら正立像（虚像）を意味します。
実像は光線が実際に1点に集まって形成される像で、スクリーンや写真フィルム・センサーに投影できます（カメラ・プロジェクターなど）。 虚像は光線の延長線が交わる「見かけ上の像」で、スクリーンには映りませんが目で見ることはできます（ルーペ・平面鏡・凹レンズなど）。 光路図では実像は実線の矢印、虚像は点線で表します。
凸レンズで a < f のとき、像距離 b = af/(f-a) が負になります。物体と同じ側（レンズ手前）に虚像ができ、正立・拡大（|m| > 1）です。 倍率は $m = f/(f-a)$ と表され、a が f に近づくほど無限大に近い倍率になります。これがルーペ・虫眼鏡の動作原理です。
カメラは物体を a > 2f（遠くの被写体）に置き、縮小された実像をセンサーに作ります。映写機（プロジェクター）は物体（フィルム）を f < a < 2f に置き、スクリーン側（遠い位置）に拡大された実像を作ります。 a = 2f のときは b = 2f となり等倍の実像ができます。この「2つの2f点の対称性」から、2f-2f間の物体は等倍で反対側の2f点に実像ができます。
近視は眼球が長すぎて網膜より前方で結像するため、凹レンズ（負の焦点距離）で光を発散させ、結像点を後方（網膜上）に移します。 遠視は眼球が短すぎて網膜の後方で結像するため、凸レンズで光を収束させます。眼鏡の「度数」（ディオプトリー D）はレンズの焦点距離（m単位）の逆数 D = 1/f で、例えば f = −0.5 m の近視レンズは −2.0 D と表記されます。

レンズ結像・倍率計算ツールとは

本ツールの物理モデルは、薄レンズの公式と結像の幾何光学に基づく。レンズの焦点距離を \(f\)、物体距離（レンズから物体までの距離）を \(a\)、像距離（レンズから像までの距離）を \(b\) とすると、次のガウスの結像公式が成立する。$ \frac{1}{a} + \frac{1}{b} = \frac{1}{f} $ ここで符号は実像・虚像を区別するために重要であり、本ツールでは実像を正の \(b\)、虚像を負の \(b\) として扱う。また、倍率 \(m\) は横倍率として次式で定義される。$ m = -\frac{b}{a} $ この値の絶対値が1より大きいとき拡大、小さいとき縮小を意味し、符号が負なら倒立像、正なら正立像を示す。物体距離が焦点距離より大きい場合（\(a > f\)）は実像が生じ、小さい場合（\(a < f\)）は虚像が生じる。本ツールはこれらの式をリアルタイムで計算し、主光線（平行光線と中心通過光線）の軌跡をCanvas上に描画することで、結像のメカニズムを視覚的に理解できるように設計されている。

実世界での応用

産業での実際の使用例
半導体露光装置メーカー（例：キヤノン・ニコン）では、レンズ設計時の結像性能評価に本ツールを活用。フォトリソグラフィ工程で使用する投影レンズの焦点距離調整や、物体距離（レチクル位置）と像面（ウェハー）の倍率誤差をリアルタイムに検証し、ナノメートル単位の重ね合わせ精度を確保している。また、スマートフォンカメラモジュールの組立工程では、レンズとイメージセンサの距離調整時に虚像・実像の判定を即座に行い、ピント調整の効率を向上させている。

研究・教育での活用
大学の光学実験や物理教育において、学生が焦点距離・物体距離をスライダーで変化させながら、像の位置や倍率が変化する様子を主光線の光路図と共に視覚的に理解できる。従来の数式のみの学習では困難だった「虚像が生じる条件」や「倍率の正負と倒立・正立の関係」を、CAEシミュレーター上で直感的に体感でき、光学設計の基礎概念の習得に貢献している。

CAE解析との連携や実務での位置付け
本ツールは、本格的な光学CAEソフト（例：Zemax、Code V）による詳細収差解析の前段階として位置付けられる。設計初期段階でガウス光学に基づく結像関係を簡易検証し、レンズ構成の大枠を決定した後、より精密な非球面最適化や迷光解析へ移行する。このプロセスにより、試作回数の削減と設計期間の短縮を実現している。

よくある誤解と注意点

「焦点距離が長いほど像は大きく見える」と思いがちですが、実際には物体距離との関係が重要です。同じ物体距離なら焦点距離が長いほど像は大きくなりますが、倍率は「像距離÷物体距離」で決まるため、焦点距離を変えれば像の位置も変わり、単純に焦点距離だけで倍率が決まるわけではありません。特に実務では、焦点距離を2倍にしても物体距離を調整すれば倍率を変えられる点に注意が必要です。

「物体を焦点より遠くに置けば必ず実像ができる」と思いがちですが、実際にはレンズの種類（凸レンズか凹レンズか）で虚像・実像の条件が変わります。凹レンズでは物体をどこに置いても虚像しかできず、実像は得られません。また、凸レンズでも物体を焦点距離よりも近くに置くと虚像になるため、結像の種類を判断する際はレンズの種類と物体距離の両方を必ず確認してください。

「倍率が1倍なら像の大きさは物体と同じで位置も同じ」と思いがちですが、実際には倍率1倍でも像の位置は物体の位置とは異なります。凸レンズで倍率1倍が得られるのは物体距離が焦点距離の2倍のときで、像はレンズの反対側に同じ距離だけ離れた位置にできます。物体と像の位置が一致することはなく、光路図を描く際にこの点を見落としがちなので注意が必要です。

使い方ガイド

  1. レンズの種類（凸／凹）を選び、焦点距離 f を cm 単位で入力します（凹レンズは内部で負の f として扱われます）
  2. 物体距離 a を cm 単位で入力します。レンズから物体までの距離を指定してください
  3. スライダーを動かすと像距離 b・倍率 m・像の虚実がリアルタイムに判定されます
  4. 物体高さ h を入力すると像高さも同時に表示されます

具体的な計算例

焦点距離 f=10cm の凸レンズで物体距離 a=25cm の場合：1/a+1/b=1/f より b = a·f/(a−f) = 25×10/15 ≈ 16.7cm（実像）。倍率 m = −b/a ≈ −0.67 で実像・倒立・縮小です。物体高さ 3cm なら像高さは約 2.0cm。f=25cm・a=30cm（f

実務での注意点

  • カメラレンズ設計では焦点距離100mm・物体距離500mmで倍率0.25倍の実像形成を確認し、撮像素子サイズとの適合性を検証してください
  • 顕微鏡対物レンズ(f=5mm)では物体距離6mmで像距離が-30mmとなり虚像を生成するため、接眼レンズとの組合せで最終倍率を計算します
  • 物体距離が焦点距離と等しい場合(u=f)は像距離が無限大となり、実際の結像系では焦点面での平行光出力となるため注意が必要です
  • 像距離が負値の場合は虚像であり、CRT投影系やプロジェクタレンズでは発散光学系の設計確認に使用します
