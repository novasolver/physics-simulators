# レンズ結像・倍率計算ツール

レンズ結像・倍率計算ツール - 焦点距離と物体距離から像の位置・倍率・虚実をリアルタイム計算。光学設計と光路図解析に対応した工学シミュレーション。

**Category:** 光学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/lens-magnification.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/lens-magnification.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/lens-magnification.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/lens-magnification
python -m http.server 8000
# open http://localhost:8000
```
