# クェット流れ シミュレーター — 平行平板間の粘性流

平行平板（上板速度 U、下板静止）の間の定常層流について、上板速度・隙間・粘性・圧力勾配を変えてせん断応力と単位幅流量、クェット＋ポアズイユの合成プロファイルをリアルタイム可視化。

**Category:** 粘性流体シミュレーター
