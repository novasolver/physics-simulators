# CSTR vs PFR 性能比較シミュレーター

CSTR vs PFR 性能比較シミュレーターは、1次反応 A→B における連続槽型反応器（CSTR）と管型反応器（PFR）の出口濃度・転化率・必要体積比をリアルタイム計算します。流量・体積・速度定数を変えて、なぜ同じ転化率なら PFR の方が小さくて済むのかを直感的に学べます。

**Category:** 化学工学シミュレーター
