# 打撃式岩盤掘削エネルギーシミュレーター

DTH（ダウン・ザ・ホール）、トップハンマー、ロータリーの打撃式岩盤掘削における単発打撃エネルギー・出力・削孔速度（ROP）・比エネルギー・空気消費量を計算。岩盤強度（UCS）・ピストン質量・速度・周波数・ビット径から、鉱業・トンネル掘削現場のドリル設計を行える無料シミュレーターです。

**Category:** 鉱業・土木掘削
