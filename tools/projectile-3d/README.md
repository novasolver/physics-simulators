# 3次元飛翔体運動シミュレーター

3次元飛翔体運動をシミュレーションできる無料オンライン計算機です。空気抵抗やマグナス効果（スピン）、風の影響を考慮し、野球・ゴルフ・サッカー・砲弾など様々なプリセットでリアルタイムに軌道を計算・描画します。物理シミュレーションを手軽に体験できます。

**Category:** 物理シミュレーター

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/projectile-3d
python -m http.server 8000
# open http://localhost:8000
```
