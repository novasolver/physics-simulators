仮想仕事の原理 — トラス撓みの単位荷重法

3部材単純トラスの頂点撓みを、仮想仕事の原理（単位荷重法）で実時間計算。形状・荷重・剛性を変えて、どの部材がどれだけ変位に効いているかを直感的に学べます。

理論・主要公式

仮想仕事の原理（単位荷重法）では、求めたい変位の方向に仮想単位荷重 1 を加え、各部材の仮想内力 n_i と実内力 N_i の積を全部材で総和して変位を求めます。

トラスの撓み（全部材を総和）。N_i は実荷重 P 時の内力、n_i は単位仮想荷重時の内力、L_i は部材長、E·A_i は剛性：

$$\delta = \sum_i \frac{N_i\,n_i\,L_i}{E A_i}$$

本トラスの内力（対称・頂点鉛直平衡より）。α は斜め部材と底辺の挟角：

$$N_\text{AC}=N_\text{BC}=\frac{P\,L_\text{AC}}{2h},\quad N_\text{AB}=\frac{P\,b}{4h}$$

仮想単位荷重時は同じ式で P=1：

$$n_\text{AC}=\frac{L_\text{AC}}{2h},\quad n_\text{AB}=\frac{b}{4h}$$

EA が共通なら、各項の寄与は N·n·L に比例します。斜め部材は2本分が加算される点に注意してください。

仮想仕事の原理シミュレーターとは

🙋
トラスの撓みって、ばねみたいに「ばね定数で割る」で求められるんですか？でもトラスって部材いっぱいあって、どれが効いてるか全然わからないです。
🎓
良い質問。トラスは部材が多くて連立方程式になるから、力学の素朴な「F/k」では追い切れない。そこで使うのが仮想仕事の原理（単位荷重法）だ。ざっくり言うと、撓みを知りたい点に「仮想の1の力」を加えて、各部材の N·n·L/(EA) を全部足せば変位が出る。式で書くと $\delta = \sum N_i n_i L_i / (EA_i)$ だね。上のシミュレーターで底辺長や高さを動かすと、寄与のバーが変わるのが見えるよ。
🙋
仮想の1の力ってどういう意味ですか？本当に荷重をかけるんじゃないんですよね？
🎓
そう、計算上の「仮想」の荷重だ。求めたい変位の場所と方向に大きさ1の単位荷重をかけたと「仮定」して、その時の各部材の内力 n_i を計算するんだ。エネルギーの保存（外仕事＝内仕事）から、実荷重 P による N_i と組み合わせて変位が出る、という仕組み。実務では「単位荷重法」と呼ばれて、トラス・梁・ラーメンどれでも同じ手順で使えるのが強みだよ。
🙋
シミュレーターで「斜め部材の寄与率 85%」って出てるんですけど、これってどう読めばいいんですか？
🎓
それがこの方法の真骨頂だ。頂点の鉛直撓み δ のうち、斜め2本の部材だけで全体の85%を占めている、という意味。つまり剛性を上げたいなら、底辺部材を太くしてもほとんど効かない。斜め部材の断面積 A を増やすのが正攻法だ。シミュレーターで「剛性 EA」を変えるとわかるけど、これは全部材共通で変えてるから、本来は部材別に最適化する。これが構造最適化の基本的な考え方だね。
🙋
なるほど！高さ h を上げると撓みが急に小さくなるのは何でですか？
🎓
鋭いね。式を見ると $N_\text{AC} = P L_\text{AC}/(2h)$ で、h が分母に来ている。つまり h を倍にすると内力が半分になる。さらに撓みは N と n の積（両方とも h に反比例）だから、h² で効く。実務では「背の高いトラスほど軽量で剛性が高い」と言われる理由はこれ。ただし、現場で多いのは天井高さや建築計画で h が制限されるパターンで、その中で最適な b/h 比を探すのが設計の腕の見せどころだよ。

よくある質問

数学的には等価です。カスティリアーノの第二定理 δ = ∂U/∂P を、トラスのひずみエネルギー U = Σ N²L/(2EA) に適用して P で偏微分すると、∂N/∂P がそのまま単位仮想荷重時の内力 n に一致するため、δ = Σ N·n·L/(EA) と同じ式になります。手計算では機械的に進められる単位荷重法が好まれますが、考え方の出発点はエネルギー法として共通です。
設計を改善する際、どの部材を補強すれば最も効果的かを判断するためです。例えば斜め部材の寄与率が85%なら、底辺部材を太くしても撓みはほとんど減らず、斜め部材の断面積を増やすべきとわかります。この感覚は、商用FEMソフトの結果を読む際にも役立ち、「全体剛性に効いている部材」を見抜く第一歩になります。
使えます。梁の場合は曲げモーメント M を用いて δ = ∫ M·m·dx/(EI) という形になり、トラスの和が積分に変わるだけです。ラーメン構造ではモーメント・軸力・せん断の各寄与を足し合わせます。ただし通常はモーメント項が支配的で、軸力・せん断項は無視できることが多いです。本ツールはまず軸力のみのトラスで原理を直感的に学ぶことを目的としています。
使えますが、ひと工夫必要です。不静定の場合、釣合いだけでは内力 N が決まらないため、冗長力を未知数として「整合条件（変位の連続性）」を立てて連立で解きます。この整合条件式自体が単位荷重法で書き下されるため、不静定解析の標準手法（柔性行列法・力法）の中心に位置します。本シミュレーターの3部材トラスは静定で、内力が釣合いだけで決まる最も基本的なケースです。

実世界での応用

建築・橋梁の設計初期検討：大規模トラス橋や屋根トラスの設計では、商用FEMにかける前に概略寸法を決める段階で単位荷重法が使われます。手計算で支配的な部材を見抜き、部材断面の初期見積もりを立てることで、後段のFEM解析の効率と精度が大きく向上します。

クレーン・ジブ・タワーの剛性評価：建設機械のジブ（伸縮アーム）やタワークレーンの先端撓みは、運転精度や荷揚げ精度に直結します。単位荷重法を使うと、先端変位に対する各部材の寄与が明確になり、軽量化と剛性向上を両立する設計指針が得られます。

構造最適化の出発点：「重量を最小化しつつ規定の剛性を満たす」という最適化問題では、各部材の感度（変位に対する寄与）を知ることが第一歩です。仮想仕事の原理は、この感度を物理的に解釈しやすい形で与えてくれるため、最適化アルゴリズム（位相最適化・サイズ最適化）の初期設計に活用されます。

有限要素法の理論的基礎：商用FEMソフト（Ansys、Abaqus、Nastran など）の根幹をなす変分原理は、まさに仮想仕事の原理を多自由度系に一般化したものです。要素剛性行列の組立てや全体方程式 Ku=f の導出はすべて、仮想仕事の評価から出てきます。FEMの結果を物理的に解釈できるかどうかは、この原理の理解にかかっています。

よくある誤解と注意点

まず最も多いのが、「仮想単位荷重」を実際にかける荷重と混同するミスです。仮想単位荷重は計算上の「もしもの荷重」であり、実構造に物理的にかかるわけではありません。求めたい変位の場所と方向に大きさ1の単位荷重をかけたと仮定して、その状態の内力 n を計算する——あくまで数学的なツールです。実荷重 P と区別がついていないと、N と n を混同して計算が全く合わなくなります。

次に多いのが、圧縮と引張の符号処理でつまずくことです。本シミュレーターでは内力を「大きさ」で扱い、圧縮（C）と引張（T）をラベルで区別しています。これは「同じ部材の同じ位置で実荷重も仮想荷重も同じ向きに内力が生じる」場合、N·n は正の積になるため、撓みへの寄与は正になるという理屈です。実務では符号付きで計算する流派もありますが、その場合は仮想荷重も実荷重と整合した符号規約で扱う必要があります。混在させると一部の項が誤って打ち消し合い、撓みが過小評価される危険があります。

最後に、EA を全部材共通とする本ツールの簡略化に注意してください。実構造では斜め部材と底辺部材で断面が異なるのが普通です。本ツールはあくまで仮想仕事の原理を直感的に理解するための教材で、EA を部材別に設定したい場合は手計算または商用FEMに進む必要があります。また、本ツールは部材の弾性（線形範囲内）のみを対象とし、座屈や塑性化、接合部の剛性などは考慮していません。実設計ではこれらの効果と安全率を必ず加味してください。

使い方ガイド

  1. 底辺長さB（mm）と高さH（mm）を設定してトラス形状を決定
  2. 頂点荷重P（kN）と部材軸剛性EA（kN）を入力
  3. シミュレーターが単位荷重法で仮想仕事方程式を自動計算し、頂点鉛直撓みδ、各部材内力、撓み寄与率をリアルタイム表示
  4. 部材応力度と変位の関係を確認し、構造安定性を検証

具体的な計算例

底辺B=3000mm、高さH=2000mm、頂点荷重P=50kN、EA=2.5×10⁵kNの対称二等辺トラスの場合：斜め部材ACの長さ√(1500²+2000²)≈2500mm、内力N_AC=62.5kN（圧縮）、底辺N_AB=37.5kN（引張）と計算され、頂点撓みδ≈8.3mmとなります。斜め部材の撓み寄与率は全体の約72%を占め、長大部材の変形が支配的であることが確認できます。

実務での注意点

  1. トラス部材の実効軸剛性EAは、鋼材（E=200GPa）では断面積との積で決定される—不等辺アングルの場合は塑性中立軸のずれに注意
  2. 仮想仕事の原理は幾何学的非線形性を無視するため、撓み/スパン比が1/100を超える場合は二次効果を別途評価が必要
  3. 鋭角部材の座屈余度が低い場合（スレンダー比λ>150）は、圧縮内力の安定性チェック（π²EI/L²）を実施すること
