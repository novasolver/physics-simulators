# 仮想仕事の原理 — トラス撓みの単位荷重法

3部材単純トラスの頂点撓みを、仮想仕事の原理（単位荷重法）で実時間計算。形状・荷重・剛性を変えて、どの部材がどれだけ変位に効いているかを直感的に学べます。

**Category:** 構造解析シミュレーター
