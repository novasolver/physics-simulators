# 細胞分裂・有糸分裂シミュレーター

細胞分裂・有糸分裂シミュレーターで間期から終期まで6ステージをリアルタイムアニメーション表示。細胞種類別の指数増殖グラフを検証できる教育用CAEツール。

**Category:** 生物シミュレーター

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/cell-division.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/cell-division.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/cell-division.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/cell-division
python -m http.server 8000
# open http://localhost:8000
```
