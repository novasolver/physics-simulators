# 主成分分析（PCA）シミュレーター — 2D データの固有値分解

2 次元相関データに対する主成分分析を可視化。共分散行列の固有値・固有ベクトル分解から主成分軸と寄与率を計算し、相関係数や標準偏差を変えてデータの構造と次元削減の効果を学べます。

**Category:** 統計・多変量解析シミュレーター
