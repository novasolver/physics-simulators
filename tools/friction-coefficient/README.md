# 摩擦係数シミュレーター — 静止・動摩擦と傾斜面解析

摩擦係数シミュレーターで静止摩擦と動摩擦を簡単解析。材料ペアと傾斜角を選ぶだけで、摩擦力や滑り判定、自己ロック角をリアルタイム計算。スチール、ゴム、テフロン等のプリセットと傾斜面アニメーションで、物理学習や設計検証を直感的にサポートします。

**Category:** 機械工学シミュレーター
