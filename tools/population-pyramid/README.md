# 人口ピラミッドシミュレーター

合計特殊出生率・平均余命・移民率を操作し、人口ピラミッドの形状変化をリアルタイム可視化。少子高齢化・人口置換水準・老年従属人口指数を直感的に学べます。

**Category:** 人口統計・社会科学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/population-pyramid.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/population-pyramid.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/population-pyramid.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/population-pyramid
python -m http.server 8000
# open http://localhost:8000
```
