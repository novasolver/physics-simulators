# オットーサイクル シミュレーター — 火花点火機関の熱効率

オットーサイクルシミュレーターで火花点火機関の熱効率を可視化。圧縮比・比熱比の影響をCAEで解析し、エンジン設計の基礎を学習できます。

**Category:** 熱機関シミュレーター

git clone https://github.com/novasolver/physics-simulators
