# ハッブルの法則シミュレーター

ハッブルの法則シミュレーターで銀河距離とハッブル定数から後退速度・赤方偏移・宇宙年齢をリアルタイム計算。宇宙膨張と光速超過現象をインタラクティブに探索。

**Category:** 宇宙物理

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/hubble-law-simulator.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/hubble-law-simulator.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/hubble-law-simulator.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/hubble-law-simulator
python -m http.server 8000
# open http://localhost:8000
```
