# 化学平衡シミュレーター・ルシャトリエの原理

化学平衡シミュレーターで、反応の濃度変化をリアルタイムにグラフ化。平衡定数KcやICE表の計算、ルシャトリエの原理を視覚的に学べます。ハーバーボッシュ法、ヨウ化水素の分解など具体例で理解を深め、温度変化の影響も確認できる無料オンライン計算ツールです。

**Category:** 化学工学
