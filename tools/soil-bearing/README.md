# 地盤支持力計算ツール

地盤の極限支持力と許容支持力をリアルタイム計算。粘着力・内部摩擦角・基礎形状（帯状/正方形/円形）を入力してテルツァーギ公式のNc・Nq・Nγ係数と支持力を即時算出。地盤工学・基礎設計に活用できる無料ツール。

**Category:** 地盤工学ツール
