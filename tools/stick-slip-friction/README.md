# スティック・スリップ摩擦シミュレーター — 自励振動の周期と振幅

バネで一定速度に引かれる質量が乾燥摩擦面上で「貼付き → 滑り → 貼付き」を周期的に繰り返すスティック・スリップ自励振動を可視化。静止摩擦と動摩擦の差が生む摩擦不安定の周期・振幅・周波数を直感的に学べます。

**Category:** 摩擦振動シミュレーター
