# 能動騒音制御 FXLMS の収束と安定性シミュレーター

能動騒音制御FXLMS の収束と安定性をシミュレーション。ステップサイズ調整による収束挙動と不安定化現象をリアルタイム解析。キャンセル波形と残留スペクトルで制御効果を可視化。

**Category:** 対話型シミュレーター

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/active-noise-control-fxlms.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/active-noise-control-fxlms.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/active-noise-control-fxlms.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/active-noise-control-fxlms
python -m http.server 8000
# open http://localhost:8000
```
