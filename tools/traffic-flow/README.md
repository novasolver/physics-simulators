# 交通流シミュレーター — LWR 基本図

グリーンシールズ・グリーンバーグ・アンダーウッドの 3 モデルで交通基本図をリアルタイム描画。流量-密度・速度-密度・速度-流量の 3 タブグラフと車両アニメーションで、渋滞発生のメカニズムを直感的に理解できます。

**Category:** 交通工学
