# 沸騰熱伝達計算機

Nukiyama曲線をリアルタイム描画。核沸騰・遷移沸騰・膜沸騰レジームを自動判定し、臨界熱流束（CHF）・ライデンフロスト点・Rohsenow相関による熱流束を計算。

**Category:** 熱解析

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/boiling-heat-transfer.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/boiling-heat-transfer.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/boiling-heat-transfer.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/boiling-heat-transfer
python -m http.server 8000
# open http://localhost:8000
```
