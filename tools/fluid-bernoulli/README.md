# ベルヌーイの定理シミュレーター

ベルヌーイの定理シミュレーターで管路内の圧力・速度・水頭をリアルタイム可視化。流体力学の計算・設計に必須のベンチュリ管・ピトー管解析ツール。

**Category:** 流体力学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/fluid-bernoulli.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/fluid-bernoulli.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/fluid-bernoulli.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/fluid-bernoulli
python -m http.server 8000
# open http://localhost:8000
```
