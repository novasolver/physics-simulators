# 歯車比・回転数・トルク計算機

歯車比・回転数・トルク計算機は、歯数や入力パラメータを設定するだけで、歯車比と出力回転数・トルクをリアルタイムに計算するCAEツールです。噛み合いアニメーションで動作を可視化。単純2歯車から複合歯車列、遊星歯車機構（リング固定）までの計算式をわかりやすく解説します。

**Category:** 機械力学
