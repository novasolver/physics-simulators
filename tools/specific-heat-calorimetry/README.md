# 比熱・熱量計算シミュレーター

Q=mcΔTをリアルタイム計算・グラフ化。材料ごとの熱容量の違い、混合熱量計による平衡温度、潜熱を含む加熱・冷却曲線を一画面で可視化します。

**Category:** 熱力学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/specific-heat-calorimetry.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/specific-heat-calorimetry.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/specific-heat-calorimetry.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/specific-heat-calorimetry
python -m http.server 8000
# open http://localhost:8000
```
