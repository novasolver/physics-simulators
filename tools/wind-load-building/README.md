# 建築物 風荷重計算ツール（ASCE 7-16）

ASCE 7-16に準拠した建築物の風荷重計算ツール。速度圧・設計風圧・ベースシアをリアルタイム算出し、耐風構造CAEの前処理に対応。風荷重解析・構造設計に。

**Category:** 構造解析

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/wind-load-building.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/wind-load-building.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/wind-load-building.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/wind-load-building
python -m http.server 8000
# open http://localhost:8000
```
