# 抗力・揚力計算機 — 球・円柱・平板の流体抵抗

抗力・揚力計算機は、球・円柱・平板の抗力係数CdをReynolds数依存の曲線から算出し、抗力・揚力・終端速度・カルマン渦周波数をリアルタイム計算します。形状・流体・速度を変更し、Stokes領域からカルマン渦まで、設計に直結する流体抵抗を把握できます。

**Category:** 流体工学
