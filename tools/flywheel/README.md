# フライホイール設計・エネルギー貯蔵・変動係数

NovaSolverの無料オンライン計算機で、フライホイール設計に必要な慣性モーメントや貯蔵エネルギー、速度変動、安全率を簡単に計算。ICエンジン、プレス機、風力発電などへの応用をサポート。ソリッドディスクやリング形状に対応した直感的な設計ツールです。

**Category:** 解析ツール

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/flywheel
python -m http.server 8000
# open http://localhost:8000
```
