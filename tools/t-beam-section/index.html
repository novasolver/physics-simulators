断面形状と曲げ応力分布

左＝T形断面（赤線＝弾性中立軸 y̅、青線＝塑性中立軸 PNA）／右＝曲げ応力分布 σ = M·y / I（上端＝圧縮、下端＝引張）

理論・主要公式

T形断面は、フランジ b_f × t_f とウェブ t_w × h_w から成る非対称断面です。図心位置と断面諸量は次式で求められます。

全面積と図心位置 y̅（フランジ上面からの距離）：

$$A = b_f t_f + t_w h_w,\qquad \bar{y} = \frac{b_f t_f \cdot \tfrac{t_f}{2} + t_w h_w \cdot (t_f + \tfrac{h_w}{2})}{A}$$

平行軸定理による断面2次モーメント I：

$$I = \frac{b_f t_f^3}{12} + b_f t_f\!\left(\bar{y}-\tfrac{t_f}{2}\right)^2 + \frac{t_w h_w^3}{12} + t_w h_w\!\left(t_f + \tfrac{h_w}{2} - \bar{y}\right)^2$$

断面係数（上端・下端）と形状係数 f：

$$S_\text{top} = \frac{I}{\bar{y}},\quad S_\text{bot} = \frac{I}{h - \bar{y}},\quad f = \frac{Z_p}{S_\text{min}}$$

塑性中立軸 PNA は A/2 の面積を上下に分ける位置で、塑性断面係数は Z_p = (A/2)(d_t + d_b)（d_t, d_b は上下重心の PNA からの距離）で計算されます。

T形断面シミュレーターとは

🙋
梁の断面って長方形や I形だけじゃなくて、T形もあるんですね。どうしてわざわざ非対称な形にするんですか？
🎓
いい質問だ。T形断面は鉄筋コンクリートのスラブ付き梁や、鉄骨のリブ補強された部材によく出てくる形だよ。広いフランジが圧縮側に来るように設計すると、コンクリートが圧縮、鉄筋が引張という役割分担にちょうど合う。上のシミュレーターで「フランジ幅 b_f」を大きくしてみて。図心 y̅ がぐっとフランジ寄りに上がるのが分かるはずだ。
🙋
既定値だと中立軸が上端から78.6 mmで、全高320 mmの中央じゃないんですね。だいぶ偏ってる。
🎓
そう、図心は「面積モーメントの平均位置」だから、面積が集中している方に引き寄せられる。式で書くと $\bar{y} = (\sum A_i y_i)/\sum A_i$ で、各部分の面積 × 重心距離の合計を全面積で割る。フランジは200×20 = 4000 mm²、ウェブは10×300 = 3000 mm² だから、面積が大きいフランジ寄りに図心が来るんだ。
🙋
あ、断面係数の S_top と S_bot もすごく違いますね。下側のほうがずっと小さい。
🎓
そこが T形断面で一番注意すべき点だ。S = I/y で、y は中立軸からの距離。下端までの距離（241 mm）は上端までの距離（79 mm）の3倍もあるから、S_bot は S_top の1/3以下になる。曲げ応力は σ = M/S だから、応力が大きく出るのは S が小さい下端側、つまり引張側。設計するときは下端側の引張強度で部材が決まることが多いんだよ。
🙋
形状係数が1.77ってありますけど、これは何ですか？
🎓
形状係数 f = Z_p/S は、断面が「最外縁が降伏する瞬間」から「全断面が塑性化する瞬間」までどれだけ余裕があるかを示す数字だ。長方形だと f = 1.5、I形だと1.1〜1.2、そしてT形だと1.6〜1.9。T形は非対称だから塑性中立軸が弾性中立軸からずれて、その分余力が大きい。塑性設計やヒンジ解析では、この余裕が重要な意味を持つんだ。

よくある質問

図心（弾性中立軸）は「面積モーメントの合計がゼロになる位置」、塑性中立軸（PNA）は「上下の面積が等しくなる位置」と、定義そのものが違うからです。長方形のような上下対称な断面では両者が一致しますが、T形のような非対称断面では一致しません。既定値では図心が上端から78.6 mm、PNAが17.5 mmと、60 mm以上ずれています。弾性挙動は図心、塑性挙動は PNA を使い分けてください。
断面諸量（I、Z_p、A）の値そのものは向きを変えても同じです。しかし曲げモーメントの符号と組み合わせると、圧縮側と引張側で材料の利用効率が変わります。鉄筋コンクリートでは「コンクリートを圧縮、鉄筋を引張」という前提から、フランジを上（圧縮側）にしてスラブと一体化させる構成が一般的です。鋼材のように引張・圧縮で強度が同じ場合は、応力レベルや座屈の有無で選択します。
曲げに対しては I への寄与が比較的小さいため、ウェブを薄くしても見かけ上は I の減少が穏やかです。しかしウェブは「せん断力を伝える」役割を担うため、薄くしすぎるとせん断応力が高くなり、ウェブの座屈やせん断降伏が支配的になります。実務では曲げ強度だけでなく、せん断強度・ウェブの幅厚比による局部座屈・補剛材の必要性まで総合的に確認します。
純粋な幾何的断面諸量としては正確ですが、実設計ではこの値を出発点として、材料係数（E、降伏応力 σ_y）、有効幅（コンクリート梁のスラブ協力幅）、安全係数、せん断・座屈・局部座屈・横座屈の検定、疲労評価などを加味する必要があります。学習・概念設計や初期検討には十分使えますが、最終的な設計判断は各国の構造基準（鋼構造設計規準・道路橋示方書・コンクリート標準示方書など）に従って行ってください。

実世界での応用

鉄筋コンクリートのスラブ付き梁：T形断面は鉄筋コンクリート構造の中で最もよく現れる断面の一つです。床スラブと梁を一体打ちすると、スラブが圧縮側のフランジとして働く「T形梁」になります。フランジの有効幅をどう取るかが設計上重要で、各国の構造基準に有効幅算定式が定められています。スラブの協力を考慮することで、長方形梁として設計するより合理的な配筋になります。

鉄骨梁とT形断面材：圧延T形鋼や、H形鋼を半分に切断して作るカットT材は、トラスの上下弦材、ブレース、軽量梁などに使われます。一方向に偏った曲げを受ける部位や、片側に取り合いを必要とする箇所で重宝されます。フランジが片側にあるため、ボルト接合や溶接施工がしやすいのも利点です。

建築・橋梁の合成梁：鋼桁の上にコンクリートスラブを乗せ、スタッドジベルなどで一体化させた合成梁は、断面性能上T形断面として扱われます。鋼が引張、コンクリートが圧縮を受け持つ役割分担で、それぞれの材料を最も効率良く使えます。橋梁の床版や、高層建築の床システムで広く採用されている構成です。

機械要素・補剛構造：機械フレームのリブ補強、薄板構造の補強材、レール断面など、片側に補強を施した形は事実上 T形断面と等価です。曲げに対する剛性を効率良く稼ぎたいとき、フランジで I への寄与を増やすという発想は、機械設計でも建築設計でも共通します。

よくある誤解と注意点

最も多い誤解は、「上端と下端で同じ応力評価をすればよい」と考えてしまうことです。T形断面は非対称なので、上下の断面係数 S_top と S_bot が大きく異なります。既定値では S_top ≈ 847 cm³ に対して S_bot ≈ 275 cm³ と3倍以上の差があり、同じ曲げモーメントを受けても下端側の応力は上端側の3倍になります。設計では必ず両側の応力を確認し、小さい方の S を基準に判定する必要があります。

次に多いのが、図心位置 y̅ と塑性中立軸 PNA を混同することです。両者は数学的に異なる量で、対称断面では一致しますが T形のような非対称断面では別物です。既定値では弾性中立軸が上端から78.6 mm、PNAは17.5 mm と60 mm以上ずれています。弾性応力を計算するときは y̅ から、塑性モーメントや塑性断面係数を計算するときは PNA からの距離を使ってください。シミュレーターでは赤線が弾性中立軸、黄破線が塑性中立軸として表示されています。

最後に、このシミュレーターは「純粋な断面諸量」だけを計算しており、実構造の挙動を完全には表していない点に注意してください。実際の T形梁では、フランジの局部座屈、ウェブのせん断座屈、横方向の倒れ（横座屈）、せん断遅れによるフランジの応力分布の非一様性、コンクリートのひび割れなど、断面諸量だけでは表せない現象が多数あります。本ツールは概念理解と初期検討用と位置付け、実設計では各国基準の規定する詳細検討を必ず行ってください。

使い方ガイド

  1. フランジ幅（Bf）とフランジ厚さ（Tf）をスライダーで設定します。例：Bf=200mm、Tf=15mm
  2. ウェブ幅（Tw）とウェブ高さ（Hw）を入力します。例：Tw=10mm、Hw=300mm
  3. 計算ボタンを押すと、断面2次モーメント I、中立軸位置 y̅、下側断面係数 S_bot、形状係数 f が自動算出されます

具体的な計算例

SS400鋼材のT形断面梁で、Bf=250mm、Tf=16mm、Tw=12mm、Hw=280mm、全長3.5mの場合を想定します。計算結果は I≈4,850万mm⁴、中立軸位置 y̅≈143mm（上端から）、S_bot≈339,000mm³となります。この梁に分布荷重7.5kN/mが作用すると、最大曲げモーメントM=11.5kN·mが生じ、曲げ応力は σ=M/S_bot≈34MPaで許容応力200MPa以下となり安全です。

実務での注意点

  • ウェブ幅が極端に薄い場合（Tw<8mm）は局部座屈を検討し、幅厚比制限 hw/tw≦85（SS400）を確認してください
  • 溶接T形断面は溶接止端部の応力集中係数を考慮し、名義応力に1.5～2.0倍の安全係数を適用します
  • 下側フランジが存在しないT形は非対称断面のため、圧縮側と引張側で許容応力が異なる場合は S_bot と S_top 両者で検証が必須です
