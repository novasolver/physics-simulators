# T形断面シミュレーター — 断面諸量と曲げ応力

T形断面のフランジとウェブの寸法から、図心・断面2次モーメント・断面係数・塑性断面係数・形状係数をリアルタイムに計算し、中立軸と曲げ応力分布を可視化します。

**Category:** 構造力学シミュレーター

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/t-beam-section.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/t-beam-section.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/t-beam-section.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/t-beam-section
python -m http.server 8000
# open http://localhost:8000
```
