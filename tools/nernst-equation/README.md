# ネルンスト方程式シミュレーター

ネルンスト方程式シミュレーター - 電極電位をリアルタイム計算、電池・燃料電池・腐食工学の基礎を直感的に学習。標準電位・温度・濃度・電子数パラメータ変更対応。

**Category:** 電気化学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/nernst-equation.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/nernst-equation.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/nernst-equation.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/nernst-equation
python -m http.server 8000
# open http://localhost:8000
```
