# 水跳び（跳水）計算ツール

水跳び計算ツール：フルード数とベランジェ方程式でリアルタイム判定。水理跳躍の共役水深・エネルギー損失を計算。水路設計・河川工学に必須。

**Category:** 水理学 / 開水路流れ

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/hydraulic-jump.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/hydraulic-jump.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/hydraulic-jump.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/hydraulic-jump
python -m http.server 8000
# open http://localhost:8000
```
