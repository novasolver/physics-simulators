# 熱交換器設計計算機（NTU-ε法・LMTD法）

高温流体・低温流体の流量・比熱・入口温度とUA値を設定し、出口温度・有効度ε・NTU・LMTD・必要伝熱面積をリアルタイム計算。並流／対向流の温度分布を可視化します。

**Category:** 熱工学シミュレーター
