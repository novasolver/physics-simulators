# 複利計算シミュレーター

元金・年利率・積立額・インフレ率を変えて資産成長をリアルタイム可視化。単利との比較、72 の法則、実質購買力までを 1 画面でチェックし、複利の力を直感的に体感できます。

**Category:** 金融数学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/compound-interest-sim.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/compound-interest-sim.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/compound-interest-sim.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/compound-interest-sim
python -m http.server 8000
# open http://localhost:8000
```
