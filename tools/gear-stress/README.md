# 歯車強度計算ツール

歯車強度計算ツール「NovaSolver」は、歯車の曲げ応力と接触応力、安全率を簡単に計算。モジュールや歯数、材質などの設計条件を入力するだけで、リアルタイムに強度評価が可能です。許容応力との比較グラフで視覚的に確認でき、機械設計や強度検討の効率化に最適です。

**Category:** 機械設計・強度解析

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/gear-stress
python -m http.server 8000
# open http://localhost:8000
```
