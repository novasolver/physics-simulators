# 球の運動シミュレーター

球の運動シミュレーターで投球軌跡を可視化。リアルタイム観察と物理パラメータ調整で流体力学・回転運動の検証が可能

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/ball-physics.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/ball-physics.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/ball-physics.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/ball-physics
python -m http.server 8000
# open http://localhost:8000
```
