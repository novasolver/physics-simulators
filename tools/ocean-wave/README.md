# 海洋波スペクトルシミュレーター

海洋波スペクトルシミュレーター：JONSWAP波スペクトルから不規則波をフーリエ合成し、有義波高・ピーク周期を操作してリアルタイム可視化。波形解析・CFDシミュレーション用途。

**Category:** 海洋工学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/ocean-wave.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/ocean-wave.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/ocean-wave.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/ocean-wave
python -m http.server 8000
# open http://localhost:8000
```
