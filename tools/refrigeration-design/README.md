# 冷凍サイクル設計計算機（蒸気圧縮式）

蒸発温度・凝縮温度・過熱度・過冷度・圧縮機効率を入力して、COP・冷凍能力・圧縮機仕事・吐出温度をリアルタイム計算。P-h線図にサイクルを可視化します。

**Category:** 冷凍・空調システム計算機

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/refrigeration-design.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/refrigeration-design.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/refrigeration-design
python -m http.server 8000
# open http://localhost:8000
```
