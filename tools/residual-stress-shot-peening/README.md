# ショットピーニングの残留応力シミュレーター

金属表面に小さな硬い球（ショット）を高速で打ち付けるショットピーニングは、表面に有益な圧縮残留応力の層を作り、疲労寿命を延ばします。降伏応力・アルメン強度・カバレッジを変えると、生じる圧縮残留応力・圧縮層の深さ・疲労限度の向上量がリアルタイムで分かります。

**Category:** 材料工学
