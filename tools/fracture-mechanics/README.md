# 線形破壊力学・応力拡大係数計算機

線形破壊力学（LEFM）に基づく応力拡大係数計算シミュレーター。き裂長さや材料特性を入力するだけで、破壊安全率や臨界き裂長さ、塑性域半径を即座に算出。直感的なK-a曲線グラフで破壊挙動を可視化し、材料設計や安全性評価を強力にサポートします。

**Category:** 計算ツール
