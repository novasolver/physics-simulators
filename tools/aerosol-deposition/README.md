# エアロゾル粒子沈降シミュレーター

粒径・密度・温度を調整して、Stokes 沈降速度・ブラウン拡散係数・Cunningham 補正係数・Stokes 数をリアルタイム計算。粒径範囲ごとの支配的な沈着メカニズムを可視化し、大気汚染解析・クリーンルーム設計・医療吸入薬開発に活用できます。

**Category:** 流体・大気工学

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/aerosol-deposition
python -m http.server 8000
# open http://localhost:8000
```
