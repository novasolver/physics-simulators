# スターリングエンジンサイクル・PV線図

スターリングエンジンサイクルのPV線図シミュレーション。温度・膨張比を操作しT-S線図・熱効率・正味仕事をリアルタイム計算。カルノーサイクル・オットーサイクルとの比較機能付き。

**Category:** 熱力学・エンジン

- 🇯🇵 [日本語](https://novasolver.jp/tools/stirling-engine-cycle.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/stirling-engine-cycle.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/stirling-engine-cycle.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/stirling-engine-cycle
python -m http.server 8000
# open http://localhost:8000
```
