# 分岐図シミュレーター — ロジスティック写像とカオス

分岐図シミュレーターでロジスティック写像のカオス現象をリアルタイム可視化。周期倍分岐とリアプノフ指数の動的シミュレーション。

**Category:** 非線形力学シミュレーター

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/bifurcation-diagram.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/bifurcation-diagram.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/bifurcation-diagram.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/bifurcation-diagram
python -m http.server 8000
# open http://localhost:8000
```
