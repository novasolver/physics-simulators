# 斜面上の運動シミュレーター

傾斜角・質量・摩擦係数・初速度を自由に設定。全力ベクトルの図解と位置・速度グラフをリアルタイム表示。摩擦による静止・滑り判定も自動計算。

**Category:** 物理シミュレーター

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/inclined-plane.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/inclined-plane.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/inclined-plane.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/inclined-plane
python -m http.server 8000
# open http://localhost:8000
```
