# ロジスティック成長モデル・人口動態シミュレーター

ロジスティック成長モデルの人口動態シミュレーター。増加率・環境収容力・初期個体数をパラメータ操作し、S字型成長曲線をリアルタイム計算。Lotka-Volterra方程式も対応。

**Category:** 生態数学・人口動態

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/logistic-population.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/logistic-population.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/logistic-population.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/logistic-population
python -m http.server 8000
# open http://localhost:8000
```
