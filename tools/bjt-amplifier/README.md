# BJTアンプ（CE / CB / CC）交流特性解析

NovaSolverの無料オンラインBJTアンプ交流特性シミュレーター。コモンエミッタ・コモンベース・コモンコレクタ回路の電圧利得、入出力インピーダンス、周波数特性を瞬時に解析。直感的な操作でボード線図を描画し、電子回路の設計・学習を強力にサポートします。

**Category:** 電磁気・光学
