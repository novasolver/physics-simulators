# 角柱・円柱後流シミュレーター — C_D とストローハル数

円柱・正方形・ティアドロップ断面のまわりに生じる後流を比較。亜臨界 Re 域での抗力係数 C_D、渦放出周波数 f、後流幅をリアルタイムに計算し、カルマン渦列を可視化します。

**Category:** 流体力学シミュレーター
