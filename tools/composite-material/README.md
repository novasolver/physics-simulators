# 複合材料（CFRP）特性計算シミュレーター

NovaSolverの複合材料（CFRP）特性計算シミュレーターは、炭素繊維やガラス繊維強化プラスチックの弾性率（E1, E2, G12, ν12）を簡単に計算。繊維体積率の影響をグラフで確認でき、積層板解析や強度評価（ツァイ-ウー破壊基準）まで対応する設計・研究支援ツールです。

**Category:** 材料工学・複合材料

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/composite-material
python -m http.server 8000
# open http://localhost:8000
```
