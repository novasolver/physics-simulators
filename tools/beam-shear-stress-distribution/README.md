# 梁内せん断応力分布 τ(y) = VQ(y)/(Ib)シミュレーター

梁内せん断応力分布τ(y)=VQ(y)/(Ib)の計算・可視化ツール。ウェブのせん断負担度を断面図と応力分布から読み取り、設計検証に活用。せん断応力分析。

**Category:** 対話型シミュレーター
