# クリープ変形計算

316Lステンレス・Inconel 718・Al6061・Ti-6Al-4Vのクリープ変形をNorton則で計算。応力・温度・時間を変えてクリープひずみ・破断寿命・Larson-Millerパラメータをリアルタイム評価。

**Category:** 材料・破壊
