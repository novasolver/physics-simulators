# 耐震設計シミュレーター

耐震設計シミュレーター「NovaSolver」は、応答スペクトル法に基づき建物の固有周期や層せん断力をリアルタイム計算。階数や地盤種別を変えて、建築基準法・IBC準拠の耐震性能をインタラクティブに検討できます。設計ベースシアや層間変位角の確認に最適なツールです。

**Category:** 構造工学

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/seismic-design
python -m http.server 8000
# open http://localhost:8000
```
