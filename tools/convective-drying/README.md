# 対流乾燥・乾燥速度計算機

恒率乾燥期間と減率乾燥期間を分離して全乾燥時間を算出。含水率 vs 時間の乾燥曲線と乾燥速度曲線（R-X線図）をリアルタイムで可視化します。

**Category:** 熱工学・乾燥工学
