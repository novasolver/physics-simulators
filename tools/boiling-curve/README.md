# 沸騰曲線シミュレーター — Nukiyama 曲線とプール沸騰

沸騰曲線シミュレーターでプール沸騰の熱流束を4域モデルで可視化。CHF・バーンアウト現象・Nukiyama曲線をシミュレーション。

**Category:** 伝熱シミュレーター

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/boiling-curve.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/boiling-curve.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/boiling-curve.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/boiling-curve
python -m http.server 8000
# open http://localhost:8000
```
