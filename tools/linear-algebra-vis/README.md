# 線形代数・行列変換ビジュアライザー

2×2行列の各成分をスライダーで操作し、2次元グリッドの回転・拡大・せん断をリアルタイムアニメーションで可視化。固有ベクトルが向きを変えない理由や、行列式（面積倍率）、固有値の意味が直感的に理解できるビジュアライザーを紹介。線形代数の核心概念を視覚的に学ぼう。

**Category:** 線形代数ビジュアライザー
