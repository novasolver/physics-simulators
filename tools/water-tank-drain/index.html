理論・主要公式

断面積 A のタンクが、面積 a のオリフィスから排水するときの非定常流出を扱います。

トリチェリの定理による流出速度と流量（Cd は流量係数）：

$$v = C_d \sqrt{2gh}, \qquad Q = a\,v = C_d\,a\,\sqrt{2gh}$$

水位の支配方程式（質量保存）：

$$A\,\frac{dh}{dt} = -Q = -C_d\,a\,\sqrt{2gh}$$

これを解くと、水位は時間の2次関数として減少します：

$$h(t) = \left(\sqrt{h_0} - \frac{C_d\,a}{A}\sqrt{\frac{g}{2}}\;t\right)^{2}$$

排水完了時間は、上式で h(t) = 0 とおいて求まります：

$$t_{empty} = \frac{A}{C_d\,a}\sqrt{\frac{2h_0}{g}}$$

タンク排水シミュレーターとは

🙋
お風呂の栓を抜くと最初は勢いよく流れて、だんだん遅くなりますよね。あれはなぜですか？
🎓
いいところに気づいたね。ざっくり言うと、流出の速さが「水位の高さ」で決まるからだ。トリチェリの定理によれば、流出速度は $v = \sqrt{2gh}$。水位 h が高いほど速く、低くなると遅くなる。上のシミュレーターで「初期水位 h₀」を上げて「排水アニメ」を押してみて。最初の勢いがまるで違うのが分かるよ。
🙋
本当だ！でも、なぜ落下した物体の速度と同じ式になるんですか？$\sqrt{2gh}$ って自由落下の式ですよね。
🎓
鋭いね。実はベルヌーイの定理を「水面」と「オリフィス出口」の2点に適用すると、位置エネルギー $gh$ がそのまま運動エネルギー $v^2/2$ に変換されることが分かる。だから自由落下と同じ式になる。エネルギー保存の観点では、高さ h だけ落ちた水の運動エネルギーと等しいわけだ。
🙋
なるほど！でも「流量係数 Cd」を 0.62 から 1.0 に上げると排水時間がかなり短くなりました。Cd って何ですか？
🎓
Cd は理論流量に対する実際の流量の比だよ。鋭い縁のオリフィスでは、流れが穴を出た直後にキュッと収縮する「縮流」が起こって、有効な断面積が減る。さらに粘性摩擦もある。だから現実の Cd は 0.6 くらい。逆に滑らかなノズルにすると 0.95 以上まで上がる。実務で配管の排水設計をするときは、この Cd を正しく見積もることが排水時間の予測精度を左右するんだ。

よくある質問

支配方程式 A dh/dt = -Cd·a·sqrt(2gh) は変数分離形の微分方程式です。両辺を sqrt(h) で割って積分すると sqrt(h) が時間の1次関数になり、したがって h は時間の2次関数として減少します。グラフが下に凸の放物線になるのはこのためで、満水時の傾き（流量）が最大、空に近づくほど傾きが緩やかになります。
排水時間はオリフィス面積 a に反比例します。直径を2倍にすると面積は4倍になるため、排水時間はおよそ4分の1になります。本シミュレーターでオリフィス面積を10cm²から40cm²に変えると、排水完了時間が約4分の1に短縮されることが確認できます。
いいえ。本シミュレーターは断面積 A が水位によらず一定の円筒（角柱）タンクを前提としています。円錐タンクや球形タンクでは断面積が水位の関数 A(h) となるため、支配方程式 A(h)·dh/dt = -Cd·a·sqrt(2gh) を改めて積分する必要があり、水位の時間変化は2次関数になりません。
トリチェリの定理の h は「自由表面からオリフィス中心までの高さ」です。オリフィスが側面の途中にある場合、水位がオリフィスの高さまで下がると流出が止まります。本シミュレーターはオリフィスがタンク底にある最も基本的なケースを扱っており、h はタンク底からの水位と一致します。

実世界での応用

給排水設備の設計：貯水タンク、プール、浄水場の沈殿池などの排水時間の見積もりに直接使われます。メンテナンスや清掃のためにタンクを空にする時間を予測し、排水弁やドレン配管のサイズを決定します。

水位計測と流量計：オリフィスやノズルを通る流れと水位（差圧）の関係は、オリフィス流量計・ベンチュリ流量計の原理そのものです。トリチェリの定理は、これらの流量計測機器の理論的基礎を与えます。

化学プラントのバッチ操作：反応槽や貯槽から次工程へ液を移送する時間の計算に用いられます。非定常流出の特性を理解することは、バッチプロセスのスケジューリングや配管設計で重要です。

水理模型実験と教育：トリチェリの定理は流体力学の入門で最初に学ぶ非定常問題の一つです。ベルヌーイの定理・連続の式・微分方程式の解法を一度に体験できる教材として、多くの大学の水理実験で扱われています。

よくある誤解と注意点

まず最も多い誤解が、流出速度がタンクの断面積 A に依存すると思い込むことだ。トリチェリの定理 $v = C_d\sqrt{2gh}$ には A が現れない。流出速度は水位 h だけで決まり、太いタンクでも細いタンクでも、同じ水位なら同じ速度で流れ出る。A が効くのは「排水時間」の方で、断面積が大きいほど排水に時間がかかる。シミュレーターで A だけを変えて流出速度 v が変わらないことを確認してほしい。

次に、排水時間を「平均流量で割る」単純計算で済ませようとするミス。流量は水位とともに刻々と変化する非定常問題なので、満水時の流量で全水量を割ると排水時間を大きく過小評価する。正しくは微分方程式を解いた $t_{empty} = (A/C_d a)\sqrt{2h_0/g}$ を使う。実は満水時の流量で割った値の「ちょうど2倍」が正しい排水時間になることを、式から確認できる。

最後に、流量係数 Cd を 1.0 として扱ってしまう落とし穴。理論式 $v = \sqrt{2gh}$ をそのまま使うと、実際より3〜4割大きい流量を見積もってしまう。鋭縁オリフィスでは縮流と粘性で Cd ≈ 0.62、現実の配管では継手や弁の損失も加わる。設計では必ず実測または信頼できる文献値の Cd を用い、安全側の余裕を見込むことが必要だ。

使い方ガイド

  1. タンク断面積(m²)をslAreaスライダーで設定します。例：円形タンク直径2m時は約3.14m²です
  2. オリフィス(排出孔)の断面積をslOriスライダーで指定します（単位cm²、範囲1〜80cm²）。例：直径4cmの円孔は約12.6cm²です
  3. 初期水位(m)をslH0スライダーで入力し、流出係数(無次元)をslCdスライダーで調整します。鋭孔は0.61、丸孔は0.98が標準値です
  4. シミュレーション開始後、リアルタイムで現在の水位h、トリチェリ速度v=√(2gh)、瞬時流量Q、排水完了時間が更新表示されます

具体的な計算例

タンク断面積A=1.0m²、オリフィス面積a=20cm²(=0.002m²)、初期水位h₀=2.0m、流出係数Cd=0.62の場合：初期流出速度はCdを掛けてv₀=0.62×√(2×9.81×2.0)=3.88m/s、初期流量Q₀=a×v₀=0.002×3.88≈7.77L/sです。水位がh=0.5mに下がると速度v=0.62×√(2×9.81×0.5)=1.94m/s、流量≈3.88L/sに減少します。排水完了時間 t_empty=(A/(Cd·a))·√(2h₀/g)≈515秒となります

実務での注意点

  • 流出係数Cdは孔の形状・縁の鋭さで変動します。腐食によって孔が拡大すると排水時間が短縮されるため、定期点検が必須です
  • 水位が0.1m以下の低水位域では、粘性損失・表面張力の影響が相対的に増加し、実測値がシミュレーション結果と乖離する傾向があります
  • 化学薬品貯蔵タンクの場合、流出液の粘度が水と異なるため、密度補正後のCd値を再設定する必要があります
  • 大型産業用タンク(A>10m²)では圧力波による振動が生じやすく、オリフィス内の乱流条件がシミュレーション仮定と異なります
