# タンク排水シミュレーター — トリチェリの定理

底部のオリフィスから排水するタンクの水位低下を、トリチェリの定理でリアルタイム可視化。断面積・オリフィス面積・流量係数を変えて非定常流出の挙動を学べます。

**Category:** 流体力学シミュレーター
