# ステファン・ボルツマン法則・輻射計算機

ステファン・ボルツマン法則に基づく輻射計算機で、黒体放射と実際の表面の輻射熱伝達をリアルタイム計算。プランク曲線によるスペクトル輝度の可視化、全輻射パワー、ウィーン変位則からの最大波長を自動算出。大環境中の小面の正味輻射熱交換も評価できるCAE技術解説です。

**Category:** 熱解析
