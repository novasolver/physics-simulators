# 建物熱損失シミュレーター

建物熱損失シミュレーターで壁・窓・屋根のU値を設定してリアルタイム計算。暖房エネルギーと断熱性能を可視化し、断熱改善効果を即座に評価できるCAEツール。

**Category:** 熱解析

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/heat-loss-building.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/heat-loss-building.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/heat-loss-building.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/heat-loss-building
python -m http.server 8000
# open http://localhost:8000
```
