# フラッター速度計算（V-gダイアグラム）

フラッター速度計算（V-gダイアグラム）の2自由度曲げ・ねじり解析ツール。準定常空力理論でリアルタイム計算。翼のフラッター速度評価に必須。

**Category:** 航空宇宙

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/flutter-analysis.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/flutter-analysis.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/flutter-analysis.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/flutter-analysis
python -m http.server 8000
# open http://localhost:8000
```
