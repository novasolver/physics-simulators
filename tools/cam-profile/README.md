# カムプロファイル設計シミュレーター

カムプロファイル設計シミュレーター「NovaSolver」で、ディスクカムの設計と動作確認をリアルタイムに実施できます。単純調和、サイクロイド、修正正弦など主要な運動プログラムを比較し、変位・速度・加速度・圧力角を同時に可視化。機械設計や機構学の学習・開発を支援する直感的なCAEシミュレーションツールです。

**Category:** 機械設計・機構学

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/cam-profile
python -m http.server 8000
# open http://localhost:8000
```
