# パラメトリック共振シミュレーター

パラメトリック共振シミュレーターで、マシュー方程式の安定・不安定領域をビジュアルに探索。δ-εパラメータ空間の安定性チャートと振動応答をリアルタイムに計算・可視化。フロケ理論に基づく直感的な理解を深める、教育・研究に最適なインタラクティブツールです。

**Category:** 振動工学
