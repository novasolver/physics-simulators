# 定在波・弦の振動モードシミュレーター

弦に張力をかけ、長さや線密度を変えると基音・倍音の定在波がアニメーションでくっきり現れます。固有周波数の値もリアルタイムに更新され、ギター調弦の感覚からFEMの固有値解析まで一直線につながる波動の基礎を体験できます。

**Category:** 波動・振動
