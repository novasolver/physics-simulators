# ねじり振動解析シミュレーター（多慣性系）

2〜4 慣性体・シャフト系のねじり振動固有値解析をリアルタイム計算。固有振動数・モード形状・キャンベル線図を即座に可視化し、回転機械の危険速度を直感的に把握できます。

**Category:** 振動解析

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/torsional-vibration.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/torsional-vibration.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/torsional-vibration.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/torsional-vibration
python -m http.server 8000
# open http://localhost:8000
```
