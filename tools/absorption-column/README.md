# 吸収塔設計計算ツール — NTU / HTU

ガス吸収塔の設計計算を支援するオンラインツールです。NTU（移動単位数）とHTU（移動単位高さ）の計算、y-x線図による操作線・平衡線の可視化、充填塔高さや吸収ファクターの算出を直感的に行えます。充填塔設計の効率化に役立つシミュレーターです。

**Category:** 化学工学・分離操作
