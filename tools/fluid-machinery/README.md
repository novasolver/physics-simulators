# ポンプ・ファン性能曲線シミュレーター

ポンプ・ファンの性能曲線をリアルタイムでシミュレーション。回転速度や配管抵抗を変更して動作点を計算し、キャビテーション（NPSH）評価も可能なツールです。ポンプ・ファン選定や性能予測に役立つシミュレーター「NovaSolver」を今すぐお試しください。

**Category:** 流体機械シミュレーター

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/fluid-machinery.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/fluid-machinery.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/fluid-machinery
python -m http.server 8000
# open http://localhost:8000
```
