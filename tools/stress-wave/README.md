# 弾性波伝播シミュレーター

NovaSolverの弾性波伝播シミュレーターは、1D棒モデルにおける応力波の挙動を可視化します。材料界面での反射係数と透過係数の計算をリアルタイムで体験でき、衝撃工学や超音波探傷の基礎学習に最適です。波動伝播の原理を直感的に理解できるツールです。

**Category:** 衝撃・波動力学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/stress-wave.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/stress-wave.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/stress-wave.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/stress-wave
python -m http.server 8000
# open http://localhost:8000
```
