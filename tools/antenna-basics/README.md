# アンテナ基礎・ダイポールアンテナ計算

ダイポールアンテナの設計をサポートする無料オンラインシミュレーターです。共振周波数や放射抵抗、アンテナ利得、指向性パターンをリアルタイムで計算・可視化。給電点インピーダンスやVSWRの特性も簡単に確認でき、アンテナの基礎学習や最適な設計に役立ちます。

**Category:** 電磁気・光学

```bash
git clone https://github.com/novasolver/physics-simulators

python -m http.server 8000

```
