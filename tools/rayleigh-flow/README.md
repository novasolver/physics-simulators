# レイリー流れ シミュレーター — 無摩擦加熱ダクト流とチョーキング

摩擦なし・加熱（または冷却）付き・一定断面ダクトを流れる圧縮性流れを可視化。入口マッハ、比熱比、加熱量、入口総温度を変えながら、出口マッハ、総温度・静圧比、レイリー線図上の状態点の動きを学べます。

**Category:** 圧縮性流体シミュレーター
