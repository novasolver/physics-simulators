# 誕生日問題シミュレーター

「n人のクラスで同じ誕生日の人が1組以上いる確率」を計算・アニメーションで体感。直感を大きく裏切る確率論の名問題をインタラクティブに探索できます。

**Category:** 確率・統計

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/probability-birthday.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/probability-birthday.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/probability-birthday.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/probability-birthday
python -m http.server 8000
# open http://localhost:8000
```
