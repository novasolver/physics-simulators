# 液体スロッシング解析

液体スロッシング解析シミュレーター。タンク幅・液深・密度を入力するだけで、固有振動数と等価振り子長をリアルタイム計算。ノルトン則に基づく最初の5モードを棒グラフで可視化し、タンク設計や耐震設計の効率的な検討を支援します。直感的な操作で液体の動的特性を把握。

**Category:** 流体解析
