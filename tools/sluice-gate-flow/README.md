# スルースゲートの流れシミュレーター

水路に立てた平板ゲート（スルースゲート）の下から噴き出す自由流出を計算するツールです。ゲート開度・上流水深・ゲート幅を変えると、流量・縮流後の水深・下流流速・フルード数がリアルタイムで分かり、射流の発生具合を確かめられます。

**Category:** 流体工学
