# 収縮拡大ノズル（ド・ラバルノズル）設計計算機

収縮拡大ノズル設計計算機。出口マッハ数・面積比から等エントロピー流れ理論により軸方向のマッハ数・圧力・温度分布を即座に計算。衝撃波位置可視化対応。

**Category:** 超音速流体力学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/nozzle-design.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/nozzle-design.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/nozzle-design.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/nozzle-design
python -m http.server 8000
# open http://localhost:8000
```
