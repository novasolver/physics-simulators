# 光電効果シミュレーター

光の振動数・光子数・金属の仕事関数をスライダーで操作。飛び出す光電子のエネルギー・停止電圧・光電流をリアルタイム計算し、量子論が古典論を覆した歴史的発見を体験。

**Category:** 量子力学・光物理

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/photoelectric-effect.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/photoelectric-effect.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/photoelectric-effect.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/photoelectric-effect
python -m http.server 8000
# open http://localhost:8000
```
