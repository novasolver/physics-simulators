# モデル予測制御シミュレーター — 有限ホライズン最適化

モデル予測制御シミュレーターで有限ホライズン最適化を実装。1次プロセスの離散化と予測ホライズンによる最適入力計算、MPC vs PID応答比較を可視化。

**Category:** 制御工学シミュレーター

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/model-predictive.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/model-predictive.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/model-predictive.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/model-predictive
python -m http.server 8000
# open http://localhost:8000
```
