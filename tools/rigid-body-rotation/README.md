# 剛体回転・慣性モーメントシミュレーター

円板・リング・球・棒の慣性モーメント I をリアルタイム計算・可視化。平行軸定理・回転エネルギー・角運動量を操作しながら、回転動力学を直感的に学べます。

**Category:** 力学・機械工学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/rigid-body-rotation.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/rigid-body-rotation.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/rigid-body-rotation.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/rigid-body-rotation
python -m http.server 8000
# open http://localhost:8000
```
