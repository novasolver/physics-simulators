# 音楽和音・倍音シミュレーター

基音・和音タイプを選んで周波数スペクトル・合成波形・倍音構造をリアルタイム可視化。協和音と不協和音の物理的な違いを数式で理解できます。

**Category:** 音楽・音響物理

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/music-chord-harmonics.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/music-chord-harmonics.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/music-chord-harmonics.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/music-chord-harmonics
python -m http.server 8000
# open http://localhost:8000
```
