# 流体静力学・水圧・浮力計算機

流体の種類・物体形状・密度を変えて水圧・浮力・圧力中心をリアルタイム計算。物体が浮くか沈むかを視覚的に確認し、アルキメデスの原理を直感的に理解しよう。

**Category:** 流体力学シミュレーター

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/fluid-statics.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/fluid-statics.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/fluid-statics.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/fluid-statics
python -m http.server 8000
# open http://localhost:8000
```
