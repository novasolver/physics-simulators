# Fick 第2法則による1次元拡散プロファイルシミュレーター

Fick第2法則の1次元拡散シミュレーター。拡散長・濃度減衰・フラックス・到達時間を同時確認。拡散プロファイル解析に必須。

**Category:** 対話型シミュレーター
