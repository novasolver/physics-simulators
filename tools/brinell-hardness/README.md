# ブリネル硬さ試験シミュレーター — HBW と圧痕径

タングステンカーバイド球圧子による塑性押込みを可視化。荷重・圧子径・圧痕径から HBW・圧痕深さ・適正判定をリアルタイム計算し、d/D 比と F/D² 荷重定数の意味を学べます。

**Category:** 材料試験シミュレーター
