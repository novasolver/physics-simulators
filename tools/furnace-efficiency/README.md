# ボイラ・炉の熱効率シミュレーター

ボイラや工業炉が燃料の熱をどれだけ有効に使えているかを、熱損失法（ジーゲルト式）で評価するツールです。燃料・空気比・排ガス温度を変えると、煙突から逃げる排ガス損失と熱効率、省エネの余地がリアルタイムで分かります。

**Category:** 伝熱工学
