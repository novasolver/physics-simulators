# DCモーター・速度トルク特性シミュレーター

DCモーターの速度トルク特性を無料でシミュレーション。分巻・直巻・永久磁石・BLDCモーターの特性グラフ、効率、起動電流をリアルタイム計算。界磁弱め制御や回生制動の影響も可視化。電圧や抵抗などのパラメータを自由に設定できるオンライン計算ツールです。

**Category:** 電磁気・光学
