# 偏光・ジョーンズベクトル・複屈折計算

偏光状態のジョーンズベクトルをシミュレーションできる無料オンラインツールです。線偏光・円偏光・楕円偏光を設定し、偏光子や位相板を組み合わせた光学システムの出力を自動計算。ストークスパラメータとポアンカレ球による可視化で、光の偏光特性を直感的に理解できます。

**Category:** 電磁気・光学
