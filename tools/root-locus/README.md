# 根軌跡法・制御系設計ツール

根軌跡法による制御系設計ツール。開ループ極・零点からゲイン変化時のs平面根軌跡をリアルタイム描画、安定余裕・ステップ応答を自動計算。制御工学・システム安定性解析に対応。

**Category:** 制御工学

- 🇺🇸 [English](https://novasolver.jp/en/tools/root-locus.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/root-locus
python -m http.server 8000
# open http://localhost:8000
```
