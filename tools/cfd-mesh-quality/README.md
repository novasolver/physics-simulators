# CFDメッシュ品質指標計算機

CFDメッシュ品質を無料で評価。アスペクト比やスキューネス、直交性など主要指標を自動計算し、OpenFOAMやANSYS Fluent、Star-CCM+の許容範囲とレーダーチャートで視覚的に確認。シミュレーション精度向上のための第一歩を。

**Category:** 流体解析

- 🇯🇵 [日本語](https://novasolver.jp/tools/cfd-mesh-quality.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/cfd-mesh-quality.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/cfd-mesh-quality.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/cfd-mesh-quality
python -m http.server 8000
# open http://localhost:8000
```
