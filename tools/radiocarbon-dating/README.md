# 放射性炭素年代測定シミュレーター

放射性炭素年代測定シミュレーター｜C-14残存率から年代と不確かさをリアルタイム計算。崩壊曲線・誤差伝播・年代測定法比較も対応

**Category:** 考古学・核物理

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/radiocarbon-dating.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/radiocarbon-dating.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/radiocarbon-dating.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/radiocarbon-dating
python -m http.server 8000
# open http://localhost:8000
```
