# ローレンツ力・荷電粒子運動シミュレーター

電子・陽子・任意の荷電粒子について、磁場・電場中での軌道をリアルタイムにアニメーション表示。ローレンツ力・サイクロトロン半径・サイクロトロン周波数を自動で計算します。

**Category:** 物理シミュレーター

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/magnetic-force.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/magnetic-force.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/magnetic-force.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/magnetic-force
python -m http.server 8000
# open http://localhost:8000
```
