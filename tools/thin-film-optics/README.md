# 薄膜光学・反射防止コーティングシミュレーター

薄膜光学シミュレーター「NovaSolver」で反射防止コーティングの設計を簡単に。膜厚と屈折率を自在に設定し、反射率スペクトルをリアルタイムで計算。高反射ミラーやビームスプリッタープリセットで、光学薄膜の開発・学習を強力にサポートします。

**Category:** 電磁気・光学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/thin-film-optics.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/thin-film-optics.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/thin-film-optics
python -m http.server 8000
# open http://localhost:8000
```
