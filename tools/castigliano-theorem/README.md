# カスティリアーノの定理 シミュレーター — エネルギー法によるたわみ計算

第2法則 δ=∂U/∂P を使い、片持ち梁の先端集中荷重 P と等分布荷重 w それぞれの寄与を分離して可視化。重ね合わせの原理と固定端モーメントを直感的に学べます。

**Category:** 構造力学シミュレーター
