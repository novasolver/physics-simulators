# キャンベル線図シミュレーター — ロータの危険速度

キャンベル線図シミュレーターは、回転機械の自然振動数とジャイロ効果による前進・後退分岐、エンジンオーダー線との交点から複数の危険速度をリアルタイムに可視化します。ロータの2モード×3次励振による危険速度マップで運転速度の余裕を直感的に学べます。

**Category:** 回転機械シミュレーター
