# 形状記憶合金（SMA）シミュレーター

変態温度（Ms/Mf/As/Af）・Clausius-Clapeyronスロープ・最大回復ひずみ・ヒステリシス幅を計算。NiTi・Cu系・FeMn系のプリセット対応。温度–応力–ひずみ応答を可視化。

**Category:** SMA Calculator
