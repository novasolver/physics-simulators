# 爆風圧・爆発荷重計算シミュレーター

TNT等価装薬量と距離から爆風の最大過圧・衝撃波速度・正圧持続時間をリアルタイム計算する爆風解析シミュレーター。Hopkinson-Cranz相似則とKingery-Bulmash近似でFriedlander波形を可視化し、防爆設計・耐爆構造解析に対応。

**Category:** 衝撃・防爆工学

```bash
git clone https://github.com/novasolver/physics-simulators

python -m http.server 8000
# open http://localhost:8000
```
