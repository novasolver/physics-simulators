# 波紋プールシミュレーター

波紋プールシミュレーターで2D波動方程式を可視化。クリックするだけで波紋を発生させ、複数の波源による干渉や回折をリアルタイムに観察できます。波の速度や減衰、波源の数も自由に調整可能。物理シミュレーションやCAE音響解析の基礎学習に最適なインタラクティブツールです。

**Category:** 振動・波動

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/ripple-pool
python -m http.server 8000
# open http://localhost:8000
```
