# 接触熱抵抗シミュレーター

2つの固体を押し付けた接触面に生じる「接触熱抵抗」を評価するツールです。接触圧力・表面粗さ・伝達熱量・界面材を変えると、接触熱コンダクタンスと界面温度差（温度ジャンプ）がリアルタイムで分かり、放熱経路のボトルネックを見つけられます。

**Category:** 伝熱工学
