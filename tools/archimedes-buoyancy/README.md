# アルキメデスの原理・浮力計算ツール

物体の密度・体積・流体の種類をスライダーで操作し、浮力・重力・合力をリアルタイム計算。浮く・沈む・浮遊の判定条件を動的に確認。船舶・気球・潜水艦の設計原理を学ぶ。

**Category:** 流体静力学・浮力

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/archimedes-buoyancy.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/archimedes-buoyancy.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/archimedes-buoyancy.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/archimedes-buoyancy
python -m http.server 8000
# open http://localhost:8000
```
