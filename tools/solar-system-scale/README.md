# 太陽系スケール比較シミュレーター — 8 惑星の距離・サイズ・光速時間

水星から海王星まで太陽系 8 惑星の距離 (AU)・直径・光が到達する秒数を実スケールで比較できる科学普及シミュレーター。ケプラーの第 3 法則 T² ∝ a³ をインタラクティブに探求でき、サイズと距離の桁感覚が掴めます。動く惑星公転は『太陽系シミュレーター』を併用してください。

**Category:** 宇宙・天文
