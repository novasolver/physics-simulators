# 弾性床上梁の反力分布と特性長シミュレーター

弾性床上梁の反力分布と特性長を可視化するシミュレーター。地盤ばね係数と沈下量の関係、支持長への影響を解析。Winkler地盤モデル対応。

**Category:** 対話型シミュレーター

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/beam-on-elastic-foundation
python -m http.server 8000
# open http://localhost:8000
```
