# Bloom フィルタの偽陽性率とビット数シミュレーター

Bloomフィルタの偽陽性率とビット数をシミュレーション。ハッシュ数最適化でメモリと精度のバランスを調整。ビット配列設計ツール。

**Category:** 対話型シミュレーター

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/bloom-filter-false-positive.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/bloom-filter-false-positive.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/bloom-filter-false-positive.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/bloom-filter-false-positive
python -m http.server 8000
# open http://localhost:8000
```
