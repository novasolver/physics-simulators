# ハーゲン・ポアズイユ流れ シミュレーター — 円管層流

円管内の完全発達層流について、半径・管長・圧力差・粘性係数を変えて体積流量と放物線速度分布をリアルタイム可視化。Q ∝ R⁴·ΔP の関係を直感的に学べます。

**Category:** 管路流体シミュレーター
