理論・主要公式

ハーゲン・ポアズイユの法則は、円管内の完全発達層流に対する体積流量を解析的に与えます。ナビエ・ストークス方程式から導かれ、ニュートン流体・層流・円管・一定断面という条件下で厳密に成り立ちます。

体積流量と平均流速：

$$Q = \frac{\pi R^{4}\,\Delta P}{8\,\mu\,L},\qquad V_{\mathrm{avg}} = \frac{Q}{\pi R^{2}} = \frac{\Delta P\,R^{2}}{8\,\mu\,L}$$

放物線速度分布（最大流速は平均の2倍）：

$$u(r) = V_{\max}\!\left(1-\frac{r^{2}}{R^{2}}\right),\qquad V_{\max} = 2\,V_{\mathrm{avg}}$$

層流判定のためのレイノルズ数：

$$Re = \frac{\rho\,V_{\mathrm{avg}}\,(2R)}{\mu}$$

$R$ は管半径 [m]、$L$ は管長 [m]、$\Delta P$ は両端の圧力差 [Pa]、$\mu$ は粘性係数 [Pa·s]、$\rho$ は密度 [kg/m³]、$r$ は管中心からの半径方向距離です。

ハーゲン・ポアズイユ流れ シミュレーターとは

🙋
点滴の落ちる速さって、針の太さと薬液の粘り、それとボトルの高さで決まるって聞いたんですけど、計算式ってあるんですか？
🎓
それがまさにハーゲン・ポアズイユの法則 $Q = \pi R^{4}\Delta P/(8\mu L)$ だ。針の半径 R の4乗、圧力差 ΔP に比例し、針の長さ L と薬液の粘性 μ に反比例する。R⁴ なのが効いていて、針径を半分にすると流量は 1/16 になる。だから医療現場で「太い針か細い針か」の選択は流量に決定的に効くんだ。
🙋
え、半径の4乗ですか！じゃあ管が少し細くなるだけで流れが激減するんですね。
🎓
そうそう。動脈硬化で血管が少し狭くなるだけで血流が大きく落ちるのも同じ理屈だよ。シミュレーターで R を 2 mm から 1 mm にしてみて。流量がきっちり 1/16 になるのが確認できる。逆に圧力差 ΔP は1乗だから、これを倍にすると流量も倍にしかならない——「管を太くする」ほうが「圧力を上げる」よりずっと効率的だ。
🙋
速度分布の図、中心ほど矢印が長くて壁に近づくと短いですけど、これって何を表してるんですか？
🎓
層流の有名な「放物線速度分布」だ。式は $u(r) = V_{\max}(1 - (r/R)^{2})$ で、中心 r=0 で最大、管壁 r=R で 0 になる。壁で速度が 0 になるのは「ノースリップ条件」と呼ばれる流体力学の基本仮定だ。これを断面で平均すると最大流速の半分になるから、$V_{\max} = 2\,V_{\mathrm{avg}}$ になる。デフォルト値（R=2 mm, L=10 m, ΔP=10 kPa, μ=0.001 Pa·s）だと V_avg = 0.5 m/s、V_max = 1.0 m/s だね。
🙋
じゃあ Re（レイノルズ数）が出てるのはなぜですか？層流の式なのに。
🎓
いい質問だ。ハーゲン・ポアズイユ式は「層流である」という前提のもとでだけ正確に成り立つ。だから Re をモニタリングして「本当に層流域か？」を確認する必要があるんだ。目安は Re < 2300 が層流、2300〜4000 が遷移、4000 以上が乱流。デフォルト値で Re = 2000 と層流境界の近くだから、ΔP を上げていくと Re も比例して増え、いつか乱流域に入る。乱流域では別途、ダーシー・ワイスバッハ式とムーディー線図が必要になる——ぜひ「ムーディー線図」シミュレーターも試してみて。

よくある質問

層流ではナビエ・ストークス方程式の慣性項が無視でき、粘性項と圧力項のバランスだけで運動方程式が解析的に解けます。その解が放物線速度分布であり、断面積分から Q = πR⁴ΔP/(8μL) が導かれます。乱流になると慣性項に起因する乱流応力（レイノルズ応力）が支配的になり、解析解が存在しません。実用上は Re が約2300を超えると乱流に遷移するため、ハーゲン・ポアズイユ式は Re < 2300 で適用するのが基本です。それ以上では Q ∝ ΔP の線形関係が崩れ、Q ∝ √ΔP に近づきます。
大動脈などの大血管では脈動流であり厳密には適用できませんが、毛細血管・細動脈・細静脈などの低 Re（数〜数十）の細い血管では良い近似となり、生理学・医学では広く使われています。ただし血液はニュートン流体ではなく赤血球濃度に依存する非ニュートン性（特にせん断速度が低いほど見かけの粘度が増す）を持つため、見かけの粘度補正が必要です。現代の血流シミュレーションでは、ハーゲン・ポアズイユ式を出発点にして非ニュートン項・脈動項・血管壁の弾性項を順次追加していく形で精度を高めます。
管入口では速度分布が一様（プラグ流）に近いですが、壁面の粘性の影響が中心に向かって広がっていき、ある距離（助走区間）を過ぎると放物線分布に落ち着きます。この状態を「完全発達」と呼びます。層流の場合の助走長は L_e ≈ 0.06·Re·D 程度（D は管径）で、Re=2000、D=4 mm なら L_e ≈ 0.48 m となります。本シミュレーターはこの助走を終えた領域での値を計算しており、入口近傍の助走部分では実際の流量・速度はやや異なります。設計では助走長より十分長い管を仮定するか、入口損失係数を別途加算します。
そのままでは使えませんが、層流であれば矩形ダクト・三角形ダクト・環状流路などにそれぞれ解析解があります。たとえば一辺 a の正方形ダクトでは Q = K·a⁴·ΔP/(μ·L) の形で K ≈ 0.0351 と表されます。実務では水力直径 D_h = 4A/P（A=断面積、P=濡れぶち長さ）を使って円管の式に置き換える近似がよく用いられますが、層流ではせいぜい10〜20%程度の誤差を含むので、精密計算には形状ごとの解析解または数値解（CFD）を使うのが望ましいです。

実世界での応用

医療：点滴・輸液・カテーテル設計：点滴の滴下速度は針の内径とボトル高さ（ヘッド圧）でコントロールされ、設計の基本式はまさにハーゲン・ポアズイユ式です。針径が R⁴ で効くため、規格化された針径（18G、20G、22G ...）の選択は薬液到達速度の主要因子です。腎透析の血液回路、麻酔薬の持続投与、CTやMRIの造影剤注入なども、流量・粘性・カテーテル径の関係をこの式で見積もって設計されています。

マイクロ流体・LOC（Lab on a Chip）：マイクロ流体チップでは数十〜数百 μm の流路を扱い、Re はほぼ常に 1 以下なので層流が前提です。ハーゲン・ポアズイユ式（および矩形断面の解析解）は流路設計の標準式として PCR・細胞培養・タンパク質結晶化などのバイオデバイスに不可欠です。流路を細くするほど ΔP が R⁴ で激増するため、ポンプ圧力と流路寸法のトレードオフが設計の中心課題になります。

地下水・多孔質媒体の浸透：多孔質媒体中の流れを記述するダルシーの法則 q = -(k/μ)∇P は、孔径分布をハーゲン・ポアズイユ式で平均することで導出されます（Kozeny-Carman 式の出発点）。地下水流動解析、油・天然ガス貯留層シミュレーション、土壌中の汚染物質拡散、CO₂地中貯留などはすべて本質的にハーゲン・ポアズイユ流れの集合体として扱われています。

潤滑・トライボロジー：軸受や歯車のすき間を流れる潤滑油の挙動も、薄い隙間内の層流としてハーゲン・ポアズイユ式と同じ枠組みで扱われます（クエット流れ＋ポアズイユ流れの重ね合わせ）。レイノルズ方程式の出発点であり、油膜厚さ・粘度・回転速度から摩擦損失と発熱量を見積もる際に基本となります。

よくある誤解と注意点

最も多い誤解は、「圧力を上げれば流量はどこまでも増える」と直感的に考えてしまうことです。ハーゲン・ポアズイユ式を見ると Q ∝ ΔP に見えますが、これは「層流域に留まっている限り」の話です。圧力を上げて Re が2300を超えると流れは乱流に遷移し、Q ∝ √ΔP のように圧力を倍にしても流量は約1.4倍にしか増えなくなります。シミュレーターで ΔP を増やしていき statRe が2300を超えた瞬間からは、表示している Q の値は層流式による「もし層流が維持されたら」の理論値で、実際の流量はもっと少なくなる点に注意してください。

次に多いのが、「半径と直径」「平均と最大」を取り違えることです。ハーゲン・ポアズイユ式に出てくる R は半径であり、直径 D ではありません。直径表記の式 Q = πD⁴ΔP/(128μL) と混同すると16倍の差が出ます。同様に Re = ρVD/μ は直径ベース、平均流速 V_avg は最大流速 V_max の半分、と細かい定義の違いを必ず確認してください。本ツールでは半径 R 入力・平均流速 V_avg・直径ベース Re で統一しています。

最後に、「水だから粘性は気にしなくていい」という思い込みです。水の粘性は確かに 1.0 mPa·s（20°C）と小さいですが、温度や添加物で大きく変わります。グリセリンは1500 mPa·s（水の1500倍）、エンジンオイルは100〜500 mPa·s 程度です。ハーゲン・ポアズイユ式では μ の逆数で流量が決まるため、粘性が10倍違えば流量も1/10になります。スライダーで μ を 0.0010（水）から 0.01、0.1（油）と上げてみると、流量がどれだけ激減するか体感できます。CAE 解析で粘性係数の入力ミスは結果を大きく狂わせる典型的な原因です。

使い方ガイド

  1. 管半径スライダー(slR)を0.5～10mmの範囲で調整し、円管の断面積を変更します
  2. 圧力差スライダー(slDP)を0.1～100kPaで設定し、駆動力となる圧力勾配を入力します
  3. 流体粘性係数スライダー(slMu)を0.0005～0.10Pa·sで変更し、水(0.001Pa·s)から油(0.1Pa·s)までの流体を選択します
  4. 管長スライダー(slL)で0.1～50mを指定するとReynolds数計算に反映されます
  5. リアルタイムで体積流量Q、平均流速、最大流速(中心部)、Reynolds数が更新される様子を観察します

具体的な計算例

管半径r=2mm、管長L=10m、圧力差ΔP=10kPa、粘性係数μ=0.001Pa·s(水)の条件では、ハーゲン・ポアズイユ式Q=πΔPr⁴/(8μL)により体積流量は約6.28mL/sになります。平均流速Vavg=ΔPr²/(8μL)≈0.5m/s、中心最大流速Vmax=2Vavg≈1.0m/sです。Reynolds数Re=ρVavgD/μ≈2000(密度1000kg/m³)となり、層流領域(Re<2300)の上限近傍であるため、ΔPを上げて乱流域に入る前の挙動を確認できます。

実務での注意点

  • 医療用カテーテル(内径1～3mm)やマイクロ流体デバイスではReynolds数100以下の深い層流域で動作するため、粘性支配的な計算が必須です
  • 油圧システムの配管(半径5mm以上)では粘温特性の変化により粘性係数が±20%変動するため、複数条件でのシミュレーション比較が推奨されます
  • 圧力差が100kPa以上では非ニュートン流体挙動が顕在化することがあり、標準的なハーゲン・ポアズイユ式の適用限界を超える場合があります
  • 管壁粗度(工業用鋼管Ra=0.05mm)は層流では無視できますが、遷移領域では補正が必要になります
