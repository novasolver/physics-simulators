# 残留応力・溶接変形シミュレーター

残留応力と溶接変形をオンラインで無料シミュレーション。熱入力や板厚などの条件を変更し、角変形や横収縮、HAZ温度サイクルをリアルタイムに計算・可視化できます。溶接設計の事前検討に最適なツールです。

**Category:** 構造解析

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/residual-stress.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/residual-stress.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/residual-stress
python -m http.server 8000
# open http://localhost:8000
```
