# 伝送線路・インピーダンス整合計算機

伝送線路インピーダンス整合計算機で特性インピーダンス・反射係数・VSWR・入力インピーダンスを計算。定在波パターンをグラフ表示、高周波回路設計に対応。

**Category:** 電磁気・光学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/transmission-line.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/transmission-line.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/transmission-line.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/transmission-line
python -m http.server 8000
# open http://localhost:8000
```
