# 吸収塔設計・NTU・HTU法

NovaSolverの無料オンライン吸収塔設計計算機。NTU/HTU法による充填塔・トレイ塔の設計計算を簡単操作で実現。吸収率や塔高をリアルタイム算出し、平衡線と操作線を視覚的に確認できます。化学工学プロセスの効率的な設計をサポートします。

**Category:** 化学工学

git clone https://github.com/novasolver/physics-simulators

python -m http.server 8000
