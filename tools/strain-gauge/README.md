# ひずみゲージ・ブリッジ計算ツール

ひずみゲージ・ブリッジ計算ツール|ゲージ率・供給電圧・ブリッジ構成から出力電圧と感度を即座に計算。4種ブリッジの温度補償効果を比較。

**Category:** 実験計測・構造解析

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/strain-gauge.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/strain-gauge.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/strain-gauge.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/strain-gauge
python -m http.server 8000
# open http://localhost:8000
```
