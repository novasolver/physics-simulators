# 遊星歯車列計算ツール

遊星歯車列の速度比・トルク比・効率をウィリス方程式で即座に計算。歯数変更でアニメーション図がリアルタイム更新される設計支援ツール。

**Category:** 機械設計・歯車工学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/gear-epicyclic.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/gear-epicyclic.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/gear-epicyclic.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/gear-epicyclic
python -m http.server 8000
# open http://localhost:8000
```
