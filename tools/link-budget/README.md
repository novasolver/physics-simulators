# 無線リンクバジェット計算機（フリスの公式）

フリスの公式を用いた無線リンクバジェット計算機。受信電力・SNR・リンクマージンをリアルタイム計算。変調方式比較・雨減衰・大気吸収損失に対応。

**Category:** 電磁気・光学

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/link-budget.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/link-budget.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/link-budget.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/link-budget
python -m http.server 8000
# open http://localhost:8000
```
