# 圧縮機のポリトロープ効率と吐出温度シミュレーター

圧縮機のポリトロープ効率と吐出温度シミュレーター。圧力比・入口温度・比熱比から出口温度と必要動力を概算。ポリトロープ効率、圧縮機設計に対応。

**Category:** 対話型シミュレーター
