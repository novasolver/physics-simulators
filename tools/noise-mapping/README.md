# 騒音マップ作成・ISO 9613-2準拠

ISO 9613-2準拠の無料騒音マップ作成シミュレーターです。複数の音源を考慮し、幾何減衰や大気吸収、地面減衰、遮音壁の効果をリアルタイムで計算。2D等音線マップを簡単作成でき、Lden算定やEU騒音規制への適合比較にも対応。環境アセスメントや工場・建設現場の騒音予測に最適なオンラインツールです。

**Category:** 振動・波動
