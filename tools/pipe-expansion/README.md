# 配管熱膨張・応力解析ツール

配管材料・温度・長さ・端末条件を変えて、熱膨張量ΔL・熱応力σ・アンカー力Fをリアルタイム計算。ASME B31.3許容応力範囲SAとの比較も即座に確認。

**Category:** 構造解析

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/pipe-expansion.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/pipe-expansion.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/pipe-expansion.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/pipe-expansion
python -m http.server 8000
# open http://localhost:8000
```
