# 生体力学・骨応力解析シミュレーター

生体力学シミュレーター「NovaSolver」は、大腿骨・脛骨・椎体への応力解析を可能にするCAEツールです。体重や動作を設定するだけで、骨の圧縮応力・曲げ応力の分布を可視化し、骨折リスクや疲労寿命を評価できます。骨強度との比較により、医療・研究・教育を支援します。

**Category:** バイオメカニクス

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/biomedical-stress
python -m http.server 8000
# open http://localhost:8000
```
