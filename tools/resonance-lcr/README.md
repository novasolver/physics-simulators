# LCR共振回路シミュレーター

LCR共振回路シミュレーター：直列・並列回路のインピーダンス・位相特性をリアルタイム可視化。共振周波数とQ値を高速計算する電気設計ツール。

**Category:** 電磁気・回路

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/resonance-lcr.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/resonance-lcr.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/resonance-lcr.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/resonance-lcr
python -m http.server 8000
# open http://localhost:8000
```
