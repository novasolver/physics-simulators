理論・主要公式

$$f_0 = \frac{1}{2\pi\sqrt{LC}}$$

共振周波数 [Hz]：L インダクタンス [H]、C キャパシタンス [F]。

$$Q = \frac{\sqrt{L/C}}{R}$$

Q値（直列共振）：R が小さいほど鋭い共振。

$$BW = \frac{f_0}{Q}$$

帯域幅 [Hz]：-3dB幅。Q値が大きいほど狭い。

LCR共振回路とは

🙋
LCR共振回路って何ですか？コイル(L)とコンデンサ(C)と抵抗(R)を繋いだだけの回路が、どうして特別な「共振」を起こすんですか？
🎓
大まかに言うと、コイルとコンデンサのエネルギーやり取りがよく釣り合う特別な周波数で起こる現象だよ。コイルは電流の変化を嫌い（エネルギーを磁界として蓄える）、コンデンサは電圧の変化を嫌う（エネルギーを電界として蓄える）。交流の周波数を変えていくと、この二つの「嫌がり方」がちょうど打ち消し合うポイントが現れるんだ。それが共振周波数だね。シミュレーターの「回路タイプ」を「直列」にした状態で、周波数スライダーを動かしてみて。インピーダンス（交流での抵抗みたいなもの）が一番小さくなるポイントがあるでしょう？
🙋
え、そうなんですか！確かに一番低いところがあります。この尖り具合は回路によって違うみたいですが、これは何で決まるんですか？
🎓
その尖り具合、つまり共振の鋭さを決めるのが「Q値（クオリティファクタ）」だ。実務では「選択度」とも呼ばれるね。式は直列回路だと $Q = \frac{1}{R}\sqrt{\frac{L}{C}}$ で、抵抗Rが小さいほど、またL/Cの比が大きいほどQ値は高くなって、グラフが鋭く尖るんだ。シミュレーターでRのスライダーを大きくしてみて。どう？山がだんだん緩やかになるでしょう？これがQ値が下がって帯域幅が広がる様子だよ。
🙋
並列にすると、共振点でインピーダンスが最大になるんですね！これはどう使い分けるんですか？例えばラジオのチューニングはどっちを使うんですか？
🎓
良いところに気づいたね！直列共振はインピーダンス最小（電流最大）、並列共振はインピーダンス最大（電圧最大）になる。ラジオの同調回路では、アンテナから来る微弱な信号電圧を大きく取り出したいから、並列共振が使われることが多いんだ。シミュレーターで「回路タイプ」を切り替えながら、LやCの値を変えて共振周波数を移動させてみよう。これが「選局」の基本動作だ。現場では、この特性を使って特定の周波数だけを通したり、遮断したりするフィルタを設計するんだ。

よくある質問

共振周波数 f₀ は、インダクタンス L とキャパシタンス C から f₀ = 1 / (2π√(LC)) で計算されます。シミュレーター上でLとCの値を変更すると、グラフ上の共振点と数値がリアルタイムに更新されるので、すぐに確認できます。
直列回路では共振時にインピーダンスが最小（Rのみ）になり、位相が0°に近づきます。並列回路では共振時にインピーダンスが最大（Rに依存）になり、位相も0°に近づきます。シミュレーターで切り替えてグラフの変化を比較してみてください。
Q値は共振の鋭さを表し、値が高いほど周波数選択性が高くなります。直列回路では Q = (1/R)√(L/C)、並列回路では Q = R√(C/L) で計算され、RやL、Cの値を変えることで調整できます。
帯域幅は共振点の両側でインピーダンスが共振時の√2倍（または電力が半分）になる周波数幅です。シミュレーターのグラフ上で、共振周波数とQ値から自動計算された数値が表示されるので、フィルタ設計などの目安として活用できます。

実世界での応用

無線通信（同調回路・フィルタ）：AM/FMラジオやテレビ、スマートフォンの無線部では、並列LCR共振回路が特定の周波数帯域の信号のみを選択的に取り出す「同調回路」として使われています。不要な周波数成分を除去するバンドパスフィルタやノッチフィルタの基本構成要素でもあります。

電力系統（力率改善・高調波フィルタ）：工場などの誘導性負荷（モータ等）では力率が悪化します。これに並列にコンデンサを追加し、系統をLCR共振回路と見なして力率を100%に近づける「力率改善」が行われます。また、特定の高調波成分を吸収するフィルタとしても設計されます。

センサー・計測：金属探知機や非接触の位置・変位センサーは、コイルのインダクタンスLが対象物の接近で変化することを利用します。このLの変化が共振周波数 $f_0$ をシフトさせるため、周波数の変化として高精度に検出できます。

電子機器（発振回路・インピーダンス整合）：水晶発振子は非常に高いQ値を持つLCR共振系とみなせ、正確な基準周波数を生成します。また、高周波（RF）回路では、アンテナと送信機の間で最大電力が伝送されるよう、LCR回路を用いたインピーダンス整合ネットワークが必須です。

よくある誤解と注意点

このシミュレーターを使いこなす上で、特に初心者の方が陥りがちな落とし穴をいくつか挙げておくよ。まず一つ目は「リアルな部品には理想値がない」ということ。シミュレーター上のコイル(L)は純粋なインダクタンスだけど、実際のコイルには巻線抵抗が必ず存在する。例えば100μHのコイルでも、数オームから数十オームの直流抵抗(ESR)を持っているんだ。これは直列共振回路ではそのまま抵抗Rとして効いてきて、計算通りの高いQ値が得られない原因になる。並列回路では、この抵抗が並列に寄生する形になるから、これも考慮が必要だ。

二つ目は「共振周波数の計算は単純だが、実際の共振点はズレる」という点。理論式 $f_0 = \frac{1}{2\pi\sqrt{LC}}$ はあくまで理想的な式。実際には、コイルの自己容量やコンデンサの残留インダクタンスといった「寄生要素」が無視できない。特に高周波になるほどこの影響は大きくなる。シミュレーターで「L=10μH, C=100pF」と設定すると約5.03MHzと計算されるが、実測では4.8MHzくらいになることも珍しくない。設計には必ずマージンを持たせよう。

三つ目は、直列と並列の「Q値の式」を混同しないこと。直列共振のQ値は $Q = \frac{1}{R}\sqrt{\frac{L}{C}}$ で、Rが小さいほどQが上がる。一方、 並列共振回路のQ値は $Q = R\sqrt{\frac{C}{L}}$ と、抵抗Rが大きいほど高いQ値になるんだ。この逆転現象を理解しておかないと、回路を組んで「あれ？思ったより鋭く共振しないな」ということになるから注意してね。

使い方ガイド

  1. 抵抗値(R)、インダクタンス(L)、キャパシタンス(C)の素子値を入力フォームに記入。例：R=50Ω、L=100μH、C=10nFの直列RLC回路を想定
  2. 回路構成を直列または並列で選択し、シミュレーション実行ボタンをクリック
  3. インピーダンス特性曲線、位相角、共振周波数、Q値がリアルタイム表示される。周波数スイープ範囲(例：1kHz～1MHz)を調整して詳細解析が可能

具体的な計算例

直列LCR回路でR=100Ω、L=47μH、C=100pFとした場合、共振周波数f₀=√(1/LC)/(2π)≈2.32MHzが計算される。このときQ値=ωL/R=2π×2.32×10⁶×47×10⁻⁶/100≈6.88となり、バンド幅BW=f₀/Q≈337kHzで帯域幅が決定。インピーダンスは共振点で最小値Zmin=100Ω(抵抗のみ)となる

実務での注意点

  1. RF回路設計で同調増幅器を設計する際、PCB配線のパラシティックインダクタンス(数nH)が共振周波数を低域シフトさせるため、シミュレーション値に5～10%の余裕を見込む
  2. 並列共振回路はインピーダンス最大値がR×Q²となり、直列回路と異なるピークインピーダンス特性を示すため、用途に応じた選択が必須
  3. 高Q値(>100)の回路は周波数安定性が向上する一方、温度変化によるコンデンサ容量変動±5ppm/℃の影響を受けやすく、信頼性設計では温度係数補償が必要
