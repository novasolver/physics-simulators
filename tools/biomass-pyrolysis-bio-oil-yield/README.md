# バイオマス熱分解 bio-oil 収率シミュレーター

木質や農産廃棄物・藻類などのバイオマスを 450〜550°C で無酸素加熱する「Fast Pyrolysis(高速熱分解)」のプロセス設計ツール。原料・温度・昇温速度・滞留時間・反応器形式を変えると、bio-oil・チャー・ガスの収率と質量収支、エネルギー効率、CO₂ 削減量がリアルタイムに分かります。

**Category:** バイオマス・熱化学変換
