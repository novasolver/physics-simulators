# マリュスの法則 シミュレーター — 3 偏光板パラドックス

マリュスの法則 I = I0 cos²θ を用いて、3 枚の偏光板（基準 P1=0°、中間 P2=θa、最終 P3=θb）の縦列構成から各段の透過強度・全透過率・中間板による寄与を実時間に計算します。直交ペアに第 3 板を挿入すると光が透過する「3 偏光板パラドックス」を定量的に可視化します。

**Category:** 光学シミュレーター
