# ポンプ運転点計算ツール

ポンプのH-Q曲線とシステム曲線（静揚程＋摩擦損失）の交点をリアルタイム表示。1台・並列・直列の3モードで運転点・効率・軸動力を即時算出。

**Category:** 流体機械

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/fluid-pump-system.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/fluid-pump-system.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/fluid-pump-system.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/fluid-pump-system
python -m http.server 8000
# open http://localhost:8000
```
