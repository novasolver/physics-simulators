# U字管マノメータ シミュレーター — 差圧測定

配管内2点間の差圧を、U字管に入れた重い液柱（水銀など）の高さ差から計算します。マノメータ流体密度・配管流体密度・標高差を変えて、静水力学的バランスによる差圧測定の原理を学べます。

**Category:** 流体計測シミュレーター
