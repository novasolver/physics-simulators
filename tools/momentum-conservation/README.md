# 運動量保存則・衝突シミュレーター

運動量保存則・衝突シミュレーターで1D・2D衝突をリアルタイム可視化。弾性・非弾性衝突の運動量保存とエネルギー変化を数値確認できるCAEツール。

**Category:** 物理シミュレーター

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/momentum-conservation.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/momentum-conservation.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/momentum-conservation.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/momentum-conservation
python -m http.server 8000
# open http://localhost:8000
```
