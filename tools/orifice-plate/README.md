# オリフィス流量計 設計計算ツール

ISO 5167準拠。配管径・ベータ比・差圧・流体種別を入力するだけで、流量係数Cd・体積/質量流量・レイノルズ数をリアルタイム算出。Q–ΔP曲線とCd収束グラフも可視化します。

**Category:** 流体計測
