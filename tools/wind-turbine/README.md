# 風力発電シミュレーター（ベッツ限界・パワーカーブ）

風力発電の理論と実務を学べる無料シミュレーター。ベッツ限界やパワーカーブ、Cp-TSR特性を視覚的に理解し、翼素運動量理論（BEM）に基づくタービン効率や年間発電量をリアルタイム計算できます。風況解析も可能なCAEツールで、再生可能エネルギー学習や設備計画の基礎を体験しましょう。

**Category:** 再生可能エネルギー
