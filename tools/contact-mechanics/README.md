# ヘルツ接触力学シミュレーター

ヘルツ接触力学シミュレーターは、球や円筒の接触問題を簡単に解くオンラインツールです。接触半径、最大接触圧力、沈込み量を即座に計算。表面下の応力分布も可視化でき、機械設計や強度解析に役立ちます。NovaSolverで高精度な接触応力解析を始めましょう。

**Category:** 接触力学
