# 確率分布シミュレーター

NovaSolverの確率分布シミュレーターは、正規分布・ポアソン分布・二項分布など9種類の確率分布をリアルタイムで可視化。PDFやCDFの表示、モンテカルロサンプリング機能で、統計学や確率論の理解を直感的に深められます。学習やデータ分析に最適なツールです。

**Category:** 統計・確率論

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/probability-distributions.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/probability-distributions.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/probability-distributions.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/probability-distributions
python -m http.server 8000
# open http://localhost:8000
```
