# ナイキスト線図・安定余裕シミュレーター

ナイキスト線図シミュレーターで開ループ伝達関数のゲイン調整から安定余裕・位相余裕を自動計算。制御系の安定性解析に必要なボード線図も同時描画。

**Category:** 解析ツール

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/nyquist-criterion.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/nyquist-criterion.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/nyquist-criterion.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/nyquist-criterion
python -m http.server 8000
# open http://localhost:8000
```
