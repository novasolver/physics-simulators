# 放射ネットワークシミュレーター — 表面抵抗と空間抵抗

放射ネットワークシミュレーターで表面抵抗と空間抵抗を可視化。灰色表面間の放射熱伝達を電気回路モデルで解析し、放射率と温度の影響を学習できます。

**Category:** 伝熱シミュレーター

## Live demos

- 🇯🇵 [日本語](https://novasolver.jp/tools/radiation-network.html)
- 🇺🇸 [English](https://novasolver.jp/en/tools/radiation-network.html)
- 🇨🇳 [中文](https://novasolver.jp/zh/tools/radiation-network.html)

## Run locally

```bash
git clone https://github.com/novasolver/physics-simulators
cd physics-simulators/tools/radiation-network
python -m http.server 8000
# open http://localhost:8000
```
